# 天空回廊ボス強化(2026-10-05)

「空そのものがボスの攻撃になる災害戦」。荒野街道/自然洞窟と同じ「ボス戦の強化」の共通基盤をそのまま使い、天空専用の基盤は作っていない。

## 共通基盤(再利用したもの)
| 仕組み | 場所 |
|---|---|
| 段階 / 特殊攻撃 / 必殺技 / 崩し(BREAK) / スーパーアーマー / 必殺技後の大きな隙 | `WildBossBase`(tune = `BossBattleTuning` の種類ごとの値) |
| 地形・予兆の攻撃(床/天井/帯/落石/柱/波/予兆)、プール | `Bosses/HazardBossBase.cs`(洞窟の `CaveBossBase` から共通部分を抜き出した)、`Bosses/CaveHazard.cs` |
| 床と天井が同時に来ない間隔、穴の確認、必殺技中は平らな地形・雑魚を止める | `Bosses/CaveBossSafety.cs`(天空は必殺技の間だけ) |
| ラン再開 / 次のボスの保留(1つだけ) / 再戦の抽選と距離の強化 | `BossManager`(`resumeStages` / `BattleTunedStages` に sky_corridor を追加) |
| 開発用の強制操作 | `Bosses/IBossBattleDebug.cs`(WildBossBase / DragonController / MajinController が実装) |

洞窟で作った `CaveBossBase` は `HazardBossBase` を継ぐだけになり、天空の `SkyBossBase` も `HazardBossBase` を継ぐ。

- 10km 以降の専用ボスの必殺技は判断を 3 回以上(1 回のジャンプでは避けきれない)。どれも避けられる(床と天井が同時に来ない・穴を作らない)。
- フェニックスの死に際の復活(HP 30〜50%)は `BossBattleTuning` の `phoenixRebirthOnFirst` / `phoenixRebirthRematchChance` / `phoenixRebirthHp`。
- 100km の死神(三女)は変更なし・再戦プールに入らない。
- 再戦の段階(Upgraded)で必殺技に一手増える(例: ベヒモスの落雷 3→5 本)、段階が 1 つ増える。80km で 1km の再戦ボスが出ても弱くならない。
- 魔人: 「遠くを漂って撃つ」だけだったので、第 1 段階から **近接の爪**(急接近 → 低い薙ぎ払い=跳ぶ → その場に 1.4 秒とどまる)を追加(7 秒ごと)。近接キャラの攻撃が届く時間になる。

## 安全
- 予兆は画面外の攻撃も必ず出す(影/光/雷/雲/風/シルエット/警告の帯/音)。
- 落雷/光柱(SkyStrike)は自動走行と一緒に流れる(画面の同じ位置に留まる)。避け方は前後の攻撃の踏み込みで位置をずらす。
- 必殺技の間は平らな地形・新しい雑魚なし・雑魚の攻撃を遅く(`CaveBossSafety`)。ラン再開の後も「避けられない穴+画面全体の攻撃+強い雑魚」が重ならない。
- 空を飛ぶボスは攻撃の届く高さへ必ず戻ってくる(崩し/必殺技後の隙は地面近く)。大きなボスは崩しで吹き飛ばさず、頭/コア/翼の姿勢で見せる。

## マルチプレイ
HOST が乱数を決める。地形の攻撃(CaveHazard)・落雷(SkyStrike)・弾・ボス本体の位置/段階/崩し/必殺技の開始・表示(バナー)は既存の同期(NetAttackSync / NetCombat)で JOIN に届く。2 プロセスの自動テスト(sky:Behemoth、必殺技 4 回)で例外 0、JOIN に SkyStrike / TrackedHazard / BossProjectile が届くことを確認。

## 開発用
- DEBUG → 「洞窟/天空ボス試験…」(DebugPanel page 6): 自然洞窟 / 天空回廊の切り替え、ボスを選んで出す(DEBUG RUN・保存なし)、初登場/再戦の段階(80〜90km 相当まで)、段階 1/2/3・必殺技・BREAK・ラン再開を強制。
- 自動テスト: `-qaSkyBoss <dir> [-qaSkyOnly Dragon,Majin...|none] [-qaSkyCases JKLMNO]`
- マルチ: `NetAutoTest -netAutoBossKind sky:<SkyBossKind>`

## 確認(Windows 開発ビルド)
- `-qaSkyBoss`: 11 体それぞれ A 出現 / B 通常攻撃 / C 段階 / D 必殺技 / E 避けられる(判断の回数・床と天井が重ならない) / F 必殺技後の隙 / G 崩し / H 攻撃の届く位置 / I ラン再開、全体 J 雑魚との混在 / K 再戦の抽選 / L 高距離の再戦 / M,N 高速(300km/h)・低速(30km/h) / O,P 次の関門の保留 / T プール、例外 0。
- 必殺技の判断の回数(初登場): 魔人 7、ベヒモス(再戦の最上段)6、クラゲ 4、フェンリル 4、ゴーレム 5、フェニックス 4、大蛇 3、守護者 4。

## 既知の制限 / Android 未確認
- 胴の横断(リヴァイアサン/大蛇)の当たりは汎用の光球/輪の見た目で、ボス本体の絵ではない。
- SkyStrike はプールしていない(1 回の必殺技で 3〜5 本、Android の負荷は未確認)。CaveHazard はプール済み。
- 暗転は HOST の画面だけ。
- 自動操作補助は SkyStrike の柱を避ける判断に入れていない(地形攻撃/弾/本体は対象)。
- Android 実機: 必殺技中の FPS、暗転と雲の重なりの見やすさ、プレイヤーの視認性、画面外予兆の見え方、大型ボスの縮尺は未確認。
