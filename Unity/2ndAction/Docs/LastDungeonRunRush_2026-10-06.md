# ラスダン 90〜99km: 走りながらのボスラッシュ(2026-10-06)

`LastDungeonBossTuning.continuousRush`(既定 true)。false で旧方式(関門ごとに距離を止めて倒す)へ戻せる(比較/切り戻し用)。
コードは `BossManager.LastDungeon.cs` の「走りながらのボスラッシュ」の節。

## 流れ
```
90km  BOSS RUSH 開始(距離は止めない = 既存の「ラン再開」と同じ状態)。ボスA(予告 1.2秒 → 出現)
91km  A が生きていれば B を追加 … 1,000m ごとに1体(98km が最後の増援)
      同時は最大3体 + タグ(大型/空中/範囲攻撃/飛び道具/追跡)の上限。超える分は待機キューで待つ(消さない)
      1体倒す → 空き → 待機中のボスが予告の後に出る
99km  ボスが残っていれば(待機中も含む)ここだけ距離を止める → 全員倒す → 報酬 → 走行再開 → 静寂
      残っていなければそのまま静寂(99〜100km はボス/雑魚なし)→ 100km 三姉妹
```
- 遭遇(`BossEncounter`)は 90〜99km 全体で1つ(`continuous`)。持っているもの: 出ているボス / 待機キュー(`waiting` + 予告中 `telegraphing`)/ 予約済みの節目(`milestonesReserved`, `nextK`)/ 残り(`Remaining` = 予定の全員 − 撃破)/ 最後の増援済み(`lastReinforcementDone`)/ 99km の足止め(`held99`)。
- 節目の予約は「今の距離 ≥ 次の節目」の間ループするので、高速/ワープで 1,000m を何度跨いでも順番に全部予約する(取りこぼさない)。
- ボスの選び方: 90〜98km の既存の表(`rushGates`)から、各 km の組を抽選し、まだこのラッシュで使っていないボスを1体(NoRush=竜/魔人は除外)。足りなければ 10,000m 格のプールから。HOST/シングルが決める。
- 強さ: その節目の距離の強さ(再戦と同じ式)× ラスダンの倍率 × `runRushHpMulPerBoss`(0.6。旧方式は1関門に2〜5体で 0.3)。**仮の値**: 実機でビルドの差がどう出るかを見て調整。
- 雑魚なし(既存: EncounterDirector の抑止 + 見つけた雑魚の片付け)。穴の確率を 0.12 → 0.06(`runRushPitChance`)。大型の障害物は既存どおりなし。
- 予告: 画面中央の警告「WARNING ○○ が迫る!」+ 警告SE、1.2秒後に出現(ゲームは止めない)。出現は最低2秒あける(同じフレームに複数作らない)。
- 報酬: 遭遇の終わり(9体すべて撃破)に1回(旧方式は関門ごとに9回)。CONTINUE の保存点も同じ(途中でやめると 89km 台の保存点から)。
- 99km の足止め: `ClampMaxDistanceTo(99,000)` + 距離の除外を開始(報酬の後で除外を折りたたむ)。静寂(`LastDungeonFlow`)は「99km 以上かつボス戦でない」で始まる(従来どおり)。

## 追従
既存のボスの追従(走るプレイヤーに付いてくる仕組み)のまま。自動テスト(実速度で 9km)の結果は下の表(プレイヤーとの距離 −4〜34m、画面外は 0.1〜0.3秒、置き去り/先へ行きすぎ/落下 なし)。

## 処理落ち
- ボスの生成そのものは 1体 3〜7ms(`BossManager.LastBossSpawnMs` で計測)。
- 出現の瞬間の処理落ちの主因は、警告バナーの日本語の文字の初めての焼き込み(ポップで文字の大きさが毎フレーム変わる)→ ラスダンの開始時に先に焼き込む(`BossBattle.WarmBannerGlyphs`)。
- 次の節目の 200m 手前で、出現時に読む効果の絵を先に読み込む(`PrewarmBossAssets`)。生成自体は軽いので、非表示の先行生成/Object Pool は入れていない(規模に見合わない)。

## 開発用
- LAST DUNGEON 90km: 89,900m から(90km で開始)。
- LAST DUNGEON 99km: 98,600m から、97/98km のボスが予約済みの状態で開始(99km の足止め → 全滅 → 静寂を確認)。
- NEXT BOSS: 出ているボスを倒して次の増援へ(待機中があればそれが出る/無ければ次の節目を今すぐ予約)。距離はワープしない。
- ENDING FLOW: 従来どおり(98,950m から。ボスなしで静寂へ)。
- 自動テスト: `-ldQa <dir> -ldQaMode runrush`(A〜L + 追従 + 旧方式の FPS)、`-ldRushPerfOnly old|new`(新しいプロセスで 89.9→93km の FPS を比べる)。旧方式は `-ldQaMode bosses`(このモードの間だけ continuousRush=false)。

## マルチ
判定は HOST/シングルだけ(`NetCombat.Replica` では何もしない。関門の距離は最前のプレイヤー基準 `GateDistance`)。ボスの出現は既存の共有ボスの経路。マルチでの 99km の足止め/全滅待ちの通し確認は未実施。

## 結果
Windows 自動テスト(`-ldQaMode runrush`、実速度で 90→100km):
- A 90km で距離が止まらずボスA(予告の後)/ B 91km で B を追加 / C 3体の時の 93km は待機 / D 1体倒すと待機が出る / E 93.4→95.05km を一気に跨いで 94・95km の2体を順番に予約 /
  F 98km が最後(9体予約、99km 以降なし)/ H 99km にボスが残る → 99,000m で停止 → 全員倒す → 静寂・走行再開 / I 99〜100km ボス/雑魚 0 / J 100km で三姉妹戦 / G 99km にボス0 → 停止なしで静寂 / L 0〜89km の関門は従来どおり停止: すべて合格、例外 0。
- 同時の上限/タグの規則の違反 0 フレーム、画面内の雑魚 0。
- 追従(9体、ボスごと): プレイヤーとの距離 −4〜34m、画面外 0.1〜0.3秒、置き去り(25m以上後ろに3秒)/先へ行きすぎ(40m以上前に3秒)/落下 なし。
- 走りながら当てられる時間の割合(ボスラッシュに入る30体、各12秒): 最低 29%(Leviathan)、Worm 36%(修正後)、ほとんどは 80〜98%。
- **Worm の修正**: 特殊攻撃/必殺技(どちらも地中/画面の先から)の後は必ず1回地上へ出る攻撃を挟む。強い再戦の段階(特殊攻撃の間隔 3.5秒)× ラスダンの頻度で、ずっと地中=無敵のままになり倒せなかった(通しの試験で 99km の足止めが終わらなかった)。洞窟の後半の関門でも同じことが起き得た。
