# COMBO 第1段階(2026-10-06)

特定のカード(能力)をそのランで一緒に持つと、それぞれ単体では起きない「新しい現象」が起きる。カードは消費しない/合体しない。

| 層 | 役割 |
|---|---|
| 通常カード | 基礎のビルド(Lv1〜9) |
| **COMBO** | 複数カードの相乗効果(新しい現象) |
| FINAL EVOLUTION | Lv9 カードの一時的な限界突破 |
| AWAKENED | 長期育成の完成の証(見た目の特典) |
| ULTIMATE | キャラクター固有の必殺技 |

## 仕組み
- 定義: `Cards/ComboTuning.cs`(`Resources/Cards/ComboTuning` を作ればインスペクターで調整。無ければコードの既定値)。
  `Combo` = id / 表示名 / 説明 / 必要な能力(第1段階は2つ、将来3つ以上も可)/ 追加の条件(どれか1つ、将来用)/ モジュール / 値(power, radius, cooldown, procChance, count)/
  強さの Lv の混ぜ方(minWeight, lv1Factor)/ 発生してよい攻撃(通常/カード/最終進化。COMBO 由来からは常に出ない)/ ENHANCED の値 / リスク / 有効 / 色 / 仮アイコンの文字。
- 成立: `Cards/ComboSystem.cs`。今のランの能力Lv(`GetAbilityRunStack` = キャラカード/取得/合成を能力ごとに合算、Lv9上限)から毎回計算する。
  Lv は要らない(Lv1+Lv1 で成立)。同じ能力を2回数えない(同じカードを重ねても成立しない)。#100 ULTIMATE は構成に使わない。カードは失われないので、ラン中は基本的に解除されない(能力が本当に無くなった時だけ外れる)。
- 強さ: 構成カードの平均Lv と最低Lv を `minWeight`(0.5)で混ぜた Lv → Lv1 で `lv1Factor`(0.45)、Lv9 で 1。Lv9+Lv1 は Lv3 相当(完成の強さにならない)。
- 効果: `Cards/CardProcs.Combo.cs`。15 のモジュール(現象)。ダメージは追加攻撃の基準ダメージ(ProcBase、攻撃の枠の一部を反映)× power × 強さ。
  既存の proc の予算(0.5秒の窓)/演出の予算/間隔/同じ敵へのクールダウン/範囲と数の上限を使う。
- 再帰の防止: すべての発生に発生源(`ProcSource`: 通常/カード/COMBO/最終進化/ULTIMATE)。COMBO の実行中は深さ(`comboDepth`)が上がり、その間の命中/撃破/属性の事件からは COMBO を出さない。
  COMBO のダメージは `DealQuiet`(命中の処理を通らない)ので、追加攻撃/属性の判定も起きない。COMBO の炎上(`ElementStatus.ComboBurned`)で倒れた敵からは WILDFIRE を出さない。
- FINAL EVOLUTION: 構成カードのどれかが ACTIVE の間だけ **ENHANCED**(範囲/強さ/追加が少し上がる)。両方 ACTIVE でも1段階だけ。FE の倍率は掛けない。終われば通常へ戻る。
- AWAKENED: 通知の金の飾り/HUD のアイコンの★/少し金色の演出だけ(能力値は変えない)。
- 通知: 初めて成立した時に画面中央へ「COMBO! 名前」+構成カード(約1秒、ゲームは止めない)+ 短い光 + SE。
- HUD: RUN BUILD HUD のカード一覧の下に COMBO のアイコンの列(仮: 色の丸+2文字)。ENHANCED は橙に脈動、AWAKENED は★。タップで名前/構成カード(Lv)/効果を5秒表示。
  COMBO に使われているカードは左下に小さな緑の点(FE の金の枠/右上の★とは重ならない)。
- CONTINUE: 成立は保存しない(読み込みの時にカードから計算し直す)。保存するのは一時的な数え(空中の命中/風刃の命中/Blood Aegis の数)と、通知を出し終えた COMBO だけ(`RunCheckpoint.Data.combo`)。2回読んでも同じ。
- マルチ: 第1段階は効果なし(`ComboSystem.Enabled`)。必要な同期は `Multiplayer8.md`。
- 開発用: DEBUG → COMBO TEST…(キャラ/ステージ/COMBO/構成カードの Lv/AWAKENED/FE/敵/ボス → 開始 → A を付ける/B を付ける/敵を6体/FE ACTIVE/FE 終了、成立中の COMBO と発生回数を表示。DEBUG RUN = 保存/記録しない)。
- 自動テスト: `QaSweep -qaCombo <dir> [-qaComboOnly BCS]`(B: A〜V / C: 全 COMBO を実際の現象で + FE の ENHANCED + 10回 / S: 負荷)。
