# 疾走出発(試作、2026-10-05)

攻略済みの道中を操作不要の演出で駆け抜け、途中のボス報酬ぶんのカードを自動で取り、選んだ関門の少し手前から通常のランへ戻る。ソロのみ(マルチの部屋に入っている間は出さない)。

## 入口
ホーム → 扉 → ステージ選択 →「出発」の右の「疾走出発…(解放数)」→ 行き先(10,000m 刻み)→ 通常の出発と同じ遷移。
未解放の行き先は理由(「20km の門番が未撃破」「40km に未到達」)を表示して選べない。

## 解放条件(`Sprint/SprintRecords.cs`)
行き先 D(10,000〜90,000m)を選べるのは、そのマップで
1. D に到達したことがある(マップ別 BEST ≥ D)
2. D より手前の 10,000m ごとの門番(10k, 20k, … D−10k)を実際に倒した記録がすべてある(未突破の門番を飛び越えない)

- 撃破の記録は新しく作った(以前は永続の記録が無かった): ソロの通常ランで 10,000m 刻みの関門の遭遇を倒した時(`BossManager.CheckEncounterComplete`)。保存キー `SprintGatesV1`(Progress)。疾走で飛ばした関門・DEBUG RUN・闘技場・マルチは記録しない。
- **以前のセーブは記録が空**なので、門番を倒し直すまで 20km 以上は選べない(10km は到達だけで選べる)。開発版は DEBUG →「疾走出発の行き先: 全解放」。
- 上限 90km: 100,000m の死神/三姉妹、ラスダンの 90km〜(ボスラッシュ/静寂/最終戦)を飛び越える行き先は作らない(90km は「90km の関門の手前」に着くので飛び越えない)。

## 疾走中(`Sprint/SprintRunner.cs`)
- ランは出発地点で止めたまま(`CountdownActive`)、全画面の演出(ステージの絵を流す/走るキャラ/距離/進み具合の帯/取得カード/リング)。通常の敵・ボス戦・障害物・被弾・落下は起きない(実際には移動しない)。
- 所要時間(リングのカード選択を除く、`SprintTuning`、目的地別に上書き可): 10km 11秒 / 20km 18秒 / 30km 25秒 / 40km 32秒 / 50km 39秒 / 60km 46秒 / 70km 53秒 / 80km 60秒 / 90km 67秒(= 4秒 + 7秒/10km)。
- カードの選択中・一時停止中・アプリが裏にある間は進まない(到着が割り込まない)。

## ボス報酬ぶんの自動取得
- 回数 = 飛ばす関門の数 = (目的地 − 250m) / 1,000m の切り捨て(例: 30km → 29 回)。目的地の関門(到着後に戦う)は先渡ししない。
- 1回 = 通常のボス報酬(3枚提示から1枚)の1枚ぶん。候補は通常のボス報酬と同じ「デッキのカードのうち、まだ取れるもの」(`CanStillPick` = Lv9 上限/封印/ULTIMATE の条件)から **ランダムに1枚**。取得は通常の選択と同じ経路(Lv の上限・重複時の成長はそのまま)。
- 候補が尽きた(全部 Lv9 など)回は何も取らない(通常のボス報酬で選択画面が出ないのと同じ)。画面に「取れるカードなし」と出す。代わりの報酬は出さない。
- 取得したカードはアイコン・名前・更新後の Lv(MAX 表示)を画面右に流す。
- 1,000m/5,000m/10,000m の関門で報酬の枚数の差は無い(通常どおり 1 枚)。BONUS ZONE は対象外。

## リング(5,000m ごと、追加のボーナス)
- 通過する 5,000m ごとに 1 つ(目的地の手前まで。30km なら 5 個)。ボス報酬の代わりではなく、くぐれたら追加で 3 択から 1 枚(回復/FINAL EVOLUTION は付けない)。
- 操作: 上下フリック(画面のどこでも)/ 画面右下の ▲▼ / キー(↑↓ W S)で高さ(上/中/下)を合わせる。
- 予告 2.6 秒前から(右端の帯 + 「RING ▲上 / ■中 / ▼下」+ 残り秒)。判定は通過の前後 0.45 秒(合計 0.9 秒)、高さが合っていれば成功。景色の速さとは無関係の実時間。リング同士は最低 3.4 秒空ける(足りない時は全体を遅くする)。
- 成功 → 疾走を止めて 3 択(右上に取得済みのカードと Lv)→ 選んだら再開。逃しても何も減らない。操作しなくても到着する。

## 到着(`GameManager.SprintArrive`)
- 目的地の関門の 250m 手前。中断再開(CONTINUE)と同じ置き方: 距離/次の関門(= 目的地)/安全な足場(到着時の速さで約 2 秒ぶんを平地に)/止まった準備画面 →「準備ができたら再開」→ 3-2-1 → GO。
- 速さは到着の距離の自然な速さ(+取得したカード)。疾走の演出の速さは能力に残らない(演出は画面だけ)。
- このランの再戦プールには飛ばした関門の本来のボスを入れる(通常に走った時と同じ状態。永続の記録ではない)。
- 到着の時点で中断データ(CONTINUE)を 1 回だけ保存(取得したカード込み)。以後の CONTINUE は到着地点から = 自動取得/リングは重ならない。疾走の途中でアプリが終わった時は何も残らない(疾走出発の前の状態)。

## 報酬と記録
| 項目 | 疾走の区間 |
|---|---|
| 持ち帰りの MILE(距離ぶん) | 飛ばした距離を除く(`SprintSkippedMeters`、CONTINUE にも保存) |
| ボス撃破の MILE/EXP | なし(戦っていない) |
| 距離の EXP / レベルアップ / 回復 | なし(距離の EXP は実際に進んだ差分しか数えない仕組み)。到着時は Lv1 のまま、HP は開始時のまま |
| 累計走行距離 | 加算しない(同上) |
| 門番の撃破記録 / 会ったボスの記録 | 付けない |
| マップ別 BEST | 到着後に実際に走って超えた分だけ(行き先は BEST 以下なので、疾走だけでは増えない) |

カードは「ボス報酬ぶんの自動取得 + リングの追加」だけで、レベルアップの 3 択は無い(二重にならない)。同じ距離まで普通に走った時はレベルアップの 3 択も付くので、疾走の方が常に強くはならない想定(実機で調整)。

## 確認(Windows 開発ビルド、`QaSweep -qaSprint`)
A 解放条件 / B 30km(リング全部逃す)→ 30km の門番が正常に出る / C 20km(リング全部くぐる)/ D Lv9 上限(デッキ 2 枚)/ E アプリ中断 / F 通常の出発は疾走しない / G 所要時間。
