# キャラセレクト立ち絵 v2(2026-10-05)

全 12 人の Character Select 中央の立ち絵(`Assets/Art/UI/Characters/<id>_main.png`、700x1100、足元が下端付近)を、性格と戦い方が分かるポーズで描き直した。ゲーム中の走行/攻撃などの画像とは別の参照(`CharacterDefinition.mainVisual` は Character Select だけが使う)。

## 素材
- ChatGPT(画像生成)。各キャラの現在の立ち絵+カード画像を 1 枚に並べた参照を添付し、顔/髪型/衣装/配色/武器/体格を保ったまま、キャラ別のポーズを指示(`ArtSource/CharacterSelectMain_v2/prompts.md`)。背景マゼンタ → `cut.py` で透過(離れた持ち物 = 浮かぶ魔導書なども残す)。
- 忍者(しゃがみが浅い)と吸血鬼(差し出した手/外套がシルエットに出ない)は 1 回描き直した。
- 元の画像と切り抜き: `ArtSource/CharacterSelectMain_v2/raw` / `cut`。**旧立ち絵は `ArtSource/CharacterSelectMain_v1/`**(同じファイル名で `Assets/Art/UI/Characters/` へ戻せば差し戻し)。

## 配置(`place.py`)
- 頭の大きさをそろえる: 頭頂〜足先(武器/翼は含めない)を姿勢の係数(しゃがみ 0.57 / 弓 0.84 / 格闘 0.90 / 踏み込み 0.92 / 浮遊 1.06 など)で「立った時の高さ」に直し、930px(キャンバス 1100)になる倍率。
- 横は左のカード一覧/右の説明欄に重ならない範囲(キャンバス x 56〜694)。はみ出す時だけ倍率を下げる(黒剣士の大剣とマント、竜騎士のランス(上も)、魔法使い、竜人の翼、巫女の袖、忍者のマフラー: 頭の大きさの差は最大約 -10%)。
- 浮遊(魔法使い)は 70px 浮かせる。しゃがみ(忍者)/弓は低いまま。

## 確認
- 16:9(1280x720)/ 19.5:9(1560x720): 12 人とも頭・足先・武器・翼が切れず、カード一覧/説明欄に重ならない(`QaSweep -qaCharSelect`)。
- 4:3(960x720): 画面のレイアウト自体(カード一覧と説明欄)が立ち絵の枠に重なる。旧立ち絵でも同じ(横長画面前提の配置)。
- 12 人の比較(カラー/黒シルエット)で、ポーズだけで区別できることを確認。お嬢様騎士/魔法使い/巫女は縦長の輪郭だが、床に立てた大剣/浮かぶ魔導書/鈴の杖が外形に出る。
