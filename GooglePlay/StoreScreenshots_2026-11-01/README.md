# Google Play スクリーンショット 一次候補(2026-11-01)

エステルのレビュー用です。構成と掲載順はマスター/エステルと決めた8枚の案どおりです。

## 撮影の条件
- 実際のゲーム画面です。合成や文字の加工はしていません。透明度を外した 24bit PNG で、大きさは 1920x1080、1枚 1.4〜2.8MB です。
- 撮ったのは**今日の最新版**です。HUD は**標準**(10/31 の刷新後)、背景は今日の「背景を控えめにして敵を見やすく」の調整後(`Docs/BgTone_2026-11-01`)です。キャラは14人、カードの絵は描き直し後のものです。
- Windows の撮影用ビルドで撮りました。開発用の透かしや表示は出ません。中身は製品と同じです。
  - 撮影の準備に、開発用の距離ワープと、撮影専用の保存ファイルを使っています(本物のセーブには触れていません)。
  - 撮影中は倒れない設定です。補助(自動のジャンプ/攻撃)は製品の設定と同じく ON です。
- 死神・隠しダンジョン・エンディングは写していません。
- ゲームの仕様や数値は、宣伝のために変えていません。
  - 07 の BREAK は、実際の戦いの中で起きた BREAK です。
  - BREAK を撮るための撮影手順 `gp_break2` は作りましたが、採用していません。この手順は、崩しのゲージを満たす時刻だけを決める方法です。

## 気になっている点(エステルに見てほしい所)
1. **01 の黒剣士が小さい**(前回の指摘と同じ)。100km/h ではカメラが引くため、キャラが小さく写ります。
   - 2.6km 付近(約60km/h)でも撮り直しましたが、カメラの寄りはほとんど変わりませんでした。しかも穴に落ちたので、不採用にしました。
   - キャラを大きく見せるには、ゲームのカメラを変えるしかありません。今回は「仕様を変えない」方針なので、そのままにしています。
2. **03 に「ボーナス MILE RUSH」の帯が写っている**。撮った区間が BONUS ZONE と重なりました。実際のゲームの表示ですが、情報が多く見えるなら撮り直します。
3. **06 は初回だけ出る説明の画面**です。仕組み(持ち帰るか、走り続けるか)は一番はっきり伝わります。ただ「説明の画面」に見えるなら、予備の alt_EscapeResult(脱出成功!)と入れ替えられます。
4. **洞窟は不採用**にしました。暗さが雰囲気なので、縮小表示では何が起きているか分かりにくいためです。荒野以外のステージは、天空回廊(夜)の1枚にしています。
5. 04 は、カードの画面なのでキャラが写っていません。
