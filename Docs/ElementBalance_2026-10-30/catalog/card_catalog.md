## 2. 属性カード

属性は「命中した時に確率で起きる追加の現象」です。どのキャラでも同じカードなら同じ効果になります。属性同士の相性や相互作用はありません(炎で凍結が溶ける、なども無し)。
属性のダメージは、属性ごとの基礎の値に **(1 + 無条件の攻撃の強化の3/4)**(CardRules.ElementAttackShare 0.75。2026-10-30 の再設計で 0.5 → 0.75) を掛けたものです。条件付きの攻撃カード(空中・締め・ボス特効など)は乗りません。下の数値は攻撃の強化が無い時の値で、通常の1発は 20(黒剣士の基礎)です。

## 4. FINAL EVOLUTION 対象

**99枚**(100枚のうち #100 ULTIMATE だけ対象外)。そのランで能力 Lv9 → 5,000m 走ると READY → LEVEL UP / ボス報酬の3択に最大1枠 → 選ぶと60秒(ランが実際に進んでいる時間)だけ限界突破。終わるとすぐ READY に戻ります。専用の処理がある代表カードは ATTACK UP / SPEED UP / ATTACK RANGE UP / VAMPIRE / PHOENIX / FLAME BLADE / THUNDER STRIKE / EXP UP / GREED。ほかは「自分の効果×倍率 + 追加の効果」です。各カードの内容は xlsx の「FINAL EVOLUTION」シート。

## 5. 出現条件と抽選の仕様(現行)

1. **解放(ガチャに出るようになる)**: BEST 距離とガチャ段階の両方を満たしたカード。段階は BEST 0 / 5,000 / 20,000 / 50,000 / 100,000m。PATHFINDER だけ BEST 500m。
2. **ガチャ**: まず★を重み(★1 50 / ★2 30 / ★3 15 / ★4 4 / ★5 1、引ける★の中だけで割る)で選び、その★の中で等確率に1枚。
