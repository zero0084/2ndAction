### 3.1 読み取り

- **どの属性も「通常」より上の場面がある**: ラッシュは全属性が通常(44体)以上、ボスラッシュは炎/氷/雷/風/混成が通常(3体)以上。
- **一強ではない**: 雑魚の群れは雷と炎、ボス単体は風と炎、BREAK は氷、生存は血。雷は群れで一番強いが、ボスでは炎・風・混成より遅い。
- **混成が成立**: 炎2+雷2 は雑魚 105秒・ボス 39秒・ラッシュ 94体で、各特化の2番手〜3番手の位置。
- 雷の雑魚100体(49秒)は炎(95秒)の約2倍速い。闘技場の100体は敵が密集して連鎖が当たりやすい条件で、実際のラッシュでは 117体 対 103体(+14%)まで縮みます。
- 雑魚100体のばらつき: 最終の一括試験では風が 180秒で 65体、通常が 180秒で 90体でしたが、風・通常・雷・炎だけを2回やり直すと **風 142/136秒・通常 132/127秒・雷 49/51秒・炎 97/97秒**(4つとも全滅)。風と通常は敵の散り方で大きくぶれ、雷と炎は安定しています(`data/elem_zako_rerun1.tsv`・`data/elem_zako_rerun2.tsv`)。
- 風は雑魚の群れでは通常と同じくらい(竜巻・風刃で敵が散り、近接の命中が通常の約4割に減る)。「群れの殲滅」ではなく「空中戦と位置の操作」の属性として、ボス(22秒 対 70秒)とラッシュ(57体 対 44体)で通常を上回る形にしています。

### 3.2 血(条件が厳しい代わりに恩恵が大きい)

- 満HP: BLOOD BLADE の出血(確率2倍)で削り、ボス戦 82秒。回復 716。
- HP25%固定: BLOOD RUSH(攻撃 +72%・出血の確率2倍・吸収2倍)が効いてボス戦 **69秒**(通常 70秒と同等)。
- 回復量はどの場面でも全ビルドで一番(雑魚 5,319・ラッシュ 2,172)。「火力は控えめ、倒れにくい」の位置です。

### 3.3 その他の測定値(100Hit の発動・追加ダメージ・撃破への寄与)

## 8. マルチ(HOST/JOIN)

- **処理**: 属性の判定・状態・ダメージは HOST だけ(今まで通り)。JOIN は計算しません。
- **同期**: `Net/NetElementFx` が HOST で「付与・凍結・落雷/連鎖・延焼・竜巻・吸収」のイベントを集め、**0.1秒ごとに1通にまとめて**送信(1Hitごとには送らない)。同じ敵の同じ状態は 0.5秒以内の延長を送らず、継続中の炎・冷え・帯電・出血の粒と頭上のマークは JOIN 側で動かします。1通は最大64件で、超えた分は捨てます(見た目だけなので遅れて出すより捨てる。捨てた数を記録、今回の試験では 0)。
- **帯域**(2人・ボス区間・120秒、全員 属性 Lv9 / HOST だけ属性): HOST の属性イベント 1,073〜1,403 バイト/120秒(**約 9〜12 B/s**)、29〜36通。HOST の送信全体 5.3〜5.6 KB/s。
- **JOIN の表示**: 受信 75〜98 件のうち再生 73〜86 件(残りは JOIN 側で敵がまだいない/もう消えた分)。JOIN で粒の最大 51〜58、状態の見た目(オーラ)1・頭上のマーク 1 を確認。
- **負荷**: 両方 fps 平均 60.0(JOIN の最低 59.2)、例外 0。
