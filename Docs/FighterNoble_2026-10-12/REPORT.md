# 格闘家/お嬢様の追加強化 + 問題のボス戦の調査(2026-10-12)

比較の基準: `Docs/BuildLab/final_v3_baseline_2026-10-12.md`(前回の最終集計)

## 1. 調査の結果(原因と修正)

### サソリ(自然洞窟、双剣士 54〜57km で3本とも敗退)= ボスの AI の不具合 → 修正(06c36a4)
- 診断(BuildLab の boss_diag、1秒ごとのボスの行動/間合い)で確定。上位強化再戦(必殺技の待ち 5.3秒)では
  「毒だまりの技(間合い 7.5m へ移動)→ 毒弾(体の前端が 6.5m より遠い時)→ 毒だまり…」が噛み合い、
  ボスが一度も近づかない(行動が MoveToGap/Telegraph/Wait だけ、Approach/Strike が0回)。
- 高速(146km/h)で被弾すると足が止まり、ボスは走る速さのまま最大の間合い 15m 先へ離れて形が固定。
  1本で 22回の命中のあと約55秒、HP が1度も減らないまま毒だまり/毒弾で倒された。
- 当たり判定の取りこぼしではない: 攻撃の判定がボスの被弾範囲に重なった振りは 151/153(双剣士)・50/52(格闘家)が命中。
- 修正: 体の前端が 3.5m 以内に来ないまま 7秒続いたら、遠くからの技を選ぶ所で近接の技(接近つき)を選ばせる
  (`WildBossBase.FarTooLong`。サソリの毒弾/毒だまり、同じ形のゴブリンライダーの魔法)。
- 闘技場での再現(54km・146km/h・20fps・上位強化 HP×4.7、3回): 撃破 54.5秒→43.4秒、被弾 8.0→5.0回。

### 格闘家 × 天空回廊(タイタン/石の巨人に当たらない)= 当たり判定の不具合ではない
- タイタンは普段 5〜14m 先(体の前端まで 8.4m)に立ち、膝をつく隙(2回の攻撃ごとに 3.2秒)だけ近接が届く設計(2026-10-03)。
  前回の試行では1戦 45〜90秒、その間に拳/衝撃と穴への落下(DeathY)で削られていた。
- 判定が重なった振りはほぼ全て当たっている。改善は「隙の間に当て切る火力」= 今回の格闘家の強化で対応。

### お嬢様 × ラスダン(魔人の前後で3本とも停止)= 被害の半分以上は地形(穴への落下)
| 試行 | 到達 | 落下(回/被害) | ボス(被害) | 雑魚(被害) | 最後の被弾 |
|---|---|---|---|---|---|
| V3A007 | 65km | 131回 / 1310 | 1282(魔人 341) | 384 | 魔人の突進・火球 |
| V3A015 | 45km | 115回 / 1150 | 610(魔人 144) | 216 | 魔人の突進・低い帯 + 落下 |
| V3A023 | 35km | 83回 / 830 | 407(魔人 108) | 168 | 魔人の低い帯・突進 + 落下 |
- ラスダンの落下はキャラ共通(格闘家 83〜92回、双剣士 89〜92回、忍者 175〜187回。魔法使いだけほぼ0)。
  お嬢様だけの問題ではなく、ラスダンの穴と補助のジャンプの課題として残る(今回は直していない)。

### 忍者 × 自然洞窟(76km/83km で停止)= 退行ではない、長いボス戦(ミミズ/コウモリ)の削られ
- 同じ実行ファイルでもう3本(診断つき): 101km 完走・102km 完走・95km(水晶ゴーレム)。
- ボスの被害の1位はどの試行もミミズ(1本 330〜380)。ミミズ戦は中央値 57〜73秒・最長 139秒、
  記録の 79% の時間は地中(無敵・攻撃が当たらない)。コウモリは 18% しか近くに来ない(MoveToGap が多い)。
- 設計どおりの動きで、不具合ではない。ボス側の調整(地中の時間を短く等)は今回はしていない(提案)。

### お嬢様(重い大剣 + 空中の技)
| 項目 | 前 | 後 |
|---|---|---|
| 大剣の間合い(基礎) | 0.75 | 1.0(見た目の大剣の長さに合わせた) |
| 一撃の威力 | ×1.0 | ×1.6 |

| 空中の下フリック | (下攻撃なし) | 振り下ろし急降下 + 着地の衝撃波 |
| ジャンプの高さ | — | 変更なし(空中の技は今の高さで十分に出せた) |

操作(全キャラ共通、専用の入力は追加していない)
- 上フリック = ジャンプ(お嬢様は上攻撃なし)
- 空中で前フリック = 前へ薙ぎ払い / 空中で後フリック = 振り向いて薙ぎ払い
- 空中で下フリック = 振り下ろし急降下(着地で衝撃波)

技の数値
| 技 | 威力 | 判定 | 時間 |
|---|---|---|---|
| 薙ぎ払い | 地上の一振りと同じ(×1.0) | 前方 0.2〜1.7m × 上下 ±1.2m(間合いの倍率で伸びる) | 構え 0.07 / 判定 0.20 / 硬直 0.12秒(攻撃速度の倍率) |
| 急降下の落下 | ×1.2 | 足元〜前方(間合いの倍率) | 落下 16m/秒(黒剣士と同じ) |
| 着地の衝撃波 | ×0.8 | 左右 1.6m × 高さ 1.1m | 着地の構え 0.22秒(入力は受け付ける) |
- 同じ敵に落下と衝撃波の両方が当たると合計 2.0倍(地上の一振り2回分)。1回の技で同じ敵に入るのは最大2回(確認済み)。
- 無敵は無い(被弾・穴・天井は通常どおり)。鎧(振っている間の被弾で止まらない)は薙ぎ払いにも効く。
- 絵: ChatGPT で生成した空中の薙ぎ払い3コマ・急降下3コマ(Assets/Art/NobleLadyAir_v1 / NobleLadyPlunge_v1)、
  斬撃は既存の大剣の斬撃を斜めに、着地は金の輪 + 岩のかけら + 揺れ + 叩きつけの音(既存の素材)。

## 5. 残っている負け筋 / 確認していないこと

- お嬢様の天空回廊(55 / 65km): タイタン・クラゲ・フェニックス戦の被弾の積み重ね。タイタンは近接の隙(膝をつく 3.2秒)が少ない設計。
- お嬢様/魔法使いの自然洞窟 94〜97km: 古代の魔人で「当てる機会が少ない」(地中/画面外の時間が長い)。ボス側の調整の候補。
- 格闘家の天空回廊(80〜83km): フェニックス/天空の大蛇/クラゲ。格闘家の命中率はタイタン 0.29・フェニックス 0.31 と低い(届く時間が短い)。
- ミミズは記録の 79% の時間が地中(無敵)。忍者/お嬢様の長期戦の原因。不具合ではないが、地中の時間を短くする調整を提案。
- ラスダンの穴への落下はキャラ共通(格闘家 83〜92回、忍者 175〜187回/1本)。お嬢様は 2段ジャンプで 14.6 → 8.9回/10km に下がった。
- マルチプレイ: 相手の画面では、お嬢様の空中の薙ぎ払いは地上の一振りの絵、急降下は振り下ろしの絵(Dive/DiveLand のコマ)で出る
  (技のポーズは同期していない)。当たり/ダメージは既存の経路(各端末が自分の攻撃を判定、JOIN は HOST へ申告)のままで、二重に入る経路は追加していない。
  実機2台での確認はしていない。
- 実機(Android)での操作感(空中のフリック、着地の硬直 0.22秒、2段ジャンプの高さ)は未確認。APK 298 で優先して見てほしい点:
  ① 空中で前/後フリック → 薙ぎ払いが出るか ② 空中で下フリック → 急降下と着地の衝撃波 ③ お嬢様の2段ジャンプで穴を越えられるか ④ サソリの再戦で近づいてくるか
- 全距離の試行は同時 8本のため 25〜35fps。60fps での全距離の試行はしていない(部分試験/診断のみ 54〜59fps)。
