## 使ったゲーム映像
- すべて現行版(APK 449 と同じコード)の Windows 撮影用ビルド(開発版の透かし無し)で、今日撮った実機映像。古い映像は使っていない。
- 撮影: `QaSweep -storeCapture`(60fps・劣化なし)。セーブは `-memSave` のみで、本物のセーブには触れていない。
  - 撮影用ビルドが本物のキーに書く窓の大きさの設定は、撮影のたびに元の値へ戻した。
- 新しく足した撮影の場面: `Unity/2ndAction/Assets/Scripts/QaSweep.PromoCapture.cs`(撮影用/開発版だけ。ゲームの仕様は不変)。
  - pv_final_wild/cave/sky: マップのラスボスの登場 → 必殺技 → BREAK → 撃破。
  - pv_boss_knight/hydra: 通常ボス。
  - pv_road(_sky): 敵の出ない区間を走るだけ。
  - pv_trio_*: 95km の3体同時。今回は未使用。
- 撮影の都合で決めたこと(性能や見た目は変えていない):
  - プレイヤーは倒れない設定、補助(自動のジャンプ/攻撃)は ON。
  - BREAK は「崩しのゲージが溜まる時刻」だけを決め、必殺技・撃破は呼び出した。
  - BONUS ZONE は起こさない。
  - 敵の出ない区間は出現率を 0 にした。
- 撮影素材(劣化なし、17GB): `C:/GameProject/SteamCaptureArchive/2026-11-08_XPromo/{play,boss2}/raw/*.mkv + .wav`

## 音
- BGM: ゲーム内の `bgm_boss_strong_n.wav`(162BPM、頭から勢いのある曲)を通しで流した。
  - プロジェクトのスクリプトで合成した自作曲で、権利表 `Docs/AudioProvenance_2026-10-23/audio_rights_registry.tsv` と MD5 0a824bcb… が一致。
- SE: 各場面の撮影で録ったゲームの効果音(攻撃のヒット・BREAK・ボスの声・撃破)。
  - 権利表で確認済みの素材だけで、ChatGPT 由来の33件はマスターの方針どおり継続使用。外部の音源は使っていない。
- BGM と SE の釣り合い: BGM 0.42 倍・SE 1.0 倍で混ぜ、最後に -14 LUFS へ。締めの道の場面は SE を半分にし、BGM は最後の2.2秒で消える。

3. 冒頭の場面で、地面の下の方が赤く写っています。ゲームの実際の表示で、加工ではありません。
