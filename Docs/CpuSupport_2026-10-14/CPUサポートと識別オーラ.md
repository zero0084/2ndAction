## 2. CPU の仲間の決まり

### 動き
- 体は本物のプレイヤーと同じ仕組み(そのキャラの攻撃・ジャンプ・回避・必殺の動き)。判断はプレイヤーの「高速時の自動操作補助」と同じ先読み(穴・段差・天井・ボスの攻撃の予兆を見て跳ぶ/避ける、届く時だけ攻撃)。
- 位置: ふだんはプレイヤーの少し後ろ(P2 1.4 / P3 2.7 / P4 4.0 後ろ)。前の近くに敵・ボスがいる時は、近接は少し前へ出て戦い、遠距離は後ろから撃ちます。
- 前へ出すぎない: プレイヤーより 3(敵がいる時 4)より前へは進みません。さらに前なら止まって待ちます。プレイヤーが被弾でのけぞっている間、前にいる仲間は待ちます。後ろの敵を追いかけたり、先に進んでイベント(関門・ボス・ボーナス区画・ラスダンの演出)を起こしたりしません。
- 呼び戻し: 25 後ろ / 9 前 / 12 下(落ちた)/ 2.5 秒進めない(プレイヤーが実際に進んでいる時だけ数える)のどれかで、プレイヤーの近くの安全な場所(穴・針の上でない地面)へ移します。
- 味方の攻撃は味方に当たりません。体どうしでぶつかりません(通り抜けます)。
- 走る速さは「プレイヤーが実際に進んでいる速さ」を基準にし、1フレームの移動にも上限を付けています(30fps と 60fps で同じ動きになるように)。
- 効果音・画面全体を止める演出(ヒットストップ)・画面の揺れは仲間の攻撃では出しません。仲間の攻撃の演出は 45% の濃さです。

### 倒れる・復帰(初期値)
| 項目 | 初期値 | 場所 |
|---|---|---|
| 倒れてから消えるまで | 1.2 秒 | `CpuParty.HideAfterDownSeconds` |
| 復帰までの時間 | **10 秒** | `CpuParty.ReviveSeconds`(開発版は起動引数 `-cpuRevive 秒` でも変更可) |
| 復帰時の HP | 最大の 50% | `CpuParty.ReviveHpFraction` |
| 復帰の場所 | プレイヤーの近くの安全な地面 | `CpuParty.FindSafeX` |

- 仲間が倒れてもランは続きます。**プレイヤーが倒れたら今までどおりランは終わります**(仲間が残っていても)。
- 仲間には満タンから1発で倒れない決まり(プレイヤーと同じ)と、SHIELD のカードの効果があります。

### 育成(仲間の強さが何を反映するか)
- **おすすめ構成**: キャラごとに12枚の構成を決めてあります(`Party/CpuBuilds.cs`。各キャラの攻略の試験で使った構成と同じ)。
- ラン開始時: 構成のキャラカード3枚を持って始めます。
- **プレイヤーのレベルが上がるたび / ボスを倒すたびに1枚**、構成の順で取ります(Lv9 に届いたカードは飛ばす)。**選ぶ画面は出さず、ランは止まりません。**
- カードの Lv は「**プレイヤーが所持しているカードの Lv**」(カード合成・強化で上がるランの外の所持 Lv。**ラン中のプレイヤーの Lv ではない**)。同じカードを複数持っていれば一番高い Lv。合成カードは主な能力のカードとして数える(副能力は仲間に付かない)。未所持なら Lv1。1回の取得で上がる量 = その所持 Lv(上限 Lv9。例: 所持 Lv5 → 1回目 Lv5、2回目 Lv9)。プレイヤーの持ち物は**読むだけ**です。消費しない・デッキを変えない・合成しない。
- 効くもの: 攻撃・攻撃速度・射程・ジャンプ・条件付きの攻撃・SHIELD・最大 HP。
- 効かないもの: ランに1つしか無い物(MILE/EXP の倍率、復活、吸収、FINAL EVOLUTION、Mastery の AWAKENED、属性)、HP を削って強くなるカード(封印)。
- 敵の HP は変えていません(仲間の分だけ敵が硬くなることはありません)。

### 報酬・記録
- 仲間が倒した敵・ボスは**プレイヤーの撃破として1回だけ**数えます(人数分に増えません)。仲間は財布を持ちません。
- 記録は今までどおり**成功した時だけ確定**し、進行はプレイヤーのもの(キャラごとの記録はプレイヤーのキャラ)です。
- 記録に「サポートあり・人数・仲間のキャラ」を残します(`RunLedger.partySize / supportIds / officialParty`)。
- **ランキング(2026-10-14 夕方に仕様変更)**: ランキングは**ソロだけ**です。一度でも CPU サポートを使ったランは投稿しません(途中で仲間が倒れても)。サポート用の表/スクリプトは作りません。詳細は `Docs/ReleaseReadiness_2026-10-14/公開準備の棚卸し.md` の 1.
- 中断と再開: 仲間の顔ぶれ・取ったカード・HP・倒れている状態と復帰までの残り時間を中断データに入れ、CONTINUE で同じ状態に戻します。
- 疾走出発: 疾走の間は仲間を隠し、着いた所でプレイヤーの近くに出します。

### 見つけて直した物(今回の確認の途中)
- 名前が仲間どうしで重なる → 横へ広げる。斜めの見せ方で名前が頭から離れる → 当たり判定の上端を基準に。
- 色の縁が黒い輪郭の後ろで見えない → 絵の形を1色で塗る方式に。加算だと明るい空で白く飛ぶ → 普通の重ね方に。
- マルチで名前が二重に出る(旧来の名前表示)→ オーラの名前に一本化。コードネームが無い人が「P3 P3」になる → 「P3」。
- レベルアップのカードの上に名前が描かれる → 画面が出ている間は名前を出さない。
- 30fps で仲間が前へ 9.8 まで出る(プレイヤーが急に止まった時)→ 1フレームでも上限を越えない。のけぞり中は前の仲間が待つ。
- ボスラッシュでプレイヤーが止まっている間に、仲間の「引っかかり」の呼び戻しが続く → 実際に進んでいる時だけ数える。
- 既存の不具合: 出発前の部屋で最後の1人が抜けると、HOST に「接続が切れました」の画面が残り、戻って出発したラン中に出る → 部屋では通知だけ。
- 試験の不具合: ラストダンジョンの確認が新しい保存だと YES の後の初回の案内で止まる → 確認の開始時に案内を済みにする(他の確認と同じ)。
