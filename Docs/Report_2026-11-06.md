## 1. 難易度(デッキ3段階)

### 方針(マスター 11-06)
- オートは人が見張る前提の補助。放置での途中脱落は失敗に数えない → **人の操作の試験(-tiMode human)を主に評価**
- 注意: human のシミュレーションは「オート + 判断イベントへの反応」で、地形の壁や穴はオートと同じにしか避けない → **人の到達距離は下限の目安**(人が見張れば事故はもっと減る)

### 高速時の事故ダメージ(AccidentDamage)
- 対象: 雑魚への体当たり/接触(空中雑魚・判断イベントの帯は除く)・障害物・地形の壁・穴/落下。ボス・攻撃・死神は対象外
- 100km/h 未満 1 / 100以上 2 / 130以上 3 ハート(DifficultyTuning で Inspector から変更可。対象の種類も切り替え可)
- 速度の欄: 100km/h 以上で細い橙の縁、130 以上で赤みの縁が点滅(AUTO の水色の文字とは別)
- 比較(同じ条件・放置): 中デッキ 事故なし 100km → あり 90km / 強デッキ 100km(5〜6%)で差なし / 初期デッキ 70km → 4.96km
- **気になる点**: 自然加速で 3.6km に 100km/h へ届くので、序盤から事故が2ハートになる。最大HPが4〜6ハートの間は事故3回で倒れる
  - 比較用に「最初の N km は1ハートのまま」(accidentFromKm、既定 0 = 指示どおり)を追加。15km で試した結果:
    剣士 人 65km / ルカ 人 16.2km(なし 5.3)/ 双剣士 人 10km(ボス)/ 弓 人 30km / 剣士 放置 50km / 双剣士 放置 55km
  - 放置は伸びるが、人の操作はばらつきの範囲。**既定はマスターの指示どおり(猶予なし)にしてある。猶予を入れるかはマスターの判断**
