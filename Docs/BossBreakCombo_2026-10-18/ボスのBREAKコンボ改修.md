# ボスの怯み / BREAK 中のエリアルコンボ(2026-10-18)

通常時のボスの強さは保ち、BREAK を取ったら「ここから一気に攻められる」戦闘にしました。
- 普段の怯み: 短い攻撃のチャンス(約0.6秒)。
- BREAK: 長いコンボのチャンス(4〜5秒)。打ち上げ → 空中追撃 → 再打ち上げ → 下降攻撃をつなげられます。

## 1. 今までの仕組み(調べて分かったこと)

| 項目 | 改修前 |
|---|---|
| ボスの作り | 荒野/洞窟/天空のボス31体は共通の土台(WildBossBase)。天空ドラゴン/荒野のドラゴンと魔人は別の作り(DragonController / MajinController)。死神三姉妹は崩しなし |
| 崩し(BREAK) | 攻撃が当たるたびにゲージが溜まり(通常1、↑3.2、↓2.4、着地の衝撃4.5、空中で当てると×1.5)、満タンで BREAK(ボスごとに2.4〜3.4秒、受けるダメージ×1.35) |
| 普段の怯み | 無かった(予備動作の中断の仕組みはあったが、どのボスも使っていなかった) |
| BREAK 中の位置 | 地面へ落ち、体の手前の端がプレイヤーから3mより遠い時だけ2mまで寄せる。地上の↑(踏み込まない技)は届かないことが多かった |
| 空中コンボ | 雑魚の仕組み(打ち上げた敵の寄せ・AIR 表示・再打ち上げ)はボスに無かった。ボスに空中で当ててもその場で止まったまま |
| ドラゴン/魔人 | 空中の滞空(NotifyAerialHit)とコンボ数に数えていなかった。協力の相手/仲間の攻撃では崩しが溜まらなかった |
| 協力の相手の攻撃 | 種類にかかわらず「通常」の量の崩し |
| BREAK の終わり | 時間が来たら、その場で行動を再開(予告なし・立ち直りなし)。すぐに次の BREAK を取れた |

## 2. 普段の怯み

- 崩しのゲージが **40% と 75%** を越えた時に、短くよろけます。
  - よろけ: 0.42秒、少し後ろへ下がり、浮いているボスは少し沈みます。その後0.2秒待ってから行動を再開します。
- 怯むのは「行動の合間」だけです。待つ/近づく/間合いを取る/構え直すの間です。
- 次の場合は怯みません(スーパーアーマー)。体に薄い白い輪が出て、当たったが耐えたことが分かります。
  - 攻撃の予備動作・攻撃中・突進/跳躍などの技の途中
  - 必殺技・段階の咆哮・無敵の間・画面の外へ回る技
  - 天井/地中にいる時、雲海に沈んでいる時(タイタン/リヴァイアサン)
- 次の怯みまで **2.5秒** 空けます。
- ゲージの目盛りで決まるので、多段の攻撃だけで怯み続けることはありません(ゲージ1本で最大2回)。
- ドラゴン/魔人: 待っている間(Idle)だけ、次の攻撃を0.7秒遅らせてよろけます。

## 3. BREAK 中のエリアルコンボ

### ボスごとの扱い

| 扱い | 対象 | BREAK 中 |
|---|---|---|
| 打ち上げ(体ごと) | 体の高さ4.6m以下の地上のボス: 巨大オオカミ、ゴブリンライダー、大蛇、大蜘蛛、魔族、黒騎士、ムカデ、大サソリ、モグラ、ワーム、サソリの王、バジリスク、ドレイク、フェンリル | ↑で体ごと打ち上がり、プレイヤーの空中攻撃が当たる所へ寄ります |
| 打ち上げ(飛行/浮遊) | グリフォン、大コウモリ、古代地底悪魔、クラゲ、フェニックス、天空の大蛇、天界の守護者、天空ドラゴン/荒野のドラゴン、魔人 | 飛行の動き(AI)を止めて落ち、地面へ着く前でも↑で打ち上げられます。BREAK の後は元の高さへ戻ります |
| 膝をつく(大型/固定) | サイクロプス、ゴーレム、ヒドラ、トロール、クリスタルゴーレム、ベヒモス、タイタン、リヴァイアサン、天空のゴーレム、メカドラゴン | 位置は動かさず、膝をついて体が2割低くなります(絵と当たり判定を同じだけ)。空中の追撃・再上昇・↓の締めが当たります |
| 対象外 | 死神三姉妹 | 元から崩し(BREAK)がありません |

### 寄せ方(BossJuggle)

雑魚の仕組みと同じ考え方です。
- この端末のプレイヤーが手動の攻撃を当てている間だけ、体の手前の端を「そのキャラの攻撃が当たる所」の少し手前へ寄せます。
- 走行の速さは変えません(相対の速さの補正だけ)。
- 寄せの速さ:
  - 位置のずれ ×9/秒、補正は最大 **10m/秒**。
  - プレイヤーの踏み込み/急降下の一瞬の速さは最大 **18m/秒** までしか追いません(1フレーム遅れて跳んで見えないように)。
- 寄せが終わる条件(終わった後は普通に落ちます):
  - 最後の命中から **0.9秒**
  - プレイヤーの着地
  - **7m** 以上のずれ
- BREAK 中のボスは、体の手前の端がプレイヤーの前 **0.9m** に来るまで寄ってきます(以前は2m)。地上の↑も届きます。
  - プレイヤーが体の中へ入り込んだら、少しだけ前へずれます(遠距離の弾が体の内側から出て当たらないのを防ぐ)。
- ↑: 地上なら打ち上げ(毎秒12m で上がる)、空中なら打ち上げ直し(少し上へ)。
- →: 空中の追撃(寄せを続ける)。
- ↓: 下へ押します(0.4秒、1.8m)。地面へ届いたら叩きつけ(締め)。届く前なら → / ↑ でつなぎ直せます。
- 天井: 頭が天井の少し下で止まります。
  - 下がってくる天井には、毎秒20m または走行の速さの1.2倍で沿って下がります。
  - 少し先(走行の速さ×0.12秒)の天井も見ます。
- 地面: 寄せている間はプレイヤーが低くても地面より下へ行きません(穴の上は両側の地面を結んだ高さ)。
- 他の参加者/仲間の攻撃では寄せません(ダメージと崩しだけ)。同時に寄せるのは1体だけです(雑魚とボスを同時に寄せない)。

### プレイヤー側

- 雑魚と同じ仕組みが BREAK 中のボスにも使えます。
  - 遠距離の技の狙いの補正、二段ジャンプを使い切った後の↑(再上昇)、急降下の途中の → / ↑ のつなぎ直し、締めの技(竜人の急降下、巫女の印 など)
  - 合わせる相手は AirComboTargets(雑魚 or BREAK 中のボス)。
- 遠距離の打ち上げ(↑の弾/矢/札)の狙い: ボスはプレイヤーと並走しているので、雑魚用の先回り(近づいてくる分)をしません。
- ドラゴン/魔人も、空中の滞空とコンボ数に数えるようにしました。

## 4. BREAK の長さと終わり

| 項目 | 値 |
|---|---|
| もとの長さ | ボスごと 2.4〜3.4秒(変えていない) |
| 延長 | 寄せている間の手動の命中1回で +0.15秒。打ち上げた時は残りを2.2秒確保 |
| 延長の上限 | 元の長さ×0.6、最小1.8秒(合計 4.2〜5.4秒)。それ以上は延びない |
| 回復の予告 | 残り0.8秒: 体が白〜水色に速く点滅、体へ縮む白い輪。これ以降は寄せない(浮いていれば落ちる) |
| 立ち直り | 地面で0.5秒(起き上がって一歩下がる、うなり声)。攻撃しない・崩しは溜まらない |
| 立ち直りの後 | 飛行のボスは元の高さへ(0.4秒)→ 0.3秒待つ → 行動。BREAK の終わりから最初の攻撃の予告まで約0.8秒以上 |
| 続けて BREAK しない | 立ち直ってから6秒は崩しの溜まりが半分 |
| 安全装置 | 落ちきらない時も、上限+1.5秒で必ず終わる。割り込み(段階の咆哮など)で BREAK の途中が止められた時も、BREAK の状態を残さない |

## 5. 演出

| 場面 | 演出 |
|---|---|
| BREAK の始まり | 今までの「BREAK!」表示・割れる音・揺れに、体から広がる金色の輪(2重)と火花を追加 |
| 打ち上げ | 上へ伸びる光の軌跡(雑魚と同じ絵をボスの大きさに)+打ち上げの手応えの音 |
| 連続の命中 | 命中の衝撃の絵が、空中の段ごとに少しずつ大きく(最大6段で約1.4倍) |
| ↓ | 下向きの軌跡 |
| 叩きつけ(締め) | 地面に広がる衝撃の輪・砂煙・叩きつけの音・短い揺れ(0.16)・短い停止(0.05秒) |
| 回復の予告 | 白〜水色の点滅と縮む輪(予告の赤とも、BREAK の金とも違う色) |

光や揺れは短くしています。予告の赤い範囲や足場を隠す大きさにはしていません。

## 6. 数値の扱い

- HP は変えていません。BREAK 中のダメージ倍率(×1.35)もそのままです。
- 撃破: HP 0 で今までどおり撃破が確定します(打ち上げ中でも寄せをやめ、BOSS FINISH へ)。報酬は1回。

## 7. 今までの仕様から変えたこと

1. 普段の怯みを追加(40%/75%、行動の合間だけ)
2. BREAK 中の位置: 手前の端 2m → 0.9m(地上の↑が届く)。プレイヤーが入り込んだら少し前へ
3. BREAK の長さ: 当て続けると延びる(上限あり)
4. BREAK の終わり: 回復の予告・立ち直り・最初の攻撃までの間を追加
5. 続けて BREAK しない: 立ち直ってから6秒は崩しが半分
6. 協力の相手の攻撃: 種類に応じた崩し(上/下攻撃は多め、空中の倍率なし)。ドラゴン/魔人は他の参加者/仲間の攻撃でも崩しが溜まる(以前は溜まらなかった)。CPU の仲間は通常の量のまま
7. ドラゴン/魔人: 空中の滞空とコンボ数に数える
8. 必殺技: 今までどおり BREAK で止まる。必殺技の途中は怯まない(スーパーアーマー)

- C 撃破: BREAK 中に打ち上げてから HP 1 にして当て、撃破が確定するかを見ます。

## 9. 制限と残り

- 協力プレイで寄せられるのは HOST のプレイヤーだけ。参加側のプレイヤーの攻撃は、ダメージと崩しだけでボスは動かない
- 死神三姉妹は対象外(元から崩しなし)
- 竜騎士は技が長いので、速い入力の列では他のキャラより当たる数が少ない(3〜5/13)。打ち上げ・追撃はつながる
- タイタン/リヴァイアサンは雲海に沈んでいる間は怯まない(割り込むと高さが跳ぶため。スーパーアーマーの輪だけ)
- 回復の予告の後(残り0.8秒)に当たった↑は打ち上げない(予告の後は落ちて立ち直る仕様)
- Android 実機での見え方・手触りは未確認(マスターの確認が必要)
