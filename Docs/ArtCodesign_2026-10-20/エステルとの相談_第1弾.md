## 1. カードの仮アイコン 9枚(全部 正式な絵に)

99枚のうち9枚だけ、コードで描いた記号のままでした。

### 相談で決まったこと
| 決まり | 理由 |
|---|---|
| 剣は描かず、**現象そのもの**を主役に | 炎/氷/雷/風の剣が既にあり、40pxで区別が付かない |
| ★3=1つの塊、★4=外へ広がる/規模が大きい、★5=別格の光 | 発光の強さだけでは、40pxでレア度の差が消える(エステルさんの意見) |
| 形の意味をぶつけない | 既存の91枚を並べて確かめた(下の表) |
| 黒の背景・太い紺の輪郭・光沢・属性色の発光 | 既存の91枚と同じ描き方 |

## 2. 画面の共通アイコン

今は文字の記号(♥ II ×)やコードで描いた図形(MILE の印・歯車・NEW の四角)でした。

### 相談で決まったこと
- **画像にした方がきれいになる物だけ画像**にする。正確な形が大事な記号(一時停止・閉じる・足す・矢印・チェック)は、コードの描き方を整える(エステルさんの提案)。
- **既存の記号の方が良ければ置き換えない**(星は文字の★のまま。鍵は今の画面に記号が無いので作らない)。
- 色の使い分け: 白銀 = 操作、金 = 価値/機能(MILE・歯車)、赤 = HP、金橙 = NEW。
- ハートは満タンと空を**同じ輪郭の2枚**にして、端数・封印はゲーム側で描く。

| アイコン | 方法 | 使う所 |
|---|---|---|
| MILE の硬貨(金の菱形) | 画像 | ラン中の持ち帰りMILE、一時停止の内訳、脱出の長押し |
| ハート(満タン/空) | 画像。端数は満タンを途中まで切り抜く、封印は空を紫にして斜めの帯 | ラン中のHP |
| 歯車 | 画像 | ホームの設定、一時停止の設定、各画面の右上、リザルト |
| NEW の札 | 画像(文字はゲーム側。言語で長さが変わるため) | ホーム(IMGUI)、キャラ選択・マップ選択(uGUI)の両方を同じ絵に |
| 一時停止 | コード(角の丸い白銀の縦棒2本) | ラン中の右下 |
| 閉じる | コード(白銀の太い×) | 設定・ランキング・広告なしパス・データ削除・デバッグ |

- 置き場所: `Resources/UI/Icons/`(128px、`UiIconImporter` でミップマップ。Android は ASTC 4x4)。コードは `Scripts/UI/UiIcons.cs`。
- 絵が無い時は、今までの描き方に戻ります。
- **まだの物**: 足す・矢印・チェック(uGUI の画面ごとに文字で作っているので、別の作業にしました)。
- 画像: `images/画面のアイコン_ゲーム内_2倍.png`(ゲームの中の撮影)

## 3. ゴブリンライダー(25コマ)

荒野の5,000m、ラスダンでもよく出るボスです。今は止め絵3枚で、狼の脚が動かず滑って見えていました。

### 相談で決まったこと(エステルさんの提案が芯)
- **狼が先に動き、ゴブリンが遅れて反応する**(着地で狼が沈むと、ゴブリンの頭と肩が慣性で前へ揺れる)。
- 走る間、ゴブリンは片手で手綱、もう片手で棍棒を体の近くに。**棍棒は振り回さない**。
- BREAK ではゴブリンは落ちきらない(戦いに戻るので)。撃破で初めて鞍から離れる。
- 縮尺は**狼の体幹**を基準に(顔だけで合わせると狼が大きく/小さく見える)。
- 作る順番: 駆け足の 1・3・5 → 2・4・6 → 残り。

| 姿勢 | コマ | 中身 |
|---|---|---|
| 駆け足 | 6 | 縮む → 蹴る → 伸びる → 着地の準備 → 着地 → 回収 |
| 棍棒 | 溜め2・攻撃3・戻り1 | 振りかぶり → 最大 → 振り始め → 命中(狼も噛みつく) → 振り抜き → 肩へ担ぐ |
| 魔法 | 溜め2・発射1 | 手を上げる → 高く上げきる → 前へ突き出す(玉はゲーム側。玉の位置を手のひらへ移した) |
| 騎乗突撃 | 3 | 低く構える → 蹴る → 伸びる。突進中は3枚を繰り返す(コードを追加) |
| 被弾 | 1 | 狼がのけぞり、ゴブリンが耐える |
| BREAK | 3 | 空中(落ちかける) / 地上(腹ばいで目を回す、BREAKの間ずっと) / 復帰 |
| 撃破 | 3 | 前へ崩れる → 横倒し+投げ出される → 地面で伸びる |

- 置き場所: `Resources/BossAnim/goblin_rider/`(幅1300、下端中央 = 足元)。
- コード: `animKey = "goblin_rider"`、魔法は2つ目の技のコマ、必殺技の中の魔法はそのコマ、手続きの反り/踏み込みは30%。**技の時間は変えていません**。
- 切り出し: `Tools/art/riderpose.py`(全コマ同じ変換)。狼の大きさが生成ごとに約1割ぶれるので、狼の頭を並べて(`headcmp.py`)コマごとに縮尺を合わせました。
- 毛色: 被弾と復帰の2枚で毛が明るい橙にぶれたので、**毛の色だけ**駆け足1コマ目に合わせました(`furmatch.py`。ポーズは描いてもらったまま)。被弾は描き直しを頼んだらポーズまで変わってしまったので、1枚目の色を直しました。
- 画像: `images/ライダー_駆け足6.jpg`、`ライダー_駆け足.gif`、`ライダー_技.jpg`、`ライダー_魔法と突撃.jpg`、`ライダー_被弾BREAK撃破.jpg`

## 6. ムカデ(21コマ、第1弾の続き)

洞窟1,000mのボス(ラスダンでも1,000m格でよく出る)。止め絵3枚で、這う時に脚が動かず滑っていました。

### 相談で決まったこと
- **最初に STEP 0**: 待機の絵の体節・脚・棘に番号を振った設計図を作り、全コマで同じ番号を追う(エステルさんの提案)。`images/ムカデ_設計図_STEP0.png`
  - 頭H(触角2・牙2)、体節14(1〜7 = 低く這う前半、8〜14 = 上へ巻き上がった後半)、手前の脚10本(L1〜L10、体節1〜10に1本ずつ)、大きな棘は体節1〜4。奥の脚・11〜14の脚は隠れていてよい。
- 這う時は**巻きを保つ**(伸ばすと別の怪物に見える)。前半の脚の波が主役、後半は遅れて揺れる。
- 縮尺の基準は「頭H+体節3〜5の甲殻」。

| 姿勢 | コマ | 入れ先 |
|---|---|---|
| 這う | 4 | move_ |
| 噛みつき 溜め/攻撃 | 2/2 | windup_ / attack_ |
| 戻り | 1 | recover_ |
| 体当たり(丸まる/薙ぐ) | 1/1 | windupB_ / attackB_ |
| 低い突進(地上の逆走も) | 1 | attackC_ |
| 背の高い突進(起こす/突っ込む) | 1/1 | windupD_ / attackD_ |
| 被弾 | 1 | hurt_ |
| BREAK(仰向け/脚をばたつかせる) | 2 | break_ / breakloop_(必殺技を外した後のひっくり返る隙にも出る) |
| 立ち直り | 1 | rise_ |
| 撃破(尾が沈む→中央が崩れる→頭が落ちる) | 3 | defeat_(蛇の倒れ方と一緒に) |

- コード: 技の組を2つから4つへ(`BossAnimSet.WindupFor/AttackFor`、animVariant 2 = C、3 = D)。ムカデは噛みつき0・体当たり1・低い突進2・背の高い突進3。背の高い突進の予告の0.95秒に「起こす」コマ。技の時間は変えていません。
- 描き直し: 溜め(這う絵と違いが小さすぎた)、体当たり1枚目(頭が2つになった)。撃破3枚は画面の大きさが変わったので体の太さで縮尺を合わせました。
- 確認: `-qaAnimDemo -adBoss Cave:Centipede`(失敗0・例外0)。BREAK で仰向けのコマが出ることを撮影で確認。動画 `video/ムカデ_戦闘_必殺技_BREAK_撃破.mp4`(コミットしない)。
- 画像: `images/ムカデ_這う4.jpg`、`ムカデ_技.jpg`、`ムカデ_突進_被弾_BREAK.jpg`、`ムカデ_撃破.jpg`

## 7. 雑魚: ゴブリンと鳥の被弾/撃破(4枚)

荒野でいちばん多く出る雑魚。走り/羽ばたき5コマだけで、被弾は赤い点滅、撃破は止め絵が飛ぶだけでした。

- この2体は「溜め/攻撃」の状態を持たない作りなので、**使える絵は被弾と撃破の2つ**(エステルさんに共有してから相談)。
- 決まったこと: **被弾は片足が地面に残って踏ん張る、撃破は完全に浮く**。短剣は手に残す(本体と一緒に動くため)。撃破は「吹き飛ぶ瞬間」の1枚で、傾きは控えめ(回転はゲーム側)。鳥は翼の左右非対称で崩れを見せ、散る羽は控えめ。縮尺は止め絵ではなく走りのコマに合わせる。
- 置き場所: `Art/EnemyPose/<走りのフォルダ名>/hit.png・death.png`(GoblinRun / WastelandBirdFlap)。`EnemyDatabaseBuilder` が走りの1コマ目と同じPPU・ピボットで取り込み、`poses.hit/death` に付けます(色違いの goblin_elite にも同じ絵)。
- 撃破は FINISH の分身(白く光って飛ぶ)がこの絵の形で出ます。
- 確認: `-qaAnimDemo -adRunOnly 1 -adMobs goblin,flying_wyvern`(雑魚を目の前に出して叩く、`mob_shots.txt` に被弾/撃破のフレーム)。被弾の絵・撃破の分身の形を撮影で確認。

## 8. キャラ選択のカード: 最初の3人(黒剣士・双剣士・お嬢様)

最初に並ぶ3人だけ、古い作り(顔のアップ・体が切れる・小さい 210〜255px 幅)でした。

- 決まったこと(エステルさんの提案): **GUNSLINGER の枠を基準**、構図は**膝から上で顔の大きさをそろえる**(全身を小さく入れるより顔・武器・衣装)。順番は黒剣士 → 双剣士 → お嬢様。
- 文字: エステルさんは「文字はゲーム側で重ねる」を勧めましたが、手元に既存9枚の書体に近いものが無いので、**既存9枚と同じく絵の中に描く**ことにし、綴りを1文字ずつ確認(3枚とも正しかった)。
- 空の枠のテンプレートを作る案は、既存カードの人物が枠に重なっていて枠だけ取り出せないため見送り。
- お嬢様の下段の札は赤のまま(上級者向けの「挑戦」のキャラの印)。
- 描き直し: 黒剣士の1枚目は全身で顔が小さかった → 膝から上に。
- 置き場所: `Art/UI/Characters/<id>_card.png`(高さ959)。`CharacterDatabaseBuilder` の portraitPath を `_card.png` へ、`SceneBuilder.Build`(Build Prototype Scene)でシーンに反映。
- 画像: `images/キャラ選択のカード12人.jpg`、`images/キャラ選択_ゲーム内.png`
- 注意: シーンの作り直しで、拳銃士の attackFrames/downAttackFrames に1コマずつ増える差分が出ました(フォルダに未反映のコマがある)。今回の作業と関係ないので戻しています。iOS の対象 OS 15.0 も戻しました。
