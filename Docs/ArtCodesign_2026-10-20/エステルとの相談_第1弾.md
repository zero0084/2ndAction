## 1. カードの仮アイコン 9枚(全部 正式な絵に)

99枚のうち9枚だけ、コードで描いた記号のままでした。

### 相談で決まったこと
| 決まり | 理由 |

| 剣は描かず、**現象そのもの**を主役に | 炎/氷/雷/風の剣が既にあり、40pxで区別が付かない |
| ★3=1つの塊、★4=外へ広がる/規模が大きい、★5=別格の光 | 発光の強さだけでは、40pxでレア度の差が消える(エステルさんの意見) |

| 黒の背景・太い紺の輪郭・光沢・属性色の発光 | 既存の91枚と同じ描き方 |

## 2. 画面の共通アイコン

今は文字の記号(♥ II ×)やコードで描いた図形(MILE の印・歯車・NEW の四角)でした。

### 相談で決まったこと
- **画像にした方がきれいになる物だけ画像**にする。正確な形が大事な記号(一時停止・閉じる・足す・矢印・チェック)は、コードの描き方を整える(エステルさんの提案)。
- **既存の記号の方が良ければ置き換えない**(星は文字の★のまま。鍵は今の画面に記号が無いので作らない)。
- 色の使い分け: 白銀 = 操作、金 = 価値/機能(MILE・歯車)、赤 = HP、金橙 = NEW。
- ハートは満タンと空を**同じ輪郭の2枚**にして、端数・封印はゲーム側で描く。

| アイコン | 方法 | 使う所 |
|---|---|---|
| MILE の硬貨(金の菱形) | 画像 | ラン中の持ち帰りMILE、一時停止の内訳、脱出の長押し |
| ハート(満タン/空) | 画像。端数は満タンを途中まで切り抜く、封印は空を紫にして斜めの帯 | ラン中のHP |
| 歯車 | 画像 | ホームの設定、一時停止の設定、各画面の右上、リザルト |
| NEW の札 | 画像(文字はゲーム側。言語で長さが変わるため) | ホーム(IMGUI)、キャラ選択・マップ選択(uGUI)の両方を同じ絵に |
| 一時停止 | コード(角の丸い白銀の縦棒2本) | ラン中の右下 |
| 閉じる | コード(白銀の太い×) | 設定・ランキング・広告なしパス・データ削除・デバッグ |

- 置き場所: `Resources/UI/Icons/`(128px、`UiIconImporter` でミップマップ。Android は ASTC 4x4)。コードは `Scripts/UI/UiIcons.cs`。
- 絵が無い時は、今までの描き方に戻ります。
- **まだの物**: 足す・矢印・チェック(uGUI の画面ごとに文字で作っているので、別の作業にしました)。
- 画像: `images/画面のアイコン_ゲーム内_2倍.png`(ゲームの中の撮影)

## 3. ゴブリンライダー(25コマ)

荒野の5,000m、ラスダンでもよく出るボスです。今は止め絵3枚で、狼の脚が動かず滑って見えていました。

### 相談で決まったこと(エステルさんの提案が芯)
- **狼が先に動き、ゴブリンが遅れて反応する**(着地で狼が沈むと、ゴブリンの頭と肩が慣性で前へ揺れる)。
- 走る間、ゴブリンは片手で手綱、もう片手で棍棒を体の近くに。**棍棒は振り回さない**。
- BREAK ではゴブリンは落ちきらない(戦いに戻るので)。撃破で初めて鞍から離れる。
- 縮尺は**狼の体幹**を基準に(顔だけで合わせると狼が大きく/小さく見える)。
- 作る順番: 駆け足の 1・3・5 → 2・4・6 → 残り。

| 姿勢 | コマ | 中身 |
|---|---|---|
| 駆け足 | 6 | 縮む → 蹴る → 伸びる → 着地の準備 → 着地 → 回収 |
| 棍棒 | 溜め2・攻撃3・戻り1 | 振りかぶり → 最大 → 振り始め → 命中(狼も噛みつく) → 振り抜き → 肩へ担ぐ |
| 魔法 | 溜め2・発射1 | 手を上げる → 高く上げきる → 前へ突き出す(玉はゲーム側。玉の位置を手のひらへ移した) |
| 騎乗突撃 | 3 | 低く構える → 蹴る → 伸びる。突進中は3枚を繰り返す(コードを追加) |
| 被弾 | 1 | 狼がのけぞり、ゴブリンが耐える |
| BREAK | 3 | 空中(落ちかける) / 地上(腹ばいで目を回す、BREAKの間ずっと) / 復帰 |
| 撃破 | 3 | 前へ崩れる → 横倒し+投げ出される → 地面で伸びる |

- 置き場所: `Resources/BossAnim/goblin_rider/`(幅1300、下端中央 = 足元)。
- コード: `animKey = "goblin_rider"`、魔法は2つ目の技のコマ、必殺技の中の魔法はそのコマ、手続きの反り/踏み込みは30%。**技の時間は変えていません**。
- 切り出し: `Tools/art/riderpose.py`(全コマ同じ変換)。狼の大きさが生成ごとに約1割ぶれるので、狼の頭を並べて(`headcmp.py`)コマごとに縮尺を合わせました。
- 毛色: 被弾と復帰の2枚で毛が明るい橙にぶれたので、**毛の色だけ**駆け足1コマ目に合わせました(`furmatch.py`。ポーズは描いてもらったまま)。被弾は描き直しを頼んだらポーズまで変わってしまったので、1枚目の色を直しました。
- 画像: `images/ライダー_駆け足6.jpg`、`ライダー_駆け足.gif`、`ライダー_技.jpg`、`ライダー_魔法と突撃.jpg`、`ライダー_被弾BREAK撃破.jpg`

## 9. 洞窟ボス: サソリ(24枚)

洞窟5,000m格のボス。止め絵だけで、ハサミ・毒針・突進・毒液のどれも同じ絵が傾くだけでした。

### 相談で決まったこと
- 設計図: 頭H・ハサミC1/C2・胴B1〜B4・尾T1〜T6・針S・脚L1〜L4。縮尺の基準は「頭+胴B1〜B3」。
- **毒針と毒液は尾の向きで見分ける**: 毒針 = 尾を前下へ振り下ろして地面へ刺す / 毒液 = 尾を高く立てて針を前へ水平に向ける。
- 這う = 左右の脚が交互、ハサミは低く。突進 = 低く平たく、尾は後ろへ寝かせる(尾が高いと当たり判定と見た目がずれる)。
- **BREAK(ひっくり返る)と、必殺技の後の「尾が地面に刺さった隙」(exhaust_)は別の絵**。撃破は BREAK と見分けるため**うつ伏せ**で終わる。
- 体から離れて飛ぶ物(毒の玉・破片)は絵に入れない(弾はゲーム側で、プレイヤーを狙って斜めにも飛ぶため)。煙・砂ぼこりはマゼンタから遠い色で。

| 姿勢 | コマ | 入れ先 |
|---|---|---|
| 這う | 4 | move_ |
| ハサミ 溜め/攻撃/戻り | 2/2/1 | windup_ / attack_ / recover_ |
| 毒針 溜め/攻撃 | 2/2 | windupB_ / attackB_ |
| 突進 | 1 | attackC_ |
| 毒液 溜め/吐く | 1/1 | windupD_ / attackD_ |
| 被弾 | 1 | hurt_ |
| BREAK(横倒し→仰向け、じたばた2) | 2+1 | break_ / breakloop_(仰向けの絵を1枚目に流用) |
| 起き上がり | 1 | rise_ |
| 尾が刺さった隙 | 1 | exhaust_(新しい種類) |
| 撃破(反り上がる→崩れる→うつ伏せ) | 3 | defeat_ |

- コード(`CaveBosses.cs` の ScorpionBoss): 技ごとに animVariant(0 ハサミ・1 毒針・2 突進・3 毒液)。毒弾/毒だまりは **絵の針の先から**出し(`StingerTipWorld`、`HazardBossBase.FakeShotFrom` を上書き)、溜めの光の玉は絵に描いてあるので出さない。必殺技の最後の隙は `exhaust_` を出し、手続きのつぶしを弱める。`BossAnimSet` に `exhaust` を追加。技の時間・当たり判定は変えていません。
- こちらでの手直し: 突進は1割半小さかった → 拡大+砂ぼこりのピンク(背景色の移り)を砂色へ(`depink.py`)。被弾と隙は少し拡大。吐く瞬間の離れた玉を消す。毒針の溜め2枚目は尾の引きが弱かったが、毒の光としずくで十分伝わるので採用。
- 確認: `-qaAnimDemo -adBoss Cave:Scorpion`(失敗0・例外0)。毒が針の先から出る・突進・BREAK の仰向けとじたばたを撮影で確認。必殺技は補助の自動攻撃で崩れて途中で終わるので、`-adUltCalm 1`(必殺技の間だけ補助を止める)を追加して最後の隙まで撮影。隙の絵が最初の0.6秒で普通の姿勢へ戻っていた(隙の中で手前へ滑ると姿勢が Move になる)ので、隙が終わるまで出し続けるよう直しました。
- 撃破は今までどおり途中から FINISH の演出に移るので、撃破の2・3枚目は短く見えます。

## 10. 荒野街道ボス: 大蛇(24枚)

10,000m の関門で毎回出るボス。止め絵3枚で、這う時も絵が止まって滑り、潜る時は止め絵が沈んで消えるだけでした。

### 相談で決まったこと
- 設計図(STEP 0、エステルさん作): 頭H・首N1〜N3・とぐろの山C1〜C4・尾T1〜T3・尾先Tip・腹板・接地・**頭の基準線**。蛇は節ではなく「どのカーブがどのカーブか」を固定する。`images/大蛇_設計図_STEP0.png`
- **向きは今の絵と同じ左向き**(荒野のボスは左向きの絵が前提。最初に右向きと伝えてしまい訂正)。
- 這う = 脚の波ではなく**圧縮の波**: 頭はほぼ固定、首元 → 胴の中央 → 後ろの輪 → 尾へ詰まりが流れ、尾先は遅れて揺れる。
- **高い頭 = 噛みつき系 / 低い頭 = 突進**で見分ける。待機・這う・噛みつきの溜めは頭の高さをそろえる。
- 潜る = 下、飛び出す = 上の対比。BREAK は腹見せの仰向け、撃破は背中を上に横たわる(BREAK と見分ける)。

| 姿勢 | コマ | 入れ先 |
|---|---|---|
| 這う | 4 | move_(8コマ/秒、輪郭をそろえた絵なのでゆっくりめ) |
| 噛みつき 溜め/攻撃/戻り | 2/2/1 | windup_ / attack_ / recover_ |
| 突進 溜め/攻撃 | 1/1 | windupB_ / attackB_ |
| 尾の薙ぎ払い 溜め/攻撃 | 1/1 | windupC_ / attackC_ |
| 潜る / 飛び出す | 2 / 1 | dive_ / emerge_(新しい種類。モグラ・ワームにも使える) |
| 被弾 | 1 | hurt_ |
| BREAK(崩れる→仰向け、のたうつ2) | 2+1 | break_ / breakloop_(仰向けの絵を1枚目に流用) |

| 撃破(反る→崩れる→横たわる) | 3 | defeat_ |

- いちばん効いた進め方: **「這う1枚目を下敷きに」**。最初の這う2枚目・溜め1枚目は、とぐろが3割大きく広がって描かれ、繰り返すと体がびくびく膨らんで見える形でした。重ねた図(赤/青)を見せて描き直してもらい、とぐろを使う絵はほぼ全部これで縮尺と位置がそろいました(`ovl.py` で輪郭を重ねて確認)。
- 噛みつきの攻撃2枚目を頼んだら首を引き戻した絵が来たので、それを「戻り」に採用し、攻撃2枚目は攻撃1枚目を下敷きに描き直し。
- こちらでの手直し: 生成ごとの大きさのぶれ(1〜2.5割)を、体の太さを見て縮尺を合わせる。とぐろを右へ寄せた絵は、とぐろの帯の中心で位置を戻す(`coil.py`)。飛び出すの土ぼこりの紫を砂色へ(`depink.py`)。
- コード(`WildBosses.cs` の SerpentBoss): animVariant(0 噛みつき・1 突進・2 尾)、潜る間は進み具合で dive_ を出し(絵で沈むのを見せてから消えるよう透明は f² で)、飛び出しは emerge_ を0.6秒(必殺技は1.0秒)。`BossAnimSet` に `dive` / `emerge` を追加。技の時間・当たり判定は変えていません。
- 確認: `-qaAnimDemo -adBoss Wild:Serpent -adUltCalm 1`(失敗0・例外0)。這う・噛みつき・突進・潜る→飛び出す(必殺技も)・尾の薙ぎ払い・BREAK→のたうつ→起き上がり・撃破を撮影で確認。動画 `video/大蛇_戦闘_潜る_必殺技_BREAK_撃破.mp4`(コミットしない)。

## 12. 洞窟ボス: 巨大モグラ(23枚)

### 相談で決まったこと

## 13. 荒野街道ボス: サイクロプス(25コマ)

荒野 20,000m のボス。止め絵3枚で、叩きつけ・足踏み・薙ぎ払いが同じ絵でした。

### 相談で決まったこと
- 頭の高さは「帯」で管理(エステルさん): 高い帯 = 歩く・溜め1・被弾・戻り / やや高い = 叩きつけの溜め2・必殺の溜め / 低い = 足踏み・薙ぎ払い・必殺の後・隙。完全に固定すると人型は硬く見える。
- 歩くは「直立すぎない半前傾」。上下ではなく前後の重心移動と棍棒の遅れで質量を見せる。
- **通常の叩きつけ = ひねる(斜め後ろへ振りかぶる)/ 必殺技の溜め = 真上・対称・反る(正面寄りの儀式的な構え)**。色を抜いても区別できる。
- **足踏み = 縦 / 薙ぎ払い = 横**(棍棒の高さが腰)。
- 必殺技の後の隙 = 立ったまま棍棒が地面に刺さって抜けない(専用の隙 exhaust_)。BREAK = 仰向け、撃破 = うつ伏せ。
- 設計図(STEP 0): H・Eye line・Shoulder・Hip・Grip・Club head・L1/R1・Ground line。**左向き**(荒野のボス)。`images/サイクロプス_設計図_STEP0.jpg`

| 姿勢 | コマ | 入れ先 |
|---|---|---|
| 歩く | 4 | move_ |
| 叩きつけ 溜め/攻撃/戻り | 2/2/1 | windup_ / attack_ / recover_ |
| 足踏み 溜め/攻撃 | 1/1 | windupB_ / attackB_ |
| 薙ぎ払い 溜め/攻撃 | 1/1 | windupC_ / attackC_ |
| 必殺技 溜め/叩きつけ | 1/1 | ult_ |
| 棍棒が抜けない隙 | 1 | exhaust_ |
| 被弾 | 1 | hurt_ |
| BREAK(後ろへ倒れる→仰向け、じたばた2) | 2+1 | break_ / breakloop_ |
| 起き上がり(片膝で棍棒をつかみ直す) | 1 | rise_ |
| 撃破(天を仰ぐ→膝から崩れる→うつ伏せ) | 3 | defeat_ |

- 描き直し: 足踏みの溜めで棍棒が後ろの手に持ち替わっていた(切り替えで体の反対側へ飛んで見える)→ 前の手で描き直し。じたばたの2枚目は手足の違いが小さすぎた → 入れ替わるくらいに描き直し。
- こちらでの手直し: 残像の弧や腰布の縁にマゼンタが移ってピンク → `Tools/art/despill.py`(明るさを保って白〜灰へ)、土ぼこりは `depink.py`(砂色)。生成ごとの大きさのぶれは頭と体の太さで縮尺を合わせ、位置は後ろ足をそろえる。棍棒がはみ出す絵は幅を広げる(1400〜2000)。
- コード(`WildBosses.cs` の CyclopsBoss): animKey と animVariant(0 叩きつけ・1 足踏み・2 薙ぎ払い)。必殺技は ult_ の2枚、叩きつけの後の衝撃波・落石の間は**叩きつけた絵のまま**(最初は歩くコマで足踏みして見えた → `holdSlamArt`)、その後の隙は exhaust_(`exhaustArt`)。技の時間・当たり判定は変えていません。
- 確認: `-qaAnimDemo -adBoss Wild:Cyclops -adUltCalm 1`(失敗0・例外0)。動画 `video/サイクロプス_戦闘_必殺技_隙_BREAK_撃破.mp4`(コミットしない)。
