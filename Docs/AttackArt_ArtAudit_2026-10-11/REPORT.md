## 1. ボスなどの攻撃が色付きの四角だけで表示される

### 原因
デバッグ用の当たり判定の表示(開発版で DEBUG を ON にした時だけの細い線)ではなかった。
**仮の絵のまま本番になっていた**: 中身が白い四角の絵(`BossFx.Block`)や手続きで作った帯(`SkyBossFx.Beam`)を、当たり判定と同じ大きさに引き伸ばして色を付けていた。
絵が透明・地形の裏・画面外になっている物は無かった(自動テストで「判定が有効なのに見える絵が無い」は 0 件)。

### 自動テスト(`-qaAtkFx`)
闘技場へ全ボス 33 体を 1 体ずつ出し(無敵)、途中で段階を進め・必殺技を出させて、当たる攻撃が有効な間の絵を毎フレーム調べる。

| | 横 960x540 | 縦 540x960(斜め表示) |
|---|---|---|
| 修正前: 四角/仮の帯で出る当たる攻撃 | **14 件** | — |
| 修正後 | **0 件** | **0 件** |
| 判定が有効なのに見えない | 0 件 | 0 件 |

### 対象と対応

| ボス | 攻撃 | 修正前 | 修正後 |
|---|---|---|---|
| 大蛇(荒野) | 噴出 | 茶色の四角 | 地面の噴出(4コマを判定の間に1回再生)+ 岩のかけら |
| サイクロプス(荒野) / トロル(洞窟) | 大叩きつけ | オレンジの四角 | 同上 ※撮影の30秒の間には出なかった(コードは同じ部品) |
| ゴーレム(荒野) | 叩きつけ / 二連叩きつけ | 茶色の四角 | 同上(二連は撮影に出なかった) |
| ゴーレム(荒野) | 必殺技の岩の柱 | 茶色の四角 | 岩の柱(根元からせり上がる + かけら) |
| 悪魔(荒野) | 地面の魔法 / 魔柱陣 / 柱の行進 | 紫の四角 | 魔炎の柱(紫、ゆらめき4コマ + 魔力の粒) |
| 古代の魔神(洞窟) | 床の魔法 / 天井の魔法 | 紫の四角 | 魔炎の柱(天井からは上下反転) |
| コウモリ(洞窟) | 天井の魔法 | 紫の四角 | 同上 ※撮影には出なかった |
| バジリスク(洞窟) | 石化の視線(帯 / 波) | 黄色の四角 | 光の帯(黄、前方からプレイヤーへ流れる向き) |
| 魔人(天空) | 爪 | 紫の四角 | 斬撃 |
| 魔人(天空) | 円陣 / 下の帯 / 上の帯 | 紫の四角 | 魔炎の柱 / 光の帯(紫) |
| リヴァイアサン・天空の大蛇(天空) | ブレス | 手続きの帯 | 光の帯(うねり4コマ) |
| 空のゴーレム(天空) | コアビーム | 手続きの帯 | 光の帯 |
| 天の守護者(天空) | 光の柱 / 聖なる床 | 手続きの帯 | 光の帯(縦) / 魔炎の柱(金) |
| (共通) | 炎・水・聖光の床/天井、天からの光 | 引き伸ばした丸/帯 | 魔炎の柱 / 光の帯 |

- 素材: ChatGPT で生成(`Assets/Resources/Effects/Atk/`、各4コマ)。光る物(魔炎の柱・光の帯)は白基調で作り、攻撃ごとの色を乗せる。土と岩(噴出・岩の柱)は色付き。
- **当たり判定・威力・速さ・範囲は変えていない**。絵は 1×1 ではないので、絵の実際の大きさで割って判定と同じ範囲に合わせた。
- **予告と攻撃の区別**: 予告の範囲は、以前は単色の四角。いまは縁取り+斜めの縞+やわらかい端(`BossFx.WarnZone`)で、点滅する半透明の「危険地帯」。色(低い=赤 / 高い=紫など)と点滅はそのまま。攻撃中は絵、予告の間は危険地帯なので見分けられる。
- 絵が消えた後に判定が残る / 判定が終わっても危険に見える: どちらも無い(判定の終わりに向けて絵を薄くし、判定が切れたら消す)。
- マルチ: JOIN 側の写しも同じ絵とコマ送り(全コマを読み込んでおく)。
- 当たり判定の四角(デバッグ表示)は従来どおり開発版の DEBUG ON の時だけ。OFF でも攻撃の絵は見える。

## 2. 画像素材の全体点検

全プレイヤー/敵/ボス/武器/飛び道具/攻撃エフェクト/カード/ホーム/障害物の画像(元の素材フォルダを除く約 1,200 枚)を、フォルダごとの一覧(全コマを1行)にして見た。
怪しい物は元の画像を原寸で開いて確かめ、使われているか(.asset / シーンからの参照)も調べた。

### 直したもの

| 対象 | 問題 | 原因 | 対応 |
|---|---|---|---|
| 竜騎士の立ち絵(dragon_lancer_main) | 手の上で穂先が柄より約8°折れて見える | **元の絵** | 穂先を柄の向きへ回した(握り・顔・衣装はそのまま)。肖像・札の槍は元からまっすぐ |
| ゴブリンの走り(5コマ、ゴブリン/エリート/T0〜2) | 胸と胴の鎧が透けて抜けている / 後ろ足が切れ、次のコマに破片 | **切り出し**(黒い背景を明るさで抜いた → 黒い鎧も抜けた / 等分で切った) | 元のシートから切り直し: 外周につながった背景だけ抜く、各コマを広めに切って隣の破片を除く。ピボットは広げた分を補正 |
| 狼(chaser/rusher)の走り | 足先・しっぽが切れ、隣のコマの破片 | 切り出し(等分) | 同上 |
| 弓兵(shooter)の走り | 弓・マントが切れる、緑の縁 | 切り出し(等分)・緑背景の抜き残し | 同上 + 緑のにじみ抜き |
| 小悪魔(irregular)・オーガ(heavy)の走り | 輪郭の明るい緑の縁 | 緑背景の抜き残し | 同上(マントの裾の暗い黄緑は元の絵に描き込まれていた色なので残る) |
| 黒剣士の上攻撃(空中/地上 各5コマ) | 端に隣のコマの赤い破片、斬撃の弧が端でまっすぐ切れる | 切り出し(元のシートが残っていない) | 端の破片を消し、左右の切り口を透明へなめらかに(切れた弧は戻せない) |
| ヒドラの攻撃 | 首が3本(待機/予備動作は5本) | 元の絵 | ChatGPT で5本の首の攻撃に描き直し |
| グリフィンの予備動作 | 移動と全く同じ画像 | 元の絵の流用 | 立ち上がって翼を上げる予備動作を描いた |
| 兵隊アリの走り2コマ目 | 1コマ目と別の角度・大きさの絵(交互に出ると跳ねる) | 元の絵 | 1コマ目と同じ絵柄・角度・大きさで脚だけ違う絵に描き直し |
| 魔法使いの終了ポーズ(短) 1コマ目 | 杖が無い(2コマ目にはある) | 元の絵 | 同じポーズで杖を持たせた |
| 巫女の終了ポーズ(長) 1コマ目 / (短) 2コマ目 | 杖が無い | 元の絵 | 杖を持たせた(膝に手をついた姿勢は杖を地面に立てて) |
| 巫女の札置き | 髪の後ろに、どこにもつながらない杖の頭がもう1つ浮いている | 元の絵 | 余分な杖の頭を消した |
| お嬢様騎士の攻撃3コマ目 | 剣先が右端で切れている | 切り出し | 刃の傾き・色を引き継いで切っ先を描き足した(画像を右へ広げ、ピボット補正) |
| カードのイラスト 67 枚 | 炎/光が画像の端でまっすぐ切れる、別の絵の破片(blood_rush など) | 切り出し(グリッドから) | 端に触れた小さな破片を消し、四辺の切り口を透明へなめらかに |
| ドレイクの攻撃(洞窟ボス)/ 青い三日月の斬撃 | 息/しっぽが端で切れる | 切り出し | 切り口を透明へなめらかに |

描き直した絵は、元のコマと**同じ画像の大きさ・同じ足元の位置・同じ高さ**に合わせて差し替えた(アニメーション中に大きさや位置が跳ねないように)。顔・衣装・配色・体格・武器・画風は元の絵を渡して保つように依頼した。

ゲーム内の大きさでの確認(Windows、闘技場): 雑魚6種の走り(`3_雑魚_ゲーム内.png`)、ヒドラ/グリフィン(`4_ヒドラ_グリフィン_ゲーム内.png`)。足元・向き・欠けに問題なし。

### 点検したが問題なし(主なもの)
- 全12人の立ち絵・肖像・選択札: 顔・衣装・武器は一致。弓兵の弓と矢、黒剣士/双剣士/お嬢様騎士の剣、拳銃士の銃、魔法使い/巫女の杖のつながり
- 竜騎士の札の左端の枠(点検で指摘があったが、枠はある)
- 各キャラの走り/跳び/着地/被弾/倒れ/開始/終了、天空の敵、ボーナスの敵、死神三姉妹、ラスダンの地形/飾り/障害物/文字、攻撃エフェクト、カードの枠・分類アイコン
- 弓兵の上撃ち/下撃ちの弦(引き手が顔の陰に隠れる描き方)

### 判断を保留したもの(意図か不明)
| 対象 | 気になる点 | 保留の理由 |
|---|---|---|
| 竜(ボス)のため攻撃 DragonCharge | 奥の翼の形がコマごとに変わる | 羽ばたきで見え隠れしている動きと見られる |
| ホームで舞うカード HomeIdle/card_A〜H | 画像が小さくぼやけている | 動きのぶれの表現かもしれない。ゲーム内の大きさで未確認 |
| 魔法使いの開始ポーズ | 本がコマによって出たり消えたりする | 本を呼び出す演出かもしれない |
| 天空の敵ハーピーの被弾 | 体が右へのけぞる | 被弾ののけぞりと見られる(敵の向きの自動補正あり) |
| ボーナスの敵ミミックの倒れ | 箱が2つに見える | 壊れて割れた表現かもしれない |
| 死神三姉妹の待機 | 待機の画像が歩きより約1.3倍大きい可能性 | 表示側で大きさを合わせているかコード未確認 |
| 拳銃士のジャンプ開始=空中 / 魔法使いのジャンプ=着地 / 黒剣士の下攻撃 2コマ | 同じ画像の使い回し | 見た目の不具合ではない |
| 吸血鬼の着地 | 右に小さな黒い点 | 着地の土ぼこりかもしれない |

### 使われていない素材(直していない)
白い斬撃の古い素材(AttackSlashFx)、古いアイコン(Icons/、Icons/Generated)、灰色の仮のプレイヤー(Player* の生成物)、白背景の控え(*_whitebg_backup)、enemy.png。ゲームからは参照されていない。
