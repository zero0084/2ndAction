# Card audit (read-only), 2026-10-28

Scope: 100 assets in `Assets/Resources/Cards` (99 cards plus `character_ultimate`), checked against the code that reads each EffectType: `GameManager.CardStats`, `PlayerController.CardStats`, `CardProcs`, `ElementStats`/`ElementSystem`, `ChallengeSystem`, `BossManager`, `RunRewards`, `FinalEvolution`/`FinalEvolutionTuning`, `CardVariant.EffectsAtLevel`, `CardBehaviorText` and `RunCheckpoint` replay.

Every EffectType that some card uses is read somewhere. I found no double application: `MaxHpHearts` is also added into `Card`, but nothing on the player side reads it there, and the legacy `ApplyLegacyCardEffects` path only runs for card IDs it cannot break down into abilities.

The heart cap is 99 wherever it is shown: the heart_up text, the "鉄の心臓" FE text, the HUD "MAX" mark and `AllyCardStats`. All 29 non-Japanese language files contain the new "上限ハート99" strings. The old "20" strings are still in the JSON, but nothing uses them.

FE durations: all 99 FE descriptions start with "N秒間" or "次のNm", and `DurationPrefix` strips every one of them. The value line shows "60秒間" (`UnifiedSeconds`), and the HUD counts seconds. After stripping, no FE text still shows a stale duration. The seconds that remain, such as "無敵+0.4秒" or "1.3秒→2.2秒", are effect values, not durations. There is no `FinalEvolutionTuning.asset`, so the code defaults apply.
