## 1. 双剣士の手 / 14人の細部点検

### 双剣士の手(修正済み: ポーズを変更)
- 元の絵では、2つの手がどちらも右手に見えていた。
  - 原因: 刃を右へ向けて握る手で、曲げた指の前面がこちらを向いている形は、右手の形になる。
  - 胸の前の手は、本来は手の甲が見えるべき手だった。
- 今のポーズのまま、エステルに手だけの描き直しを3回頼んだ。
  - 胸の前の手は毎回ほぼ同じ拳にしかならず、手の甲を描かせることはできなかった。
  - 手だけを移す方法では、直しきれなかった。
- マスターの了解(「別のポージングに変えてもいい」)を受けて、ポーズを変えた。
  - X字の交差: 両腕が1つの拳にまとまり、片方の手が消えた → 不採用
  - 両手を離す構え: 親指が描かれず、左右の判別が弱かった → 不採用
  - **逆手で両手に1本ずつ持つ構え**: 採用。両手が鏡写しの握りになり、左右の違いが見て分かる。
    - 手前の手は顔の前、奥の手は腰の横に構える。
    - 顔・髪・衣装・スカーフ・剣の意匠はそのまま。カードの絵(走りながら低く構える)とも違う形。
- エフェクトは、新しいポーズに合わせてエステルに描き足してもらった(`f28_fx_dual_blade_v5.png`)。2. と同じ方法で重ねている。
- 比較画像:
  - `dual_blade_hands_before_after.jpg`: 上が元の2つの手、下が新しい2つの手
  - `dual_blade_full_before_after.jpg`: 全身

## 2. キャラを引き立てるエフェクト(調整済み)
新しく `Tools/portrait/fxmerge2.py` を作り、14人すべてのエフェクトを同じエステルのエフェクト絵から重ね直した。新しく描かせた絵はない。

1. キャラの上には一切重ねない。
   - 以前の `fxmerge.py` は、体の中も明るい方の色を採っていた。そのため刃や体の上に光の帯が乗り、輪郭が見えにくかった。
   - 体を横切っていた光は、体の後ろを通っているように見える。
2. 輪郭のすぐ外は濃さを抑えた。
   - 輪郭から 3px までは無し。20px で元の強さに戻る。
   - 輪郭の線が光に溶けない。
3. 顔の周りはさらに控えめにした。
   - 頭の高さでは、離す距離を 1.6 倍にした。
   - 近くの濃さは 0.7 倍にした。
4. 離れた所は強めた。
   - 全体の濃さは 1.2 倍。
   - 輪郭から 30〜80px より外は、さらに最大 1.25 倍。
   - 派手さは背後と外側で出す。

全体を一律に薄くしたのではなく、近くは抑え、遠くは強めている。

### 魔法使い・巫女・竜人(マスターの回答⑤)
実際のキャラ選択画面の大きさで見ると、この3人はまだエフェクトが画面を埋めていた。竜人は特に、赤い体と赤い炎が溶け合っていた。そこで、この3人だけさらに次のように調整した。

- 輪郭のすぐ外に、薄い暗い幕を敷いた(`--halo`、幅14px)。濃さは魔法使い・巫女が0.5、竜人が0.7。
  - 同じ色の炎の中でも輪郭が浮く。
- 体から離す距離を 30px、顔の周りでは2倍にした。
- エフェクトの濃さの上限を 0.85 にした(画面いっぱいの光を少し透かす)。

派手さは外側の光で残している。

- 比較画像: `fx_mage_miko_dragonkin.jpg`
- 実画面: `onscreen_dualblade_mage_miko_dragonkin.jpg`(左4枚 = 横、右4枚 = 縦)、`onscreen_cs_land_14.jpg` / `onscreen_cs_port_14.jpg`(14人)
- 作り直す時のコマンド:
  ```
  fxmerge2.py ... --near 30 --head 2.0 --gain 1.0 --far 1.2 --cap 0.85 --halo 0.5 (竜人は --gain 0.95 --halo 0.7)
  ```

- 比較画像: `fx14_before_after.jpg`(左 = 今朝の版 / 右 = 今回)
- キャラ選択の実画面(縦・横)での確認: 下の「実画面」の節
