# 全画面のレイアウト点検(2026-10-28 夜〜10-29、マスターの依頼)

対象: 闘技場からホームへの遷移・合成結果のボタンのはみ出し(先の2件)と、全画面のはみ出し/重なり/露出/スクロール/タップの点検。
比較画像は `layout/`(左: 直す前 / 右: 直した後)。

## 1. 確かめ方
- 開発版の巡回の試験(`-qaPortrait`)に、まだ撮っていなかった画面と配置の自動チェックを足した(`QaSweep.Layout.cs`)。
  - 巡回する画面: ホーム → 設定(言語・表示)→ ランキング → マルチ → ステージ選択 → キャラ選択 → デッキ編集 → 合成 → ガチャ → ラン中(横から/上下2段/斜め)→ デッキ12枚 → カード選出 → 一時停止 → リザルト → 疾走 → チュートリアル
  - 足した画面: お知らせ / キャラカード / 確認の画面 / 合成の結果(同名・異名・失敗・MASTERY)/ 疾走の行き先 / CPU の仲間選び / データの削除 / ライセンスの最初と最後 / デバッグ画面の上と下 / 帰還の確認 / 闘技場の5つのタブ / 闘技場からホームへ(毎フレーム)
  - 開いたまま回す: ホーム・キャラ選択・デッキ編集・ラン中(従来)+ 確認の画面・合成の結果・設定・帰還の確認
  - 自動チェック(uGUI の画面): 文字/ボタンが画面・安全領域・枠の外に出ていないか、文字が切れていないか、文字同士が重なっていないか。手前の画面の後ろに隠れている物は数えない。
  - IMGUI の画面(設定・ランキング・デバッグ・闘技場・HUD・一時停止・リザルト・ガチャ・疾走)は自動では測れないので、撮った画面を目で確かめた。
- 画面の大きさ(Windows の試験版。本物の保存は前後で変わらないことを確認):

| 名前 | 大きさ | 条件 |
|---|---|---|
| 縦・細長い | 486×1080(20:9) | 回転あり |
| 縦・標準 | 608×1080(16:9) | |
| 横・細長い | 1920×864(20:9) | |
| 横・標準 | 1280×720 | 回転あり |
| 横・高さが低い | 1280×560 | |
| 切り欠き | 縦の上 90px / 横の左 100px / 横の右 100px | 開発版の `-fakeSafeTop/Left/Right` |
| 長い訳 | ドイツ語(縦・横)/ タミル語(低い横) | |
| 多い/最大 | MILE 9,999,999・所持カード 80種 | `-qaLayoutMax 1` |

- 直した後に同じ巡回を撮り直した(8通り、さらに最後の修正の分を3通り)。自動チェックの件数は 1通りあたり 360〜490件 → 2〜38件(残りは回転の直後に後ろの画面まで数えたもので、画面を見て問題なし)。

共通部品を直したもの:
- `UiScroll.Text`(長い説明のスクロール): 収まるかの判定を実際の幅で、余裕を持って。収まる時も枠の外へは描かない。使う画面(ガチャの説明・疾走の説明・カード詳細など)は撮り直しで確認。
- `ConfirmDialogUI`(確認の画面): デッキ編集/キャラカードで共通。
- `UiInputGate.ModalOpen` に闘技場の覆いを追加(覆いの間はラン/ホームの操作を受けない)。

## 3. 試験側の問題(ゲームの不具合ではない)
- 撮影はフレームの終わりなので、撮った同じフレームで閉じると閉じた後が写っていた(最初の巡回の合成の結果・疾走/CPU の一覧・お知らせ)。撮影の後に1フレーム待つよう直した。
- データの削除は確認の通信の間は閉じない作り。試験が待たずに閉じていたので、次の画面に残って写っていた。
- 自動チェックの最初の版は、後ろに隠れた画面の文字や、文字ではなく枠の大きさで数えていて誤検出が多かった。手前の幕より後ろを除く・文字の実際の範囲で測るよう直した。

## 4. 見つけたが今回は直していないもの(訳の抜け)
長い訳の確認で、組み立てた文が訳の表に無く、日本語のまま出ているものが見つかった(配置ではなく訳の作り)。
- 合成の画面: 能力の数値(「攻撃力 +5%」「移動速度 -4%」)、【主】/【副】、「強化 ×1→×2」「継承成功」「レア度 ★★」、MASTERY の「★3つ分、余りは次の★へ繰り越し」「9 (上限)」
- 疾走の行き先: 「10km まで疾走 (約11秒 + リングのカード選択)」
- ラン中のお知らせ: 「新しい敵: ELITE GOBLIN」
- 案: 文の部品ごとに訳す作りへ直し、エステルに30言語の訳を頼む(レビューの後に反映)。

## 5. Android 実機で見ていただく項目(Windows では確かめられないもの)
1. 本物の切り欠き(パンチホール/ノッチ)と、左右どちらの横持ちでも、ホーム・合成・デッキ・ラン中で文字やボタンが隠れない。
2. 合成の結果・確認の画面・設定・帰還の確認を開いたまま、端末を回す(縦⇔横、横の左右)。
3. 闘技場の準備画面で「ホームへ」→ 戦闘画面が一瞬も見えず、「読み込み中…」からホームへ。覆いの間に画面を叩いても何も起きない。
4. 縦画面のカード選出で、カードを決定した瞬間に画面の端からはみ出さない。
5. 高さの低い横画面(分割画面など)で、一時停止の「持ち帰り予定MILE」が右上の HP に重ならない。疾走のリングの案内が ▲▼ に隠れない。
6. 文字の描き方は端末のフォントで少し変わるので、長い言語(ドイツ語・タミル語など)で一時停止・ランキング・疾走出発のボタンを一度見る。
