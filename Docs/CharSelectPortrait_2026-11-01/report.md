# キャラ選択の立ち絵 サイズと見切れ(2026-11-01)

## 見切れの原因の切り分け
| 原因 | 結果 |
|---|---|
| 元画像の欠け | なし(14人とも 700x1100、足元は y≈1074〜1084 にそろっている) |
| 切り抜き(crop) | なし(Image は preserveAspect で全体を描いていた) |
| 表示のマスク | 無かった(→ 枠からはみ出してカルーセル/情報パネルの下に潜っていた) |
| 画面端・UIとの重なり | **これが原因**。横画面は立ち絵の箱(560x880)がカルーセル(幅734)と情報パネルに重なり、槍・翼・オーラが隠れていた。縦画面は情報パネル横の小さな枠に、画像全体(武器/エフェクト込み)で合わせていたため、体が小さく見えた |

## 直したこと(キャラ選択の立ち絵だけ。ゲーム中のキャラの大きさ・当たり判定は変更なし)
- 立ち絵専用の表示領域 `MainVisualClip`(RectMask2D、左右だけ柔らかく消える)を作り、他のUIと重ならない場所に置いた
  - 横画面: カルーセルを 734→最大600 に細くして、カルーセルと情報パネルの間を立ち絵の領域にした
  - 縦画面: 左の列で、戻るボタンの下からカルーセルの上まで(幅は画面幅の半分、最大560)
- 倍率は「画像全体」ではなく、キャラごとの体の範囲(x0〜x1 と頭の上端)で決める表 `VisualFit`(CharacterSelectUI.Visual.cs)
  - 足元をそろえ、身長の基準を共通にした(竜騎士は槍で小さくならない)
  - 低い構えの忍者は ×1.30、弓使い ×1.15 で体の大きさを他にそろえる(立っている高さまでは伸ばさない)
  - ルカ ×1.40 / ペンタトゥットゥル ×1.15(小さい体の差は残しつつ、小さすぎないように)
  - 領域に収まらない時だけ縮める(縦横比は維持)
- 切り替え時は、フェードで見えていない間に倍率/位置を入れ替える(切り替えの途中で伸び縮みしない)
