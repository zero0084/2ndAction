# 疾走出発: 見た目とリング報酬の改善(2026-10-06)

## 1. 確認した事実(「取れるカードがありません」の原因)

- 90km・デッキ10枚・リング全部くぐる(自動テスト H)の結果:
  - 自動取得 76回 + リングの選択 14回 = 90 = デッキ10枚 × Lv9。
  - その後の自動取得13回が候補なし。原因の内訳は `runLv9 10 / sacrifice-blocked 0 / ultimate-blocked 0 / missing 0`。
  - つまり、デッキ内の対象カードがすべてラン中 Lv9 に達したためと確認した。
- 候補が空になる原因は `GameManager.SprintPoolDiagnose` が3つに分ける。毎回ログに内訳を出す。

| 状態 | 内容 | リング成功時 |
|---|---|---|
| `HasCandidates` | 候補あり | 追加の3択(従来どおり) |
| `AllMaxed` | 対象カードがすべてラン中 Lv9 | MILE |
| `Blocked` | 犠牲カードがハート不足で上げられない / データ欠け 等 | 報酬なし(全 Lv9 と混同しない) |

- 対象カード = デッキのうち ULTIMATE の条件で出ない物・データの無い物を除いたもの。

## 2. 変更

### キャラ
- 疾走中のキャラは 80%(`charScale`)。左寄りの配置はそのまま。
- リングの中心はキャラの胴体の中心(`torsoFrac`)。
- リングの判定は「高さの段 + 時間の幅」のままなので、小さくしても厳しくならない。
- 段の移動は見た目だけ滑らかに追従する(`laneFollow`)。判定はすぐ移る。
- 足元に控えめな光の足場と、光の軌跡を描く。空中の段では少し明るい。

### 到着
- 疾走のキャラを、実際のキャラの位置と大きさへ寄せながら画面を薄くする(`outroSeconds` = 0.5秒)。
- 補間の時間は1フレーム最大 0.05 秒で数える(到着の処理の重い1フレームで飛ばない)。
- 通常ランの能力値・当たり判定は変えていない。

### リング成功
- リングが弾ける光 + 短い粒子 + 文字(「BONUS CARD」または「+N MILE」)。
- 文字は 40px 相当で、次のリングやキャラを隠さない大きさ。
- カードの3択は弾けるのを見せてから開く(`ringChoiceDelay` = 0.45秒)。
- その間の自動取得で候補が尽きた場合は、全 Lv9 なら MILE にする。1回の成功で、カードか MILE のどちらか1回だけ。

### 操作説明
- 開始時に「上下で移動 / リング通過で追加カード」を3秒だけ、地面の帯(通り道の外)に大きく出す。
- 案内は最後に使った機器に合わせる。
  - タッチ: 上下フリック / ▲▼
  - パッド: 十字キー・スティック(A=上 / B=下)
  - キーボード: ↑↓ / W・S
- リングの早めの予告と操作の猶予は従来どおり。

### 全 Lv9
- リング成功で `ringMileReward` の MILE を自動で受け取る。選択画面・確認はなく、疾走は止まらない。
- ボス報酬の自動取得は、候補が無ければ何も取らない(MILE にはしない)。
- 途中で全 Lv9 になったら、一度だけ「デッキ内のカードがすべてLv9になりました。以降のリング報酬はMILEです」と出す。最初から全 Lv9 なら、開始の説明で案内する。
- 右側に「取れるカードなし」を積み重ねない。状態の1行(「デッキ全カード Lv9 MAX / リング報酬は +100 MILE」)にまとめる。
- カードを取れる間は、従来どおり取得カードと更新後の Lv を出す。

## 3. MILE の仮設定額: 100 MILE / リング1回

根拠(既存の相場):

| 項目 | MILE |
|---|---|
| 通常の走行の距離 | 100m ごとに 1。リングの間隔(5,000m)で 50 |
| 荒野のボス | 30〜500 |
| BONUS ZONE の CLEAR | 30〜100 |
| ガチャ1回 | 500 |

- 疾走で飛ばした区間は距離もボスも MILE にならない。
- リングの MILE は 90km で最大 17回 = 1,700(ガチャ 3〜4 回分)。
- 同じ区間を通常に走った時の稼ぎ(距離 900 + ボス 89 体分)を大きく下回る。
- それでも1回で BONUS ZONE の CLEAR 1回分になるので、リングを狙う嬉しさは残る。
- カードの MILE 倍率は掛けない固定額(分かりやすさ優先)。

扱い:
- このランの仮取得 `RunRingMile`。`RunMile` に含まれる。
- FINISH・脱出(Win)で持ち帰り、GAME OVER で失う(既存のルールどおり)。
- CONTINUE のデータ(`runRingMile`)に保存する。到着の時点の1回だけで、重ならない。
- 結果画面: 「RING BONUS +N MILE」。BONUS ZONE と両方ある時は1行にまとめる。
