## 0. 結論(要約)

1. **レア度が実際に効くのは「ガチャ」だけ**(と、合成の★の継承/還元MILE、表示/演出)。ラン中の LEVEL UP / BOSS REWARD / 疾走の候補は、デッキからの**一様な抽選でレア度を一切見ない**。つまり「入手のしやすさ」= ガチャで所持できるか、で決まる。
2. ガチャは「★の箱を重み 50/30/15/4/1 で選ぶ → 箱の中から一様に1枚」。**重みは『その段階に1枚でも存在する★』だけで配り直される**ので、★の数が少ない箱ほど1枚あたりが濃い。今は ★3=34枚、★4=36枚 と箱が大きく、**特定の★3は1回0.44%、特定の★4は1回0.11%**(段階5)。
3. 推奨の変更は**4枚だけ、すべて「下げる」**。
   | カード | 現在 → 推奨 | 狙い | 1回の確率(段階5) |
   |---|---|---|---|
   | LONG HAUL | ★3 → ★2 | 成長(EXP)ビルドの入口を広げる | 0.44% → 2.31% |
   | EXECUTIONER | ★2 → ★1 | 基本の MILE カードを持ちやすく | 2.31% → 5.00% |
   | MOMENTUM | ★4 → ★3 | COMBO 2種(SONIC MOMENTUM「基本+上位」・REDLINE「両方★4」)の律速を外す | 0.11% → 0.43% |
   | COMBO MASTER | ★4 → ★3 | COMBO FINISHING BLOW(「基本+上位」)の律速を外す | 0.11% → 0.43% |
4. **BOSS KILLER は「上げる候補」として検証した結果、据え置き(★3)を推奨**。Lv9 単体で対ボス ×1.53 と、ATTACK UP Lv9(無条件 ×1.45)と大差がなく「単純で強すぎる」状態ではない。上げるなら**★だけでなく段階も3へ上げないと逆効果**(段階2で★4を1枚で独占し、1回の確率が 0.46% → 4.04% と約9倍に上がる)。
5. PHOENIX(★5)、GREED(★3)、ONE MORE MILE(★5)、EXP 系の上位(LEVEL BREAK/EXPERIENCE BURST/THE LONG ROAD)は**据え置き**。EXP UP はすでに★1・初期所持。EXP の逓減(CardRules.ExpMultiplier)には触れない。
6. **COMBO は★をいくつか動かしても、ほとんど揃わない構造**(後述 §7)。15種中11種は「段階5で両方そろうまで期待700回以上(=35万MILE以上)」。提案で SONIC MOMENTUM と FINISHING BLOW は約900回 → 約235回に縮むが、属性系8種は ★3+★4 のまま約900回。根本はレア度ではなくガチャの仕組み(箱の大きさ)の問題で、別の論点として挙げておく。
7. 既存セーブ: レア度は所持データの「素のカードID」には入っていない(アセットの値を読む)ので、Lv1のカードは表示も合成も新しい★に自動で変わる。**合成済み(Lv2以上)のカードは v2キーに★が焼き込まれており、変更しても古い★のまま**残る(§8)。

### ★5 の特別扱い(まとめ)
- ガチャの重み1(1%)。**★5が1枚でも対象にある段階**(= 段階3 から。ULTIMATE `character_ultimate` が段階3)からだけ箱ができる。
- 段階が上がるほど★5の箱に入る枚数が 1 → 3 → 8 枚と増えるので、**ULTIMATE の1回の確率は 段階3 1.00% → 段階4 0.33% → 段階5 0.125% と、先へ進むほど下がる**(BEST を伸ばした人ほど ULTIMATE を引きにくい逆転。別途検討の余地あり)。
- ガチャ結果のオレンジの光/★の色(`GameManager.Gacha.cs:139-141`, `:163`)、カードの枠(★5用の画像)、効果音(★4以上と共通)。
- 合成の ★+1 は★5で止まる(`CardFusionLogic.cs:175`)。
- FINAL EVOLUTION の候補は★5の見た目(`FinalEvolution.cs:197`)。
- ゲームの性能で★5を条件にしている所は無い。

### ULTIMATE(#100 `character_ultimate`)の入手方法
- アセット: ★5 / gachaStage 3 / unlockDistance 20,000m / category 特殊(`Resources/Cards/character_ultimate.asset`)。
- **入手はガチャだけ**(BEST 20km 以上)。所持したらデッキかキャラカードへ入れ、ラン中の LEVEL UP / BOSS REWARD / 疾走で他のカードと同じ一様抽選で候補に出る。
- マルチでは候補に出ない(`Ultimate/UltimateArt.cs:58` Offerable → `GameManager.cs:4931` CanStillPick)、COMBO の構成に使わない(`Cards/ComboSystem.cs:80`)。
- 開発用: ULTIMATE TEST がラン中だけ Lv を付ける(`Dev/EndgameDebug.Ultimate.cs:84-85`、所持には書かない)。闘技場も全カードを試せるが所持には書かない。

## 3. 変更候補と理由

### 推奨(4枚、すべて「下げる」。段階/距離は変えない)

| カード | 現在 → 推奨 | 理由 |
|---|---|---|
| **LONG HAUL** `long_haul` | ★3 → ★2 | EXP+15%/Lv と最大HP(3Lvごと+1)の控えめな複合。EXP は1つの枠に足してから一度だけ曲線(`Cards/CardRules.cs:26`, `:109`。+180%まで等倍 → +450%まで半分 → その先20%、`GameManager.CardStats.cs:413-416`)を通るので、LONG HAUL を持ちやすくしても EXP 特化の上限は変わらない。EXP UP(+20%/Lv)より EXP は弱い。段階2(5km)は据え置き |
| **EXECUTIONER** `executioner` | ★2 → ★1 | 撃破MILE+15%/Lv だけで代償なしの素直な MILE カード(カテゴリは Risk だが中身は純粋な強化)。★1 にして序盤から MILE を稼ぐ手段を持ちやすくする。GREED / ELITE / HELL MODE などの強い Risk/Reward と、最上位の ONE MORE MILE(★5)は据え置くので長期の経済への影響は小さい |
| **MOMENTUM** `momentum` | ★4 → ★3 | COMBO 2種の要。SONIC MOMENTUM(SPEED UP★1+MOMENTUM)は大事な「基本+上位」、REDLINE(MOMENTUM+OVERDRIVE)は**15種で唯一「両方★4」**。効果は速さ条件つき(100km/h 超で伸び始め150km/hで最大、Lv9 +36%、「条件の攻撃」の枠)で単体は突出しない。段階3(20km)は据え置き |
| **COMBO MASTER** `combo_master` | ★4 → ★3 | COMBO FINISHING BLOW(COMBO PLUS★2+COMBO MASTER)は「基本+上位」だが★4側が律速。締めの特殊衝撃は SHOCKWAVE / GROUND BREAKER(★3、同じく現象を起こすカード)と同格。段階3(20km)は据え置き |

### 検証した上で据え置き/個別検討

| カード | 推奨 | 理由 |
|---|---|---|
| **BOSS KILLER** `boss_killer` | ★3 据え置き(個別検討) | ボスへ+8%/Lv は「条件の攻撃」の枠(`CardRules.cs:15`, `:101`, `:112`、ボス判定 `PlayerController.CardStats.cs:89`)を通るので Lv9 単体で ×1.53。ATTACK UP Lv9(×1.45、無条件)と大差なく、ボス以外では効果なし。v3 の計測(`Docs/CardBalanceV3_2026-10-04.md` のボス撃破時間の表)でも、6例中5例で「Attack 特化 Lv9」の方が「Boss 特化 Lv9」(BOSS KILLER 入り、`Cards/CardBuildPresets.cs:17`)よりボスを速く倒しており、ボス撃破に BOSS KILLER は必須でも突出でもない。**上げる場合は ★4 + 段階3/20,000m をセットで**(下の注意)。段階を上げると BEST 5〜20km の人はガチャで引けなくなる(所持済みは使える) |
| TREASURE HUNTER | ★2 据え置き(代案 ★1) | BONUS ZONE/WANTED の報酬MILEが中心(ボス/距離MILEも少し)。EXECUTIONER と同時に★1にすると★1の箱が 9→11 枚になり、初期カード(ATTACK UP など)の複製が約18%出にくくなる(合成/Mastery 用)。今回は EXECUTIONER だけを推奨 |
| LEVEL BREAK | ★4 据え置き(代案 ★3 は推奨しない) | EXP+30%/Lv は EXP UP の1.5倍。下げると EXP 特化(EXP UP+LEVEL BREAK+EXPERIENCE BURST)が序盤から強くなりすぎる。成長ビルドの入口は LONG HAUL の★2化で足りる |
| FLAME BLADE / FROST EDGE / THUNDER STRIKE / WIND CUTTER | ★4 据え置き(代案 ★3) | 属性の「入口」なのに★4/段階3で、上位の BURNING SOUL / ICE PRISON / CHAIN LIGHTNING / GALE(★3/段階2)より入手しにくい逆転がある。★3にすると各属性の1つ目の COMBO が約900回 → 約390回に縮む(案B)。方針(少数だけ)に合わせ今回は代案扱い |
| PHOENIX | ★5 据え置き | 倒れた時に1回だけ復活(ハート1〜5)、復活するとカードが外れ取り直しは Lv1 から。強力だが1回きりで、段階4(50km)・★5は妥当 |
| GREED / ONE MORE MILE / EXP 系上位 | 据え置き | 方針どおり(強い Risk/Reward、長期経済、EXP 特化の上限) |
| ULTIMATE `character_ultimate` | ★5 据え置き | 1枚だけの専用カード。ただし段階が進むほど1回の確率が下がる点(§1)は★ではなく段階/重みの問題として別途検討 |

> **【注意】★と段階は必ずセットで考える。** 重みは「その段階に存在する★」だけで配られる(`GameManager.cs:1136-1146`)。段階2には★4が1枚も無いので、BOSS KILLER を★4にして段階2のまま置くと、★4の箱(4%)を1枚で独占して **段階2での1回の確率が 0.464% → 4.040%(約9倍)** に上がる。同じ理由で、段階1に★3を置く/段階2に★4を置くといった変更はすべて「上げたのに出やすくなる」逆効果になる。

## 4. 各抽選への影響

| 抽選 | 影響 |
|---|---|
| ガチャ | 下の §5。変更した4枚の他に、同じ★の箱の他のカードが少し薄まる/濃くなる |
| LEVEL UP / BOSS REWARD / 疾走 | **確率の式は変わらない**(★を見ないため)。変わるのは「そのカードを所持してデッキに入れられる人の割合」だけ |
| 初期デッキ / おすすめ編成 | 変わらない(sortOrder / recommendPriority / 段階を変えないため) |
| 解放(段階/距離) | 推奨案では変えない。BOSS KILLER を上げる場合だけ段階2 → 3 |
| 合成 | 変えたカードの素の Lv1 は新しい★で合成される(★の継承、異名成功の+1、両方失敗の還元MILE)。例: 両方失敗の還元は Lv1 1枚あたり EXECUTIONER 100 → 50 MILE、MOMENTUM/COMBO MASTER 200 → 150 MILE、LONG HAUL 150 → 100 MILE |
| Mastery / FINAL EVOLUTION / COMBO の成立 | 変わらない(★を見ない) |

## 5. 出現率シミュレーション(現状 → 提案)

### モデル(コードの再現)
- **ガチャ1回** = `DrawFromGachaPool`(`GameManager.cs:1124-1149`)そのもの: 対象 = `IsCardEligible`、★の箱を「存在する★だけで正規化した重み」で選び、箱の中は一様。評価は各段階のしきい値ちょうどの BEST(0 / 5,000 / 20,000 / 50,000 / 100,000m)。重みはシーン値(`Main.unity`)= コード既定値 50/30/15/4/1。
- **N回引いた後に1枚以上所持** = 1-(1-p)^N。**k枚そろうまでの期待回数** = k/p(Lv9 は同名合成で9枚、AWAKENED は 9+15=24枚)。2枚とも1枚以上そろうまでの期待回数 = 1/pA + 1/pB − 1/(pA+pB)(厳密)。初期デッキのカードは最初から所持として扱う。
- **ラン中の3択** = デッキ(重複を含む)から重複なしで3件(`GameManager.cs:2857-2865`)。候補 n 件のうち1件が出る確率 = 1 − C(n−1,3)/C(n,3) = 3/n。
- MILE の目安(参考。2026-10-04 の計測値で現在は変わっている可能性あり、`Docs/CardBalanceV3_2026-10-04.md` §E): カードなしで 10km 800 / 50km 4,000 / 100km 8,000 MILE。距離の MILE はコード上 100m ごとに1(`GameManager.cs:3563`)、残りは撃破/ボス/BONUS。GAME OVER ではそのランの MILE を失う(`GameManager.cs:3560-3562`)。ガチャ1回 = 500 MILE ≒ カードなしで約6km ぶん。

## 6. EXP / MILE / ボス / 生存の各方針との照合

- **EXP**: EXP UP は★1・初期所持で下げる余地なし。LONG HAUL を★2へ(EXP の量は EXP UP より少ない複合カード)。LEVEL BREAK / EXPERIENCE BURST / THE LONG ROAD は据え置き。EXP の枠と曲線(`CardRules.cs:26`, `:109`)は変えないので、EXP 特化の最大値は変わらない(入口が早く揃うだけ)。
- **MILE**: 代償なしの EXECUTIONER だけを★1へ。GREED(速度と敵の出現増)、ELITE/HORDE/HELL MODE/PANDEMONIUM、EXP CONVERTER、ONE MORE MILE は据え置き。MOB KILLER(★2/段階1)は既に入手しやすい。
- **ボス**: BOSS KILLER は据え置き推奨(強すぎない・必須でない)。ボス向けの他のカード(HUNTER★3、BOSS CHALLENGE/BOSS RUSH は Risk)も据え置き。ボス撃破に必要な高レア度カードは無い状態を維持。
- **生存**: PHOENIX ★5(段階4)、SECOND WIND ★4、LAST CHANCE ★3、PERFECT GUARD ★4 は据え置き。

## 8. 既存セーブへの影響

| データ | レア度を持っているか | レア度を変えた時 |
|---|---|---|
| 所持カード `OwnedCardsV1`(`CardInventory.cs:23`、行は cardId/level/count) | **素のID(ガチャで引いた Lv1)は持っていない** → アセットの★を読む(`CardVariant.cs:56`) | 表示・合成とも自動で新しい★になる |
| 同上の v2キー(合成で Lv2 以上になったカード) | **持っている**(`v2|主ID|Lv|★|…`、`CardVariant.cs:15`, `:65-67`, `:121`) | 古い★のまま残る。表示の★、異名合成の★+1、同名合成の「大きい方」、両方失敗の還元MILE がすべて古い★で計算される。例: MOMENTUM★4 の Lv2 を持っている人が、変更後に★3の Lv1 と同名合成すると結果は★4(大きい方)。同じ性能でも変更前後で作ったものはキーが別になり、所持一覧で別の行に分かれる(数は失われない) |
| デッキ `DeckCardIds` / キャラカード / CONTINUE のデータ | キー文字列だけ(★なし) | 影響なし(参照は切れない) |
| Mastery `CardMasteryV1` | 主カードIDごと(★なし) | 影響なし(必要枚数もレア度に依存しない) |
| ガチャの結果 | 引いた時点で所持に入るだけ | 引き直しや取り上げは起きない |
| BEST / 段階 | 距離だけ | 推奨案では段階を変えないので影響なし。BOSS KILLER を段階3へ上げる場合は、BEST 5〜20km の人がガチャで引けなくなる(所持済みはデッキ/キャラカードで使える。デッキ編集は所持だけを見る `GameManager.cs:121-127`) |
| マルチ/ランキング | ★を送受信・保存していない | 影響なし |

v2キーに焼き込まれた★を新しい値へそろえたい場合は、`CardDataMigration` に「主IDの★が変わったカードの v2キーの★を書き換える」移行が別途必要(今回は提案のみ)。そろえない場合でも不具合にはならず、「古い★の合成済みカード」が残るだけ。

## 9. 実装する時のメモ(今回はしない)

- 値の正本はアセット(`Assets/Resources/Cards/<id>.asset` の `rarity`)。`Editor/CardDatabaseBuilder.cs` は既存アセットの★が既定値(1)以外なら上書きしない(`CardDatabaseBuilder.cs:111-118`)ので、アセットを直接直す。新規作成時の値をそろえるなら同ファイルの Spec(`rarity =` の行)も合わせて直す。`Editor/CardBalanceV3.cs` は★を扱わない。
- ★を下げる時は「その段階に下げた先の★がすでにあるか」を必ず確認(推奨4枚はすべて既存の箱へ移るので問題なし)。★を上げる時は段階も一緒に上げる(§3 の注意)。
- 変更後に `simulate.py` を再実行すれば、新しいアセットから同じ表が作り直せる(PROPOSAL を空にすると「新しい現状」の表になる)。
- 自動テストに★の値を前提にしたものは無い(`QaSweep*.cs` を検索して確認)。FINAL EVOLUTION の代表カード(MOMENTUM/BOSS KILLER/LONG HAUL を含む)は Lv9 到達で決まり★と無関係。

## 10. ついでに気づいた点(レア度とは別、未対応)

- **同じカードをデッキに2枚入れると、1回の3択に同じカードが2枠出ることがある**(LEVEL UP / BOSS REWARD / 疾走のプールは重複を除かない。`GameManager.cs:2836-2865`)。同じカードの重複は出現率を上げる手段にもなっている(候補12件で 25% → 45.5%)。
- **おすすめ編成は「解放済み」から選んでから所持で絞る**ので、未所持のカードが上位にあると12枚に満たないデッキになり得る(`CardDatabase.cs:204-219` → `GameManager.SetDeck`)。
- EXECUTIONER はカテゴリが Risk(6)だが代償の無い純粋な MILE 強化(表示の分類だけの問題)。
- ULTIMATE は先の段階ほど引きにくくなる(1.00% → 0.33% → 0.125%)。
