- 以前の調整(2026-10-01)は今も全ステージで有効です。ただし対象は **Player だけ**でした(Player の縁取りと、Player の周りの楕円の幕)。敵と、敵が出てくる画面の右側は対象外でした。

## 2. 直したこと
### 背景の絵だけを控えめにする(`Visibility/BackgroundTone.cs` + `Resources/Shaders/SpriteBgTone.shader`)
- 対象は、背景の1枚絵、昼夜/景色の重ね絵、天空の夜の絵、ラスダンの重ね絵、空の雲です。
- 地面・足場・穴・障害物・天井の針・敵・攻撃の予告・エフェクトは**一切触りません**。試験で「並び順 -40 より手前に、この描き方が付いていないこと」を毎回確かめています。
- やることは次の3つです。
  - 彩度を落とす
  - 明暗差を、その場面の背景の平均に近い色へ寄せて縮める。**一律に暗くはしない**(敵の周りの平均の明るさ L* の変化は ±6 以内)
  - 細かい模様を少しなだらかにする
- **敵が通る高さ(Player の足元から上の横の帯)だけ、少し強めにかけます**。空の上の方や景色の雰囲気は残します。帯は Player の足元にゆっくり付いていくので、ジャンプで背景が揺れて見えることはありません。
  - 縦画面の「上下2段」と「斜め」では帯を使わず、全体の値だけにしています。
- ステージ/時間帯ごとの値は次のとおりです。昼夜の移り変わりには約1.5秒かけて追従します。

| 場面 | 彩度を落とす | 明暗差を縮める | 帯の中で追加 |
|---|---|---|---|
| 荒野 昼 → 夜 | 26% → 20% | 20% → 14% | +20%/+18% → +12%/+12% |
| 洞窟 | 22% | 12% | +10%/+8% |
| 天空 昼 → 夜 | 22% → 20% | 18% → 16% | +18%/+16% → +12%/+12% |
| ラスダン | 20% | 22% | +10%/+10% |

### 暗い場面だけ、敵の縁取りを淡い色に(`SpriteOutline.cs`)
- 今までの敵の縁取りは黒だけでした。暗い背景(洞窟・夜・ラスダン)では、黒い縁が背景に溶けて輪郭が分かりませんでした。
- 背景の明るさが 0.36 未満の時だけ、敵の縁を淡い青白(不透明度 45%)の1色塗りに替えます。明るい場面は今までどおり黒です。
- 光らせる表現(加算)は使っていません。Player と他の参加者には使いません。

## 3. 前後の比較(同じ瞬間を前/後で撮影)
- 撮り方: 試験(`-qaBgTone`)で見えにくい敵を出し、時間を止めます。同じ瞬間を「前/後」×「敵あり/敵なし」の4枚で撮ります。
  - 出す敵: 小さい(ゴブリン/アリ/インプ)、暗い(コウモリ/ワーム/オーガ)、飛ぶ(ワイバーン/ハーピー/精霊)、背景と色が近い(スライム/ガーゴイル)
  - 通常速度と高速(約4.5倍)の両方で撮っています。
  - 測り方は `Tools/bgtone/measure.py` です。敵の画素とその後ろの背景の明るさの差(ΔL*)を、敵の周りの背景のばらつき(ごちゃつき)で割った「浮き上がり」を比べます。
- 結果: **35の場面すべて(横の8場面 × 2速度、縦画面の3つの見え方)で、浮き上がりが良くなりました(+1%〜+40%)**。周りの背景のごちゃつきは 2〜22% 減り、周りの背景の彩度は 10〜58% 減りました。
  - 「敵と後ろの色の差 ΔE」は、多くの場面で少し下がっています。背景の彩度を落としたぶん、色みの差が減ったためです。明るさの差(輪郭の見分け)は保たれるか増えています。
  - 結果の表: `summary_land.md`(横)、`summary_pside.md` / `summary_pfold.md` / `summary_pobl.md`(縦画面の 横から/上下2段/斜め)。敵ごとの値は `metrics_*.csv`。

| 横画面(通常速度) | 浮き上がり 前→後 |
|---|---|
| 荒野 昼 | 3.51 → 3.95(+13%) |
| 荒野 夕 | 2.07 → 2.61(+26%) |
| 荒野 夜 | 1.75 → 1.77(+1%)※高速時は +28% |
| 荒野 夜明け | 1.98 → 2.19(+11%) |
| 洞窟 | 2.35 → 3.04(+29%) |
| 天空 昼 | 2.72 → 3.43(+26%) |
| 天空 夜 | 2.95 → 3.27(+11%) |
| ラスダン | 1.68 → 1.79(+7%) |

- 画像:
  - `land_*.jpg`(横、前後を上下に並べたもの)
  - `enemies_land_*.jpg`(敵の周りの拡大、上=前/下=後)
  - `portrait_*.jpg`(縦画面の 横から/上下2段/斜め)
- 動画: `video_*_before_after.mp4`(左=前/右=後、各3秒)。動画は前と後を続けて撮ったので、敵の位置や場面は少し違います(静止画は同じ瞬間です)。

## 4. 確認
