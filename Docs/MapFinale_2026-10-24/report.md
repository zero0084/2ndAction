# 通常マップの終盤(90〜100km)の作り直し / FINAL EVOLUTION 60秒(2026-10-24)

テーマ: **「90km 以降で最後のビルドを完成させ、その力で 100km の死神から逃げる」**
対象は荒野街道 / 自然洞窟 / 天空回廊(ソロ・CPU サポート・協力マルチの HOST)。**ラスダンは変えていない。**

## 流れ

| 距離 | 内容 |
|---|---|
| 90,000m | そのマップ本来の 90km のボス(荒野 = 黒騎士 / 洞窟 = 古代地底悪魔 / 天空 = 天界の守護者)。通常の関門(1体) |
| 90〜95km | 雑魚の大群(関門なし)。1km ごとに段階が上がる。95km に入ったら雑魚は出さない |
| 95〜99km | 1,000m ごとにボス3体を1体ずつ(同時には出さない)。距離は関門で止まる |
| 100,000m | 今までどおりの死神の追跡(仕様は変えていない) |

- 以前の「90〜98km を走りながら9体」(BossManager.MapRush.cs)は残してあり、開発用の起動引数 `-mapFinale 0` で戻せます(比較用)。
- 95〜100km は雑魚を出しません(関門と関門の間も)。BONUS ZONE も 90〜100km では始まりません。

## 1. 90〜95km の雑魚の大群

**段階(波)**

| 区間 | 間隔の倍率 | 激しさ | 休憩 | 寄せ方 |
|---|---|---|---|---|
| 90-91km | 0.5 | 0.55 | 少なめ | ラッシュの始まり(まだ普通寄り) |
| 91-92km | 0.4 | 0.7 | 少ない | 飛ぶ敵の枠がある組を多く |
| 92-93km | 0.35 | 0.85 | 少ない | 地上と空の混成・地上の多い組を多く |
| 93-94km | 0.25 | 1.0 | なし | ほぼ途切れない |
| 94-95km | 0.18 | 1.0 | なし | 最大 |

**この区間だけの変更**
- 速さで間隔を広げる分を外しています(以前は終盤の速さで間隔が広がり、画面に1〜2体しか居ませんでした)。
- 上下ルートの分岐を作らない一本道にしています(敵が2つのルートに分かれて群れになりませんでした)。協力マルチは全員の地形を同じにする必要があるので、分岐はそのままです。
- 雑魚1体の HP は ×0.35 です。高速で走り抜けながら斬り進めるように、数で押します。
- 生きている敵の上限(36体)は、走り過ぎた敵を数えません。一番後ろの人より 45m 以上後ろの雑魚は片付けます。以前は後ろに残った敵で上限に届き、91〜93km にほとんど出ていませんでした。

**密度(自動試験、1280x720、補助の自動攻撃)**

| マップ | 画面内の平均 90→95km の各区間 | 最大 | 出した敵 | 倒した敵 |
|---|---|---|---|---|
| 荒野街道 | 2.8 / 3.9 / 5.2 / 6.5 / 5.1 | 15 | 約470 | 119〜125 |
| 自然洞窟 | 3.3 / 4.7 / 4.7 / 5.3 / 5.9 | 10 | 約450〜480 | 166〜220 |
| 天空回廊 | 2.5 / 4.1 / 5.2 / 6.2 / 6.1 | 12 | 約460 | 96 |

倒した数は構成と腕で大きく変わります。試験は無敵で、補助の自動攻撃だけで戦っています。

**同時に攻撃できる雑魚の上限: 3体**(ZakoAttackLimiter、大群の区間だけ)
- 予兆から攻撃までを始められるのは3体まで。残りは少し待って、空いたら攻撃します。
- 体当たりと、すでに飛んでいる弾は数えません。
- 試験の最大は 3/3 で、上限を超えた回はありません。

**EXP / レベルアップの目安**
- 特別な経験値倍率は入れていません。数が増えた分だけ増えます。
- 90km のボスの後から 95km までで **Lv +4〜+7、カードの選択 5〜9回**(90km のボスの報酬を含む)。

## 2. 95〜99km のボス3体の関門

**3体の格(弱 → 強)**
- 1,000m級/5,000m級のボスは各マップに1種類ずつしかないため、本来の出現距離で3つの格に分けました。

| 格 | 荒野街道 | 自然洞窟 | 天空回廊 |
|---|---|---|---|
| C1 | オオカミ / ゴブリンライダー / 大蛇 / サイクロプス | ムカデ / サソリ / モグラ / トロル | ドラゴン / 魔人 / ベヒーモス / タイタン |
| C2 | クモ / ゴーレム / グリフォン | ワーム / クリスタルゴーレム / 大コウモリ | クラゲ / リヴァイアサン / フェンリル |
| C3 | ヒュドラ / デーモン / 竜 / 黒騎士 | サソリキング / バジリスク / ドレイク / 古代地底悪魔 | スカイゴーレム / フェニックス / スカイサーペント / 天界の守護者 |

**関門ごとの並び**

| 関門 | 3体の並び |
|---|---|
| 95km | C1 → C1 → C2 |
| 96km | C1 → C2 → C3 |
| 97km | C2 → C2 → C3 |
| 98km | C2 → C3 → C3 |
| 99km | C3 → C3 → C3(そのマップの強いボス) |

**抽選**
- そのマップのボスだけから選びます。このランで倒したボスと、今までに会ったボス(保存の記録)を優先します。
- 直近に戦った3体と、同じ関門の中での重複を外します。抽選は HOST/ソロだけが行います。

**強さ**
- その関門の距離での再戦の強さ(BossRematchTuning)に、格の倍率を掛けています: C1 ×0.45 / C2 ×0.6 / C3 ×0.75。
- 撃破までの秒数(補助の自動攻撃・無敵)は1体 14〜43秒、1関門 約70〜110秒、95〜99km で約8分でした。
  - 荒野 mix Lv5: 95km 24/24/29秒 … 99km 21/26/33秒
  - 洞窟 mix Lv9: 14/19/33秒 … 19/22/30秒

**テンポ**
- 1体倒すと、FINISH の演出(約1.1秒)→ 0.8秒 → 予告「NEXT ○○ (2/3)」0.9秒 → 次のボス。撃破から次の出現まで、ゲームの時間で約2.8〜4.1秒です。
- その間に溜まったレベルアップの選択があれば、次のボスの前に出します。
- 3体目の撃破で「BOSS RUSH ○○km CLEAR!」→ ボス報酬の3択(関門ごとに1回)→ 距離の再開 → 次の関門。

**EXP**
- ボスの EXP は格ごとです(C1/C2 = 小、C3 = 中。15体 + 報酬5回でレベルアップが多くなりすぎないように)。
- 95〜99km で **Lv +11〜+15、カードの選択 15〜19回**(関門の報酬5回を含む)。

**90〜100km の合計**: Lv +16〜+23、カードの選択 23〜31回。走る時間(補助・無敵)は約12〜13分。

## 3. FINAL EVOLUTION

- **3枚提示**: 通常の LEVEL UP とボス報酬の3択の中に入ります。専用の1枚の提示にはしていません。
  - 通常のカードが2枚以上あれば FE は1枠。
  - 通常のカードが足りない時は FE の候補で3枚まで埋めます(以前は FE が1枚だけで出ることがありました)。
  - ボス報酬に FE が出るのは今回からです。
- **60秒**: 全カード共通で、実際にランが進んでいる時間の 60秒です。以前の秒/距離の長さと、AWAKENED の延長は使いません。
- **止まる条件**: カード選択 / 一時停止 / ヒットストップ / 時間の止まる演出 / CONTINUE の準備 / RESULT の間は減りません。
  - Time.deltaTime で数えているので、TimeControl が止めている間は自動で止まります。RESULT ではもともと更新しません。
- **再取得**: ACTIVE の能力も候補に出ます。ほかに READY の能力がある時は、そちらを先にします。
  - 選ぶと残りを 60秒へ戻します(足し算はしません)。
  - 効果は掛かったままです(掛け直さない = PHOENIX の緊急復活は戻りません)。
- **表示**: 左の列(持ち帰り予定の下)に「FINAL EVOLUTION / カード名 00:59」を小さく出します。
  - 最大3行です。残り10秒から軽く点滅して色を強めます。
  - 画像: `fe_hud.jpg`(取り直しで 60s に戻った所)、`fe_three_cards.jpg`(通常のカードが無い時の3枚)
- **カードの性能値は変えていません。**
- 以前の仕様の比較: 開発用の `-feSeconds 0` で以前の長さに戻ります。
