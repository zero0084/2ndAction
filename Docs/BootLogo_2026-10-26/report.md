# 起動ロゴ(MIXGame)が Android 実機でほとんど見えない件 — 調査と修正(2026-10-26)

確認用 APK: **377**(`Unity/2ndAction/Builds/Android/2ndAction.apk`、開発版・development 接続)

## 1. 原因として確認できたこと

**Unity の起動画面(方法A)は「ロゴを見せる時間」を持っていなかった。**

- ロゴの欄(logos)が空で、背景の絵にロゴを入れる方式のため、Unity の起動画面には最低の表示時間がありません。
- 最初のシーンのデータを読み終えた時点で終わります(ログ `[Boot] before scene load ... unitySplashFinished=True`)。
  - Windows: 起動 0.54秒で終了
  - エミュレーター: 約6〜10秒で終了
- その後、ゲームの初期化(保存の読み込み・ホームの準備)の間は画面が描き直されず、起動画面の **最後のコマがそのまま残ります**。

**ロゴの絵は読み込みが済んでから描かれる。**

- 最後のコマにロゴが描かれていたかどうかで、見え方が決まっていました。
  - Windows(読み込みが速い): 最後のコマにロゴがある → 初期化の約2秒の間ロゴが残る → 「約2秒見える」ように見えていた
  - Android: 最後のコマはまだ無地のことが多い → ロゴは一瞬、または出ない
- 起動ごとに変わるのは、端末のファイルのキャッシュ(直前に起動したか)や、端末の空き具合で、絵の読み込みと起動画面の終わりの前後が入れ替わるためと考えています。
- 「何度か完全終了して再起動すると一瞬見える」という実機の様子と合います。

**以前のエミュレーターでロゴが写らなかった件も同じ仕組みです。**

- エミュレーター(arm の命令を変換して動かすので実機の約10倍遅い)では、絵が描かれる前に起動画面が終わっていました。
- 今回、起動の命令からの時刻を記録して確かめました(`Tools/bootlogo/`)。
- 背景色の無地(#060810)のまま、最初のフレームまで約25秒続きます。

**そのほか確認したこと**

- 絵の読み込み・描画の設定(大きさ・圧縮・ぼかし)に問題はありません。
- Android の OS の起動画面(アプリの窓ができるまで)は約1〜4秒(エミュレーター)で、Unity の窓に切り替わってから Unity の起動画面になります。
- OS の起動画面からの切り替わりで、白や灰色のちらつきは出ていません(録画で確認)。

**描画方式(GLES/Vulkan)による違い**

- 前回、エミュレーターでは GLES/Vulkan のどちらでも同じでした。
- 実機の描画方式の違いは、上の仕組み(起動画面の終わり方)には関係しません。

## 2. 採用した表示方式: **Android は方法B / Windows は方法A のまま(機種で使い分け)**

**Android の構成**

- **Unity の起動画面**: 背景色(#060810)だけにしました。
  - Android のビルドの間だけ背景の絵を外します(`BrandSplashSetup.AndroidScope`、ビルド後に必ず元へ戻す)。
  - 速い端末で Unity のロゴが一瞬出て、ゲーム側のロゴがもう一度出る「二重表示」を防ぐためです。
- **ゲーム側のロゴ(`BootSplash`、方法B)**: 毎回、最初のフレームから描きます。

**Android の流れ**

1. OS の起動画面
2. 濃紺の無地(Unity の起動画面と初期化の間)
3. ロゴが 0.3秒でフェードイン
4. 1.2秒そのまま
5. 0.35秒でフェードアウト
6. 背景が 0.2秒で消えてホーム

**ロゴの見た目**

- 背景 #060810、C案の全体ロゴ(三毛猫・虹色の MIXGame・小さな「by マジル旅人」)。素材は描き直していません。
- 大きさは Windows の起動画面の絵と同じです。横画面は高さの5割、縦画面は高さの3割です。
- Unity のロゴは引き続き出しません。

**直したこと**

- 端末が縦向きの時に起動すると、ゲームが設定(横)へ画面を回します。
  - その回転がロゴの途中に重ならないよう、回り終わるまで(最大 1.5秒)はロゴを出さず背景だけにしました。
  - 回る必要が無い時は待ちません。
- 起動直後のコマが重い端末で、演出の時計を1コマで最大 1/30秒しか進めていなかったため、演出が何倍にも延びていました。
  - これを 0.1秒に変えました。
- 安全装置(15秒で強制終了)が、遅い端末ではロゴを見せる前に「早送りで閉じる」ことがありました(APK 375 で発見)。
  - ロゴを見せ終わってから働くように直しました(APK 376)。
- ロゴの表示中にタップで飛ばせるのは、出始めから 0.8秒後からです(誤タップでロゴが見えないことを防ぐ)。

**Windows は変更なし**

- 方法A のままです。
- ゲーム側のロゴは Android だけ動きます。開発版は `-bootSplash 1` でどの機種でも試せます。

## 3. 起動時間(Android エミュレーター、APK 377、横2回・縦2回ずつ)

比較のため、同じ APK でゲーム側のロゴだけを止めた起動(`-bootSplash 0`)も測りました。

- ロゴを止めた起動は、背景の絵が無い以外は今までの方法A(APK 374)と同じ流れです。
- 方法Aの絵は時間に影響しません。
- エミュレーターを起動し直した同じ状態で測っています。

| 項目(起動の命令から、秒) | ロゴなし(=方法A相当) | 修正後(方法B) |
|---|---|---|
| 最初の表示(OS の起動画面) | 約0.5〜1 | 約0.5〜1 |
| Unity の窓が出る(Displayed) | 2.5〜2.8 | 1.3〜4.1 |
| 最初のフレーム | 27.6 / 28.3 / 30.9 / 28.0 | 26.3 / 24.6 / 24.5 / 22.2 |
| ロゴが見えている時間(ログ) | 0(エミュレーターでは写らない) | **1.74 / 2.59 / 2.44 / 2.15** |
| ロゴが見えている時間(録画、0.2秒刻み) | 0 | 1.8 / 1.6 / 1.8 / 2.0 |
| ロゴが消えてからホームまで | — | 0.29 / 0.28 / 0.25 / 0.33 |
| **ホームを操作できるまで** | 27.3 / 28.0 / 30.8 / 27.9(平均 28.5) | 32.9 / 30.8 / 29.6 / 27.5(平均 30.2) |

**ばらつき**

- エミュレーターは起動ごとに ±2秒ほど変わります。
- 増えた時間は平均で約 1.7秒です。

**実機での見込み**

- 最初のフレームの後に約2秒(フェードイン 0.3 + 1.2 + フェードアウト 0.35 + 背景 0.2)増えます。
- ただし、ホームの準備(`[Loading] done`)はロゴの裏で進むので、その分だけ短くなります。

**時間の記録**

- 「ロゴが見えている時間」は、ロゴの濃さが半分を超えてから下回るまでの実時間です。
- 製品版のログにも `[BootSplash] logo visible / logo hidden / done` として出ます。

**参考: 方法A(APK 374)の測定**

- エミュレーターが重い状態(最初のフレームまで約50秒)で測ったので、上の表と時間は比べられません。
- どの回もロゴは写りませんでした。
- 録画: `Tools/bootlogo/bootrec.sh`(エミュレーター本体の録画、30fps)、分類: `bootframes.py`、まとめ: `boottimes.py`

**流れの一覧**: `android_emulator_apk377_sequence.jpg`

- 上が横画面、下が縦画面です。
- 左から: 起動直後 / Unity の起動画面(無地)/ ロゴの出始め / ロゴ / 終わり際 / ホーム
- エミュレーターの録画は本体の向きのまま撮るので、横画面は90度回って写っています。

## 4. 確認の結果

| 環境 | 確認 | 結果 |
|---|---|---|
| Android エミュレーター 横 | 完全終了→起動 ×2(+ 修正前の 376 で ×3) | ロゴ 1.7〜2.6秒、途中で消えない、二重表示なし、ホームへ移る |
| Android エミュレーター 縦 | 完全終了→起動 ×2(+ 376 で ×2) | 同上(縦用の大きさ) |
| Android 連続の再起動 | 376 で4回・377 で4回(ロゴあり) | 8回とも毎回ロゴが出た。375 では5回中3回、遅い初期フレームで安全装置が先に働いてロゴが見える前に閉じた → 376 で修正 |
| Windows 製品版 | 試験用の別名の製品版で起動 ×2 | 起動画面は今までどおり(方法A)。ゲーム側のロゴは動かない(ログに無し)。最初のフレーム 2.31秒(前回 2.50/2.61) |
| ホームへの移行 | 全回 | 正常(ホームの準備ができるまでロゴの後の背景で待つ) |
| 保存 | Android は毎回 試験用の保存ファイル(`-fileSave bs/…`)、Windows は別名の製品版 | Android「normal save untouched」/ Windows 本物の保存(レジストリ)は前後で同一 |

- Windows の録画は、ゲームの窓が他の窓の後ろで起動したため画面が写りませんでした。ログで確認しています。
- 見た目は前回(APK 370)の方法Aの撮影と同じ設定のままです。

## 5. Android 実機で確認してほしい項目

1. アプリを完全に終了してから起動 → 濃紺の画面にロゴが **毎回** 約1.5〜2秒出る(一瞬だけ・出ない、が無い)
2. 続けて3〜5回、完全終了→起動を繰り返しても同じ
3. 端末を **横** に持って起動 / **縦** に持って起動(設定が横の時は、回り終わってからロゴが出る)
4. 設定で「縦画面」にして起動 → 縦用の大きさで中央に出る
5. ロゴがフェードで消え、自然にホームが出る(白・灰色のちらつき、ロゴの二重表示が無い)
6. Unity のロゴが出ない
7. 起動からホームを操作できるまでの時間が、前(APK 374 など)と比べて気にならない程度か(+約2秒の見込み)
8. ロゴの間に画面をタップすると(0.8秒後から)早めに閉じる(必要なら)
