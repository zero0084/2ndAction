## 2. 近接の隙・強攻撃の後の隙は使えるか
- 照射/横払い/バルカンの後は「冷却」で低く降り(地面すれすれ、距離 1.4〜3.0m)、近接が届く。記録の `grounded=True gap=1.4〜3.0`
- 格闘家 D の与ダメージの **55%** は強攻撃の後の隙、黒剣士 D は 25%、黒剣士 A は 88%(短時間の試行)。**近接で実際に削れている**
- 待機中も低空(地面から 2〜5m)に留まるので、ジャンプ攻撃が届く(待機中の与ダメージ 29〜60%)

## 3. 空襲の安全な場所に行けるか
- 爆発の柱は高さ 2.4m。予告(赤い照準)の後、**跳んで上を越えれば当たらない**。天井が低くて越えられない所(天井まで 5.2m 未満)では、**プレイヤーのいる列を必ず安全な列にする**(届かない安全地帯を作らない)
- 実測(育成済みの全試行、プレイヤーの上で爆発した 152回): 跳んで越えた 37 / 空中だが 2.4m 未満 52 / 地面 42 / 穴に落ちている最中 21
  - 当たった回数は D で1試行 2〜9回(Shield・短い無敵で防いだ物は数えない)。越えられた例が全試行にあるので、**動きの性能で届く**
  - 跳ぶのが早すぎ/遅すぎの 52回は自動操作補助のタイミング(手で遊ぶ時は予告を見て跳ぶ)

## 4. 穴・天井のトゲで実質的に避けられない所があるか
- 穴は**ハート1つ減って足場へ戻る**(即死ではない)。天井のトゲは 1試行 0〜2回
- メカドラゴン戦の穴の頻度は 1分あたり **2.93回**。同じラストダンジョンの他のボス(過去の BuildLab のラストダンジョンの記録から、ボス戦の時間あたり): ムカデ 3.42 / ゴブリンライダー 3.01 / 不死鳥 4.16 / ワーム 4.31 / オオカミ 1.55
  → **メカドラゴンだけ穴が多いわけではない**(ラストダンジョンの地形と、自動操作補助がボスへ跳ぶ/避けて二段ジャンプする時に穴に落ちる)
- 黒剣士 D の落下 24回の直前の記録は、自動操作補助の「二段ジャンプ(回避)」「ジャンプ(ボスへ)」の最中が多い(攻撃を避ける/ボスへ跳ぶ判断と、穴を跳ぶ判断がぶつかる)。穴の幅そのものは今回測っていない(地形の生成はメカドラゴン戦専用ではなく、ラストダンジョン共通)

## 5. 「地形への埋まり 最大11フレーム」「BREAK 中の移動 最大1.3m」
- **埋まり → 不具合だった。直した**: 段差を上がる所で、足もとの高さのなめらか化が遅れて体が地面の下に入っていた(t=12.3秒、待機の構え、体の下端 3.67m / 地面 4.02m)。上がる時はすぐに合わせるように修正 → **全6試行で 0フレーム**
- **BREAK 中の移動 → 自然な動き**: 崩れた後、届く距離(2.5m→4.9m)へ寄る基本の動き。プレイヤーの後ろへ流れる事は無い(後ろへ回ったフレーム 0)。修正後の試行では最大 0.82m

## 5b. 縦画面の「画面の外からの攻撃」(以前の 37〜83 フレーム)
- **確認の測り方の誤りだった**: 上下2段(FoldView)はカメラを Update で元の位置へ戻し、LateUpdate で段の位置へ置く。確認の処理はその間(Update の後)にカメラの位置から計算していたので、下の段に全身が映っている時も「段の外」と数えていた(撮影で確認: 下の段の中央に全身)
- 斜め上から(Oblique)も同じく、絵を「カメラへ向けた写し」で描くため元の絵の isVisible が立たず誤って数えた(撮影で確認: 画面の中央)
- 測り方を「実際に描かれたか」+「カメラの位置」のどちらかで映っていれば画面内、に直した → 上下2段・斜め・横の全部で 0 フレーム(下の 9)

## 5c. 斜め上から見た時、ボスが細い縦の帯に見える(新しく見つけた不具合・直した)
- ボスの絵は格子のセル(66枚)に分かれている。斜めの表示ではセルを1枚ずつその場でカメラへ向けていたので、セルの並び(世界の横方向)だけが斜めのカメラで約2割に縮み、セルが重なって**細い縦の帯**に見えていた(メカドラゴンで発見。格子のセルを使う全ボス共通。2026-10-11 の斜め表示の対応から)
- セルの位置もボスの中心からカメラへ向けて回し、ボス全体を1枚の絵として向けるように直した(当たり判定・攻撃範囲は動かさない)

## 8. ラッシュ中の単独戦(暫定。進行の仕様は今回変えていない)

**今の動き**(第1弾で入れた「Solo」の印。メカドラゴンだけに付く)
- メカドラゴンの番が来ても、他のボスが生きている間は出さない(`SOLO(wait others)`)
- メカドラゴンが居る間は、次のボスを出さない(`SOLO(alive)`)。倒した後で、待たせたボスを順に出す
- 元のラッシュの仕様: 90〜98km で1kmごとに次のボス、同時に最大3体(大型・空中などの組み合わせの上限あり)

**実測の流れ**(動画 video/rush_mech_solo_flow_暫定.mp4、960x540、黒剣士、攻撃力の上乗せなし)
| 距離 | 出来事 |
|---|---|
| 90,000m | 1体目 サーペント |
| 91,029m | 2体目 サイクロプス(サーペントと2体同時) |
| 92,000m | メカドラゴンの番 → サイクロプスが居るので**待つ** |
| 92,778m | サイクロプスを倒した後にメカドラゴン(**778m 遅れ**) |
| 93,000m | 次のゴーレムの番 → メカドラゴンが居るので**待つ** |
| 94,000m | レヴィアタンの番(ゴーレムの後ろに並ぶ) |
| 94,428m | メカドラゴンを倒した → ゴーレム(**1,428m 遅れ**)、3秒後にレヴィアタン(520m 遅れ)が続けて出る |

**もう1回の実測**(縦画面・斜め上から、同じ条件): メカドラゴンの番は 95km だったが、他のボスが常に1〜3体残っていたので**99,000m(ラッシュの最後、9体目)まで待った**(4km の遅れ)。プレイヤーの火力が低いと、メカドラゴンがラッシュの最後へ押し出される

**こうした理由**(第1弾の判断。測った根拠ではなく設計の判断)
- メカドラゴンの攻撃は「帯の色で、跳ぶ/地面にいる、を指示する」作り(赤い帯 = 跳ぶ、紫の帯 = 地面にいる)。他のボスの低い攻撃(跳んで避ける物)と重なると、指示が食い違って避けられない場面が作れる
- 空襲・照射・バルカンは画面の広い範囲を使い、弾も最大 14 発出る。他のボスと重なると画面が読みにくくなる

**影響**: ラッシュの後半のボスが遅れて出る(上の例で約1.4km)。倒した直後に待たせたボスが続けて出る。火力が低いとメカドラゴン自身が最後(99km)まで押し出される。ラッシュの距離の中で出し切れない時は、計画の後ろのボスが出ない可能性がある

**選択肢**(マスターの判断用)
- (a) 今のまま(単独戦)
- (b) Solo を外す(他の規則 = 同時3体・空中/大型の上限 はそのまま)
- (c) メカドラゴンをラッシュの候補から外す(関門の希少な強敵だけにする)
- (d) メカドラゴンの番の時だけ、他のボスを先に退かせる演出を入れる(出る距離は遅れない)

比較の測定(開発版だけの切り替え `-mechRushNoSolo 1`、製品の動きは変えない): 下の 10

## 10. 比較: Solo の規則を外した時(開発版だけの切り替え。製品の動きは変えていない)
条件: 黒剣士・横画面・攻撃力の上乗せなし・被弾あり(`-mechRushWeak 1 -mechMortal 1`)、撮影なし。2回ずつ

| | 1回目 | 2回目 |
|---|---|---|
| Solo あり(今) | 420秒待ってもメカドラゴンが出なかった(96km の番から `SOLO(wait others)` のまま) | 92km の番 → 92,809m で単独(他のボスは最大1体=メカドラゴンだけ)。次のワームは `SOLO(alive)` で待った |

- フレーム時間: Solo なしで3体同時・弾最大16発でも 99% 16.9ms・最大 36ms(Windows)
- 分かった事: **Solo を外してもメカドラゴンは遅れて出る**(メカドラゴンは「空中・大型・飛び道具」の印も持つので、同時の上限・大型/空中の上限で待つ)。遅れの主な原因は Solo だけではない
- 被ダメージの比較は今回の測り方(HP の増減)ではレベルアップの回復が混ざって比べられなかった(1回はマイナス)。必要なら被弾の記録で数え直す
