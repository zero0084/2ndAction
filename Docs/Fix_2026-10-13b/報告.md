## Android で確かめて欲しい事(APK 302)
1. **距離の解放**: 新しいデータ等で 1,000m を越えた所で「解放条件達成: … / ランを無事に終えると確定します」が出る → わざと倒れる → 闘技場/結果で解放されていない。もう一度 1,000m を越えて脱出成功 → 結果に「NEW: 新しい敵: ELITE GOBLIN」
2. **中断→再開**: 1,000m を越えた後でアプリを閉じる → CONTINUE → お知らせが2回目に出ない → 脱出成功で確定
3. **カードの説明**: 合成カードの詳細(能力ごとの Lv と数字)、FINAL EVOLUTION の3択(説明に秒数が無く、カードの下の数字だけ)。日本語以外(英語など)で文が出るか
4. **ガチャ**: 同じ新カードを続けて2回 → 1回目 NEW、2回目 DUPLICATE
5. **ランキング**: 機内モードで開く → 「順位を読み込めませんでした」、成功したランを機内モードで終えた後 → 「送信失敗・再送待ち」も一緒に出る。通信を戻して再送 → 消える
6. **縦画面の「斜め上から」**: ボス(どのボスでも)が細い帯ではなく、ちゃんとした形で見える。当たり判定の位置に違和感が無いか
7. **合成画面(縦画面)**: カードの下の「所持/使用可」「能力/★」が切れない。ちょうど Lv.9 になる同名合成で「Lv.9 MAX 到達!」
8. **メカドラゴン**: 実機のフレーム時間(弾が多い時・必殺技の始まり・登場の時に引っかかりが無いか)。斜め上から見た形
9. **Shield と落下**: Shield を持ったまま穴に落ちる → Shield 1つで足場へ戻る(全部は減らない)
