# 判断が必要な項目(2026-10-13 第2弾)

今回は挙動・名前を変えず、「現状・選択肢・推奨案・変更の影響」をまとめた。

## 1. クレジットの正式表記
- **現状**: エンドロール(StaffCreditsData.cs:54-56)は GAME DESIGN = ESTELLE / ART / DESIGN = ALICIA / (IRENE) など、コード上の仮の名前。役職の GAME DESIGN と ART / DESIGN の担当範囲も重なる。巨大な文字の足場は A〜Z・0〜9・一部の記号だけ。
- **選択肢**: (a) マスターの活動名(+スタジオ名)だけ (b) マスター+「AI ASSISTED」等の1行 (c) 今の仮名を正式名として残す
- **推奨**: (b)。人の名前は実名か活動名、AI の協力は個人名ではなく役割の1行にする(公開後の問い合わせや誤解を避ける)
- **影響**: Resources/LastDungeon/StaffCredits.asset の文字列だけ(足場の文字は A〜Z なのでローマ字表記)。翻訳は不要(英字のまま)

## 2. GIANT SLAYER の名前と効果

- **選択肢**: (a) 名前を効果に合わせる(例: HEAVY BLOW / 剛撃) (b) 効果を名前に合わせる(大型/ボスへの攻撃+ を足す = バランスの変更)
- **推奨**: (a)。cardId(giant_slayer)は保存データに入っているので変えず、表示名だけ変える
- **影響**: カードのアセットの表示名 + 30言語の訳。所持・デッキ・合成は cardId なので影響なし

## 3. PHOENIX REBIRTH(不死鳥の必殺技名)

- **推奨**: (c)。技名は技の中身に、復活は見出しで知らせる(倒したのに戦いが続く理由が分かる)
- **影響**: SkyBossesBattle.cs の技名 + 見出し1つ(30言語)。強さは変えない

## 8. Shield が落下で消費される仕様
- **現状**: Shield は落下のダメージも防ぐ(1つ使う)。**今回直した不具合**: 防いだ時に足場へ戻していなかったため、落下の判定が毎フレーム続き、Shield を全部使い切ってから被弾していた → 1つ使って足場へ戻るように修正
- **選択肢**: (a) Shield は落下も防ぐ(今の仕様。修正済み) (b) 落下は Shield で防げない(必ずハート1つ減る)
- **推奨**: (a) のまま、カードの説明に「Shield は落下も防ぐ」と書き足す。カードの短い無敵(LAST CHANCE 等)は落下を防がない(説明どおり)
- **影響**: (b) にするなら GameManager.TryDamagePlayer の Shield の判定に落下を除く条件を1つ足すだけ

## 9. インド系などの文字の形(画面内に収まるか とは別の検証)
- **「画面内に収まるか」**: 30言語×縦横で、はみ出し 0件(TextFit の記録)
- **「文字が正しい形で読めるか」**: 下の表(横画面の結果画面などを撮影し、拡大して目で確かめた結果)

  | 言語 | 形 | 見つけた崩れ |
  |---|---|---|
  | ヒンディー語(hi) | × | 結合文字が組まれず、子音の間にハラント(्)が見える(例 रिकॉर्ड・स्टेज) |
  | ベンガル語(bn) | × | ハサント/ya-phala/reph が落ちる(例 ব্যর্থ が বযরথ に見える、দূরত্ব) |
  | クメール語(km) | × | 下付き子音(coeng)が記号のまま、前後に分かれる母音記号がばらばら |
  | タミル語(ta) | ○ | 点(புள்ளி)は正しい表記。二つに分かれる母音記号も正しい |
  | ラオ語(lo) | ○ | 声調記号の重なりも読める |
  | ミャンマー語(my) | ○ | 前に回る母音記号も正しい位置 |
  | タイ語(th) | ○ | |
  | アラビア語(ar) / ペルシャ語(fa) | ○ | 文字の連結・右から左とも正しい(ゲーム側で並べ替え) |
  | その他(ラテン/キリル/CJK/ハングル) | ○ | |
- **原因**: ゲームの文字の描画(Unity の旧 Text / IMGUI)は、文字を組み合わせる処理(結合文字・前に回る母音記号・下付き子音)をしない。フォントに字はあっても、正しい形に組まれない
- **直し方の候補**:
  - (a) 文字の描画を UI Toolkit の高度な文字生成(Unity 6、HarfBuzz で組む)に移す — 画面の作りを大きく変える(今の IMGUI/uGUI の全画面)
  - (b) 対象の言語だけ、文を前もって組んだ画像(またはフォントの合字)で出す — 文の数が多く、文が変わるたびに作り直し
  - (c) 対応できるまで、その言語を言語の一覧から外す(または「試験的」と表示)
- **推奨**: 公開の時点では (c)、長期的には (a)
- **影響**: (c) は言語の一覧(Loc の言語の定義)だけ。(a) は大きな作業
