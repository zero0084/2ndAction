# 道中の変化(道中イベント・空中ボスの乱入・敵の増加)/ 序盤の小型雑魚を一撃に(2026-11-04)

目的: 「次のボス地点までただ走る」時間を減らす。敵は「硬い」より「多い・危ない・倒すと気持ちいい」。序盤から「斬り抜けて走る」。
APK 429 の方針(0〜20km は 1km ごと / 20〜90km は 5km ごと / 10km ごとに大ボス / 90km 以降の終盤 / 雑魚は倒しやすく被ダメージは中盤から上がる / 背景の旅 / 死神は即死 / ラスダンは対象外)はそのまま。

値はすべて Inspector で直せる: `RoadEventTuning`(道中イベント・乱入)/ `DifficultyTuning`(密度・小型雑魚の HP の上限)。
asset(`Resources/Balance/RoadEventTuning`, `Resources/Balance/DifficultyTuning`)が無ければコードの既定値。
比較用(開発版): `-roadEvents 0`(道中イベントなし)/ `-airRaid 0`(乱入なし)/ `-densityV1 1`(APK 429 の密度)/ `-hpCapOff 1`(HP の上限なし)。

## 1. 道中イベント(Encounters/RoadEvents.cs)

20〜90km を 5km の区間に分け、区間ごとに 1 回(確率 90%)、次から 1 つ。中身は今までの Formation のまま(1 か所に重ねない)で、
間隔・休憩・激しさ・Formation と敵の選び方の重みだけを変える。

| イベント | 中身 | 長さ | 知らせ |
|---|---|---|---|
| 敵ラッシュ | 間隔 ×0.5・休憩なし・激しい寄り(終盤の大群の段階 1 くらい) | 24 秒 | WARNING HORDE / 地響きの音 / 前方の地面から砂ぼこり / 小さな揺れ |
| 飛行編隊 | 飛ぶ敵の組 ×4・地上だけの組 ×0.25・飛ぶ敵 ×4・間隔 ×0.75 | 22 秒 | WARNING <飛ぶ敵> / 風と羽音 / 4 つの影の V 字の編隊が前から |
| 強敵の混成 | HP 1.5 倍以上の敵 ×5・激しい組 ×2 | 22 秒 | WARNING <強敵> / 重い足音 2 回 + 揺れ |
| 追跡 | 速い敵(追跡/突進)×5・間隔 ×0.75 | 20 秒 | WARNING <追跡の敵> / 風切り音 / 後ろの地面から砂ぼこり |
| 空中ボスの乱入 | 下の 3 | 撃破か 60 秒 | 下の 3 |

- 選び方の重み: ラッシュ 1.0 / 飛行 1.0 / 強敵 0.8 / 追跡 0.6 / 乱入 0.9。その帯に居ない種類の敵のイベントは選ばない(例: 天空に追跡の敵は居ない)
- 区間の中の位置: 5km の関門の 0.8km 後〜次の関門の 1.0km 前。10km の関門の後(門 → 内部 1.2km)は 1.6km 後から
- ボス戦/BONUS ZONE/門をくぐる間/カウントダウン中は始めない(80m ずつ後へ。区間の窓を過ぎたらその区間は無し)
- 文言は訳済みの「WARNING  {0} が迫る!」だけ(新しい文は無し。{0} は敵の表示名/HORDE/ボスの名前)

### 背景の旅とのつながり
- 章の後半(5〜10km、目的地の城/結晶/神殿へ近づく区間): 敵ラッシュ ×2・強敵 ×1.5。敵ラッシュは目的地の目の前(章の 8.2〜9.0km)に置く = 「城門の前で敵ラッシュ → 関門の大ボス → 門 → 内部」
- 章の前半(0〜5km、内部を抜けた後): 飛行編隊 ×1.5・追跡 ×1.3・乱入 ×1.2
- 天空回廊: 飛行編隊 ×1.6・乱入 ×1.5(空の旅)/ 自然洞窟: 強敵 ×1.3(地底の大物)
- 門をくぐる時に小さな風の音(LandmarkJourney)

## 4. 序盤の小型雑魚の HP の上限(DifficultyTuning.CapSmallHp)

マスターの追加の依頼「序盤から走りながら一撃で斬り抜ける爽快感」。

- 基準 = カードなし・初期状態の黒剣士の前攻撃 1 段目の威力(20)。普通の小型雑魚(HP 倍率 1.25 以下)の HP の上限 = 基準 × 下の値
- 中型(HP 倍率 1.25〜1.75: 兵隊アリ/ガーゴイル/雷精霊/天空の狩人…)は小型の 3 倍(黒剣士で約 3 発)。大型(1.75 以上)・BONUS の宝の敵・ボスは上限なし(今までどおり)
- 上限はカードの成長に関係なく決まった値 → カードで攻撃が上がると、より遠く/より多くの敵が一撃圏内に入る(成長の意味は残る)
- 「敵が硬くなる」カードの倍率は上限の後に掛ける

| km | 0 | 20 | 30 | 40 | 50 |
|---|---|---|---|---|---|
| 上限(基準の何発分) | 0.95 | 0.95 | 1.9 | 4.5 | 12(= 上限が効かなくなり APK 429 の HP へつながる) |
| 小型の HP(上限の後) | 19 | 19 | 38 | 90 | 今までどおり |
| 小型の HP(APK 429) | 50 | 150 | 175 | 200 | 228 |

## 6. エステルと相談した内容(実際の画面の連番シート)

1 回目(31〜35km・71〜75km の走行動画、乱入の連番): 敵の数は概ね良好(今の密度を基準に、これ以上増やさなくてよい)、背景とのつながりは良好(目的地へ近づく後半にラッシュ/強敵)。改善: 乱入の予兆と飛行編隊の分かりやすさ。
- A 乱入の予兆: 影は黒に近い単色(65〜75%)、後ろ → 頭上 → 前へ約 1 秒、0.5 秒から WARNING 1.2 秒 + 短い咆哮、全体 1.6 秒、画面は揺らさない
- B 飛行編隊: 4 つの影の浅い V 字(先頭 1.5 倍・残り 1.2 倍)、羽音と WARNING を同時、揺らさない
- C 60 秒で逃げる: 攻撃をやめて上昇 → 向きを変える → 右上の画面外へ(約 1.2 秒)、HP バーは外へ出るまで残す、薄れて消さない、WARNING は出さない
2 回目: A/B/C 採用。影の位置(乱入 = 上から 28%、編隊 = 帯より上の 15〜25% で間隔 1 割詰め)、逃走は画面外へ出きってから。後回しのカード選択は出きった後。天空の乱入ボスの HP はまず 90%
3 回目(逃走の撮り直し): そのまま確定。「ここからは見た目より実機の高速走行での視認性」
