ゲーム本体・行動(Action)・設定の土台は共通にして、入口(タッチ / キーボード / マウス / ゲームパッド)と設定の項目だけを環境に合わせて切り替えるようにしました。

- 旧 Input Manager だけを使っています(新しい Input System は入っていません)。

## 4. キー設定(設定 → 操作 → キー設定)

**画面**
- 設定と同じパネルの中で、中身だけ「キー設定」のページに切り替わります(UiTheme・金/紺のまま)。
- タブ: 「キーボード・マウス」(キー1 / キー2 / マウス)、「ゲームパッド」(ボタン1 / ボタン2)。
- 表の段: 「ラン中の操作」「メニューの操作」。メニューの行にはマウスの欄がありません。
- スクリーンショット: `shots/O_keys_keyboard.png`、`shots/O_keys_gamepad.png`

**変える**
- 欄を押すと「新しいキーを入力してください」と出て、次に押した入力を割り当てます。
  - パッドの欄は「新しいボタンを入力してください」、マウスの欄は「マウスのボタンを押すか、ホイールを回してください」です。
- 欄を押した指やボタンが離れてから受け付けます。
- 待ち受け中はメニューの移動を止めます。十字キーやスティックも割り当てに使えます。
- 取り消し: Esc、「キャンセル」、10秒で自動。
- 「割り当てなし」で欄を空にできます。

**重複**
- 同じ場面(ラン中 / メニュー)の中で、もう使っている入力を選ぶと次の確認が出ます。
  - 「このキーはすでに「○○」に使われています」→「入れ替える」/「キャンセル」
  - 入れ替えると、相手の行にはこの欄の前の入力が入ります。
- 固定の入力(例: メニューの ↑)を取ろうとした時は、「この操作のキーは変えられません」と出て、キャンセルだけになります。
- ラン中とメニューの間では同じキーを使えます(Space = ジャンプ / 決定 は今までどおり)。
- Esc は割り当てられません。

**初期化と保存**
- 「初期設定に戻す」は確認の後、全部を初期の表に戻します。保存した割り当ても消します。
- 保存は設定のデータ(SettingsSave)の `InputBindingsV1` です。
  - 進行のデータとは別で、SaveKeys に登録しています。
  - 変えるたびにすぐ保存します。
- Android は PC のキー設定を読みません。今までの固定の表のままです。

## 5. 入力機器の切り替えと操作の案内

**最後に使った機器**
- キーボード / マウス / ゲームパッド / タッチの4種類です。
- マウスは、ボタン・ホイール・大きく動かした時に切り替わります。机の振動くらいの小さな動きでは切り替わりません。
- フォーカスの枠(メニュー操作)は、キーボードとパッドの時だけ出ます。マウスとタッチの時は出ません。
- ゲームは止まりません。ランの途中で機器を変えても、走り続けたまま操作が効きます(試験 U)。

**同じフレームの二重発火**
- 複数の機器から同じフレームに入っても、技の要求は1つにまとまります。
- 試験では、D + パッド X + 右スティック→ を同時に入れて、前攻撃が1回だけでした。

**操作の案内**
- 練習(チュートリアル)の「前: …」「ジャンプ: …」などは、PC では今の割り当てを最後に使った機器で出します。
  - 例: キーボードなら `[D] [→]`、マウスなら `[左クリック] [D] [→]`、パッドなら `[X] [RS →]`
  - キーを変えると案内も変わります。
- 脱出の案内:
  - キーボード: `[H]を3秒長押し`
  - マウス: 「マウスの左ボタンを3秒長押し」
- Android(Bluetooth のキーボード/パッドを含む)は今までの文のままです。

## 7. Windows の画面設定(設定 → 画面)

**表示モード: フルスクリーン / ウィンドウ**
- このゲームの Windows 版は DirectX 12 です。
- Unity では、排他のフルスクリーンを指定してもボーダーレスの全画面になります(Unity の説明と試験で確認)。
- そのため「フルスクリーン」は全画面のウィンドウ(ボーダーレス)で、今までの既定と同じです。「ボーダーレス」を別に並べると同じ物が2つになるので、出していません。

**解像度**
- 画面が対応している大きさの一覧(960x540 以上)から選びます。
- ウィンドウの時は、デスクトップより大きい物は出しません。

**適用と確定**
- 「適用」を押すと、「この表示のままにしますか？(10秒後に元に戻ります)」と出ます。
- 確定しないと元に戻ります。画面が見えなくなっても戻れます。
- 保存するのは確定した時だけです。
- 設定を閉じた時や Esc の時も元に戻ります。

**垂直同期 / FPS 上限**
- 選択肢: 垂直同期 ON(既定)/ OFF、FPS 上限 60 / 120 / 144 / 無制限。FPS 上限は垂直同期が OFF の時だけ選べます。
- 先に、ゲームの速さが FPS で変わらないことを確かめました(下の表)。

| FPS 上限 | 実際の FPS | 10秒で進んだ距離 | ジャンプの高さ |
|---|---|---|---|
| 60 | 56 | 50.1m(毎秒 5.00m) | 1.950 |
| 144 | 122 | 50.0m(毎秒 5.00m) | 1.950 |
| 無制限 | 181 | 50.0m(毎秒 5.00m) | 1.950 |

**安全な初期値**
- 保存が無い間は何も変えません(Unity の既定: 全画面・画面の解像度・垂直同期 ON)。
- 保存のキー: `DisplayModeV1` / `DisplayResolutionV1` / `VSyncV1` / `FpsCapV1`(設定のデータ)

## 11. Android への影響

- タッチ / フリック / タップ / 二段ジャンプ / カード選択 / ホーム / 縦横 / Safe Area / 高速補助は、変えていません。
  - タッチの道(`PlayerController` のフリック・タップ)は、マウスの左クリックの割り当ての1行(PC だけ)以外、そのままです。
- 割り当ては今までの固定の表のままです(Bluetooth のキーボード/パッドも同じ)。キー設定は出ません。
- 設定画面は今までと同じ項目です(画面の向き・縦画面のラン表示あり、キー設定・画面なし)。
- 細かい変更が2つあります:
  - 設定やチュートリアルの説明などの板が開いている間は、キー/パッドの技も出さないようにしました。タッチは前から止まっていました。
  - マウスの4番目以降のボタンは、キーボードを使った判定に数えないようにしました。
- エミュレーター(APK 371)で確かめました:
  - Android の設定(`-qaInput` の android): 今までの固定の表、キーボードの Z = 前 / B = 後ろ → 合格。
  - adb の本物の指: タップ = 前攻撃(3回とも)、左右のフリック = 前/後ろ、上 = ジャンプ → 二段ジャンプ、空中で下 = 下攻撃。
