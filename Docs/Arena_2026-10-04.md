# 開発用「闘技場」(2026-10-04)

キャラ・カード・敵の動作やバランスを短時間で確かめる試験場。

- 好きな条件を決めて戦い、カードや能力を変えて、同じ条件ですぐ再戦できる。
- 開発版(Editor / Development Build)だけ。リリース版には入口も処理も無い(`ArenaMode.Active` が常に false)。

## 1. 入口と通常データの保護

- 入口: ホームの DEBUG → 「闘技場(キャラ/カード/敵の試験、DEBUG RUN)」。
- 試験は **DEBUG RUN**(既存の仕組み)で行う。
  - BEST / MILE / 所持カード / 通貨 / 累計距離 / 解放 / 中断データ(CONTINUE)/ 選択中のキャラは保存しない。
  - 保存の入口で止めたうえで、開始前の値へ戻す。
- キャラは未所持/未解放でも選べる。カードも所持に関係なく試験用のビルドへ足せる。
- 退出(ホームへ / 停止メニューのホームへ戻る)はシーンを読み直す。試験の設定はすべて戻る:
  - 速度の指定
  - 闘技場の無敵
  - 操作アシスト(保存されている設定を読み直す)
  - 止めた仕組み(出現 / 障害物 / 関門 / BONUS / 雲)
  - 距離の固定
- 既存のカード調整(CARD BALANCE TEST)と同じく、ゲームのカードの処理をそのまま使う(下の 3)。

## 2. 闘技場と速度

- 見た目: 石畳の床(石の積みの模様)と、奥の観客席(8段の観客・アーチの壁・柱・旗・空)。
  - どちらも手続き生成の仮素材。
  - 床は模様を世界の位置にそろえてカメラに合わせて並べ直し、観客席は少し遅れて流れる(視差)。
  - 走り続けても端に着かない。
- 地面: 闘技場では、これから作る地面をすべて平地にする(`TerrainManager.ConfigureArena`)。
  - 穴・坂・分岐・空中足場・天井(洞窟)・飾り・チャンクの敵は作らない。
  - 障害物(ObstacleSpawner / EnemyWallManager)と通常の出現(EncounterDirector)は止める。
  - プレイヤーは開始時に、新しく作った平地の上へ置く。
- 速度(自然加速は止める):

| 指定 | 動き |
|---|---|
| 0 km/h(または「停止」)| **自動前進だけ**を止める(速さ 0)。時間・攻撃・ジャンプ・重力・ノックバック・敵の行動・クールダウンは通常どおり。座標の固定やゲームの停止はしない。構えの立ち姿 |
| 基準速度 | 指定の km/h × キャラ×カードの補正(走る速さ / 共通の基本速度)。自然上限も掛けない |
| 実効速度固定 | 指定の km/h そのもの。カード/キャラの速度の補正は移動に入れない(画面に明記)|

- 指定方法: プリセット 0 / 30 / 60 / 100 / 150 / 200 / 300 km/h と、数値の入力(0〜600)。
- 画面には「基準」「実効(今の実際の速さ)」「補正の倍率」を出す。
- ボスや弾も同じ速さで流れる(通常どおり、自動前進の速さに合わせる)。

## 3. キャラとカード

- 全12キャラ。キャラ固有の能力/攻撃は通常どおり(同じ処理)。
- カード: 検索(名前/ID)と分類(移動/攻撃/防御/成長/回復/特殊/リスク)で探して「+ 追加」。
  - ビルドの各カードに取得Lv(ラン中のLv。能力ごとに最大9)を `-` / `+` / `×` で付ける。全解除あり。
- 所持カードのコピー: 所持している合成カード(Lv2 以上、能力一式)をそのまま試験に入れる。
  - 「所持コピー 合成Lv n 能力 m種 ×回数」と表示し、ラン中の取得Lvとは別に見せる。
- 毎回キャラの基準値(キャラカードも外す)から、レベルアップで選んだ時と同じ処理(`ApplyUpgradeByCardId`)で掛け直す。
  - 能力ごとの Lv9 上限もこの中。
  - 「適用して再戦」でシーンを読み直すので、追加/解除を繰り返しても効果は残らない(自動テストで確認)。
- 表示: HP(封印)、攻撃力(カードの倍率)、攻撃速度、範囲、Shield、速度(基準/実効/補正)、ジャンプ力/回数、距離条件(雑魚の基本HP)、ビルド。

## 4. 敵の呼び出し

- 一覧:
  - 雑魚(全種、AI Tier T0〜T4 を選ぶ)
  - 荒野ボス 11種 / 洞窟ボス 11種 / 天空ボス 11種
  - 動かない標的
- 設定: 種類 / 数 / 前方の位置(m)/ 間隔(m)。構成として複数を並べる(個別に削除 / 構成を空に)。
- 動かない標的: ゴブリンの体で、動かず攻撃もしない(接触ダメージなし、HP 99,999,999、ノックバックなし)。
  - 走っている時はプレイヤーとの間合いを保つ。
- 距離条件:
  - 敵の強さ(雑魚の HP / 段階、ボスの関門の番号 → ボスのHP)に使う距離。
  - 試験の間はこの値で止める(距離を進めない)。
  - プリセット 0 / 1 / 5 / 10 / 30 / 50 / 99 km と数値の入力。
- 起きないようにしたこと:
  - 距離のイベント・EXP・解放・中断の保存
  - 自動のボスの関門
  - BONUS ZONE
  - 死神/三姉妹(距離条件 99km でも出ないことを確認)
  - ボスの報酬のカード選択 / レベルアップ(EXP 停止)
  - エンディング(荒野街道なので無し)
  - ボスの「時間でラン再開」
- 全敵削除(雑魚/ボス)と、同じ構成での再戦。
- 敵の AI / 予兆 / 攻撃 / 必殺技 / 被弾反応は通常のまま(通常の生成の処理で出す)。

## 5. 操作と試験用の機能

- 操作: 通常のフリック。
- 左のボタン列(戦闘中):
  - ≡ 設定
  - 同条件で再戦
  - 試験を終える(結果)
  - HP全回復
  - 無敵 ON/OFF(初期 OFF。闘技場だけの設定で、通常の無敵の設定は変えない)
  - 敵を全削除
  - ホームへ退出
  - このボタンの上で始めたタッチは、攻撃/ジャンプのフリックにしない。
- 操作アシスト(闘技場の中だけ、保存しない): OFF / 高速時のみ(開始の速さ km/h)/ 常時(0km/h から)、「障害物を壊して通る」「着地前の二段ジャンプ」。
  - 既存の設定画面は「高速時の補助 ON/OFF + 開始速度」で、「常時オート」は無かった。そのため闘技場の中だけの指定として、既存の補助の処理にこの3つを渡す形にした。
- 設定パネルを開くと試験を止める(ゲームの時間を 0。計測/戦闘/敵が進まない)。閉じると再開。
  - 閉じた後は今の指が離れるまで入力を通さない(パネルの操作が攻撃/ジャンプにならない)。
- キャラ・ビルド・敵の構成・速度・距離条件・シードの変更は、止めた状態で編集して「適用して再戦」で反映する。無敵・HP・操作アシストはすぐ反映。

## 6. 再戦と計測

- 「同条件で再戦」(ワンタップ): シーンを読み直して同じ設定で作り直す。
  - 保持: キャラ / ビルド / 速度 / 敵の構成 / 距離条件 / シード / 操作アシスト / 無敵。
  - 初期化: プレイヤーの位置 / HP / 状態異常 / 攻撃の状態 / クールダウン、敵の位置 / HP / 行動、残った飛び道具 / 設置攻撃 / 演出、計測。
- 乱数のシード: 固定(既定 12345)して毎回同じ値で始める / 指定 / 新しいシード。敵の行動の乱数(Unity の Random)に使う。
- 計測:
  - 与ダメージ
  - 命中数(敵/ボスへのダメージの回数。継続ダメージ/追加攻撃も含む)
  - DPS
  - 被ダメージ(実際のHP減少)
  - 本来の被ダメージ(無敵/シールド/カードの無敵を含めて、受けるはずだった量)と、その回数
  - 撃破数
  - 戦闘時間
  - 全滅までの時間
  - 結果(全滅 / 手動で終了 / 倒れた)
- 時間はゲームの時間(停止中は進まない)。
- 全滅すると「全滅 n秒」を出して計測を止める。倒せない試験(0km/h で標的だけ等)は「試験を終える」で結果を出せる。
- 倒れても(HP 0)ランは終わらない。試験を終えて結果を出し、HP を戻す。「同条件で再戦」ですぐやり直せる。
- 直前の結果を残し、今回と並べて比べる(「同条件で再戦」で今回が直前になる)。

## 7. 表示

- 戦闘中は、上の中央(Lv/EXP の下)に1行の計測と、左のボタン列だけ。設定パネルは閉じられる。
- Android の横画面向けに、全体を画面の短辺 720px 基準で拡大(ボタン 44〜48px 相当)。戦闘の中央を隠さない配置にした。
- ソロの試験場(マルチでは開かない)。

## 9. 未対応・制限

- 闘技場の地形は荒野街道。洞窟ボス/天空ボスも荒野街道の上で出す。
  - 洞窟の天井・天空の足場に依る動き(潜る/飛ぶ高さの基準など)は、本来のステージと違う見え方になることがある。
- ボスの出現位置は、ボス自身の登場(前方から走り込み/間合い)で決まる(前方の位置の設定は雑魚と標的だけ)。
- 三姉妹(ReaperBase)とラスダンの演出は呼べない。
- 「敵を全削除」は敵/ボスを消すだけで、残った飛び道具は消さない(「同条件で再戦」なら全部消える)。
- 乱数のシードは Unity の Random。地形の乱数(平地なので影響なし)・時間による揺らぎ(フレーム時間)までは固定しない。
- 闘技場の中で ULTIMATE を使うと、平地の上を前進する(距離は進まない)。
- 見た目(床/観客席)は手続き生成の仮素材。
- Android 実機では未確認。
