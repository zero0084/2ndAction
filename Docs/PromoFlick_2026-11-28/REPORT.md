## フリックの表示
- **撮影時の入力**: 本物のタッチと同じ入口(開発用の仮想の指 `PlayerController.DebugPointer`)で入れています。指を置き、4コマで画面の高さの11%動かし、離します。
  - 技を直接呼んでいません。
  - 自動攻撃と自動回避(補助)は切っています。攻撃はすべて手のフリックです。
  - 横画面だけ、穴を越えるための自動ジャンプを入れています。攻撃は手のフリックです。
- **記録**: 撮影中、各コマの指の位置(画面に対する割合)と押しているかを `capture/<表示>/raw/<場面>_touch.tsv` に残しています。出た技は `_flicks.tsv` です。
- **表示**: 編集はその記録どおりに描いています。
  - 置いた所に白い丸、動いた向きに金の線と矢印を出します。
  - 離してから0.3秒で消えます。
  - 記録の無い所には何も足していません。
- **確認**: 冒頭の上フリックでは、1.98秒に指が触れ、2.03〜2.08秒に上へ動き、2.08秒にキャラが攻撃して敵が打ち上がります。表示と動きの一致を、コマ送りで確認しました。
- **置き場所**: 指はキャラ・敵・HP・コンボ数と重ならない空の所に置いています(縦は画面の中ほど、横は道より上)。
  - 横画面は最初、道の高さに置いたため斬撃に重なりました。指の位置を変えて撮り直しています。

## 撮影と編集のやり方(後で直す時)
1. **撮影用ビルド**: Unity の `BuildStoreCapture.Build`。出力は `Unity/2ndAction/Builds/StoreCapture/OneMoreMile.exe`
2. **撮影**(表示ごとに1回。縦は 608×1080 の窓を2倍で録画)。台本は `Tools/qa/sis_video.sh` の cap の行です。
   - `OneMoreMile.exe -screen-width 608 -screen-height 1080 -fileSave <dir>/save.json -storeCapture <dir> -scShots pf_launch,pf_combo -scLang ja -scNoBonus 1 -scVideoSuper 2 -caps android -pview side`
   - 上下2段: `-pview fold -scShots pf_launch`
   - 斜め上: `-pview oblique -scShots pf_launch`
   - 横: `-screen-width 1920 -screen-height 1080 -scVideoSuper 1 -scShots pf_land`
   - キャラは `-pfChar`(既定 dual_blade = 双剣士)
3. **区切り**: `python make_edl.py <capture のフォルダ> edl_ja.json`
   - 区切りはフリックの時刻が基準で、技の途中で切らないようにしています。
   - `edl_ja.json` は手で直せます(秒・字幕・字幕の位置 caption_y / caption_size・BGM の音量)。
4. **編集**: `python edit.py edl_ja.json <出力.mp4> <作業フォルダ>`

撮影の生の素材(約3.6GB、`capture/*/raw/*.mkv` / `.wav`)と動画は Git に入れていません。この PC の `Docs/PromoFlick_2026-11-28/` にあります。
