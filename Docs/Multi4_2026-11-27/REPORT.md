## 3. 到達地点と終了結果

**CO-OP**
- L1: 94.5km(75分の上限で終了、死神の 100km は未到達)。
- ほかのランは 1〜20km で、全員 DOWN による自然な終わり。
- 個人の脱出: L1 で 12km、S2 で 3 人、D4 で 1,200m。
- 確認した終わり方: DOWN → 長押し復活、全員 DOWN、個人の脱出。脱出した人はホームで待ち、次のランに再び参加できた。

**VERSUS**
- V1 の流れ: P4 脱落(#4) → P2 脱落(#3) → 5分で死神が乱入 → P1 脱落(#2)。P3 は 3km で脱出した。
- 順位ボーナスと死神ボーナスは、RESULT の表示額と保存額が一致した。

**ゲームクリアは未確認です。** マルチにはソロのような「ゲームクリア」が無く、終わりは死神です。死神(100km)まで自然な通し試験では到達しませんでした(L1 の 94.5km が最長)。

## 4. 4人それぞれのデータ照合

- **キャラ・デッキ**: 保存・ラン中・RESULT・再起動後を通して、各自のものから変わらなかった。他人と混ざった例は無い。
- **HP / 最大HP**: 他の人の画面の表と本人の値が、2 秒以上食い違ったことは 0 回(全試験)。
- **Lv / EXP / カード**: レベルアップとカードの選択は本人だけに起きた。同時のレベルアップや、他の人が選んでいる間の撃破も確認した。
- **MILE**: 全試験で RESULT の表示額 = 確定額 = ホームの所持(チャレンジの MILE を含めて計算)。対戦の持ち帰り、負けた時の喪失、脱出の持ち帰りを確認した。**修正前は 1 件ずれていた**(下の 6 章 ③)。
- **ボス報酬**: とどめの人だけに 1 回出た。ほかの人は脱出が解放されるだけ。
- **再起動後**: MILE・キャラ・デッキ・所持カード・BEST・累計距離が終了時と同じ。重複付与もデータ消失も無かった。
- **距離**: CO-OP のチーム距離は全員の画面で同じ。個人距離は置き直しの分だけ少ない(マスター判断で今のまま)。VERSUS は個人距離と順位が RESULT の行と一致した。

## 5. 座標・同期

- **残り続けるずれ**: LOCAL では無かった。最大値が大きく出たのは、置き直しの瞬間と、カード選択から戻る瞬間だけ。
- **ONLINE**:
  - 通信の遅れによる一時的な差(2.5〜4m が約 5 秒)が 1 回あった。ジャンプ中で ping が上がった時で、その後は戻った。
  - 敵の位置の差は p95 で 1m 前後、最大 3m 以内。
- **埋まり・浮き**: 本人の画面では 0 回。他の人の表示で 1m 前後のものが数回あった(坂・着地の補間)。
- **置き直し**: 安全な位置へ移動した。移動分の距離・距離の MILE・EXP は加算されなかった(WARPAUDIT で確認)。
- **選択・一時停止・ヒットストップ**: 無関係な人や世界は止まらなかった。

## 7. 退出・切断

- **参加者の退出・切断**(カード選択中 / ボス戦中 / DOWN 中 / RESULT 中 / 強制終了)
  - HOST は「P○が切断しました(残り○人)」と表示し、その人を出現範囲・終了の判定から外した。
  - 残りの人はそのまま続けられた。
  - RESULT 中に抜けた人の持ち帰りは正しく保存された。
- **HOST の退出・切断**
  - 参加者に「HOSTとの接続が切れました」と表示される。
  - ゲームが止まり、「このまま走る」(3・2・1 の後に 1 人で続ける)か「ホームへ戻る」を選べる。
  - 保存は壊れなかった。
- **MILE の分配人数**: 退出した後も、ランの始めの人数のまま(例 1/4)。今の決まり(途中で計算し直さない)どおり。変えるかどうかはマスターのご判断です。

  - 訳が入るまで、日本語以外では知らせを出さない(合流そのものは同じく動く)。
  - 今までのカード選択の後の置き直しでも、同じ知らせを出す。

**② 退出・切断の後の MILE の分配人数**
- 退出・切断が確定した人(状態が Out)を、それ以降の分配の人数から外す。
- DOWN・カード選択・一時停止・通信の遅れでは外さない。
- すでに配った分は計算し直さない。距離の MILE は「人数が変わるまでに走った距離 ÷ 前の人数」を固定し、その後の距離だけ新しい人数で割る。
- 撃破の MILE は、HOST が撃破を確定した時の人数を撃破の知らせに載せる。全員がその値で受け取るので、退出と重なっても二重配布や取りこぼしが起きない。
