# 起動ロゴ: Unity のロゴを消す / MIXGame の起動ロゴ(2026-10-24)

## 1. Unity のロゴの非表示(済み)

**設定**
- Project Settings → Player → Splash Image の **Show Splash Screen を OFF**、**Show Unity Logo も OFF** にしました。
  - `ProjectSettings.asset` の `m_ShowUnitySplashScreen: 0` と `m_ShowUnitySplashLogo: 0` です。
- Player の共通の設定なので、Windows / Android / 将来の iOS のすべてに効きます。
- Unity のロゴの絵(約2.7MB)もビルドに入らなくなりました。APK は 365 → 366 で 100,801 バイト小さくなっています。

**ライセンス**
- Unity の公式サポートの記事によると、Unity 6 から Personal でも起動ロゴを消す/変えることができます。
  - Unity 6 より前のバージョンでは、Personal では消せませんでした。
- このプロジェクトは Unity 6000.5.6f1 で、ライセンスは Unity Personal です(ビルドのログで確認)。有料プランへの変更は要りません。
- 出典: https://support.unity.com/hc/en-us/articles/212165803 / https://docs.unity3d.com/ScriptReference/PlayerSettings.SplashScreen-show.html

**確かめた方法**
- 起動の記録 `[Boot]` を足しました。Unity のロゴが出たかどうか(`SplashScreen.isFinished`)と、最初の画面までの時間をログに出します。製品版も同じです。
- Windows の製品版: シーンの読み込みの前の時点で `unitySplashFinished=True`(ロゴは出ていない)。
- Android(エミュレーター、APK 366): `unitySplash(show)=False`(ロゴは出ていない)。
- 比べるために作った試験版(Unity の起動ロゴの仕組みで自前のロゴだけを出す版)では `show=True` になりました。判定が正しく働いていることも確かめています。

**黒い画面について(気になる点)**
- Unity のロゴを消したので、ゲームの最初の画面が出るまでの間は何も描かれない画面になります。
  - Windows: 黒。起動から最初の画面まで、この PC で 約3〜5秒。
  - Android: OS の起動画面(濃い灰色)。
- 以前は、この時間の一部を Unity のロゴの演出が埋めていました。
- ちらつき(白い画面が一瞬出るなど)は、ログと Android の撮影では見つかっていません。
- 黒い時間を MIXGame のロゴで埋めるかどうかが、下の「実装方法」の選びどころです。

## 2. MIXGame の起動ロゴの実装方法(用意済み、ロゴの確定待ち)

2つの方法を用意して、実際に測りました。

| | 方法A: Unity の起動ロゴの仕組みに MIXGame のロゴだけを入れる | 方法B: ゲーム側で描く(BootSplash、作成済み) |
|---|---|---|
| 出る時期 | 起動してすぐ(この PC で約0.7秒)。読み込みと同時に進む | ゲームの最初の画面が出てから(約3〜5秒の黒い画面の後) |
| 黒い画面 | ロゴと背景色で埋まる | 埋まらない(今と同じ) |
| 起動時間 | ほぼ増えない(読み込みと重なる) | ホームまで 約1.6〜1.8秒増える(飛ばせば 約0.5秒) |
| 長さ | Unity の決まりで、ロゴ1つ2秒以上 + フェード | 自由(今は 0.4秒で出る / 0.7秒表示 / 0.4秒で消える / 背景 0.25秒) |
| 飛ばす | できない(読み込み中なので、飛ばしてもホームは早くならない) | タップ/クリック/キーで飛ばせる(ホームの準備ができるまでは待つ) |
| 動き | Unity の用意した寄り(Dolly)か静止だけ | 軽い寄り・フェードなど自由 |
| 対応 | Windows / Android / iOS で同じ設定 | 同じ(IMGUI で描く。横・縦で大きさを合わせる) |

**おすすめ(アイリーン)**
- 依頼の条件(1〜2秒、飛ばせる、読み込みは省略しない)を全部満たすのは **方法B** です。
- 「黒い画面を出さない」「起動時間を増やさない」を優先するなら **方法A** です。
- 正式なロゴが決まったら、両方を実機で見比べて、マスターに選んでいただくのがよいと思います。
- どちらも、正式な絵を1つ置くだけで切り替えられます。

**方法B(作成済み)の中身**
- ファイルは `Scripts/UI/BootSplash.cs` です。
- 正式なロゴの絵 `Resources/Brand/MIXGame_Logo` が無い間は、何もしません。今は絵を置いていないので、ゲームは今までどおりすぐホームへ進みます。仮の素材は入れていません。
- 起動して最初の1回だけ出ます(ラン → ホームでは出ません)。自動試験の時も出しません。
- 表示中はホームの操作を止めます。飛ばした指はホームのボタンへ通しません。
- 起動直後の重いフレームでフェードインが飛ばないように、演出の時計は1フレームで最大 1/30秒しか進めません。
- ロゴの大きさは、横画面は横幅の46%・高さの42%以内、縦画面は横幅の80%・高さの30%以内です。

**試した結果(開発版、試しの絵はプロジェクトの外に置いて起動引数で読ませた)**

| 場面 | 結果 |
|---|---|
| 横画面 | 1.75秒で終わる |
| 縦画面 | 1.76秒で終わる |
| 読み込み中(0.07秒)に飛ばす | ホームの準備まで待ってから 0.52秒で閉じる |
| 準備後(0.6秒)に飛ばす | 0.99秒で閉じる |

- 本物の指やマウスでの確認ではなく、開発版の「この時刻に押した」扱いの入口で確かめました。
- `candidates_board.jpg` の下の段が、C案をこの方法で表示した様子です。

## 3. MIXGame のロゴのデザイン(エステルと相談、候補3つ)

`candidates/`(画像生成はエステル)、一覧は `candidates_board.jpg`

| 案 | 内容 | エステルの評価 |
|---|---|---|
| **C案(本命)** | 三毛猫の顔のシンボル + 虹色の「MIXGame」+ 小さく「by マジル旅人」 | 長く使える・アイコンにも使える。表記も正しい |
| A案 | X のアイコンに近いマスコット + 虹色の看板 | 親しみやすい。情報量が多め。**表記が「MiXGame」(i が小文字)** |
| B案 | 文字だけ | 一番すっきり。個性は弱め。**表記が「MiXGame」(i が小文字)** |

- 参考にしたのは、マスターの X のアイコン部分だけを切り抜いた画像です(プロフィールの他の情報は渡していません)。
- A案・B案を選ぶ場合は、文字を正しい「MIXGame」で作り直します(エステルに頼むか、フォントで組み直す)。
- 「by マジル旅人」はロゴ本体に入れず、起動画面だけ MIXGame の下に 20〜30% の大きさで添える前提です(エステルの提案)。

**次の流れ**
1. マスターが案を決めます。修正の希望もあればお願いします。
2. 正式な素材を作ります: 背景が透明の高解像度 PNG と、「by マジル旅人」あり/なしの版。
3. 方法A / B のどちらで出すかを決めて組み込みます。
4. Windows の製品版と Android の実機で確かめます。

## 4. そのほか

- **Android の起動画面**: Unity より前に、OS が濃い灰色の画面を出します。将来、ここにアイコンや背景色を設定することもできます。
- **iOS**: 起動画面(Launch Screen)は今は既定のままです。iOS 版を作る時に、ロゴと同じ背景色に合わせるのがよいと思います。
- **保存の扱いの報告**:
  - 製品版の起動試験の1回目で、保存(レジストリ)の控えの書き出しに失敗していました。Git Bash が `/y` を書き換えたためです。
  - 削除も同じ理由で失敗していて、データは何も消えていません。
  - 起動で行われた保存の形式の更新(2 → 3)は、その前の控え(同じ日の 02:14)へ戻しました。バイト単位で一致しています。
  - 試験のスクリプトは、控えが取れなければ起動しない・戻した後に比べる、ように直しました。
