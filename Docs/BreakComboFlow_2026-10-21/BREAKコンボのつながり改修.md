# BREAK 中のコンボのつながり改修(2026-10-21)

APK 327 のボスの BREAK 中のエリアルコンボを土台に、**コンボが途切れる原因**(入力が消える・技が出ない・位置がずれて外れる)を
入力1回ずつの記録で突き止めて直しました。BREAK の長さ・HP・攻撃力は変えていません。

確認用 APK: **APK 339**(開発版)。Android 実機の手触りの確認をお願いします。

## 0. まとめ

| 依頼 | やったこと | 結果(自動試験) |
|---|---|---|
| 1. 竜騎士を中心に入力をつなぎやすく | 予約は1つ。技の最中は予約を消さずに待つ(入れてから0.9秒まで)。竜騎士は「当たったら早めに次の段」、↑で突きを切った時の待ちの持ち越しを廃止、急降下の締めの判定を前へ・太く | 竜騎士の命中 218/485(45%) → 346/491(70%)(同じ入力)。消えた入力 104 → 26 |
| 2. 高速時の位置ずれ | 洞窟の天井の段で雑魚が横に止まって置いていかれるのを「下げてくぐる」に。高速の段差で一瞬浮いた着地では寄せを終えない(0.25秒の猶予)。膝つきの大型で上がりすぎない | 12人 × 10場面: 命中 824/1076(77%) → 858/1080(79%)。大きく良くなったのは竜騎士・膝つきのサイクロプス・双剣士・吸血鬼 |
| 3. 協力の JOIN もコンボ | JOIN の打ち上げ/追撃/↓を HOST が判定して寄せる。基準は最初に打ち上げた人。ほかの人の命中で基準は替わらない | HOST / JOIN / 両方 × 4体: JOIN の命中 10/10、基準の入れ替わり 0、横の跳び最大 0.37m/フレーム |
| 4. 膝つきの見た目 | 止め絵の大型は縦につぶさず、脚を折って上半身を前へ倒す(格子の変形)。判定も同じだけ低く・少し前へ | 撮影 `images/膝つき_改修前後.jpg` |
| 5. 予告を締めの合図に | 予告の後も寄せを続けて少しずつ下げる(→ と ↓ が届く)。打ち上げ直しはしない(維持)。紫の輪+頭上で弾む紫の ↓ | 合図を見てから ↓: 締め 0/30 → 21/30 |

## 1. 調べ方(入力1回ずつ)

「13回入力して何回当たったか」では、重い技で回数が少ないのか、入力が消えているのかが分かりません。
入力1回ごとに次を記録する試験を作りました(`-qaChain`、開発版)。

| 記号 | 意味 |
|---|---|
| H | 技が出て、狙いの相手に当たった |
| W | 技が出たが外れた(その時の「当たる所」とのずれ dx, dy も記録) |
| C | 技は始まったが、攻撃が出る前に次の入力(↑など)で自分で切った |
| A | 受け付けたが技が出なかった(新しい入力に上書きされた、着地した 等) |
| R | 受け付けられずに消えた: e = 時間切れ / r = 次の同じ入力に置き換え(予約は1つ) / m = 連撃の次の段が既に予約済み / c = 被弾・停止で捨てた / i = 何も起きなかった(着地後の↓など) |

- 入力は本物の1回のフリックと同じく1フレームだけ入れます(以前の試験は2フレーム続けて入れていて、実際より入力が多かった)。
- ヒットストップ(命中の一瞬の停止)の最中に入れた入力も、本物の指と同じく先行入力になります。
- 比べるため、開発版だけの切り替え(改修前 = APK 338 の動き)を付け、同じ版で改修前後を測りました。

## 2. 入力のつながり(依頼1)

### 見つけた原因

| 原因 | 起きていたこと |
|---|---|
| 竜騎士: ↑で突きを切ると、その突きの硬直の待ち(3段目は約1秒)が残る | 再打ち上げの後の → が約1秒すべて受け付けられず、打ち上げ直した相手へ追撃できなかった(↑→→→↑→→→↓ の後半の → がほぼ全部消えていた) |
| 竜騎士: 急降下の締めの判定が足元の真下 ±0.23m だけ | 寄せた相手の手前の端(0.25m 先)に届かず、ぴったり寄っていても空振り |
| 先行入力が技の最中も時間切れで消える(0.45秒) | 1回の技が長い竜騎士(3段目 約1.1秒)の早めの入力が、出る前に消えた |
| 空中の再打ち上げを「入力が受け付けられた」と見ていなかった | ヒットストップ中に入れた ↑ が、受け付けられるまで毎フレーム出直す恐れ(入力の連打のように) |

### 変えたこと(全員共通)

- **予約は1つだけ**。新しい入力は前の予約を置き換えます。連撃の次の段(同じ向き)が既に予約されていれば、重ねて覚えません。
- **技の最中は予約を消さずに待つ**。技が終わる/次の段の受付が開いた瞬間に出します。ただし**入れてから0.9秒**たった入力は出しません(操作をやめたのに古い入力で攻撃し続けない)。
- 技が終わって動けるのに使えなかった入力(着地した後の ↓ など)はその場で捨てます(後でジャンプした瞬間に古い入力が出ない)。

### 竜騎士(重さは残す)

| 変えたこと | 内容 |
|---|---|
| 当たったら早めに次の段 | 突きが当たった時だけ、硬直の早めから次の段へ(1・2段目: 硬直の45% → 20%、3段目: 最後まで → 50%)。空振りの時は今までどおり重い |
| ↑で突きを切った時 | 突きの硬直の待ちを持ち越さない(次の → は1段目から) |
| 空中コンボの締めの急降下 | 判定を少し前(0.7m)・太く(約1.4m)。見た目の風圧も同じ所へ |

技の長さ・威力・突進の距離は変えていません。双剣士のような速さにはしていません。

## 3. 高速時の位置ずれ(依頼2)

| 原因 | 変えたこと |
|---|---|
| 洞窟: 雑魚が天井の段(急に低くなる天井)の前で横に止まる → 走るプレイヤーに置いていかれ、4.5m 離れて寄せが切れる(45km/h でも) | 段の下へ体が入るなら、下げてくぐらせる(下げる速さは毎秒20m まで、入りきるまで横に進まない = 天井を突き抜けない)。入らない時は今までどおり止まる |
| 高速(150km/h)の段差で、プレイヤーが一瞬浮いて着地しただけで「着地 = コンボの終わり」 | 着地から 0.25秒の猶予(その間に跳び直せば続く)。雑魚とボスの両方 |
| 膝つきの大型(動かない)に ↑ で上がりすぎ、体の上を空振り | 膝つきの相手とのコンボ中は、攻撃の当たる高さが体の上端の少し下で止まる速さに抑える |
| 協力の JOIN の画面で、ボスが HOST の自分のコンボの時より約1.6m 手前に見える(HOST が分身の少し前の位置に合わせていた) | 分身の再生の遅れと、JOIN がボスを描く時刻の遅れ(約0.07秒)の分だけ先の位置に合わせる → 差は約0.5m |

- 走行の速さは変えていません。遠くの敵は引き寄せません(今までどおり 4.5m/7m 以上離れたら寄せない)。
- コンボの終わり方は今までどおり: 当たらない(0.9秒)・着地(猶予の後)・敵が倒れる・BREAK の時間切れ。
- 雑魚の長い手動コンボ(上限30秒の安全装置)と、ボスの BREAK(延長の上限あり、締めの合図の後は延びない)は別のままです。ボスを無限に浮かせ続けることはできません。

## 4. 協力の JOIN(依頼3)

- **位置と BREAK の状態は HOST が決めます。** JOIN の打ち上げ/追撃/↓は今までどおり HOST へ命中を送り、HOST がそれを BREAK のコンボとして扱います(以前はダメージと崩しだけ)。
- **基準の人**: 最初に有効な打ち上げ(↑)を当てた人。HOST はその人の位置に合わせてボスを寄せます。
  - ほかの人も追撃できます。命中は滞空を延ばすだけで、基準は替わりません(左右に引っ張り合わない)。
  - 基準の人が離れた/倒れた/切断した/当てなくなった/着地した → 直前(0.5秒以内)まで当てていた人へ引き継ぎ。いなければ寄せを終えて落ちます。
- JOIN の端末には HOST から BREAK のコンボの状態(基準の人・受付中・締めの合図・浮き・膝つき)を送り、JOIN のプレイヤーの空中の補助(再上昇・狙いの補正)と、大型の膝つきの見た目に使います。
- CPU の仲間の攻撃は今までどおりダメージと崩しだけ(基準にはならない)。ダメージ・撃破・報酬は今までどおり HOST が1回だけ確定します。
- 大型(膝つき)は体を動かさず、JOIN も空中の追撃で当てられます。

#### 協力(HOST + JOIN の2つの端末、BREAK の0.6秒後から ↑→→→↑→→→↓ を0.3秒おき)

| ボス | HOST だけ | JOIN だけ | 両方(JOIN は0.15秒遅れ) |
|---|---|---|---|
| 黒騎士(打ち上げ) | 打ち上げ2回 | JOIN の命中 10/10 が HOST で処理・JOIN の打ち上げ1 | JOIN の命中 9、基準は HOST のまま(替えなかった命中 8)、引き継ぎ 0 |
| サイクロプス(膝つき) | 例外0 | JOIN の命中 10/10 | JOIN の命中 10、基準は替わらず(4) |
| グリフォン(飛行) | 打ち上げ2回 | JOIN の命中 10/10・JOIN の打ち上げ1 | JOIN の命中 10、基準は替わらず(8) |
| 荒野のドラゴン | 打ち上げ2回 | JOIN の命中 10/10・JOIN の打ち上げ1 | JOIN の命中 10、基準は替わらず(7) |

- ボスの横の1フレームの跳び(自分のプレイヤーから見て): 最大 0.37m(瞬間移動ではない)。例外は全部で0。
- 通信の遅れ(往復の ping): 約160ms で JOIN の命中 10/10、約240ms で 9/10。約550ms(とても遅い回線)では 3/10 で、打ち上げの後の追撃がつながりにくい。
- 両方が殴る時、JOIN が基準の人(HOST)から離れている(1.5m 以上後ろ)と、ボスは HOST に合わせて寄るので JOIN の攻撃は届きにくい(ある回は JOIN の命中 3)。

## 5. 大型ボスの膝つき(依頼4)

- 以前: BREAK の間、絵を縦に2割つぶしていました(止め絵のボスは「平たく潰れた」見え方)。
- 今回: **止め絵の大型**(ゴーレム・ヒュドラ・クリスタルゴーレム・ベヒモス・タイタン・リヴァイアサン・天空のゴーレム・メカドラゴン)は、格子の変形で**脚を折りたたんで低くなり、上半身を前(プレイヤーの方)へ倒して頭を下げます**。高さは同じく約2割低く、当たり判定も同じだけ低く・少し前へ。
- サイクロプス/トロールは BREAK の専用の絵(仰向けに倒れる)があるので、絵のままです(判定の高さは絵とほぼ同じ 約8割)。
- 協力の JOIN の画面でも同じように膝をつきます(以前は JOIN では膝をつかず、判定も高いままでした)。
- 画像: `images/膝つき_改修前後.jpg`(左: 立ち / 中: 改修前 / 右: 改修後)

## 8. 制限と残り

- **竜騎士の速い連打(0.15秒おき)**: 予約は1つなので、技(約0.3〜1.1秒)より速い連打はまとめられます。当たりは 35% → 56% になったが、0.2秒以上の間隔の方が安定します(重さを残したため)。
- **主攻撃が長いキャラ**(お嬢様騎士・魔法使い・忍者・巫女・弓使い): 0.25秒の連打では → の一部がまとめられます(仕様: 予約は1つ)。
- **150km/h の雑魚**: 試験の置き方で最初の打ち上げが届かない回がある(上のルート/段差の上に出た等。試験では置き直して確認)。プレイ中の打ち上げのタイミングはプレイヤーに任せています。
- **150km/h の1フレームの跳び**(1.2〜2m/フレームが時々): 改修前から。高速で敵が段差/天井に当たった時・急降下の着地の後など。今回は増えていない。
- **協力**: 両方で殴る時、JOIN が基準の人から離れていると(1.5m 以上)、ボスは基準の人に合わせて寄るので JOIN の攻撃は届きにくい。とても遅い回線(往復 約550ms)では JOIN の追撃がつながりにくい(約240ms までは 9〜10/10)。JOIN の画面では、打ち上げの光の演出は出ない(命中の衝撃は出る)。
- **BREAK の時間**: 今の長さ(2.4〜3.4秒+延長 最大1.8〜2秒)で、0.3秒おきの ↑→→→↑→→→ の後に合図 → ↓ が間に合います。0.45秒おき(ゆっくり)では9回目より前に合図が来ることが多い(合図の後の → と ↓ は当たる)。ゆっくりの操作でも9回全部を入れたい場合は、延長の上限を +0.6秒ほど増やす案があります(今回は変えていません)。
- **Android 実機の手触り**は未確認です(マスターの確認をお願いします)。
