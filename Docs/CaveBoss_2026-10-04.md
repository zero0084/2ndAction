# 自然洞窟ボス強化(2026-10-04)

荒野街道の「ボス戦の強化」(段階 / 特殊攻撃 / 必殺技 / 崩し(BREAK) / スーパーアーマー / 必殺技後の隙 / ラン再開 / 次ボス保留 / 再戦プール / 距離による強化)を
**そのまま**自然洞窟の11体に使う。洞窟専用の第二の仕組みは作らない。

- 荒野 = ボスの体を見て避ける
- 洞窟 = ボス + 地形(床 / 地中 / 壁 / 天井)の予兆を見て避ける。「洞窟そのものが攻撃してくる」

## 変えた共通の仕組み

| 場所 | 内容 |
|---|---|
| `BossBattleTuning` (+ asset) | 洞窟11体の段階/特殊/必殺技/崩しの値を追加。`resumeStages` に `natural_cave`。asset に無い種類はコードの既定値で補う(`MergeDefaults`) |
| `BossManager.BattleTunedStages` | `natural_cave` を追加。洞窟ボスの生成で `ApplyTuning(kind)` → `ApplyRematchTo`(荒野と同じ順) |
| `BossManager.CaveBoss.cs` | 洞窟ボスが生きている間、CaveStage のボス区間(通常天井・天井の針なし)をプレイヤーに追従(シングルのみ)。開発用 `DebugCaveEncounter` / `DebugForceResume` |
| `CaveBossSafety` | 床(跳ぶ)と天井(地面にいる)の攻撃がプレイヤーの列で同時に有効にならないよう、後の方の発動を遅らせる(予告が伸びるだけ)。天井の攻撃の最中に穴が来るなら天井の攻撃を出さない。必殺技中は新しい穴を作らない(シングル)/雑魚を出さない |
| `CaveHazard` | 地形の攻撃の部品(床/天井/帯/落石/毒だまり/結晶柱/横切る体/予兆)。走行の座標系で流れる。シングルは使い回し、マルチのHOSTは毎回破棄(NetAttackSyncの消滅通知のため) |
| `CaveDarkness` | ECHO HUNT の「少し暗く」(最大0.4、真っ暗にしない)。必殺技が終わると自動で戻る |
| `TerrainManager.PickNextType` | 洞窟ボスの必殺技中は平地(シングルのみ) |
| `EncounterDirector` | 洞窟ボスの必殺技中は新しい雑魚を出さない |
| `BossBattleHud.Banner` / `NetCombat` | HOST のボスの大きな表示(段階/必殺技名/BREAK/隙)を JOIN にも(OpBanner) |
| `WildBossBase` | 開発用 `DebugSetPhase` / `DebugForceUltimate` / `DebugForceBreak` |

予告の色: 赤=低い(跳ぶ) / 紫=高い・天井から(地面にいる) / 金=背が高い(二段ジャンプ)。
地面の攻撃は高さ1.2以下、天井の攻撃は地面から2.3より上で止まる。落石は影+天井のひび+小石が先に出る。

## 再戦(HP以外の強化)

`BossRematchTuning` の段階(通常 / 強化 / 上位 / 最終)を `RematchTierApplied` で読む。
- 強化再戦以上: 必殺技に一手追加(落石/飛び出し/節/輪などが1つ増える)
- 上位強化再戦以上: 段階が1つ増える(既存の `extraPhase`)、第2段階の技を最初から使う
- 第3段階: 隙(回復)が短くなる。予告の長さは変えない

## 開発用

DEBUG → 「洞窟ボス試験…」: ボス11種 × 初登場/再戦の段階 を選んで出す(DEBUG RUN、保存しない)。
戦闘中に 段階1/2/3・必殺技・BREAK・ラン再開 を強制。地形の攻撃の生成/使い回し/重なりの件数も表示。

自動テスト: `-qaCaveBoss <dir>` (`-qaCaveOnly Centipede,...` / `-qaCaveVideo 1`)。
マルチ: `-netAutoBossAt 10 -netAutoBossKind Mole` などで洞窟ボスを出し、段階2→必殺技を強制。
