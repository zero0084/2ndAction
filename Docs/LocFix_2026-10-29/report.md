# 訳の抜けの修正(2026-10-29、マスターの依頼)

対象: 合成画面の能力と数値・【主】【副】・継承結果、疾走の行き先、「新しい敵」の表示。あわせて、同じように日本語が固定で残っている所の確認。
方針(依頼どおり): 能力名や短いラベルは既存の訳を使う / 文は単語をつながず、言語ごとに語順を変えられる型にする / 名前・数値・距離は差し込み変数 / 能力値の計算・ゲームの動きは変えない。

## 1. 原因
- 合成・デッキ・疾走などで、数値や名前を差し込んで組み立てた文を、表の訳の型(キー)と1対1で照らしていた。
  型の無い組み合わせ(「【主】ATTACK UP Lv2  (攻撃力 +10%)」「<color>継承成功</color>」「能力名 数値 / 能力名 数値」など)は、どの言語でも丸ごと日本語のまま出ていた。
- 合成カードの説明は、作った時に一度だけ訳して保存していたため、言語を切り替えても前の言語(多くは日本語)のまま残っていた。
- 右から左の言語(アラビア語・ペルシャ語)の並べ替えが、色/太字/大きさのタグに対応していなかった。日本語のまま出ていた間は表に出なかったが、訳が当たるとタグの < > まで逆に並んで崩れた(合成の結果・デッキの詳細)。
- 合成の結果の見出し(「合成大成功！」等)と演出中の文が、訳の表を通っていなかった(訳はあった)。
- デッキの詳細の「(★5後の保管 N)」は、訳の型が無かった。

## 2. 直したこと
### 訳の仕組み(`Localization/Loc.cs`)
- 型に当たらない文は、部品に分けて訳す(全部の部品が訳せた時だけ使う。一部だけ訳した文は出さない):
  - タグで囲んだ語(`<color=…>継承成功</color>`)→ 中身を訳す。前に日本語の無い語があってもよい(`×2 <b>強化 ×1→×2</b>`)
  - 「能力名 数値」(`攻撃力 +5%`・`移動速度 -4%(固定)`)→ 能力名は既存の訳、数値はそのまま、後ろの括弧は訳す
  - 2つ以上の空白、または「 / 」で区切った並び → 部品ごとに訳す(カード名・`カード名 Lv3`・`カード名 ×2` は名前だけ訳す)
  - 後ろの括弧の注記(`(Lvで伸びる)`・`(強化量12・効くのはLv9まで)`)→ 切り離して訳す
- 型に差し込む語は「訳だけ」にして、右から左の並べ替え/インドの文字の形づくりは一番外の文に1回だけ(以前は2回かかる所があった)。
- 「・」(U+30FB)は訳でもそのまま使う記号なので、「日本語が残った」に数えない。
- `Loc.Src(キー, 値…)`: 元の文(日本語)に値を差し込むだけ。作り置きの文(合成カードの説明など)は日本語の元の文で持ち、表示の時に訳す → 言語を切り替えればその場で変わる。
