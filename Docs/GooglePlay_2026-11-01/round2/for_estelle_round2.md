## 4. 操作説明ショート(縦 1080x1920・60fps、日英、20.2秒)
- 動画: `video/omm_gp_short22_draft1_{ja,en}.mp4`(軽い版は `_review.mp4`)
- 一覧: `short_grid_ja.jpg` / `short_grid_en.jpg`
- 撮り方:
  - 縦画面(608x1080 の窓)を4倍(2432x4320)で撮りました。
  - 縦画面のカメラではキャラが小さいので、キャラの周りを切り出して拡大しています(約2.4倍。空中コンボは HIT 数が入るように約1.7倍)。
  - ゲームのカメラは変えていません。
- 指とフリックの矢印は、撮った映像に後から重ねています(ゲームには描いていません)。
  - 出すタイミングは、撮影の台本が実際に入力したコマに合わせています。
- 打ち上げと急降下は 0.6倍、空中コンボは 0.4倍のスローです。スローの間はゲームの音を消して、BGM だけにしています。

| 秒 | 映像 | 字幕(日 / 英は仮訳) |
|---|---|---|
| 0〜2 | 自動で走る | キャラは自動で走る / Your hero runs on their own |
| 2〜5 | 前の敵へ →(指と矢印) | 前フリック：前方攻撃 / Flick forward: Attack ahead |
| 5〜7 | 走り抜けた後ろの敵へ ← | 後ろフリック：後方攻撃 / Flick back: Attack behind |
| 7〜9 | 敵の近くで ↑ → 打ち上げ | 上フリック：ジャンプ／打ち上げ / Flick up: Jump / Launch |
| 9〜14 | 空中で → を続ける、HIT 数が増える | 当て続けるとコンボ / Keep hitting to build a combo |
| 14〜17 | 空中で ↓ → 急降下 | 下フリック：空中で急降下 / Flick down: Dive (in midair) |
| 17〜20 | ロゴ | あとは、どこまで走るか。 / How far will you go? |

- 字幕の「前/後ろ/上/下フリック」の文言は、マスターの指定どおりです。
- コードと撮影の記録で照合しました。
  - 上フリック: 敵の近くでは打ち上げになり、空中の段数(AIR)が数えられます。
  - 下フリック: 空中にいる時だけです。
