## 作り方

1. エステルに相談しました。
   - 構図・城・月・光の道・剣・鎧・ポーズはそのまま。
   - マントだけを肩から一続きの一枚布にする。
   - 大きなひだを 2〜4 本、大きな尖りは左上と左下。
   - 細い帯・深い切れ込み・ギザギザ・ほつれは描かない。
   - 面積は今の 85〜100%(小さくすると疾走感が落ちる)。
   - 赤い光の軌跡は、布とは別に残す。
2. エステルが元の絵を部分編集しました(3枚それぞれ。正方形アイコン/フィーチャー/アダプティブは別々に描かれた絵で、そのまま移せないため)。
   - 1回目は、脚の横の布の端のギザギザと、拳の下の細い帯が残ったので、2回目で直しました。
3. 合成は `Tools/art/capecomp.py` で行いました。
   - 赤い布の範囲(元と新の両方)を少し広げた所だけ新しい絵を使い、ほかは元の画素のままです。
   - 確認: 違いはマントの範囲(画像の左側)だけです。城・月・右半分の背景は元のままです。
4. エステルのレビューで、3枚とも「採用」でした(追加の直しは必須ではない)。
   - 48px でも「赤いマントの黒剣士が青い光の道を走る」印象が保たれ、マントと鎧の区別は旧より良くなった、とのことです。
   - 脚の横の布の先が鋭いのは、走る向きの勢いのため現状維持です。
