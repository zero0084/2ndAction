# エリアルコンボ改修(2026-10-18)

全12人で、打ち上げ(↑)→ 空中追撃(→)→ 下降攻撃(↓)を自由に組み合わせて、速度が上がっても長い空中コンボをつなげられるようにしました。
追加の依頼(長いコンボ・↓は攻撃しながら下降・再上昇)を優先しています。

## 1. つながりにくかった原因(調べて分かったこと)

| 原因 | 内容 |
|---|---|
| ヒットストップ中の指を見ていなかった | 命中の一瞬の停止(時間 0)の間、指の入力を読んでいなかった。止まっている間に置いた指は、そのタッチ全体がフリックにならなかった |
| 攻撃の最中のフリックが消えていた | 前の攻撃の前半(0.2秒)や3段目の最中の → は予約されずに捨てられていた。技を使うキャラ(格闘家など)の ↓ は、前の連打が終わるまで受け付けなかった |
| 敵とプレイヤーの上がり方が違った | 打ち上げた敵は重力15・最高2.7m・0.6秒、プレイヤーのジャンプは重力20・最高2.0m・0.45秒。高さも時間もずれていた |
| 前後のずれ | 敵の並走の速さに、プレイヤーの踏み込み・減速が入っていなかった(前の攻撃のたびにプレイヤーが0.7m近づき、追い越すことがあった) |
| 叩き落としで置き去り | 叩き落としの間、敵の横の速さが0になり、走り続けるプレイヤーから数m置いていかれていた |
| 打ち上げられないキャラ | 拳銃士/お嬢様/弓使い/魔法使い/巫女は、上の技が「打ち上げ」になっていなかった。拳銃士/巫女/竜人は叩き落としが無かった |
| 遠距離の弾が届かない | 横撃ちの弾は銃口の高さで真っすぐ飛ぶため、打ち上げた敵(2.7m上)に当たらなかった |
| 高速で打ち上げが間に合わない | 速いほど敵がすぐ後ろへ抜け、上攻撃の判定が出る前に通り過ぎていた |
| 上ルートの床への吸い上げ | 浮いた敵が「覚えているルートの床」だけを見ていたため、上ルートの下で叩き落とした敵が上の床へ数m吸い上げられることがあった |

## 2. 直したこと(共通の仕組み)

### 先行入力(PlayerController.AerialCombo.cs)
- 技の最中に入れたフリックは捨てずに覚えて、技が終わった/次の段の受付が開いた瞬間に1回だけ出します。
  - 覚えている時間: **0.45秒**。
  - 新しいフリックが入ったら、覚えている入力をそれに置き換えます。
- 受け付けたかどうかは「入力の前後で技の状態が変わったか」で見ます。同じ技が2回出ることはありません。
- ヒットストップ(命中の一瞬の停止)の間も指を読みます。入ったフリックは、止まりが明けた最初のフレームで出します。
- 停止画面/カード選択/被弾/必殺技の間は、覚えている入力を捨てます(またいで出ません)。

### 打ち上げた敵の位置(EnemyController.AerialCombo.cs)
- この端末のプレイヤーが打ち上げた敵を、「プレイヤーの斜め前の、そのキャラの攻撃が当たる所」へ短い時間だけ寄せます。
  - 寄せ方は、プレイヤーの実際の移動速度(踏み込み・減速を含む)に合わせて並走させ、ずれを足して戻す形です。
  - 画面全体の走行速度は変えていません。
- 補正の速さは最大 **7m/秒**(瞬間移動しない)、ずれ ×9/秒 で戻します。
- **4.5m より離れた敵は寄せません**(遠くから吸い寄せない)。
- 寄せている間の決まり:
  - 天井より上に出ない
  - 高い段差へ横から入らない
  - 上り坂は地面に沿って乗り上げる
  - 地面から 0.45m 以上に保つ(↓で押している間を除く)
- コンボが続く条件: **手動の攻撃が当たってから 0.9秒以内**に、次の手動の攻撃が当たること。
  - カードの追加攻撃/結界や燃える地面の継続ダメージでは延びません。
- コンボが終わる時(そのあと敵は普通に落ちます):
  - 空振りや入力が止まって 0.9秒が過ぎた
  - プレイヤーが着地した
  - 4.5m より離れた
- 時間の打ち切りは、安全装置の30秒だけです。成功しているコンボを3段や短い時間で止めることはしません。

### プレイヤーの滞空
- 手動の攻撃が空中で当たるたびに、0.3秒だけ重力を 0.35倍にします。落ちる速さも 1.5m/秒まで弱めます。
- コンボ中は、1回の滞空の合計の上限(1.6秒)を設けません。
- 空振りや入力が止まれば、0.3秒で普通に落ち始めます。
- 追加の無敵は付けていません。周りの敵の攻撃や地形には今までどおり当たります。

### 入力ごとの役割(全員共通)
| 入力 | 地上 | 空中 |
|---|---|---|
| ↑ | ジャンプ+打ち上げ | 二段ジャンプ+打ち上げ直し。**近く(前3.2m・上下2.6m)に追撃できる敵がいれば、二段ジャンプを使い切っていても再打ち上げ+再上昇**。足元の床から 5.5m より上へは上がらない |
| → | 攻撃 | 連続追撃。当たると短い滞空。敵は遠くへ飛ばさず、当たる間合いのまま |
| ↓ | (キャラによる) | **攻撃しながら下降**。コンボの敵に当たったら、敵を 1.6m下へ押す(0.4秒)。その間に地面へ届けば**叩きつけ**(衝撃・強い音・前へ大きく飛ばす = 締め)。届く前なら → / ↑ でつなぎ直せる(急降下も止まる)。地面の無い所(穴の上)では衝撃を出さない |

### 遠距離キャラの狙い
- 空中の追撃の間だけ、打ち上げた敵(近くのコンボの敵1体)へ向けて撃ちます。
  - 範囲: 9m以内、向きの差40°以内。
  - ↓の技は、前にいる敵へ95°まで向けてよい。
- 普段の射撃、地上の射撃、遠くの敵には効きません(自動で追いかける弾にはしていません)。

### 高速での打ち上げ
- 上攻撃の判定も、100km/h から速さに合わせて前へ伸ばします。
  - 横の攻撃と同じ式で、最大1m伸ばします(150km/h で 1m)。

## 3. キャラごとの操作と特徴

| キャラ | ↑(打ち上げ) | →(空中追撃) | ↓(下降攻撃/叩きつけ) |
|---|---|---|---|
| 黒剣士 | 斬り上げ | 空中連斬(3段) | 叩き斬り(急降下) |
| お嬢様騎士 | **大剣の振り上げ(新しい絵3コマ)** | 大剣の薙ぎ払い(重い追撃) | 落下斬り(衝撃) |
| 双剣士 | 打ち上げ | 素早い連続斬り(5段) | 急降下 |
| 二丁拳銃士 | **上向きの射撃で浮かせる**(以前は浮かなかった) | 空中連射(コンボの敵へ向ける) | **下向きの射撃で叩き落とす**(以前は落とせなかった) |
| 竜騎士 | 槍でかち上げ | 空中連突き | 急降下突き(真下の突きに合わせて敵を寄せる) |
| 魔法使い | **雷撃で浮かせる**(高度が1段上がる) | 空中で魔弾(コンボの敵へ向ける) | 下向きの魔法で叩き落とす |
| 弓使い | **上向きの矢で打ち上げ** | 空中追撃射(コンボの敵へ向ける) | 下向きの矢で叩き落とす |
| 格闘家 | アッパー | 空中連打(4段) | 蹴り落とし |
| 忍者 | 斬り上げて跳ぶ | 空中斬り・手裏剣 | 急降下斬り |
| 竜人 | 爪で打ち上げ | 翼で滞空しながら爪 | **急降下攻撃(新しい絵3コマ)**。コンボ中でなければ今までどおり炎のブレス |
| 吸血鬼 | 爪で浮かせる(霧で前へ) | 敵へ接近して連撃 | 叩き落とし(急降下) |
| 巫女 | **扇の札で浮かせる** | 札で空中追撃(コンボの敵へ向ける) | **敵の真上に結界の印を押し当てて叩き落とす**(地面の結界も今までどおり) |

- 技を使うキャラ(格闘家/吸血鬼/竜人/巫女/忍者/弓使い/魔法使い)と竜騎士は、空中のコンボ中の↓で、前の技の連打/後の隙を切って下降攻撃へ移れます。
- 大型ボス(荒野/洞窟/天空のボス)は浮かせません。今までの反撃・BREAK・耐性のままです。
  - プレイヤーの上昇・空中追撃・下降攻撃は使えて、届く部位に当たります。

## 4. 演出
- **打ち上げ**: 敵から上へ伸びる光の軌跡(エステル作の新しい絵 `Resources/Effects/AirRise`)と、打ち上げの手応えの音(HitLaunch)。
- **空中追撃**: 「N HIT」の下に、小さく「AIR 2」「AIR 3」… を出します。0.9秒で消え、敵・足場・予告には重ねません。
- **↓の命中**: 小さな下向きの軌跡(`Resources/Effects/AirSlam`)。
- **叩きつけ(締め)**: 下向きの軌跡、強い手応えの音(StrongHit)、地面の衝撃(SlamImpact)を出し、生き残った敵は前へ大きく飛ばします。
- **撃破**: 今までの撃破の演出(FINISH)のまま。撃破はその瞬間に確定します。
- 追加のヒットストップや画面の揺れは足していません。

## 5. 攻撃力・カード・既存の機能
- **攻撃力・ダメージの倍率は、今ある技は変えていません**(当たる種類を「打ち上げ」「叩き落とし」に変えただけ)。
- 新しくダメージが出る技:
  - 竜人の急降下: 爪 1.3倍 + 着地の衝撃 0.8倍。コンボ中の↓だけ。
  - 巫女の結界の印: 1.2倍。空中のコンボ中の↓だけ。
- 見た目だけの追加の命中はありません。命中は全部、実際の攻撃です。
- カードの発動は今までどおり命中ごとです。コンボで当たる回数が増えた分だけ、発動の機会も増えます(意図どおり)。
  - DOUBLE ATTACK などの1振り1回の決まりや、1秒あたりの上限(0.5秒に14回)は、そのまま効いています。
- 雑魚のHPは変えていません。途中で倒れた敵は、その瞬間に撃破と報酬を確定します(試験で報酬は1回だけ)。
- **CPU仲間/協力プレイ**:
  - 寄せるのは「この端末のプレイヤーが打ち上げた敵」だけです。仲間や他の参加者の命中では、寄せの位置も滞空も変わりません。
  - 仲間の上攻撃で、プレイヤーのコンボの敵を引き寄せない(瞬間移動のように見えた)ようにしました。
  - 撃破と報酬は今までどおり1回です(死亡の確定と HOST の判定)。
  - 協力プレイの JOIN 側の打ち上げは、HOST の画面では寄せません(今までどおりの打ち上げ)。

## 6. 確認の結果(Windows の開発版、2026-10-18)

### 確認の方法(`QaSweep -qaAerial`)
- 自動前進したまま(実際のプレイと同じ)、前に置いた敵へ長い入力例 **↑→→→↑→→→↓→→→↓**(13回)を入れます。
- 入力と入力の間:
  - 早め 0.2秒 / ちょうど 0.3秒 / 遅め 0.42秒(技の長さは約0.3〜0.4秒)
  - 最初の↑だけは、早めの間隔でも 0.18秒以上あけます。
- 速さ: **18 / 45 / 100 / 150km/h**。
  - 150km/h は、カード(SPEED)と FINAL EVOLUTION の SPEED UP で届く上限です。
  - `DebugRunOnlyScale` で、走る速さだけをこの値に合わせています。
- 場所: 荒野街道(坂・上下ルート・穴)、自然洞窟(低い天井・天井の段)。
- 敵:
  - 検証用の敵: HP 100,000 で、攻撃しない。
  - 普通の敵: 普通の HP。打ち上げ → 前を何回か。
- 1回の入力ごとの結果を、次のように分けて記録しました。
  - H = 当たった
  - q = 前の技の最中で、先行入力として待っていた
  - Wf = 振ったが遠くて外れた
  - Wh = 高さのずれで外れた
  - W = その他の空振り
  - 不受理 = 覚えた入力が出ないまま消えた
  - K = 撃破
- あわせて、瞬間移動、天井/地面へのめり込み、滞空の長さを記録しました。

- 打ち上げてからは、ほぼ全員が最後の入力まで敵を空中に残せました。
  - 長い入力例は、黒剣士・双剣士・格闘家・吸血鬼・忍者で 13回中 10〜12回当たります。
  - 二丁拳銃士は、150km/h でも 13回中 13回成立した回があります。
- 当たる数が少ないキャラ(お嬢様・竜騎士・巫女)は、1回の技が長く、0.3秒ごとの入力に技が追いつかないためです。
  - 次の入力が待っている間(q)に、さらに入力が来て上書きされています。
  - 技の長さに合わせて入力すれば、つながります。
- 速いほど当たる数は少し減ります(150km/h で 13回中 4〜10回)。
  - 原因は、地形(坂・段差)でプレイヤーが着地して、コンボが自然に終わることです。
- **魔法使いの打ち上げは低め**です(33〜67%)。
  - 雷撃が斜め上へ飛ぶので、地上の敵に当たる位置が狭いためです(浮いた後のつながりは良い)。
- 入力の不受理(覚えた入力が出ないまま消えた数)は、1回の試行(13入力)あたり 0〜1.5回でした。

  - 1フレームで 1.2〜1.9m 動く。

- 荒野街道では、地面へのめり込み・瞬間移動は出なくなりました。
