# A. マルチ安定化

LOCAL / ONLINE で分けていない(接続の後のゲームの処理は共通)。HOST 権威・CO-OP / VERSUS のルールは変えていない。

## A-1. Interest Management(送り先ごとの同期範囲)

**以前**: 敵の状態は「活動中の全員を含む範囲 ±90m」の中にあれば 20Hz で、**全 JOIN へ同じ内容**を送っていた。
2人が数km離れると、間にいる敵まで全部が高頻度になっていた。攻撃の写し(弾・判定)は範囲の区別そのものが無かった。

**いま**(`Net/NetInterest.cs`): HOST が送り先(JOIN)ごとに、送る物と頻度を決める。

| 区分 | 条件 | 頻度 |
|---|---|---|
| 近い | その人の **前方 120m / 後方 45m**(画面ではなく、高速時の先読みと縦画面の斜め表示の見通しを含む) | 変化があれば毎回(20Hz)、無くても 0.5 秒ごと |
| 範囲外でも近い扱い | ボス / その人を狙っている敵・攻撃 / **直前 3 秒にその人と戦った敵** / 狙いが変わった瞬間 | 同上 |
| 遠い | 上以外 | 2 秒ごとの生存確認だけ |

- 出現・HP・AI・死亡・LastHit の正解は HOST のまま。出現/HP/死亡/消滅の通知(信頼できる経路)は今までどおり全員へ。
- 遠い敵は相手の画面で「止まって見えるだけ」で、消したり死なせたりしない(消すのは HOST の正式な消滅通知だけ)。
- 位置の分からない JOIN(読み込み中・VERSUS で脱落して観戦中など)は、活動中の最前の人の位置を使う。
- CO-OP の救出地点: DOWN の人は「参加中」として範囲の基準に入る(その人の周りの敵は近い扱い)。

## A-2. プレイヤー位置の同期

**洗い出した重複**:
1. Owner が NGO の `SendTo.NotOwner` で全員へ 30Hz → HOST が残りの JOIN へ中継(人数 N で (N-1)(N-2) 件)。**遠い人へも 30Hz**。
2. 止まっている間(カード選択中・DOWN)も 30Hz で送り続けていた。
3. 距離は位置の送信(30Hz)と表(1Hz 以上)の両方に入っている(表は HP/状態と一緒の 1 秒ごとなので残した)。

**整理**(`Net/NetPlayer.cs`):
- JOIN → HOST へ 1 件だけ送り、HOST が送り先ごとに中継する。**130m 以内の人へは今までどおり 30Hz**(一緒に走っている人の見た目は変えない)、それより遠い人へは 5Hz。
- 止まっている間は 6Hz。瞬間移動(ワープ・復帰)の瞬間は全員へすぐ送る。
- 同期の版を 2 → 3 に上げた(古い版とは VERSION MISMATCH で接続しない)。

## A-4. ボスの攻撃の効果(HOST だけに効いていた物)

全ボスの「プレイヤーへ影響を与える攻撃」を洗い出した(ダメージ・押す/強制移動・減速・弾の命中・地面/範囲)。

| ボス・攻撃 | 効果 | 以前 | 修正 |
|---|---|---|---|
| 天空 タイタン「突風」 | 減速 0.62 × 1.8 秒 + 押し戻し -3m/s | **HOST のプレイヤーにだけ**(範囲の判定も無し) | HOST が範囲(±30m)の全員を決め、対象の端末へ送る(`Net/NetPlayerFx.cs`) |
| 天空 大蛇「嵐」「HEAVEN SERPENT STORM」の強風 | 減速 | **HOST のプレイヤーにだけ** | 同上 |
| オオカミ「突進」/ ゴブリンライダー「突撃」 | 当たったかどうかで「チャンス」(転倒)が出る | JOIN に当たってもボスは外れた扱い | HOST が JOIN の被弾を確定した時にボスへ知らせる |
| 全ボスの必殺技の強い一撃 | ダメージ量 | JOIN は常にハート1つ | HOST が本物の攻撃からダメージ量を決める |
| バジリスク「石化の視線」(帯 / 波) | 減速 | 帯: JOIN が自分で掛けていた / 波: マルチでは減速が届かなかった | 減速は HOST の確定で掛ける(二重に掛けない) |
| 当たっても消えない弾(岩柱・大玉) | — | JOIN が触れると HOST の本物まで消えた | 消さない |
| 洞窟の地形の攻撃 | — | HOST より後ろの JOIN へ届く前に消えていた | 最後尾の活動中の人より後ろで消す |

- 権威: HOST が「誰に・何を・どれだけ」を決める → 対象が JOIN ならその端末へ通知 → その端末が自分のプレイヤーへ1回だけ掛ける。押された結果の位置は通常の位置同期で全員に共有。JOIN のローカルの当たりと HOST の当たりは二重に適用しない。
- 対象はプレイヤー番号(P1〜P8 の任意)。P1/P2 専用の処理は無い。
- 天空ボス 11 種を確認した。ベヒモス・クラゲ・リヴァイアサン・フェンリル・空のゴーレム・フェニックス・守護者・竜・魔人の攻撃はダメージのみ。いずれも共通の攻撃の写しを通るので、JOIN にも当たる。荒野/洞窟のボスに押す/引く/打ち上げる攻撃は無い(上の表の物だけ)。
- 確認(Windows、HOST=P1 / JOIN=P2)。
  - タイタンの突風は両方の端末で減速 0.62 と押し戻しが掛かった。JOIN は HOST からの通知で受け取った。
  - 大蛇の嵐は両方で減速が掛かった。
  - **本物の Relay でも同じ**(突風が JOIN に届いた)。
  - HOST/JOIN を入れ替えた試験はしていない(処理はプレイヤー番号で共通)。

## A-5. 距離のイベント(100,000m など)の HOST 依存

| 箇所 | 以前 | 修正 |
|---|---|---|
| 100,000m の死神(三姉妹の追跡) | HOST 自身の距離 | **共有世界の進行距離**(`Net/WorldProgress.cs`: 最前の人の最高到達) |
| 死神の出る位置 | HOST の後ろ | 最前で走っている人の後ろ |
| ボスの関門 | 最前と HOST の大きい方(先頭が脱落すると下がり得た) | 最高到達(下がらない) |
| ボス戦の後の「通過した関門」の数え方 | HOST 自身の距離 | 共有世界の進行距離 |
| 敵の強さ・隊列の距離(HOST が出す敵) | HOST 自身の距離 | 共有世界の進行距離 |

- **一意な発火**: イベントごとの ID(`death_100k`)を HOST が「起きた」と記録し、二度と起こさない。記録は表の見出しで全員へ送る(JOIN は自分で起こさない)。
- **巻き戻さない**: 最高到達は先頭が脱落/DOWN/切断しても下がらない。起きたイベントはランが終わるまで「起きた」のまま。
- **シングルプレイ**: 進行距離 = 自分の距離(従来どおり)。

確認(Windows、2 人、99,860〜99,975m へワープして走る):

| ケース | 結果 |
|---|---|
| 1 HOST が先頭 | HOST(P1)の到達で 1 回発生、JOIN にも同じ死神 |
| 2 JOIN が先頭 | **JOIN(P2)の到達で発生**(HOST は 60m 後ろ) |
| 3 直前で先頭交代 | 1 回だけ |
| 4 発生後に先頭(VERSUS の P2)が脱落 | 巻き戻り・再発生なし |
| 5 CO-OP / VERSUS | 両方で状態が一致(JOIN は HOST から受け取った記録) |
| ONLINE(本物の Relay、VERSUS、JOIN 先頭 → 脱落) | JOIN 到達で 1 回発生、巻き戻りなし |

# B. 道のつなぎ目の突起・段差

## 原因
**見た目だけの問題**。走る面・当たり判定に段差は無い(全ステージ・全継ぎ目で、継ぎ目の前後 0.05m の走る面の高さの差は 0)。
地面の板(草の面+岩の断面の絵)は区間ごとに傾けて並べている。傾きの違う板どうしの継ぎ目には隙間が出るので、次の区間の絵を前の区間の側へ少し伸ばして隙間を埋めていた。
- へこんだ継ぎ目(平地→上り坂 / 下り坂→平地)では、板の下側が開くので伸ばす必要がある。
- 出っぱった継ぎ目(**平地→下り坂** / 上り坂→平地)では下側は重なるので伸ばす必要が無い。にもかかわらず伸ばしていたため、次の区間の絵が前の区間の面より上へ **三角に突き出したり(添付の 90,167m)、垂直の小さな壁に見えたり** していた。

上ルートの分岐区間(`TerrainManager.GenerateNextBranch`)と下ルート(通常の地面・断面の帯・最初の区間の作り直し)の両方で、同じ処理だった。

## 修正
隙間埋めをへこんだ継ぎ目だけに掛ける(`TerrainManager.NeedsJoinBleed` / `SkyJoinBleed`)。意図した坂・段差・穴・浮島・上下の分岐は変えていない。走る面の高さ・当たり判定のコードは変えていない。

## 確認(Windows)
- 修正前後: `継ぎ目_*_左が修正前.png`(開発版の `-legacyBleed 1` で以前の伸ばし方を再現して撮影。地形の乱数は同じ種だが、ワープの都合で配置は完全には一致しない)。
- 全 4 ステージ × 3km / 90km で、平地/坂、坂どうし、穴の縁、上ルートの継ぎ目を確認。走る面の段差 0。
- 走り抜け(上ルートの出っぱった継ぎ目、約 90km/h、自動操作補助 OFF): 4 回のうち 3 回は接地したままの上向きの飛び 0.10m 以下、被弾 0。1 回は継ぎ目を過ぎた後に穴へ落ちた(補助 OFF のため跳ばなかった。継ぎ目での上向きの飛びは 0)。動画: `video_道の継ぎ目_走り抜け_*.mp4`。
