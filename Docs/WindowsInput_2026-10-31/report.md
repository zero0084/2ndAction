# Windows のマウス/キーボード操作 報告(2026-10-31)

## 最終の操作方法(PC)

| 入力 | 操作 |
|---|---|
| ↑↓←→ | 項目の選択・移動(スライダーは ←→ で値) |
| Enter | 選んだ項目の決定 |
| Esc | 戻る・閉じる(一番手前を1段だけ)/ ラン中は一時停止を開く・閉じる |
| Tab / Shift+Tab | 次 / 前の項目へ(上から、同じ行は左から。端で反対の端へ) |
| PageUp / PageDown | 一覧・長い文章のスクロール |
| マウスのホイール | ポインターを置いている一覧・文章をスクロール(キャラ選択では前/次のキャラ) |
| マウスの戻るボタン(サイド) | Esc と同じ(1回で1段だけ。ラン中は一時停止を開く。ランを終えたりホームへ戻ったりはしない) |
| ラン中 | 既存のまま(Space ジャンプ、WASD/矢印 攻撃、C ULTIMATE、H 脱出、P 一時停止 など。キー設定で変更可) |

既存の割り当てとの調整:
- PC の初期の表で「後攻撃 = マウスの戻るボタン(Mouse3)」だったのを外し、戻るボタンは「戻る」専用に(後攻撃は A / ← / パッド Y のまま)。保存済みのキー設定にマウスの戻るボタンが入っていた場合も、読み込み時に外します。
- Tab とマウスの戻るボタンはキー設定で行動に割り当てられないようにしました(二重に動かないため)。

## 変更内容

1. **ホイール**: デッキ編集(所持カード/デッキ)、カード合成(一覧/詳細/結果)、キャラ選択に対応(以前は届いていなかった)。設定・説明文・ランキング等の IMGUI の一覧は前から対応していたが、手前に窓がある時は後ろの一覧を動かさないようにした。1目盛り = 見えている高さの約2割。
2. **マウスの戻るボタン**: Esc と同じ経路(`GameManager.DoBack`)。RESULT でも Esc と同じくホームへ。
3. **キーボードだけで完結**:
   - Tab / Shift+Tab を追加。
   - **RESULT の「ホームへ戻る」を Enter で押せなかった不具合を修正**(メニュー操作中の決定がボタンに使われて捨てられていた)。
   - 画面ごとに選んでいた項目を覚えて、戻った時にそこへ(お知らせ/確認の窓は別に覚える)。初めて開いた時はホーム = 出発、RESULT = ホームへ戻る から。
   - ホームの部屋は名前の札を候補にした(以前は大きく重なった部屋の物が候補で、矢印での移動が飛び飛びだった)。
   - 一覧の外の項目へ移ったら、その向きへ自動でスクロール。
   - Enter の押しっぱなし・画面の切り替えでの持ち越し防止(決定した押下は、離すまで次の画面の決定/ジャンプに使わない)。
   - 文字の入力中(デッキ名・ランキングの名前・マルチの IP/ポート)はキーで項目を動かさず、ゲームの操作もしない。Enter で入力を終える。
   - マウス/タッチからキーへ持ち替えた最初の押下は、選択枠を出すだけ(今の項目から急に動かない)。
   - 選択枠を見やすく(中を明るく + 左に ▶ の印)。
