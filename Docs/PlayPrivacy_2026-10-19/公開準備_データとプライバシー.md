## 2. LOCAL PLAY の暗号化

### 方式
- **Unity Transport の DTLS**(Relay と同じ暗号化。NGO の `UnityTransport.UseEncryption` + `SetServerSecrets` / `SetClientSecrets`)。独自の暗号は作っていません。
- **証明書**: HOST が、アプリの起動ごとに新しい自己署名の証明書を作ります。
  - RSA 2048 / SHA-256、名前 `omm-lan-host`、30日。
  - 秘密鍵は HOST の端末のメモリの中だけです(送らない・保存しない・ログに出さない)。
- **JOIN の確認**: 部屋の案内に入っている HOST の証明書を「信頼する証明書」として使います(証明書の固定)。
  - JOIN は、その証明書と同じ秘密鍵を持つ相手としかつながりません。
- **部屋の案内**(UDP 47777 の一斉送信)には、個人の情報を入れません。
  - 中身: 部屋の番号(乱数)、モード、人数、最大人数、状態、ポート、アプリの版、HOST の証明書(公開の部分)、部屋の名前「ROOM xxxx」。
  - 以前は部屋の名前が「コードネーム's Room」で、LAN の全員へ1秒ごとに流れていました。ONLINE の公開の部屋一覧の名前も同じ扱いに変わりました。
  - コードネームは、つないだ後の暗号化した通信の中だけで送ります。
- **準備できない時は、暗号化なしに戻しません**: 証明書を作れない端末では、部屋を作れません(「安全な通信を準備できなかったため…」)。
- **互換**: 版を 8→9 に上げました。古い版の端末とは「VERSION MISMATCH」でつながりません(暗号化していない古い版と混ざらない)。Windows 版と Android 版は同じ仕組みです。
- **ONLINE PLAY(Relay)**: 変えていません。Relay の DTLS のままです。LOCAL の設定は Relay の経路の前に外します。
- **8人**: 今までどおりです(接続の数や同期の作りは変えていません)。

### 守れる範囲 / 残るリスク
| | |
|---|---|
| 守れる | ゲームの通信の中身(コードネーム、位置、状態、戦闘など)の **盗み見**。同じ Wi-Fi の第三者が通信を記録しても読めません |
| 守れる | なりすましの HOST へ **途中から割り込まれること**(つないだ後は、固定した証明書の相手だけ) |
| 残る | 部屋の案内は暗号化していません。同じ LAN の攻撃者が、**偽の部屋**(自分の証明書入り)を出して、そこへ参加させることはできます。この時に送られるのはコードネームとゲームの状態です。本物の HOST の通信は読めません |
| 残る | 部屋の案内の中身(個人の情報ではない)は誰でも見られます |

### 確認の方法と結果(Windows、2026-10-19)
- 2つのプロセスの間に、通信を中継して全部を記録する仕組み(`udp_tap.py`)を挟み、中身にコードネームが出るかを調べました。
  - 暗号化あり: 約27万バイトの中に、HOST と JOIN のコードネームは **0回**。
  - 比較(開発版だけの `-lanPlain` で暗号化を止めた時): 同じ方法で **見える**(4回 / 1回)。確かめ方が正しく働いている裏付けです。
  - 部屋の案内: どちらもコードネームは0回。部屋の名前は「ROOM F97B」の形。
- 部屋の発見 → 参加 → 同期(20秒): 成功、例外0、往復の遅れ 約35ms。
- IP を直接入れて参加: 成功(HOST へ問い合わせて証明書を受け取る)。
- 版違い(VERSION MISMATCH)/ 接続できないポート(CONNECTION FAILED): 今までどおり断る。
- 証明書を作る時間: Windows で 0.6〜5.4秒(マルチの画面を開いた時に裏で作り始める)。

## 3. データの削除

### 場所
設定 →「データとプライバシー」→「データの削除」→ 内容の確認 → 「削除する」→ 確認(取り消せない)→ 実行

### 消すもの / 消さないもの
| 消す(サーバー) | 消さない(この端末) |
|---|---|
| ランキングの記録(全マップ)と、表示名(コードネーム) | カード・MILE・解放したキャラ・進行・設定・コードネーム |
| ランキングへ送った記録の履歴(Cloud Save の `omm_runs` ほか、本人の既定の項目すべて) | 広告なしパス(Google Play のアカウントの購入。PlayerId とは結びついていない。削除の後も「購入を復元」で使える) |
| オンライン用の匿名のアカウント(PlayerId) | |
| この端末のランキングの参加/送信待ち/送信済み/資格のある自己ベスト(参加し直しても古い記録を送り直さない) | |

### 順番と安全のための決まり
1. **サーバーのデータ**: Cloud Code `omm_delete_player` を呼びます。
   - 削除の対象は、呼び出しを認証された本人(`context.playerId`)だけです。PlayerId を引数で受け取らないので、他人の ID を渡しても消せません。
   - Cloud Save は本人の項目を削除します。
   - Leaderboards は Admin API の purge で、全部の表から本人の記録を消します。サービスアカウントの鍵は Secret Manager に置き、アプリには入れません。
2. 1. が成功した時だけ、**匿名のアカウントを削除**します(`DeleteAccountAsync`)。その後、サインインの記録も消します(`SignOut(true)` / `ClearSessionToken`)。
   - 1. が失敗したらアカウントは消しません。消すと、残ったデータを本人が二度と消せなくなるためです。画面にはメールでの申請を案内します。
3. **新しい PlayerId**: 次にランキングや ONLINE PLAY を使った時に、新しい匿名アカウントで自動でサインインします。削除の直後には作りません。
- 削除の画面を開いただけでは、新しいアカウントを作りません。サインインの記録が無い端末では「まだオンライン機能を使っていません」と出します。
- マルチの部屋にいる間は削除できません(部屋を出てから)。

### 確認の結果(Windows、専用の保存ファイル)
- **模擬のサーバー(開発版だけの切り替え)で成功**: 4言語とも、変わった保存は **ランキングの4つの記録だけ**でした。
  - カード・MILE・進行・設定・広告なしパスの権利(`NoAdsEntitlementV1`)を含むほかの保存は、1つも変わりませんでした(全部の保存の項目を前後で比べた)。
- **模擬のサーバーで失敗**: 何も消えない。
- **戻るボタン**: 削除の画面が先に閉じる。
- **本物の経路(開発版)**: development 環境が無いので「オンラインのサービスに接続できませんでした」と出る。新しいアカウントは作られない。
- **未確認**: 本物の Cloud Code での削除、削除の後に古いランキングの記録が残らないこと、他人のデータを消せないこと(作りの上では引数で ID を受け取らない)、新しい PlayerId での再ログイン。いずれも development 環境ができてから確認します。

### 制限
- Google Play の購入の記録(Google が持つ)と、AdMob(Google)が持つ広告のデータは、このゲームからは消せません(Google の設定/Google への依頼)。
- Unity のサービスの記録(ログなど)の保持は Unity の決まりによります。
- アプリを削除した後は、この端末のサインインの記録も消えるため、アプリからは古いアカウントの削除ができません → メールで申請(§5)。

## 6. プライバシーポリシーに追加・修正すべき文章(案)

Google サイトの文章はエステルと確認して修正してください(アプリからは変えていません)。

**① 集める情報**
> 本アプリは、オンライン機能(ランキング・ONLINE PLAY)を使う時に、Unity Gaming Services(Unity Technologies)を使って次の情報を扱います。
> - 匿名のプレイヤーID(アプリが自動で作る識別子。氏名やメールアドレスとは結びつきません)
> - コードネーム(ランキングとマルチプレイで表示する名前。本名など個人の情報は入れないでください)
> - ランキングの記録(マップ、距離、キャラクター、プレイ時間など)
> - マルチプレイの通信(位置・状態など。保存しません)
>
> 広告(Google AdMob)は、広告ID・おおよその位置(IP アドレスから)・アプリの操作・診断の情報を扱います。購入(Google Play)の情報は Google が扱い、本アプリは購入の確認のための情報だけを端末に保存します。

**② 通信の暗号化**
> オンラインの通信(Unity Gaming Services・Relay・広告・購入)は暗号化(TLS / DTLS)して送ります。同じネットワークの中で遊ぶ LOCAL PLAY の通信も、DTLS で暗号化します。部屋を探すための案内(部屋の番号・人数など)には、個人を特定する情報を含めません。

**③ データの削除**
> アプリの「設定」→「データとプライバシー」→「データの削除」から、サーバー上のデータ(ランキングの記録・コードネームの掲載・送った記録の履歴・匿名のプレイヤーID)を削除できます。端末の中のデータ(カード・MILE・進行など)は削除されません。端末の中のデータは、アプリをアンインストールすると削除されます。
>
> アプリを削除した後や、アプリから削除できない場合は、アプリに表示されていたプレイヤーID(分からない場合はコードネーム・マップ・おおよその距離と時期)を書いて tempestars0605@gmail.com へご連絡ください。内容を確認したうえで、30日以内に削除します。本人であることを確認できない場合は、削除をお断りすることがあります。
>
> 次の情報は本アプリから削除できません: Google Play の購入の記録(Google のアカウントで管理)、Google AdMob が扱う広告の情報(Google の広告の設定から管理できます)、法令やサービスの安全のために一定期間保持が必要な記録。
