# メールでのデータ削除の申請の手順書(運営者向け、2026-10-19)

問い合わせ先: **tempestars0605@gmail.com**

## 0. 前提
- このゲームのオンラインのデータは、**匿名のアカウント**(Unity Authentication の PlayerId)に結びついています。メールアドレスや Google のアカウントとは結びついていません。
- サーバーにあるのは、ランキングの記録(表示名 = コードネームを含む)・送った記録の履歴(Cloud Save)・匿名のアカウントです。
- **プレイヤーIDは秘密の値ではありません**。ランキングを見られる人には分かります(ランキングの一覧が ID を返すため)。ID だけでは本人の証明になりません。
- 端末の中のデータ(カード・MILE・進行)は、アプリをアンインストールすると消えます。運営側では消す必要がありません。

## 1. 受け付け
1. 申請のメールを受けたら、受付の返信をします(例: 「受け付けました。30日以内に対応します」)。
2. 次の情報をそろえてもらいます(足りなければ返信で聞く)。
   - プレイヤーID(アプリの「設定 → データとプライバシー → データの削除」に出ていた値)
   - コードネーム
   - 記録したマップと、おおよその距離・時期
   - (アプリがまだ入っている場合)→ **アプリの中の削除を案内**します。認証された本人の操作なので、一番確実です。

## 2. 本人の確認
| 状況 | 対応 |
|---|---|
| アプリが入っている | アプリの中の削除を案内(メールでは消さない) |
| アプリを削除した。プレイヤーID+コードネーム+記録の内容(マップ・おおよその距離・時期)が、Dashboard の記録と合う | 削除する |
| プレイヤーIDだけ / コードネームだけで、記録の内容が合わない・分からない | 追加の情報を聞く。そろわなければ、理由を伝えてお断りする(他人の記録を消される嫌がらせを防ぐため) |
| 記録が見つからない(ランキングに参加していなかった等) | 「サーバーにあなたの記録はありません」と返信する。匿名のアカウントだけが残っている場合、ID が分からないと特定できないことを伝える |

記録の照らし合わせ: Dashboard(production)→ Leaderboards → 各表 → プレイヤーIDで検索(表示名・距離・更新の日時)。

## 3. 削除の作業(Dashboard、production。マスターが行う)
1. **Leaderboards**: 4つの表(`omm_best_*`)で、そのプレイヤーの記録を削除
2. **Cloud Save**: Player data → プレイヤーIDで検索 → 項目(`omm_runs` など)を削除
3. **Authentication**: Player Management → プレイヤーIDで検索 → **Delete**(匿名のアカウント)
4. 削除した日時と ID を、作業の記録に残す(申請のメールと一緒に保管。記録には ID と日時だけを書き、申請者のメールアドレスは別に管理)

## 4. 返信
- 削除した: 「サーバー上のデータを削除しました。端末の中のデータは、アプリのアンインストールで削除されます」
- 削除できないデータがある時: Google Play の購入の記録(Google のアカウントで管理)、Google AdMob の広告の情報(Google の広告の設定)は、このゲームからは削除できないことを伝える

## 5. 期間
- 受け付けから **30日以内** に対応します(プライバシーポリシーの記載と合わせる)。

## 6. 将来の改善(今は作っていない)
- アプリの中に「削除申請のコード」(本人だけが読めるサーバーの項目と照らし合わせる乱数)を出しておけば、アプリを消した後でも本人の確認が確かになります(サーバーの準備が要ります)。
