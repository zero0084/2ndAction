# エステルとの相談 1(2026-11-06、ChatGPT「ガチャ画面改善相談」)
見せたもの: 横/縦のホーム、筐体の5段階、仮実装(色の光+既存の粒子)、結果の画面

エステルの意見(要点):
- A 方式: 「引いたカードの土地で台が変わる」は採用。ただし **回している間に土地の予兆を出さない**(結果が先に分かって驚きが弱くなる)
  流れ: 回す=共通の金の光と振動 → 排出の直前に土地の色/模様が一瞬 → 排出=カードと土地の演出 → 結果=土地名と紋 → 閉じた後は台がその土地の飾りのまま
- 台の下の5つの紋は残してよい。**下線は「選択中」と誤解されるのでやめ、最後に引いた土地の紋だけ明るく**
- 共通のカードを引いた時は飾りを外して元の青金の台へ
- B 飾り: **色より形(遠目で分かるシルエット1つ)を優先**
  荒野=看板の上から左右に大きく張り出す角(獣の頭骨)+赤茶の布、砂/岩は補助 / 洞窟=看板の左右から斜め上へ伸びる大きな青緑の結晶(足元に小さな結晶)/
  天空=左右に大きく広げた白金の翼(本体からはみ出すくらい)+看板の上の光輪、雲は控えめ / ラスダン=背後の大きな紫の封印円+左右に巻きつく黒鉄の鎖
  看板・ハンドル・カードの排出口を隠さない
- C 縦画面: 優先 = 大きなシルエット > 発光色 > 排出の一瞬の演出 > 細かな飾り・粒子。小さな紋の列は無理に出さず、結果画面で土地名と紋をはっきり。
  縦はガチャの演出中だけ台を 1.3〜1.5 倍にする案も(重ならないか確認してから)
- D 部品ごと(透過 PNG、共通の基準座標): 前面(角・結晶・鎖)/ 背面(翼・光輪・封印円)/ 軽い演出。第5段階で確かめてから第1段階でも破綻しないか。装飾 1〜3 枚 + 短い演出
- E 結果画面: 土地名と紋は **カードの真上の小さな見出し**(NEW CARD → 土地名 → カード → 名前 → ★)。カードが小さくなるなら今の左のままでよい
- 進め方: まず荒野の1セットを作って実画面で横/縦を確認 → 規格を決めてから洞窟・天空・ラスダン
