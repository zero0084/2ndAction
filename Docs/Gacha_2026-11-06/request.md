# 2026-11-06 マスターの依頼: ガチャ画面のマップ別の見た目
(原文の要点。全文は会話のとおり)
- 目的: カードのマップ分類とガチャの見た目を一致させる。説明を読まなくても、どの土地のカードを引いているか雰囲気で分かる
- 対象: 共通 / 荒野街道 / 自然洞窟 / 天空回廊 / ラストダンジョン
- 構造: 共通の筐体 + マップ別のスキン・装飾・エフェクト(5台を別に作らない)
- 変えない: 排出確率・レア度・抽選ルール。★表示・レア度色・カード枠・結果画面の読みやすさは共通
- 共通: 今の標準デザインを基準(ニュートラル)
- 荒野: 砂・乾いた風・赤茶・鉄・獣・火花。回す→砂が舞う→内部が赤橙に光る→排出で火花・砂粒。無骨
- 洞窟: 岩・結晶・苔・青緑の光・地底。回す→結晶が脈打つ→光が強く→排出で結晶片・青緑の粒子。暗すぎず神秘的
- 天空: 白金・雲・羽・神殿・風・光。回す→風が集まる→光の輪→排出で羽・光粒。明るく神聖で軽やか
- ラスダン: 黒鉄・古代文字・封印・紫/赤の光・不穏。回す→封印文字が光る→封印がほどける→排出で黒粒子・古代文字・紫光。特別感
- エフェクトはカード本体・★を隠さない。★4/★5 は今のレア度演出が主役(競合はレア度優先)
- 未解禁マップ: 暗め・鍵・シルエット・光が消えている。未解禁カードの内容はネタバレしない
- レイアウト: 実画面を確認。タブ/ボタン/マップ名/選択中のガチャが分かる配置。情報だらけにしない。横・縦
- 負荷: Android で軽く。大量の高解像度画像・重い Particle・常時アニメを増やしすぎない(静止装飾+小さな Loop+軽い Particle)
- エステル: 各マップらしさ・色・装飾・エフェクト・読みやすさ・レア度との競合・縦横を実画面で相談。ラフ/仮実装のスクショを見せる。画像生成も手伝ってもらえる
- 既存の良い部分(操作感・分かりやすさ)は残す
- 報告: 共通筐体の構造/各マップの変更/新規画像枚数/新規エフェクト/排出演出/高レア演出との関係/未解禁表示/横/縦/Android負荷/Windows確認/エミュ確認/実機の有無/エステルとの相談/Exception・Error/コミット/APK versionCode/容量と前回差
