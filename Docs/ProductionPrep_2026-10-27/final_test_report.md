# production への反映と最終試験の報告(2026-10-27)

マスターの指示どおりの順で production へ反映し、production 専用の試験プレイヤーで最終試験を行いました。
`ProductionReady` はリポジトリでは **false のまま**です(製品版ビルドもまだ作っていません)。

## 1. production への反映

| 順 | 内容 | 結果 |
|---|---|---|
| 1 | ランキングの表 4つ(荒野街道・自然洞窟・天空回廊・LAST CORRIDOR) | 作成。高い順・自己ベストのみ(keepLatest)・リセットなし |
| 2 | Access Control | `deny-player-leaderboard-writes`(プレイヤーが表へ直接書けない) |
| 3 | Cloud Code 3本(`omm_submit_run` / `omm_set_name` / `omm_delete_player`) | 作成・公開(版1) |
| 4 | 読むだけの監査(UgsProdAudit) | 3本とも公開版が手元のファイルと一致。表4つ・Access Control あり |

- 反映の前の監査では、表・スクリプト・Access Control はどれも無い状態でした(既存の物を書き換えていません)。
- Secret の一覧は API から読めません(404。development と同じ)。ただし、Secret を使うアカウント削除が production で成功しているので、Secret は登録どおり使えています。
- Secret の値・認証情報はログにもこの報告にも出していません。

## 2. 最終試験の方法

- 配らない確認用の製品版(Windows)を2つ用意しました。
  - 製品名は「One More Mile Test」と「One More Mile Test 2」で、本物の保存とは別です。
  - production 固定のリリースビルドです。起動ログには `UGS Environment = production (release build, release build (fixed))` と出ます。
  - 開発用の画面や診断表示は出ません。
  - このビルドだけ `OMM_PROD_VERIFY` で `ProductionReady = true` にしています。
- 長い距離を走らせるため、このビルドにだけ自動操縦(ProdVerifyPilot)を入れました。製品版には入りません。
  - 操縦は、オートで走る・カードは先頭を選ぶ・指定の距離を過ぎたら脱出する、の3つだけです。
- 本物の「One More Mile」の保存は、試験の前後で**1バイトも変わっていない**ことを確かめました。

### 試験の後片付け(production に試験記録を残さない)
- 試験で作ったプレイヤーは3人で、3人ともアプリの正式な削除で消しました。
  - A1: 最初の3本を走ったプレイヤー
  - B1: 削除後に作った新しい ID
  - S2: ONLINE / LOCAL で部屋を作った側
- 最後の監査の結果:
  - **4表とも記録0件**
  - 3人とも記録・Cloud Save・アカウントなし
  - 削除の後に新しい匿名アカウントもできていません(端末側にサインインの情報なし)
- 試験用の保存は試験前の状態へ戻しました。試験後の保存は消さずに控えへ移してあります。

## 4. 試験中に見つけて直した不具合(3件、LOCAL PLAY)

1. **自分で「退出する」を押しても「接続が拒否されました」と出ていた**
   - 自分で抜けた後の切断は、この画面にしないようにしました。
   - 確認版で、退出しても画面が出ないことを確かめました。
2. **その切断の画面の「OK」が押せず、閉じられなかった**
   - マルチの画面が開いていると、そちらが先にクリックを取っていました。
   - 相手の切断でも起きるので、公開版にあれば閉じられない画面が残るところでした。
   - 切断の画面が出ている間はマルチの画面を描かないようにしました。
   - 確認版で、HOST が部屋を閉じた時の画面を OK で閉じられ、元の画面に戻ることを確かめました。
3. **HOST が部屋を閉じた時も「接続が拒否されました」と出ていた**
   - 「HOSTとの接続が切れました」に直しました(既にある30言語の訳を使います)。
   - 本当に断られた場合(版が違う・満員・走行中)の文は変えていません。
   - コンパイルは確認済みです。実際の表示は、次の製品版ビルドで確かめます。

## 5. 残っていること
- マスターの確認の後に行うこと:
  - `ProductionReady = true` にする
  - 製品版をビルドする
- Windows のファイアウォールの確認画面は、新しい場所の exe を初めて LAN で使う時に出ます(マスターに「許可」を押していただきました)。製品版を配る時も、初回の LOCAL PLAY で同じ画面が出ます。
