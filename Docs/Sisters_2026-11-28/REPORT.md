## 1. 命中不良の原因(調べた方法と結果)
攻撃1振りごとに(ゲーム内の振りの番号で)、攻撃の判定と姉妹の被弾の範囲が物理の1歩以上重なったかを毎フレーム調べました。比べた条件は次のとおりです。
- 横画面と、縦の3つの見え方(横から見る / 上下2段 / 斜め上)
- 近接(剣士)と遠距離(拳銃士)
- 1人ずつ / 三人同時

| 切り分け | 結果 |
|---|---|
| **射程外・画面外**(原因) | 三姉妹は横画面に合わせた間合いで戦い、三人同時の時は技の間合いに並び順のずれ(+4.6m/+9.2m)が足されて、三女は 12〜19m 先に立ち続けていました。<br>プレイヤーから写る範囲は、横 約30m、縦・横から見る 約17m、上下2段の下の段 約14m です。そのため縦では姉妹が画面の端・外にいる時間がありました(上下2段で次女・三女 約25%)。<br>三姉妹戦は並走の戦いで、「近接が届かないボスが近くへ来て隙を見せる」機能(CloseIn)が働かず、三人同時の三女に近接が届く時間は**縦でも横でも 0〜12%** でした。 |
| **マルチの位置**(原因) | 三姉妹戦を動かす HOST だけが並走の例外で走り続け、参加者は HOST の「止まれ」で止まっていました。95秒で 2.6km 離れ、HOST を狙う姉妹に参加者の攻撃が届きませんでした。 |
| **連続した上攻撃**(原因・全ボス共通) | 空中で上攻撃を続けると、前の振りの判定が有効のまま次の振りになります。ボスは「重なり始めた瞬間」の知らせでだけ当たるので、2振り目以降が入りませんでした(物理は接触と認めているのに当たらない)。<br>雑魚はすり抜け対策の別の処理で当たっていました。縦横に関係なく起きます。<br>直す前は試験8回中4回で計6件、直した後は 0件です。 |

| **高さや当たり判定のずれ** | 主な原因ではありません。技の姿勢の絵で体の描かれる位置は、絵の幅の最大2割ずれます。ただ、ずれる向きは主にプレイヤーから見て奥で、正面からの攻撃が届かなくなる向きではありません。後ろや上から当てる時だけ、体の奥の端が範囲から少し外れます(未修正、影響は小)。 |
| **狙う相手の選択** | マルチでは、姉妹は狙った人(多くは先頭の HOST)を基準に立ちます。後ろに並んだ近接の人は、自分から踏み込まないと届きにくいです(下の「残るリスク」)。 |
| **通信上の判定** | 原因ではありません。参加者の攻撃は HOST が確定し、HP と撃破は全端末で一致していました(4本×4人)。 |
| その他(縦だけの違い) | 三女の「羽刃の雨」の刃の出る高さを見た目のカメラで決めていたため、縦画面では刃が約2倍の高さから出て、地面まで届かないことがありました(マルチでは HOST の画面で決まる)。足元から一定の高さ(17.5m)に直しました。 |

## 2. 直したこと
**ゲームの動き**: 縦横で同じにしています(マルチで HOST が決めても全員同じ)。三姉妹だけに効きます。
- **立ち止まって戦う形**(追加のご依頼): 他のボスと同じく、戦闘の始まりに自動前進を止めます。攻撃の踏み込みや空中攻撃などはそのままです。
  - 三姉妹を全員倒すまで止めたままで、1体倒すたびに走り出しません(止まり始めと走り出しは各1回)。
  - 100km の前後(手前 20m 〜 先 120m)は穴も坂もない平地にしました。ラスダンはもともと静寂の区間から先が平地です。
  - マルチは、戦場に着いた人から止まります。後ろの人は走って追いつき、既存の合流補助で参加します。カード選択や一時停止は本人だけで、ゲーム全体の時間は止めません。
  - 戦闘中の距離の扱いは、通常のボス戦と同じです(距離を止める)。
- **立ち位置の上限**: 並び順のずれを足しても、長女 10m・次女 12.2m・三女 14.4m までにしました。押し出されても 15.5m までです(以前は 18m)。
- **三人同時の詰め**: 三人同時で姉妹が倒れたら、残りの並び順を前へ詰めます。
- **近寄る隙**: 近接が届く所に5秒来なかったら、攻撃の後に近くへ来て隙を見せます(他のボスの停止戦と同じ CloseIn)。
- **近接の振りの出し直し**: 判定が有効のまま次の振りになる時は、いったん無効にして有効にし直し、新しい重なりとして知らせ直させます。
  - 対象は、通常攻撃・上攻撃・下攻撃・急降下の着地・キャラ専用の技・槍の6か所です。
  - 結界や燃える地面などの場の攻撃は、当たり方が変わってバランスに響くので対象外です。
  - 全ボスに効く修正です。

**見た目だけ**(縦画面)
- 三姉妹が写る範囲の外に立つ時だけ、カメラを少し引きます(最大 1.3 倍、横から見る・上下2段)。斜め上は遠くまで写るので引きません。

**比較用**: 開発版では次の起動引数で前の作りに戻せます。
- `-sisHalt 0`(並走)
- `-sisReach 0`(間合い・詰め・カメラの引き)
- `-swingCycle 0`(振りの出し直し)
- `-sisBuff 0`(強化)

## 3. 強化(試作値)
**対象**: ラスダンで戦う、倒せる三姉妹だけです。通常3マップの追跡の死神は別のクラスなので掛かりません。ラスダンは今まで通り、死神に倒されても復活できます。

| | 変更前 | 変更後 |
|---|---|---|
| HP 1人ずつ(長女/次女/三女、カードの倍率の前) | 2,800 | **4,200**(×1.5) |
| HP 三人同時(1人あたり) | 2,000 | **3,000**(×1.5) |
| 攻撃力(大鎌・急降下・叩きつけ・回転・大地断ち・急降下断罪の判定、魂の弾・地を這う斬撃、全ての弾、噛みつき) | 1発 10 | **12**(×1.2) |

**掛かり方の確認**
- **二重に掛からないか**: HP は三姉妹戦の進行(ReaperFinaleBattle)で1回だけ掛けます。参加者の端末は HOST の HP で上書きされます。
  - カードの BOSS CHALLENGE(ボスHPの倍率)とは掛け算です。全カード Lv9(倍率 2.8)では 2,800 × 2.8 × 1.5 = **11,760**、2,000 × 2.8 × 1.5 = **8,400** で、実測と一致しました。
  - マルチの人数によるボスHPの補正は、もともとありません。
  - 被弾の倍率(再戦用の DamageMul)は、三姉妹戦の間 1.00 でした(記録で確認)。
- **予兆と回避**: 予兆・溜め・攻撃の間隔は変えていません。数値だけです。
- **怒り中の BREAK 不可との組み合わせ**: 三姉妹には段階(怒り)が無く、全員「段階1」のまま倒れます。BREAK 不可は一度も掛かりません。戦いが長くなった分、BREAK の回数はむしろ増えました(1人プレイ 1戦 13〜18回 → 21〜25回)。近接で攻めて崩す機会は残っています。

## 5. 確認したこと
**1人プレイ**
- 横画面と縦の3つの見え方で、三姉妹全員に攻撃が通ります。
- 止まって戦う形は、三姉妹戦の 100% の時間止まっていました。
- 戦闘範囲に穴はありません(普通に走って入った時の地面を調べて「なし」)。
- 撃破 → エンドロール(文字に乗る/石板)→ ONE MORE MILE? → **YES で走り直し**(8秒で 100,537→100,711m、10秒でさらに 250〜280m)。**NO でホームへ**。どちらも通りました。

**4人マルチ**(全カード Lv9。HOST=横、P2=縦・横から見る、P3=縦・上下2段、P4=縦・斜め上)
| 試験 | 結果 |
|---|---|

## 6. 残るリスク・未確認
- **マルチの後ろの近接キャラ**: 姉妹は狙った人(多くは先頭の HOST)を基準に立ちます。全カード Lv9 では1体が数秒で倒れるので、後ろに並んだ近接の参加者は、攻撃の踏み込みで前へ詰めないと当てる前に終わりやすいです。試験のボットは詰めないので、命中が 0 の試験がありました。
  - 姉妹の狙う相手を順に替える、などで改善できます。仕様に関わるので、ご判断をお願いします。
- **全カード Lv9 での手応え**: 強化後でも三姉妹戦の合計は約47秒で、被ダメージはほぼ 0 でした。終盤の強いデッキに対しては、試作値の 1.5倍 / 1.2倍 ではまだ軽い可能性があります。
- **開発用のワープの不具合**(既存、製品の動きには影響なし): ワープの瞬間に作る地形だけ、座標の切り替えより先に作られます。そのため、静寂の区間でも穴が出ることがありました(ワープ先から約120m)。試験ではワープを三姉妹の手前(99,700m)にして避けました。
- **未確認の環境**: Android 実機(縦横の回転を含む)、実機どうしのマルチ(LOCAL/Relay)、人の操作での手応え。試験はすべて Windows の開発版と試験用ボットです。
- **VERSUS で YES の後の最終順位**: 前回の報告のとおり、ご判断待ちです。
