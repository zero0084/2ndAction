## 攻撃(役割をはっきり)
### 荒野王 ガルムード(距離を止めた決戦、前方に立ちはだかる)
- 通常: 角の振り上げ(地上の低い帯 → 跳ぶ)
- 移動を要求: 突進(画面の右から左へ。予兆 = 前脚で地面を掻く + 砂煙 + 地面の帯)→ 跳んで越える / 二段
- 上下の判断: 城壁の瓦礫を投げる(高い弧 = 地上にいる / 低い = 跳ぶ。軌道線)
- 強攻撃: 大地割り(前脚の踏み込み → 地面の衝撃波が 2 列。低い → 跳ぶ、続けて高い砂嵐 → 地上)
- 必殺技「荒野の終焉」: 亡霊の騎兵隊が上下交互の帯で駆け抜ける(低 → 高 → 低)+ 本体の咆哮
- BREAK: 前脚が崩れて伏せる、背の城壁が崩れ軍旗が倒れる、角の付け根(弱点)が光る → 打ち上げ・空中攻撃で大ダメージ
- BREAK 明け: 立ち上がりの咆哮(砂の衝撃波、小さい = 跳ぶ)
- 撃破: 前のめりに崩れ、砦の瓦礫が崩れ落ち、砂嵐が止んで街道が開ける

### 深淵の主 ノクタリス(走りながら、地面の下を並走)
- 通常: 背びれの結晶が地面から列で突き出る(地面の帯 → 跳ぶ)
- 移動を要求: 天井から結晶のつららを落とす(落ちる列の影と光 → その場所を通る時は地上で前へ / 跳ばない)
- 上下の判断: 長い尾で上の帯を薙ぐ(高い帯 = 地上にいる)/ 頭で下を噛む(低い = 跳ぶ)
- 強攻撃: 深淵の大顎(地面に光る輪 → 真下から飛び出して噛む → 輪の外へ跳ぶ/越える)
- 必殺技「深淵の潮」: 画面が暗くなり、結晶の光だけで見える上下交互の帯 + 闇の波(光る線で予告)
- BREAK: 地上に全身を出してのけぞり、胸の大結晶(核)がむき出し → 打ち上げ・空中攻撃
- BREAK 明け: 潜る時の結晶の飛散(低い = 跳ぶ)
- 撃破: 結晶が次々に砕け、光が消え、地底湖へ沈む

### 天帝 セラフィエル(走りながら、前方の空)
- 通常: 光の羽根の連射(低い列 / 高い列を交互、色で区別)
- 移動を要求: 光の槍を地面へ降らせる(地面の光の円 → 円を避けて進む = 跳んで越える)
- 上下の判断: 翼の薙ぎ払い(上の帯 = 地上 / 下の帯 = 跳ぶ。翼の動きで予告)
- 強攻撃: 裁きの光線(高さを示す細い線 → 太い光線が横切る。線が低い = 跳ぶ / 高い = 地上)
- 必殺技「天の裁き」: 光輪が広がり、上下交互の光の帯 3 本 + 最後に全体の閃光(安全な高さを光で示す)
- BREAK: 翼が畳まれ光輪にひび、プレイヤーの跳べる高さまで降りてくる → 空中攻撃・急降下で大ダメージ
- BREAK 明け: 翼を広げる風(弱い押し戻し)
- 撃破: 翼が羽根になって散り、光輪が砕け、雲海が割れて光が差す
