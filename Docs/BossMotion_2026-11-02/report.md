# ボス戦のアニメーションの見直し(2026-11-02、APK 419 の続き)

対象: 荒野の竜 / メカドラゴン / 天空回廊のボス 10体(魔人・ベヒーモス・タイタン・ジェリーフィッシュ・リヴァイアサン・フェンリル・スカイゴーレム・フェニックス・スカイサーペント・ガーディアン)

## 見方
- 新しい試験 `-qaBossMotion <dir> -bmBoss <種類>` で、実際のボス戦(足を止めて向き合うカメラ)を通常速度・30fps で撮影した。
  - 1体あたり 73 秒: 普段の技 30 秒 → 最終段階の技 20 秒 → 必殺技 12 秒 → BREAK に入る → 立ち直り 10 秒。
  - フレームごとに、姿勢・表示中の絵の名前・絵の位置・攻撃判定の有無・BREAK を記録した(`bm_log.tsv`)。
- 絵が切り替わる瞬間ごとに、前後のコマを同じ縮尺・同じ切り抜きで並べた(`bmstrip.py` / `montage.py`)。
- 2枚の絵の形の一致度と、重心・頭の位置のずれも測った(`bmjump.py`)。

## 見つかったこと(変更前)
- 天空回廊のボスは、待機・構え・攻撃・戻りがそれぞれ1枚絵で、1コマで切り替わっていた。
  - 武器・翼・首が一瞬で元の位置へ戻る。
  - 特にひどかった所: ガーディアンの突き → 戻り → 待機、フェニックスの突進 → 待機、ジェリーフィッシュの放電 → 戻り。
- BREAK 中も待機の絵のままで、崩れたことが体で分からなかった。
  - 天空の9体、竜、魔人が該当。
  - メカドラゴンだけは専用の絵があった。
- 竜:
  - 立ち上がった溜め → 頭から急降下 → 翼を打ち下ろして上昇、がそれぞれ1コマで切り替わっていた。
  - 上昇の後は、翼を打ち下ろした1枚の絵のまま、約1.3秒すべって戻っていた。
- 魔人: 腕を組んだ待機 → 腕を大きく広げる振りかぶり、と、戻り → 待機が1コマで切り替わっていた。

## 直し方
変更は見た目だけです。予兆の長さ・攻撃判定の時刻・回避できる時間・BREAK の長さは変えていません。

- **つなぎのコマ**(`Scripts/Bosses/BossLink.cs`、`Resources/BossPose/<ボス>/links.txt`)
  - settle: 絵が A → B に変わった直後の 0.12〜0.15 秒だけ、中間のコマを出す(B の時間を借りる)。
  - lead: 溜めの最後の 0.14 秒だけ、構えのコマを出す(竜の「飛び込む直前」)。
- **BREAK の姿勢**: BREAK の間は崩れた姿勢の1枚を出す。
  - 天空のボスは `break.png`、竜と魔人は `stun.png`。
  - 立ち直りは、戻りの絵 → つなぎのコマ → 待機、の順に流れる。
- **竜の戻り**: 打ち上がった後の帰りは、羽ばたきのコマに戻した(コードの1行)。
- **攻撃の瞬間**(溜め → 攻撃)は、一撃の速さを残すため、わざと1コマで切り替えたまま。
- 絵はエステルと2つの会話で、全ボスぶんを相談しながら描いた(36枚)。
  - ゲームと同じ縮尺の3枠(直前 / 空き / 直後)を渡した。
  - 描き直しは2回: ガーディアンの BREAK(脚が3本に見えた)、スカイサーペントの BREAK(渦巻きの目と星が漫画的すぎた)。
  - 足元の土ぼこりが緑がかって残った1枚(タイタン)は、その部分だけ消した。

ただし技は抽選なので、撮影の 73 秒に出なかった技もありえます。絵の切り替わりは技ごとではなく「どの絵 → どの絵」で決まるので、同じ組み合わせの技には同じつなぎが入ります。

## 試験結果
- `-qaBossMotion` 12体 × 3回(変更前 / 途中 / 最終)。失敗 0・例外 0。本物の保存は変化なし。
- **技の時刻**
  - 撮るたびに技の抽選の順番が変わるので、フレーム単位ではなく「区間の長さの集まり」で比べた(`bmstat.py`)。
  - BREAK の長さ: 全12体で前後の差は 0〜1 フレームだった。これは撮影の 30fps の刻みの範囲。例: ガーディアン 92 → 93、竜 84 → 84、メカドラゴン 106 → 106。
  - 予兆の長さ・攻撃判定の長さ・予兆の終わりから判定までの間: 普段の技は前後で同じ値がそろった。
    - 例: ガーディアンの予兆 15/18/27/30/33 フレーム、判定 7/11 フレーム、予兆 → 判定 0 フレーム。
    - 合わない値は、試験が段階・必殺技・BREAK を強制した瞬間に途中で切れた区間だけだった。
- **Android(エミュレーター、APK 420)**: ガーディアンで同じ撮影をした。
  - 失敗 0・例外 0。
  - つなぎのコマ(突き → 戻り、戻り → 待機、構えへの入り)と BREAK の姿勢が、ゲームの中で撮った画面にも出ていた。
- **見た目だけであることの確認(コード)**
  - ボスの当たり判定・ホバーの高さ・攻撃の出る位置は、初期化時の値か当たり判定の箱から決まる。表示中の絵は読んでいない。
  - 絵を読むのは HUD の顔アイコンと撃破エフェクトの大きさだけ。
