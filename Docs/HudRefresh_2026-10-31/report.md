## 1. ゲーム中の HUD(刷新)

- 左上: 走りの情報を **1枚の板** にまとめた(BEST の小さな行 / 距離(大) / 速度 / 持ち帰り予定 MILE)。旧は4枚の板で高さ約 204 → 新は約 110(設計の単位)。
- 中央上: Lv と EXP の細い帯(高さ 54 → 30)。ボス戦ではその下にボスの欄。
- 右上: HP。その下にカード(キャラ/デッキ)。
- 右下: 一時停止(大きさの設定に関係なく同じ大きさ = 押せる範囲を保つ)。
- 見た目: 半透明の濃紺 + 細い金の線 + 角の小さな金の印(`UI/HudStyle.cs`)。文字は影付きで、背景を薄くしても読める。文字の大きさ・余白・線の太さを1か所で統一。
- 位置はすべて「短辺 720 の設計の単位」× 画面の倍率で決める(解像度・縦横・セーフエリアで崩れない)。

## 2. 画面情報の表示(設定 → 「画面情報の表示」)

| モード | 表示する物 |
|---|---|
| 標準(初期) | すべて(新しい配置) |
| シンプル | HP・距離・速度・ボスの HP・BREAK・一時停止 |
| 非表示 | 一時停止のボタンだけ(控えめ)。被弾の直後 2.5 秒と HP が 1/4 以下の間だけ HP を表示 |
| カスタム | 14項目を個別に ON/OFF |

- カスタムの項目: BEST / 現在の距離 / 速度 / 持ち帰り予定 MILE / Lv・EXP / HP / キャラカード / デッキ / ボスの HP / BREAK ゲージ / コンボ数 / FINAL EVOLUTION の残り時間 / 操作ガイド・補助情報(SPEED UP!・COMBO 発動の知らせ)/ マルチの参加者。
  - 既存の表示を調べて「FINAL EVOLUTION の残り時間」「マルチの参加者」を追加しました。
  - **ダメージ数値は、今のゲームには表示がありません**(BONUS ZONE の得点表示と開発用の表示だけ)。新しく作ると画面が増えるので、今回は項目に入れていません。
- どのモードでも消さない物: 一時停止(→ 設定)、必殺技のボタン(操作)、敵の攻撃予兆・危険箇所(ワールドの演出)、脱出・カウントダウン・再開の案内、カードの3択などの画面、マルチの「切断」の表示。
- 変更はすぐ反映、保存は SaveKeys に登録した4つのキー(`HudModeV1` / `HudItemsV1` / `HudScaleV1` / `HudOpacityV1`)。再起動後も保持(試験済み)。
- HUD を隠していても、一時停止 → 設定 から戻せます(設定画面ではこの欄が右の列の一番上)。

## 3. HUD の大きさ・背景

- 大きさ: 小 75% / 標準 100% / 大 125%(ラン中の HUD だけ。一時停止のボタンとメニューは変えない)。
- 背景: 通常 / 薄め / 最小(板だけ薄くする。文字と枠は薄くしない)。

## 4. デッキの表示

- 標準: カードの欄を小さく(72%)、見出しの字を出さず板の色で分ける(金 = キャラ / 青 = デッキ)。
- **欄を軽くタップすると 6 秒だけ大きく**(見出し付き)。もう一度タップで戻す。指が動いた(フリック)時は切り替えない。欄の上で始まったタップは攻撃にしない(既存の仕組み)。
- **一時停止の間は、表示の設定に関係なく全部を大きく表示**(シンプル/非表示でも全12枚を確かめられる)。
- シンプル/非表示: 隠す。カスタム: キャラ/デッキを個別に。

## 5. ボス戦のカメラ

- ボス戦の間だけ: **13% 寄る + 地表を画面の下から 27% に置く**(旧は地表が画面の中央 = 下半分が地面の断面)。通常走行のカメラは変更なし。
- 開始/終了は 0.55 秒でなめらかに。
- 適応型: 交戦中のボス(30m 以内)とプレイヤーが画面に収まるよう、寄りを自動で弱める(横/縦。複数ボス・打ち上げ・飛ぶボス)。頭とボスの上端は画面の下から 80% まで(上は HUD)、足元は 10% より上。
- 跳び退く/駆け抜けるボスで寄り/戻りを繰り返さないよう、60m 以内にボスがいる間と見失ってから 1.5 秒は構図を保つ。
- 走りながらの戦い(停止しないボス戦)は寄りを 40% に弱める(高速の見通し)。
- **地形・当たり判定・判定用の画面幅(GameView)は変えていません**(カメラの見た目だけ)。マルチでも各端末が自分のプレイヤー基準で同じ構図。
- 縦画面(横から見る表示)はもともと地表が画面の下 22% なので今までどおり。

| 測定(1280×720) | 旧 | 新 |
|---|---|---|
| 単体ボス: 地表の高さ(画面の下から) | 0.50 | **0.27** |
| 単体ボス: プレイヤーの高さ | 128px | **147px(+15%)** |
| 単体ボス: ボスの高さ | 78px | **89px(+14%)** |
| 複数ボス: 地表の高さ | 0.50 | **0.27** |
| 交戦中のボスが画面内 | 3/3, 4/4 | 3/3, 4/4 |

## 6. ボスの HP・BREAK・コンボ

- ボスの HP/BREAK を **画面上の専用の欄に1体1行** でまとめた(`Bosses/BossHudPanel.cs`)。1本のゲージにまとめない。
  - 行: ボスの今の姿の小さな絵(識別)+ 番号(2体以上の時)+ HP の帯(段階の目盛り)+ BREAK の帯(BREAK 中は点滅と「BREAK!」)。
  - 2体以上の時は、ボスの頭の上(旧の HP の帯の場所)に同じ色の番号の印。
  - 撃破の演出で帯が消え始めたら行も消える(残ったボスの行は詰める)。
  - 横画面 = 中央上の Lv の下 / 縦画面 = 画面の下(地面の上。必殺技と一時停止の間)。
- 頭の上の HP の帯は描かない(重なっていた原因)。値は今までどおり各ボスが更新し、欄はそれを読むだけ。
- コンボ数(N HIT)と BREAK!/段階の知らせは、ボスの欄の下へ置く(重ならない)。
- ボスの名前は表示していません(今のゲームに訳した名前が無いため、姿の絵と番号で識別)。

## 7. ホーム画面(軽微な整理)

- 部屋の札5枚(キャラ選択/デッキ編集/出発/ガチャ/カード合成)の **幅と高さを統一**。出発は主な操作なので金の地(大きさは同じ)。
- 横画面の右の列(設定/マルチ/ランキング/闘技場): 狭くて字が小さすぎた → アイコンを上・名前を下に積んで字を大きく。
- 縦画面: 下のボタン列と同じ名前の部屋の札(キャラ選択/デッキ編集/カード合成/ガチャ)を出さない(同じ名前が2か所に並んでいた)。部屋の物はそのまま押せる。出発/続きから は部屋の札のまま。
- 背景・ロゴ・キャラ素材・画面遷移は変更なし。
