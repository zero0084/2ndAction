# 敵のアニメーションのドタバタの見直し(2026-10-24)

## 調べ方

コマ一覧だけでなく、ゲームの中で動かして毎フレームを記録しました(新しい `-qaAnimJitter`)。

- 対象: 雑魚20種 + ボス21体(荒野10・洞窟11)を、補助の自動攻撃で戦わせて記録しました。
- 記録した内容: 毎フレームの「出ている絵の名前・絵の基準点(pivot)の位置・大きさ」。
- 絵の見える範囲は PNG と .meta から出して、画面での足元/横の位置/高さを計算しました(`Tools/art/animjitter.py`、`animfeet.py`)。
- 数えたもの:
  - コマが替わった時の 足元・横・高さ の跳び
  - 走りの途中で1枚目へ戻る回数
  - 姿勢の細かい行き来
  - 根元の上下の震え
- 通常の速さと、高速(2.5倍)の両方で測りました。
- 目で確かめたもの:
  - 気になったコマを、基準点をそろえて並べた絵
  - ゲームの中の連続したフレーム
  - 修正の前後の動画(横画面・縦画面)

## 見つかった原因と直したもの

### 1. 雑魚: 走りが細かく1枚目へ戻る(重装のオーガ、追跡型など)

- **原因**: 「動いているか」を、1フレームごとの移動量だけで決めていました(`EnemyAnimator`)。
  - 追跡の止まる距離の境目、穴の手前、不規則な動きの種では、動く/止まるが毎フレーム入れ替わることがあります。
  - そのたびに走りのコマが1枚目へ戻り、待機の伸び縮み・揺れと交互に出ていました。
- **直し方**: 最後に動いてから 0.25秒は「動いている」のまま、走りのコマを続けます。本当に止まった時の動きは今までどおりです。
- **結果(通常の速さ)**:
  - 重装のオーガ: 走りの途中で1枚目へ戻る回数 0.33回/秒 → **0回**
  - 追跡型: 0.24 → 0.12回/秒(残りは本当に止まった所)
  - 突進型の残りは「突進 → 止まる → 突進」の本来の止まりです。

### 2. 雑魚: 2枚だけの走りのコマで、体が膨らむ/縮む(洞窟のバッタ、穴のワーム)

- **原因**: 2枚だけのフォルダは、コマごとに高さをそろえる縮尺(PPU)で取り込んでいました。
  - 跳ぶ姿勢と縮む姿勢で高さが違うため、体の大きさが1枚ごとに変わっていました(横幅でバッタ −33%、ワーム +39%)。
  - 同じ縮尺で並べると、2枚の体の大きさは同じでした。絵の問題ではなく、取り込みの問題です。
- **直し方**: 2枚のフォルダも縮尺を共通にしました(`SceneBuilder.ConfigureSpriteFolderImportWithFootPivotSharedSize`)。
  - 基準は1枚目の今の縮尺です。攻撃/被弾の絵は1枚目に合わせて作ってあるので、その釣り合いと当たり判定は変わりません。
- **変わった値**:
  - バッタの2枚目: PPU 564 → 400(1枚目と同じ)
  - ワームの2枚目: 430 → 481
  - 兵隊アリはもともと同じでした。
- **結果**: 体の大きさがそろいました。跳ぶ姿勢は脚が伸びる分だけ背が高くなります(体の大きさは同じ)。

### 3. ボス: 絵の脚とは別に、下半身が横へ揺れていた(本物の走りのコマを持つボス全部)

- **原因**: 本物の走りのコマがあるボスにも、昔の1枚絵用の「格子の変形で作る偽の脚の動き」が 0.2倍で残っていました(`BossAnimSet.rigLocoScale`)。
  - 絵の脚とは別の周期で、下半身が絵の幅の約3%(大きなボスで数十ピクセル)横へ揺れ、絵の動きと競っていました。
- **直し方**: 本物の走りのコマがある時は 0(偽の動きを足さない)。走りのコマが無いボスは今までどおりです。

## 確認したが、直さなかったもの(意図した動き)

- **ボスの姿勢の切り替えで「横へ跳ぶ」と出たもの**(サイクロプスの溜め → 攻撃 0.41 など): 棍棒・尻尾の位置で絵の重心が動いただけでした。基準点をそろえて並べると、体と足元はずれていません。
- **足元の位置**: 地上のボス/雑魚の走りのコマは、足元の跳びがほぼ 0 でした(以前の動きの見直しで直っていました)。
- **羽ばたきの敵**(コウモリ、ワイバーン、ハーピー): 羽の上下で絵の範囲が大きく変わりますが、体の位置は安定していて、羽ばたきとして自然です。
- **天空の騎士・ハンターの予兆の絵**: 剣を振り上げる/羽をたたむ姿勢の違いで、体の大きさは同じでした。
- **BREAK(崩れ → 膝つき → 立ち直り)**: 高さが大きく変わりますが、崩れる/立ち直る姿勢そのものです。

## 攻撃のタイミング

- 直したのは見た目(コマの選び方・縮尺・格子の変形)だけです。攻撃力・攻撃の間隔・予兆の長さ・当たり判定は変えていません。
- 2枚の雑魚の当たり判定は1枚目の絵から作るので、1枚目の縮尺を変えていない今回の変更では変わりません。

## まだ気になるところ(今回は変えていません)

1. **ボスの被弾の絵の割り込み**: 当て続けると、走りの間に被弾の絵が0.7秒に1回(0.12〜0.28秒)入ります。被弾の手応えとしての仕様ですが、連続で当てるとせわしなく見えるかもしれません。間隔を広げる案があります。
2. **当たった時の赤い点滅**: 多段の攻撃では、赤 ↔ 元の色が速く入れ替わります。
3. **高速時の足の滑り**: 2.5倍の速さでは、ボスの脚の回転が速さに追いつきません(テンポの上限 1.35倍)。上限を上げると脚が速く回りすぎるので、今のままにしています。
4. **止まっている雑魚**(洞窟アリ・ゴブリンなど): その場で待つ間は走りのコマが止まり、待機の伸び縮みだけになります。ドタバタではありませんが、硬く見えるかもしれません。
5. **ボスの移動のコマのテンポ**: 毎秒9〜18コマで、60fps の画面では1枚の表示が3〜5フレームとばらつきます。
6. **Android 実機**では確認していません。実機で気になる敵があれば、名前を教えていただければ同じ方法で測ります。
