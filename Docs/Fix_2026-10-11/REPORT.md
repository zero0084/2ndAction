# 実機の不具合/要望の対応(2026-10-11)

対象: 疾走後に細くなるキャラ / 持ち帰り予定 MILE / 縦画面の斜め表示の地形の切れ目 / 縦画面のカード選択 /
追加: 読み込み中の表示 / 障害物の警告 / ホームの入口の札

確認は Windows の開発版(-qaFix5、`QaSweep.Fix5.cs`)で行った。**Android 実機での確認はしていない**(下の「実機で見てほしいこと」)。
画像と動画はこのフォルダ(番号 = 項目)。

## 1. 疾走終了後にキャラが細く小さくなる

- 原因: 縦画面の「斜め上から見る」表示では、キャラの絵(Visual)をカメラへ向けている(Billboard、横へ約77°)。
  斜めのカメラが止まった時(縦 → 横の回転、表示方式の変更)に何もしていなかったため、その向きが横画面に残り、
  横から見ると幅が約2割(cos 77°)になっていた。残像(ソニックムーブ)は本体の向き/大きさを写すので残像も細かった。
- 毎回ではない理由: 被弾や穴からの復帰の姿勢で絵の向きが入れ直されると元に戻る。疾走の後は通常ランが始まるまで
  被弾が無いので、細いまま走り続けやすい。
- 見た目だけ: 当たり判定(Root とその子の攻撃判定)は回っていない(記録の hitbox の大きさ/向きは前後で同じ)。
- 修正: Billboard はカメラが止まったら元の向きへ戻す。PlayerAnimator に見張り(斜めのカメラ以外で Z 以外の回転/姿勢の演出以外の
  大きさの変化が2フレーム続いたら記録して戻す)と記録(疾走の到着/表示方式の変更の時の向き・大きさ・表示方式)。
- 確認(Windows):
  - 直す前の動きを再現(縦の斜め → 横で、向きのずれ 78°・幅 0.21)= `1_before_再現_…`
  - 直した後は 0°。表示方式の切り替え(横から/上下2段/斜め)を5回 → いずれも正面
  - 疾走(30km/90km/20km)の到着 → 正面・幅 1.00。縦の斜めで疾走 → 到着後に横へ回転 → 正面
  - 見張りが直した回数 0(他の原因は見つからなかった)
  - 動画: `video_A_sprint_to_run.mp4`(疾走 → 通常ラン)、`video_A_landscape_run.mp4`

## 2. ラン中の「持ち帰り予定 MILE」

- HUD の左の列(BEST/距離/速度の下)に「持ち帰り予定 ○○ MILE」(金色の印)。所持 MILE とは別の、帰還に成功した時に受け取る今回分。
- 脱出の長押しの間と一時停止の画面に、今回の持ち帰り / 帰還後の所持 / 通常ガチャ(1回 500 MILE)何回分 / 倒れる・ランを破棄すると受け取れないこと。
  (帰還はボタンの画面ではなく3秒の長押しなので、その間に出す。横画面は脱出の輪の右、縦画面は左の列の下)
- 値は終了時の計算と同じ式(`TakeHomeMile` = 距離の分 + 敵 + ボス + BONUS + 疾走のリング)。表示のために先に加算しない。
  広告の「MILE 2倍」は含めない。
- 確認(Windows): 表示の額 = 帰還で実際に増えた額(129 = 129)、帰還後の所持とガチャの回数も一致。
  中断 → CONTINUE の後も同じ額(二重に増えない)、中断では所持は増えない。
- 縦画面のカード選択の間だけ、1枚目の枠に重なるので持ち帰り予定の行を隠す。

## 3. 縦画面の斜め表示で前方の地形が切れたように見える

- 原因: 描画だけの問題(本来の穴ではない)。斜め上から見るカメラは道の先を遠くまで見通すが、洞窟の暗さの幕は横から見るカメラの幅
  (プレイヤーの前 約28m)までしか無く、その先の床/天井が暗くならずに明るい灰色の縦の断面に見えていた。地形と天井の生成の先端(64m/44m)も画面に入っていた。
- 修正: 斜めの時だけ、暗さの幕を生成済みの地形の先まで広げ、明かりの前方の届きを 1.7倍、地形/天井を 120m 先まで生成。
  地形の形・穴・当たり判定は変えていない。
- 確認(Windows、縦 540x960/480x1040): 切れ目は無くなり、先は自然に暗く、明かりの中の敵と穴が見える。荒野/天空/ラスダンの斜め、洞窟の横から/上下2段、横画面も確認。
  動画: `video_C_cave_oblique_run.mp4`

## 4. 縦画面のカード選択

- 候補3つを縦に並べ、それぞれ「左にカード、右に説明」を1つの枠で囲む(候補の間に余白)。
- 説明は カード名(明るい金)→ Lv/取得前後(水色、「→」)→ 効果文(白)。未選択も読み比べられる明るさ(カードの暗さ 0.55 → 0.86)。
- 選択中は枠全体を金色の縁(太く)と明るい背景にし、「✓ 選択中」(✓ は文字ではなく図形)と「もう一度タップして決定」。
- タップ: カードでも説明でも、押して動かさずに同じ枠で離したら選択(選択中なら決定)。別の候補を押すと選択の切り替え。
  押してから動いた(説明のスクロール)指は選択/決定にしない。
- 長い説明は枠の中でスクロール(文字は縮めない)。下の案内は2行まで折り返す。
- 確認(Windows): 540x960(日/独/露)、480x1040、600x900、横 960x540(横は今までどおり)。1回目で選択、別の候補で切り替え、同じ候補で決定。

## 追加 A. 読み込み中の表示

- 原因: シーンの読み直し(ラン開始/ホームへ/Retry/練習/マルチ/DEBUG のワープ)が同期の読み込みで、その間は画面が一切描かれず暗い覆いのまま止まって見えた。
- 修正(`UI/LoadingScreen.cs`): 裏で読み込み(LoadSceneAsync)、0.3秒を超えた時だけ「読み込み中…」と回る印(暗い下地+金の飾り、縦横とも中央)。
  架空の%は出さない。見せるための待ちは足さない。読み込みの間と新しいシーンの最初の重いフレームの間は時間を止め、タップを通さない(タッチ/IMGUI/uGUI)。
  終わった時に押したままの指は離すまで次の画面へ通さない。失敗/時間切れは「シーンを読み込めませんでした」+「もう一度読み込む」。起動直後も同じ。
- 確認(Windows): 読み込みの間に古いランは進まず(距離の加算なし)、入力は止まる、表示は描かれ続ける(一番長いフレーム 0.3〜0.38秒 = シーンを有効にする瞬間)、
  失敗の表示 → もう一度読み込む → 次の画面へ進む。
- 疾走 → 通常ランはシーンの読み直しが無いので、この表示は出ない(なめらかにつながることを優先)。

## 追加 B. 障害物の警告

- 対象: 当たると被害のある障害物(石/木/壁/大岩/ラスダンの落下物の着地後)と洞窟の天井の針。背景の飾り(当たり判定なし)は対象外。
- 近づいた物だけ: 速さ×1.6秒(最小14m、最大110m)の先まで、近い順に最大4個。壊れた/通り過ぎた/当たり判定が無くなった物はすぐ消す。
- 見た目: 絵の外側だけの赤い縁(塗りつぶさない)+ 小さな赤い札に白い「!」。点滅は約0.8秒周期で明るさ 55〜100%(白い閃光なし)。
  洞窟の暗さの幕より手前に縁を描く。設定 → 表示 → 「障害物の警告」で 点滅あり / 輪郭のみ。
- 確認(Windows): 荒野の昼/夕方/夜(3/52/78km)、洞窟、縦の横から/斜め。同時に最大4個以内、壊れた物に縁なし。天空回廊/ラスダン 3km では障害物が出なかった。

## 追加 C. ホームの入口の札

- 押せる物の近くに常に札: キャラ選択(肖像画の下)/ デッキ編集(ベッドのカード)/ カード合成(本)/ ガチャ(機械の下)/ 出発(扉の下、中断中のランがある時は CONTINUE の表示があるので出さない)。
  縦画面の施設のボタンの列も同じ名前に統一。札を押しても物を押したのと同じ。
- 札の縁はゆっくり明るくなる(札ごとに周期と位相をずらす)。物ごとの動き(扉の光、ガチャの揺れ、カードが浮く、本の光)は既存の演出のまま。
- 確認(Windows): 横 960x540/1280x600、縦 540x960/480x1040/600x900、日/独/露。札は画面の中に収まり、札どうしは重ならない。
