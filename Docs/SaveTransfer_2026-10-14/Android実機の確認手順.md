# データ引き継ぎ — Android 実機の確認手順(APK 310 以降)— 2026-10-14

**通常のデータに一切触れずに**、引き継ぎ(書き出し → 別の状態へ変える → 読み込み)を実機で確かめる手順です。
**実機ではまだ確認していません**(マスターが行う作業です)。エミュレーターでは、下の「0. 先に確かめたこと」を確認済みです。

## 0. 先に確かめたこと(試験の操作が通常のデータに影響しないこと)

- 試験は **専用の試験ファイル** で行います。
  - アプリのフォルダに `qa_filesave.txt` を置いている間は、起動のたびに専用のファイル `qa_test/<名前>` だけを読み書きします(開発版の APK だけの機能)。
  - 通常のデータ(PlayerPrefs)は、読みも書きも消しもしません。
- 次の物も、専用のファイルの隣(`qa_test/`)に置きます。通常のデータの物には触れません。
  - バックアップ(`SaveBackups`)
  - 引き継ぎの途中の控え(`import_pending.json` / `pre_import_*.json`)
  - デバッグランの控え(`DebugRunRestore.json`)
  - ※ デバッグランの控えだけは、APK 309 まで通常の場所を使っていました。APK 310 で直しました。
- 専用のファイルで起動している間は、画面の上の中央に赤い印 **`TEST FILE: <名前>`** がずっと出ます。印が出ていない時は通常のデータです。**その時は試験の操作をしないでください。**
- 専用のファイルから書き出したファイルの名前は `OneMoreMile_TEST_save_年月日_時分.json` です(通常は `OneMoreMile_save_…`)。
- エミュレーター(APK 310)で確認した結果:
  - 専用のファイルで起動し、ホームの操作と再起動を行った前後で、**通常のデータの PlayerPrefs と、バックアップのファイル(一覧と中身の md5)が完全に同じ**でした。
  - `qa_filesave.txt` を消した後の起動は、通常のデータ(印なし)でした。
  - 結果の数字は「6. 結果」に書きます。

## 1. 準備

- APK 310 以降(開発版)を入れた端末。PC に adb(Android SDK の platform-tools)、端末は USB デバッグを ON。
- パッケージ名 `com.zero0084.action2nd`。アプリのフォルダ: `/sdcard/Android/data/com.zero0084.action2nd/files/`
- **(推奨)通常のデータの控え**:
  - 試験の前に、通常のデータのまま 設定 → データ引き継ぎ → 「ファイルに書き出す」で控えを取ります(書き出しは今のデータを変えません)。
  - 所持MILE・BEST・カードの枚数をメモ(またはスクリーンショット)しておくと、最後に戻った時に見比べられます。
- 専用の試験ファイルを始める(PC で):
  ```
  echo devtest.json > qa_filesave.txt
  adb push qa_filesave.txt /sdcard/Android/data/com.zero0084.action2nd/files/qa_filesave.txt
  adb shell am force-stop com.zero0084.action2nd
  ```
  - アプリを起動 → 上の中央に **`TEST FILE: devtest.json`** が出ることを確かめます。
  - DEBUG → テストデータ にも「専用の試験ファイルで起動中: qa_test/devtest.json(通常のデータは読み書きしていません)」と出ます。
  - 初回は新規ユーザーと同じ状態です。チュートリアルが出たら進めるか、飛ばしてください。

## 4. 終わり方(通常のデータへ戻る)— 各端末で

1. DEBUG → テストデータ → **「専用の試験ファイルを終わる(次の起動から通常のデータ)」**。PC から行う場合:
   ```
   adb shell rm /sdcard/Android/data/com.zero0084.action2nd/files/qa_filesave.txt
   ```
2. アプリを完全に終了 → 起動。**`TEST FILE` の印が出ないこと**を確かめます。
3. ホームの MILE・BEST・カードが、試験の前(「1. 準備」のメモ)と同じであることを確かめます。
4. (任意)試験のデータを消す。中身は試験の物だけです:
   - `adb shell rm -r /sdcard/Android/data/com.zero0084.action2nd/files/qa_test`
   - ダウンロードの `OneMoreMile_TEST_save_….json`
   - **通常のデータの読み込みに、`TEST` の付いたファイルを使わないでください。**

## 5. 注意
- 専用のファイルで起動している間は、DEBUG の「テストデータ」の切り替えは出ません(混ざらないように)。
- 「進行だけ初期化 / 完全初期化」などの DEBUG の操作も、専用のファイルにだけ効きます。ただし、試験の手順には不要なので使わないでください。
- `qa_filesave.txt` の中身は**ファイルの名前だけ**です(`/` や `..` を含む物は使わず、通常のデータで起動します)。
- 製品版の APK には、この機能は入っていません。
