# 動作のつなぎ / 空中の攻撃 / 走りのグラグラ(2026-11-02)

エステル(ChatGPT)と1枚ずつ確認しながら描き足し、アイリーンが Unity に組み込んで実際の画面で確かめた。
入力への反応・攻撃が当たる時刻・次の入力の受付・敵とボスの動きの速さ・落下の軌道は変えていない(足したのは見た目のコマだけ)。

## 仕組み
- `Scripts/Data/MotionLink.cs`: 動作のつなぎの定義と再生。
  - 入る直前: 次の動作の頭に出す。当たるコマ(技の「判定が出た」段)の時刻は動かさず、その手前の構えのコマと時間を分け合う
  - 戻り: 攻撃などが終わって走りへ戻った最初に出す。操作は止めず、次の入力が来たらすぐやめる
  - 空中用: 技を空中で出した時、地上の踏ん張りの絵の代わりに出す。時間は元の技のまま(構え=当たる前、振り=当たってから)
- 素材: `Assets/Art/MotionLink/<キャラ>/`(links.tsv + コマ)。取り込みは `MotionLinkImporter.ImportAll`(シーンの作り直し不要)
- ボス: `Resources/BossAnim/<ボス>/recover*_00.png`(攻撃の後の戻り)。3〜5つ目の技の戻り(recoverC/D/E)も読めるようにした
- 走りの揺れ: `run_offsets.txt`(走りのコマごとの表示位置の補正)
- 確認用: `QaSweep -qaMotion`(`-mtLinks 0` で直す前の見た目)

## ついでに見つけて直した既存の不具合(見た目のみ)
- 連撃の2段目・3段目は、前の段の最後のコマ番号が残り、**最後のコマだけ**が出ていた(黒剣士・双剣士・拳銃士)
- ATTACK SPEED UP で振りが短くなると、攻撃の絵が途中で切れていた → 絵も同じ割合で速く
- 1枚だけの上攻撃の絵(双剣士・お嬢様の二段目)が 0.056 秒で消え、判定の間は跳ぶだけの姿勢だった → 判定の間(0.28秒)保つ
- 急降下を↑で止めた時の空中上攻撃で、攻撃の絵が出ていなかった(黒剣士・双剣士・お嬢様)
- お嬢様の走りの絵だけ、体が他の絵の約0.69倍で描かれていた(攻撃のたびに急に大きくなる)→ 走りの縮尺を 1.45 倍
- 通常ゴブリンの待機が「走りの途中の形」で止まっていた / 攻撃で押されて滑る間に走りの脚が回っていた

### ボス(攻撃の最後→移動の間の「戻り」1枚)
グリフォン・オオカミ・古代地底悪魔・大コウモリ・クリスタルゴーレム(1つ目/3つ目)・サイクロプス(2つ目/3つ目)・大ムカデ(4つ目)・ヒュドラ(3つ目)・黒騎士(3/4/5つ目)・大蛇(2つ目)・サソリ(2つ目/3つ目)・ケイブトロル(2つ目) … 計17枚。
攻撃の最後と移動の絵の重なり(形の一致度)を全ボス全技で測り、差の大きい順に描いた。スコーピオンキング・バジリスク等は元から近い形で不要。

## 走りのグラグラの調査
- 14人の走りを同じ縮尺・同じ地面で並べ、頭/胴の位置を型合わせで追った(最後→最初のコマも含む)
- 足元は全員ほぼ接地(キャラごとのピボットで合っている)。目立つのは**体全体が前後に揺れる**キャラ: 双剣士 29%・拳銃士 23%・竜騎士 20%(0,1コマ目だけ前にずれる)・お嬢様 20%(体の高さに対する割合)
- 体全体のずれなので、絵は変えずに**コマごとの表示位置**で85%打ち消した(踏み込みの上下動、マント・髪の揺れは残す)
- 上下の揺れが大きいルカ(4コマ目)・巫女・吸血鬼は、走りの踏み込みの上下動として自然な範囲と判断(絵の描き直しはしていない)
