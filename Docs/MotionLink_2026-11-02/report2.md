# 動作のつなぎ 第2弾(APK 418 の続き、2026-11-02)

方法は第1弾と同じ: 実際に再生される「直前 / 空き / 直後」をゲームと同じ縮尺で並べてエステルに渡し、描いてもらったコマを Unity へ戻して通常速度で確認。
入力・命中・次の技の受付・移動速度・落下軌道のタイミングは変えていない(見た目のコマだけ)。

## 判断の仕方
- 直前と直後の絵を同じ縮尺で重ね、形の一致度(IoU)と胴の中心のずれを全キャラ全技で測った(`scratchpad/ma/jump.py`)。
- 低い所は目で確認。
  - 一瞬で切り替わるのが自然な所は「既存で自然」とした: 突進の踏み込み(忍者の駆け抜けなど)や、元から構えのコマがある連撃など。
  - 姿勢が飛ぶ所だけ描き足した。

## 走りの位置補正と足の滑り
- 測り方(`scratchpad/ma/footslide.py`): 接地している足が、地面に対してどれだけ動いて見えるかを、補正の前後で比べた。
- 結果: 走る速さ 8 m/s では、元の絵の時点で足が体の高さの 6〜93%(平均)滑っている。補正による変化は −7〜+9 ポイントにとどまる。
- 目に見える差ではないと判断し、補正はそのままにした。お嬢様は縮尺の再調整に合わせて補正量も変えた。

- つながった回数(chain)の合計: 今回 1858 / 1856、直す前 1892

  - プレイヤーの絵の形を読むゲームの処理は無いこと(コード検索)も確認
- 結論: 入力・命中・コンボの受付は変わっていない
