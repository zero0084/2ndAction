# ボス戦の見直し: 止まって戦う形・後ろ攻撃・予兆の先読み・マルチ・死神の退避(2026-10-29〜30)

確認は Windows の試験版「One More Mile Test」(本物の保存は試験の前後で変わらないことを毎回確認)。

## 1. 走行を止めて戦う方式(BossHalt)
### 仕組み
- ボス戦(距離を止める遭遇 = BossManager.HoldsRun)の間は、**実際の前進だけ**を止める(`BossHalt.Factor`: 1 = 走る / 0 = 停止)。
  ゲーム全体の一時停止ではない(時間・攻撃・ジャンプ・重力・ノックバック・敵の行動はそのまま)。闘技場の 0km/h と同じ形。
- 関門に着くと **0.7秒**で止まり(関門の警告の演出の間)、撃破 → 報酬の選択が終わってボスの遭遇が終わると **0.9秒**で走りへ戻る。
- 止まっている間のプレイヤーは走りではなく**構えのポーズ**(開始準備のコマの「構え」で止める)。
- 移動のボタンは足していない。前後への移動は今までのフリックの攻撃の踏み込みと、ボスの接近で。
- **実際の前進と能力としての速さを分けた**:
  - `CurrentAutoRunSpeed` = 実際の前進(止まっている間は 0。ボスの並走・弾の座標系・雑魚・カメラ・地形の生成・風の音・速さの線)
  - `AbilityRunSpeed` = 能力としての速さ(止まっても変わらない。HUD の km/h・カード(MOMENTUM 等)・高速時の自動補助が働くか・予兆の先読み)
  - 高速時の自動補助は「能力の速さ」で働くかを決める(止まっても切れない)。先読みの範囲だけは実際の前進で
- **足元の安全**: 関門の距離は前から分かっているので、関門の手前 20m 〜 先 55m を、生成する前に**穴・坂・上下ルートの分岐・空中足場の無い平地**にする
  (ソロ/CPU サポート。分岐は範囲の先へ送る)。それでも危ない所(上の道の上・足元の前後に穴・分岐の中)で始まったら、止まらずに走って平らな所で止まる(マルチはこちら)。
- **残った道中の敵**: 止まる時に、戦闘範囲(後ろ 9m 〜 前 30m)の雑魚と障害物を煙と一緒に片付ける(報酬なし。ボスは消さない。マルチは共有なので触らない)。
- **カメラ**: 止まっている間は前の見通し(走りの先読み)を減らし、少し中央寄り(後ろも見える)。
- **対象と対象外**:
  | 場面 | 扱い |
  |---|---|
  | 通常の関門(1km ごと)・95〜99km の3連戦・ラスダンの通常の関門・99km の足止め | 止めて戦う |
  | ラスダン 90〜98km の走るボスラッシュ(ラン再開/連続の遭遇) | **走ったまま**(走りながらの作り。HoldsRun が false) |
  | 死神の追跡 | ボス戦ではない(走ったまま)。ボス戦の間は死神が退避(5.) |
  | 三姉妹との最終戦 | **対象外**(並走のまま「攻めて突破」) |
  | エンディング・脱出の演出 | 対象外(それぞれの止まり方のまま) |
  | 開発用の闘技場 | 今までどおり自分の速さの設定 |
- 報酬・脱出・距離の記録・中断再開の決まりは変えていない(距離はボス戦の間止まったまま、報酬の後に走り出してから進む)。

## 2. 後ろ攻撃とボスの攻撃の形
### 後ろ攻撃(全14キャラ)
止まった状態(自動前進なし)で、標準の雑魚(ゴブリン)を後ろ d m に置いて1回だけ後ろへ攻撃した時に当たる範囲(-qaHitAudit R、0.2m 刻み、最大 4m まで)。
ボス戦の中では後ろへの踏み込みが 1.6倍になる(既存の BossBattle の調整)ので、ボスにはこれより遠くまで届く。
| キャラ | 後ろ攻撃 | 当たる範囲(後ろ) | 今回の調整 |
|---|---|---|---|
| 剣士・双剣士・お嬢様 | 振り向いて斬る + 少し下がる | 1.2〜4.0m | なし |
| 二丁拳銃 | 跳び退き撃ち | 1.2〜4.0m | **撃った後に前へ向き直す**(以前は左を向いたままで、続く上/下の射撃も左へ出ていた不具合) |
| 竜騎士 | 石突きで突く(向きは変えない) | 1.2〜4.0m | なし |
| 弓・巫女・忍者・吸血鬼 | 後ろへ撃つ | 1.2〜4.0m | なし |
| 魔法使い | 後ろへ魔法弾 | 最低高度で当たる。高度を上げると地上の敵の上を越える(個性のまま) | なし(試験の手順で高度が上がっていたのを確認) |
| 竜人 | 尾の薙ぎ払い(打ち上げ) | 1.2〜4.0m | なし |
| 格闘家 | 下がって構え → 肘打ち(構えの間に被弾するとカウンター) | 1.2〜3.2m(以前は約2.2m) | 肘打ちの長さ ×1.4 |
| ルカ | 後ろ跳び → しっぽ払い | 0.2〜3.4m(以前は約1.7m、空中 1.15m) | しっぽの長さ ×1.4 |
| ペンタトゥトゥル | 膨らんで背中で弾く | 1.2〜3.8m(以前はその場で 1.2m) | 膨らむ間に背中側へ 0.8m ずれる + 弾く範囲 ×1.4(弾き飛ばしの強さはそのまま) |
- 後ろから当てた雑魚は**後ろへ**弾く(以前は当てた向きに関係なく前 = プレイヤーの方へ押し込んでいた)。
- ボス戦(止まった形)の確認: 全キャラの戦いで前/後ろとも当たる(1.の表、-qaHalt)。後ろへ入れた攻撃は 1/4 〜 8/6(後ろにボスがいる時間が短いキャラは少ない)。

### ボスの攻撃の形(止まって戦う形への適応)
- 予備動作(予兆)→ 攻撃 → 反撃できる隙(戻り)の流れは既存のまま。HP・攻撃力は変えていない。
- **近接のキャラにも届く機会**: 体(被弾の範囲)の近い端がプレイヤーから 2.6m 以内に **5秒**来ないと、次の「攻撃の後の戻り」で
  **近くまで歩いて来て(浮いていれば低く降りて)、戻りの時間(最低1.3秒)そこで隙を見せる**(見た目で分かる反撃の機会)。
- **大きく離れる間合い取りは背を向けて歩く**(3m より遠く。着く手前でこちらへ向き直る)。短い後ずさり(跳び退き)は前を向いたまま。
- 天空のドラゴン/魔人(別の作りのボス): 止まって戦う間は、浮いて待つ間合いを縮める(ドラゴン 8m → 体の前の端が 1.3m の所・被弾の範囲の下の端が地面から 0.3m、
  魔人 14m → 5.5m・揺れを小さく)。
- 背後への回り込みは増やしていない(後ろにボスがいる時間: 0〜36%(フェンリルが最も多い)、多くは突進ですれ違った後)。
- 測った値(剣士、ボスを出して25秒、被弾の範囲が前後 3m 以内かつ跳んで届く高さ = 「近接が届く」):
  | ボス | 届く時間の割合 前 → 後 | 届かない状態の最長 前 → 後 |
  |---|---|---|
  | ヒュドラ | 0% → 73% | 25.0s → 6.7s |
  | 天空ドラゴン | 55% → 85% | 10.2s → 2.9s |
  | 魔人 | 55% → 100% | 3.7s → 0.0s |
  | ベヒモス | 29% → 88% | 17.7s → 1.8s |
  | ティターン | 37% → 45% | 8.0s → 7.8s |
  | リヴァイアサン | 8% → 14% | 11.9s → 7.9s |
  | スカイサーペント | 18% → 5% | 6.2s → 7.3s |
  | メカドラゴン | 15% → 14% | 9.2s → 6.3s |
  | コウモリ(洞窟) | 32% → 55% | 7.2s → 7.4s |
  | その他(荒野・洞窟・天空の24体) | 58〜100%(変化なし) | 0.0〜5.8s |
  - 全ボスで「届かない状態」は 8秒以内になった。リヴァイアサン・スカイサーペント・メカドラゴンは届く時間の割合が低いまま(潜る/雲を縫う/高い所のレーザー
    の技が多い作り)。届く機会は来るが、短い → 調整の候補として残件。

## 3. 予兆の先読み
### 仕組み(TelegraphLead)
- スローモーションではない。**敵の行動の速さ・攻撃の時刻・当たり判定は全員共通**で、変えるのは「その画面で予兆を出し始める時刻」だけ。
- 先読みの長さ = **能力としての速さ**(止まっていても変わらない)から: 60km/h 以下は 0(今までどおりの予兆だけ)、150km/h で上限 **0.4秒**。間は直線。
  - 初期値の根拠(今ある攻撃の溜め=予告の時間を数えた): 荒野 41技 最短 0.35 / 中央 0.9 / 最長 2.3秒、洞窟 37技 0.5 / 0.85 / 1.1秒、天空 42技 0.4 / 1.0 / 1.8秒。
    上限 0.4秒 = 中央の約4割(判断の余裕が増える。最短の溜めの技でも、普通の速さで避けられる今の予兆はそのまま)。
  - 調整: `BossBattleTuning` の `foresightStartKmh`(60)/ `foresightFullKmh`(150)/ `foresightMaxLead`(0.4)。
- **ボスが実際に決めた攻撃だけ**を出す: 技を始めて(=その攻撃に決めて)から溜めに入るまでの、もともとある間(近づく/間合いを取る/待つ/高さを合わせる/複数体の順番待ち)の
  **最後の先読み秒だけ**、その攻撃の範囲に「先読みの印」を出す。未決定の行動を推測して出すことはしない。**先読みのために待ち時間を延ばしていない。**
  溜めに入れば今までどおりの予兆へ切り替わる。BREAK/怯み/撃破で、印も消える。
- 印の見た目: **四隅のかぎ括弧 + 点線の枠(中は塗らない)**。今までの予兆(縞の塗り + 点滅)と色だけでなく形で区別する。
- 対象の範囲: 範囲の予兆を持つ攻撃で、決めてから溜めまでに間があるもの = **44技**(荒野15・洞窟9・天空12・三姉妹の最終戦6・共通の近接/突進2)。
  - 地面に置く警告(TrackedHazard/洞窟の床と天井/天空の落雷 など)で知らせる技、技の始めにすぐ溜めに入る技(約70)は、**置いた瞬間に場所が決まる**(プレイヤーの今の位置を狙う)ため、
    早く出すには攻撃そのものを変えることになる → 今回は今までどおりの予兆だけ(残件)。
  - 発射前に追尾する攻撃(メカドラゴンのレーザー照準・コウモリの天井・グリフォンの急降下 など): 今までの予兆(照準/影)のまま。追尾中と確定後の見た目の区別は今回は足していない(残件)。
  - 発射後も追尾する弾: ボスの弾には無い(調査で確認。跳ね返した三姉妹の弾がボスへ向かうものだけ)。
### 確認(-qaLead、同じボス・同じ乱数で 45km/h と 150km/h、各14秒)

|---|---|---|---|---|---|
| オオカミ | 0 / 0.40秒 | 1.32秒 ×5 | 1.32秒 ×5 | 1回・0.40秒前 | 0 / 0 |
| 黒騎士 | 0 / 0.40 | 0.47〜0.62 | 0.37〜0.62 | 2回・0.40 | 0 / 0 |
| サソリ | 0 / 0.40 | 0.60〜0.82 | 0.62〜0.82 | 3回・0.40 | 0 / 0 |

- 普通の速さ(45km/h)では先読みの印は出ない(今までどおり)。先読みの印は上限(0.4秒)より前には出ない。

## 4. マルチ
- **止まる範囲と参加者**: HOST が「止まる遭遇の最中か」と**戦闘範囲の基準(関門に着いた最前の人の論理X)**を JOIN へ配る(変わった時と3秒ごと)。
  各端末は**自分のプレイヤーが戦闘範囲に入ったら**止まる。後ろにいる人は追いつくまで走る(無関係な人を急に止めない)。撃破の報酬が終わったら全員が走りへ戻る。
- **攻撃の決定・対象・時刻は HOST だけ**が決める(今までどおり)。速さの違う参加者がいても、攻撃の時刻/判定は全員同じ。
- **予兆の先読み**: HOST は決めた攻撃の範囲と「溜め(予兆)が始まる共通時計の時刻」を、先読みの上限 + 0.25秒前に JOIN へ送る(見込みが 0.15秒以上ずれたら送り直す、
  攻撃が来なかった時は取り消しを送る)。JOIN は**自分のプレイヤーの能力の速さ**で先読みの長さを決めて、その時刻の前に印を出す。
  **遅れて届いて予兆の時刻を過ぎていたら出さない**(古い予兆を後から出さない)。攻撃の時刻を端末ごとに変えることはしない。
- 確認(HOST/JOIN の2つの起動、JOIN は走りが 2.6倍、HOST は先読み 45km/h 扱い、JOIN は 150km/h 扱い):
  | | オオカミ | 黒騎士 |
  |---|---|---|
  | JOIN: HOST から「止まる」を受け取り、戦闘範囲で止まる/撃破後に戻る | ○ | ○ |
  | HOST(後ろ): 戦闘範囲へ追いついてから止まる | ○ | ○ |
  | 先読みの知らせ 送った/届いた/遅れて捨てた | 5/5/0 | 7/7/0 |
  | 先読みの印 HOST(45km/h)/ JOIN(150km/h) | 0 / 5 | 0 / 7 |
  | 例外 | 0 | 0 |
- 未確認: 3人以上・実際のネットの遅れ(同じ PC の2つの起動で確認)。ONLINE(Relay)での確認はしていない。

## 5. 死神の退避(追跡中に通常のボス戦が始まった時)
- ボス戦が始まったら(関門の警告から報酬の選択が終わるまで)、死神は大鎌の予告/攻撃を止めて判定を切り、**画面左端の外まで歩いて下がり、そこで待つ**。
  接触・攻撃・被弾は起きない(死神に体の判定は無く、大鎌の判定を止める)。見た目だけ外へ出して判定が残る、ことはない。
- 追跡の状態は**一時停止**(リセットしない): 登場からの時間(詰める速さの強化)・引き離された時間・再追跡の強さはそのまま止まる。
- 報酬の選択が終わって走りへ戻ったら、**退避の前と同じ間合い**(画面左端までの距離に対する割合)へ戻ってから追跡を続ける。
  ただし**落ち着く位置(割合 0.6)より近くには戻さない**(戻った瞬間に捕まる配置にしない)。戻る速さはプレイヤーの今の走り(止まった所から加速する分)に合わせる。
- 脱出/ゲームオーバーは今までどおり死神を止めたまま(再開しない)。マルチは HOST が位置を決めて配る(JOIN は届いた位置のまま)。中断再開は今までどおり(ボス戦中は中断データを書かない)。
- 三姉妹との最終戦(ReaperSisterBoss)は別のもので、この退避の対象外。
- 確認(-qaReaperRetreat、荒野/洞窟/天空、101km の関門):
  | | 荒野 | 洞窟 | 天空 |
  |---|---|---|---|
  | 退避の前の間合い | 2.1m(割合 0.14 = 捕まえる寸前) | 同 | 同 |
  | 画面の外へ出るまで | 0.44s | 0.42s | 0.42s |
  | 戦いの間の攻撃 / 強化の時間の進み | 0回 / +0.00s | 0回 / +0.00s | 0回 / +0.00s |
  | 戻った間合い / 戻るまで | 11.2m(0.72)/ 1.98s | 同 / 2.03s | 同 / 2.03s |
  | 戻って2秒以内に捕まる | なし | なし | なし |
- **扱いの注意**: 捕まる寸前(割合 0.14)でボス戦に入った時は、戻る時に落ち着く位置(0.6)まで離れる = **少し有利になる**。それ以外(0.6 以上)は前と同じ間合いへ戻る。
  「ボス戦を挟むだけで捕まらなくなる」ほどではない(戻った後は今までどおり詰めてくる)。
