# タイトル画面 / デッキ編集の操作の仕上げ / カードの分解 報告(2026-10-31)

## 1. タイトル画面

**流れ**: 起動 → (起動ロゴ) → **タイトル** → 入力 → ホーム。アプリを起動した最初の1回だけ(ランからホームへ戻る時の読み直しでは出ない)。

| 項目 | 内容 |
|---|---|
| 題名 | 中央に「ONE MORE MILE」。エンディングの最後の問い「ONE MORE MILE?」と**同じ金の文字の絵**(GlyphFont)を使い、? の無い形 = 開始時は題名、エンディングでは問い |
| 背景 | 夜明け前の暗い空と、地平線(中央の消失点)まで続く一本の石畳の道。人物・城・文字なし。**エステルと相談して生成**(画風は荒野街道の背景に合わせた)。`Resources/Title/title_bg.png`(1664×936、4の倍数にそろえて圧縮が効く大きさ) |
| 案内 | Android など: 「タップして開始」/ PC: 「キー・クリック・パッドのボタンで開始」(機器で切り替え、30言語)。ゆっくり明滅 |
| 開始 | タップ / マウスのどのボタン / どのキー / パッドのボタン・十字。押してから **約0.35秒**で消えてホームへ(長い演出なし)。押した指/キーはホームへ持ち越さない |
| Esc / Android の戻る | タイトルの間は何もしない(後ろのホームへ通さない) |
| 読み込み | ホームはタイトルの下で普段どおり準備(セーブの読み込み・設定・移行・サービス・ランキングの準備・画面の向き・Safe Area・入力機器)。**タイトルのために待たせる処理は無い**。準備が終わる前に押した場合は、準備が終わった時点で受け付ける(案内は準備中は薄く表示) |
| 縦/横 | 背景は画面を覆うように切り抜き(道と消失点は常に中央)。文字は画面の幅に収める |

計測(Windows、1280×720): タイトル表示 1.7秒 → ホームの準備完了 3.3秒(表示から 0.2秒後)→ 入力から 0.33秒でホーム。

## 2. デッキ編集

### 配置(縦・横とも)
- **上段**: キャラカード 3枠(1行・コンパクト)+ **デッキ 12枠(6列×2段)** + 「デッキ n/12」・**種類の内訳(7種類のアイコン×枚数)**・おすすめ編成・全て外す(赤のまま)
- **下段**: 所持カードの一覧(横画面 9列前後・縦画面 5列。以前は3列)+ **小さな詳細**(名前 / 種類・Lv・★・所持 / 主な効果 / 説明 / 「詳細」ボタン)
- 小さな詳細は**畳める**(横画面は細い帯に、縦画面は1行に。畳むと一覧が広がる)。全部の情報は長押しの大きな詳細で
- 縦画面: 戻る・デッキの切り替え → キャラカード|枚数・内訳・ボタン → デッキ 6×2 → 小さな詳細 → 絞り込み → 一覧
- 右上の共通の設定ボタン(⚙)に重ならないよう、その下から並べる
- 絞り込みの7種類(+全て)はそのまま。並べ替え/絞り込みを足せるよう、一覧の並びは `displayedStacks` の1か所で決める作りのまま

### 操作
| 操作 | 結果 |
|---|---|
| タップ(所持) | 今までどおりデッキへ入れる(+ 小さな詳細) |
| タップ(デッキ) | 今までどおり外す |
| **長押し**(所持/デッキ/キャラカード) | **大きな詳細**: 名前・種類・Lv・★・所持数(分解できる数)・主な効果・**Lv1/現在/Lv9 の効果**・説明・**COMBO**(一緒に持つと発動する相手)・**FINAL EVOLUTION**・使用状況(デッキ/キャラカード/ほかのプリセット)・解放条件・Mastery/AWAKENED |
| ドラッグ 所持 → 空き枠/デッキの欄 | 入れる(緑で表示) |
| ドラッグ 所持 → 埋まった枠 | **勝手に置き換えない**。橙で表示し、離すと「デッキの『A』を『B』に入れ替えますか？」の確認 |
| ドラッグ 同じカード(Lv違い/合成違いも) | **赤**で表示し、デッキにある方が点滅。離すと「このカードはすでにデッキに入っています」(入れない) |
| ドラッグ デッキ → 一覧 | 外す(一覧の上に「ここで離すとデッキから外します」) |
| ドラッグ デッキ → デッキの別の枠 | 並び替え(埋まった枠とは入れ替え、空き枠へは末尾へ) |
| ドラッグ 所持 → キャラカード枠 | 装備(埋まっていれば確認) |
| 持ち上げの見た目 | カードが 1.12 倍で少し傾いて浮き、影が付く。元の場所は半透明。タッチの時は指で隠れないよう少し上に |

**長押しとドラッグの区別(Android 向けの値)**
- 動いたとみなす距離: 画面の dpi × 0.07(約1.8mm。420dpi で約29px。最低14px)
- 長押し: 動かさずに 0.5秒 → 大きな詳細
- タッチで一覧のカードを運ぶ: 0.2秒押してから動かす(押した時に少し大きくなって「持ち上げられる」合図)。0.2秒より前に動かすと**一覧のスクロール**
- デッキのカード: すぐ動かせば持ち上がる(デッキはスクロールしない)
- マウス: カードの上から動かせばすぐ持ち上がる(一覧のスクロールはホイール/カードの無い所のドラッグ)
- パッド/キー: ドラッグはしない。今までのタップ操作 + 小さな詳細の「詳細」で大きな詳細(分解もここから)

## 3. カードの分解

| 項目 | 内容 |
|---|---|
| 入口 | 長押しの大きな詳細(またはパッド/キーは小さな詳細の「詳細」)→「分解 +N MILE」 |
| 単位 | 物理的な1枚((カード, Lv) の束から1枚)。処理は枚数を受け付ける作り(将来のまとめて分解用。画面は今は1枚ずつ) |
| 使用中 | デッキ・使っていないプリセット・どれかのキャラのキャラカード枠で使っている分は分解できない。空きの枚数からだけ。空きが無ければ「使用中のカードは分解できません。デッキ・プリセット・キャラカードから外してください。」(**勝手に外さない**) |
| 最後の1枚 | 分解できる。確認の窓で赤字の強い警告(「これはこのカードの最後の1枚です…」)+「はい」が赤 |
| 高いレア度 | ★4以上 または Lv5以上: 「レア度の高いカードです(★n Lv.n)」+「はい」が赤 |
| 確認の窓 | カード名・Lv・受け取る MILE・「分解したカードは元に戻せません。」 |
| 分解の後 | 所持 -1・MILE 加算・一覧/内訳を書き直し・残りがあれば大きな詳細の数を更新、無ければ閉じる・「分解しました: +N MILE」 |
| 保存 | すぐに1回で(所持カード + MILE + Mastery の記録をまとめて書く。合成と同じ方式) |
| 記録(ログ) | `[Dismantle] cardId=… Lv… ★… x1: count a->b, MILE +N (total T), remaining of this card R` |
| 守るべきカード | 調査の結果、所持が必要なカードは無い(解放は距離、初期デッキ/ULTIMATE/チュートリアルは所持に依らない。デッキが空でもランは始まる)ので、特別に守るカードは設けていない |
| Lv / Mastery | Lv はその1枚に注ぎ込んだ Lv1 の枚数以下なので Lv 倍で払い戻す。Mastery の進み・AWAKENED は所持と別の記録なので変わらない。**Lv9 を分解する前に MAX の記録を確定**(MAX x/112 が減らない) |
| 以前の CONVERT(一律 100 MILE) | 分解に置き換え(小さな詳細のボタンは「詳細」に) |

### 払い戻し(正式な値の提案)
**★の数 × Lv × 50 MILE**(合成の「両方失敗」の払い戻しと同じ式)

| レア度 | Lv1 | Lv9 |
|---|---|---|
| ★1 | 50 | 450 |
| ★2 | 100 | 900 |
| ★3 | 150 | 1,350 |
| ★4 | 200 | 1,800 |
| ★5 | 250 | 2,250 |

- ガチャ1回 500 MILE に対する期待値: 段階1 約69(14%)/ 段階2 約82(16%)/ 段階3以上 約88(18%)。目安の約20%より少し低い
- **分解→ガチャ→分解で増えない**: ガチャは必ず Lv1。どのカードも Lv1 1枚の払い戻しは最大 250 < 500。Lv は「合成に使った Lv1 の枚数」を超えないので、Lv9 の 2,250 も元手(9枚以上 = 4,500 MILE 以上)を下回る。レア度を上げる合成(両方成功で★+1)を挟んでも、1枚あたり 250 を超えない
- 広告ガチャ(1日3回まで・Android)のカードは元手 0 なので、分解すると 1日最大 約750(期待値 約260)MILE になる。マスターの判断材料として記載(値は `CardFusionLogic.RefundCoefficient` 1か所)
- エステルの意見: 式は分かりやすく採用でよい。Lv9 で 500 を超える点は「Lv9 は9枚以上の合成」で妥当と確認。確認の窓にカード名・Lv・MILE を出すこと(対応済み)
