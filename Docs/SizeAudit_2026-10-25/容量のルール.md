# 容量のルール(v1.0 の後に素材を足す時、2026-10-25)

前の決まり(`Docs/Size_2026-10-18/画像の取り込みの決まり.md`)に、Windows と見張りを足した物です。

## 画像

1. **幅と高さを4の倍数にする**(一番大事)
   - Android(ASTC)はどの大きさでも圧縮できますが、**Windows(BC7)は4の倍数でないと無圧縮(1画素 4バイト)になります**。
   - 今回の 3.87GB の原因はこれでした。
   - エステルの絵を入れる時、大きさが4の倍数でなければ `Tools/art/pad4.py` でそろえます(透明な画素を足すだけ、ピボットも直す)。
     - `python Tools/art/pad4.py <画像のパスの一覧.json> <記録.tsv>`(`--dry` で試すだけ)
   - 例外: 背景・地面・つながる絵・繰り返しの絵は、透明を足すとすき間が出ます。不透明なまま(Windows は RGB24)にします。
     - 置き場所は `SizeGuard.KnownRaw` にあります。
2. **置き場所の決まりに従う**(`Assets/Art` か `Assets/Resources`)
   - `TextureImportRules` が自動で掛けます。
     - Android: ASTC 4x4 / 5x5 / 6x6
     - Windows: BC7
   - 専用の取り込み(BossAnim など)は、Android を各取り込みが決め、Windows は TextureImportRules が BC7 を掛けます。
3. **大きさの目安**: キャラ・敵のコマは高さ 600〜800px、アイコン 256〜512px、カードの枠・立ち絵 1024px 前後、背景 横 1600〜2048px、エフェクト 512〜1024px。
   - 4096 を超える物は SizeGuard が警告します。
4. **同じ絵を複製しない**: 行って戻るコマなどは、再生順の仕組み(ボスは `move_seq.txt`)で同じ絵を使います。
5. **Resources の下に置く物は全部ビルドに入ります。** 使わなくなった絵は、Resources の外へ移すか消します。
   - 消す前に、コードの `Resources.Load("…")` の名前を確かめます。

## ビルドのたび(自動)

- `SizeGuard`(`Assets/Editor/SizeGuard.cs`)
  - ビルドの前: `Builds/SizeGuard_<機種>.txt` に警告を出します。止めはしません。
    - windows-raw: 4の倍数でない(KnownRaw と Repeat を除く)
    - android-no-override / windows-setting: 決まりが掛かっていない → `Tools/2ndAction/Apply Texture Import Rules (Android + Windows)`
    - huge: 4096 を超える
  - ビルドの後: `Builds/SizeHistory.tsv` に大きさを記録します。同じ種類の前回より **5% 以上増えたら警告**します。
  - 手で調べる: `Tools/2ndAction/Size Guard: Scan Textures`(`-executeMethod SizeGuard.Run`)
- APK の記録のコミットには、今までどおり大きさと前回との差を書きます。

## ストア用

- **Android の AAB は必ず Split Application Binary を ON にします**(`Tools/2ndAction/Build Android AAB (Store, split)`)。
  - OFF だと base が約396MB で、Google Play の上限 200MB を超えます。ON で base 約168MB です。
- Windows: フォルダ 1.48GB。Steam のダウンロードは圧縮されて約 0.6GB の見込みです。

## 調べる道具

- `SizeAudit.Run -sizeReport <buildreport> -sizeOut <dir>`: 画像ごとの容量・設定・Android / Windows の形式
- `SizeAudit.AstcCompare -astcFiles "a.png;b.png" -cmpFormats BC7,DXT5,ASTC_4x4 -sizeOut <dir>`: 形式ごとの画質(PSNR)と戻した絵
- 開発版の `-qaMemProbe <dir>`(ホームとランの画像メモリ)、`-qaVisCmp <dir>`(画質の比較の撮影、ボスの後のメモリ)
