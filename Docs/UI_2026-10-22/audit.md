## UiTheme
今は色9個だけで、全体で 672 個の色の直書き(金系 56種・紺系 70種)。共通の部品(OrnateUi / UiKit のボタン)自身が UiTheme を使っていない。
追加したい: GoldHover / TextSubBlue / PanelFill / PanelFillDeep / Selected / Locked / Warning(Danger と別) / Success / レア度5色 / カテゴリ7色、文字の大きさの段(見出し/本文/補足)。
進め方: 共通の部品を UiTheme に通す → 画面ごとに置き換え(見た目が変わらない値から)。
