# 画面側の完成度向上 第2段階の続き: RESULT の正式化と残りの UI(2026-10-23)

## RESULT(`GameManager.DrawResults`)
強さの順: ①距離 ②MILE ③ラン中の強化(カード)④大事な更新 ⑤細かい結果 ⑥ホームへ戻る。成功/失敗で骨格は同じ(中身だけ切り替え)。
- ① 距離: いちばん大きく。成功は下に「BEST n m」。**NEW BEST!** は「確定した成功」(LastCommit.committed && newBest)で BEST を超えた時だけ(金の札 + ごく軽い明滅)。
  失敗は到達距離を出すが、NEW BEST に使わず BEST も書かない(元の仕様どおり)。下に小さく「今回の距離は、正式な記録(BEST・累計距離・ステージ/キャラの解放)には残りません」
- ② MILE: 成功 = 「持ち帰った MILE」+コイン+大きな「+n」、下に1行で内訳(距離/敵/ボス/BONUS)と帰還後の所持。
  失敗 = 「失ったもの: このランの MILE n」(警告色はこの行だけ)/「残るもの: これまでに確定した記録・カード・MILE(所持 n)」(緑)
- ③ カード: ラン中の強化は所持に入らない(今の正式な仕様)ので、見出しは「ラン中の強化(ラン中だけ・持ち帰りません)」。共通のカード面(CardFaceRenderer)で入るだけ並べ、残りは「+N」。所持の NEW の札は出さない
- ④ 大事な更新: 起きた時だけ(金の縁で少し強く)。BEST の更新(前 → 今回)/ 新しいステージ / キャラ(お嬢様騎士の「1,000m 以下で倒れる」解放もここに出るようにした)/ 距離の解放(新しい敵など)
- ⑤ 細かい結果: タイム・敵/ボス・EXP/強化 を1行で小さく
- ⑥ 「ホームへ戻る」: 共通のボタン(UiKit)、板の下端。**指/マウスはこのボタンの上だけ**で戻る(以前は画面のどこをタップしても戻った → 情報の上の誤タップで戻らない)。パッド/キーの決定・戻るは今までどおり
- 板の高さは中身に合わせる。距離と MILE は常に上、③〜⑤は入らない時だけ中でスクロール、ボタンは常に下
- 確認: `-qaResult <dir> [-rsLangs ja,en,de,ar,my]`(成功 NEW BEST / 成功 / 失敗 / 強化が多い時、横 1280x720・縦 720x1280)
