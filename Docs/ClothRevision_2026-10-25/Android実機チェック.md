- 確認用 APK: `Unity/2ndAction/Builds/Android/2ndAction.apk`(APK 373、開発版。黒剣士の試作の絵 61 枚を入れた状態で作った物。リポジトリは元の絵のまま)
- 代表の動きの動画(Windows、人物のまわり3倍): `Docs/ClothRevision_2026-10-25/ingame/video/黒剣士_一枚布_代表動作と切り替え.mp4`
- 見る物: マントが「赤い一枚布」で、コマが変わっても付け根・長さ・裾がそろっているか。体(顔・鎧・剣)は元の絵のままです。

## チェック(黒剣士を選んで、荒野街道で1回走るだけで大半が見られます)

1. [ ] **キャラ選択**: 黒剣士のカード(選択中・となりを選んだ非選択)と、右の立ち絵のマントが一枚布。枠・文字は元どおり。
2. [ ] **ホーム**: 左上の額縁の中のカードが崩れていない(額縁の揺れと一緒に揺れる)。
3. [ ] **出発**: 3・2・1 の間の構え2コマ → GO → 走り、でマントの形が飛ばない。
4. [ ] **走り(通常・高速)**: マントのちらつき・ガタつきが無い。7→1コマ目のつなぎ目で跳ねない。
5. [ ] **切り替え**: 走り ↔ 前攻撃(3段コンボ)・ジャンプ・着地・上攻撃(地上/空中)・下攻撃→着地の突き刺し・被弾、で色と形が一瞬で変わらない。
6. [ ] **暗い背景**: 自然洞窟で赤いマントがはっきり読める(白い縁取りの内側)。
7. [ ] **到着**: 脱出の長押し → 減速 → 到着のポーズ2コマ → 結果。距離で絵が4種類(1km 未満 / 10km 未満 / 50km 未満 / それ以上)。1種類見られれば十分です。
8. [ ] **闘技場**: キャラ欄の黒剣士の小さいカードが崩れていない。
9. [ ] 端末で重くなっていない(絵の大きさ・圧縮の設定は元と同じです)。

## 既に分かっていること(絵の不具合ではありません)

- 倒れる4コマは、とどめの直後に結果の画面(FAILED)が中央を覆うので、ほとんど見えません。結果の画面を少し遅らせるかは仕様の判断です。
- 脱出の長押しがジャンプ中に完了すると、到着のポーズのまま空中に止まります(既存の動き、布とは別件。直す作業を別に提案済み)。
- 脱出成功の後、結果の画面の裏で人物の絵が倒れる絵に切り替わります(1280x720 では隠れて見えません。縦画面などで見えたら教えてください)。
