# 実機の7件(2026-11-04)

マスターの実機確認で見つかった7件の調査と修正。原因が分かっていなかったものは、直す前の動きを残した切り替え(起動引数)で
「直す前に再現 → 直した後に消える」を同じ試験で確かめた。数値の元は `data/`、動画は別途(コミットしない)。

| # | 件名 | 原因 | 直し方 |
|---|---|---|---|
| 1 | 出発前に選んだデッキがランに反映されない | 出発の瞬間(`SetSelectedStage`)に「このマップで前回使ったデッキ」へ自動で切り替えていた | ソロの出発では切り替えない(今使っているデッキ = 最後に選んだデッキで出発) |
| 2 | デッキ編集の空白をタップするとカードが入る | 一覧から外へ出た(マスクで見えないだけの)カードが、上のデッキの空き枠/余白に重なり、タップの判定が先に当たっていた | 一覧/デッキの見える範囲の中を押した時だけカードに当てる |
| 3 | 障害物が画面内に突然現れる | 置く位置を「走行距離 + 28m」で決めていた。走行距離はボス戦の間に進んだ分を引くので、ボスのたびに置く位置が手前へずれた。28m は横画面の右端とほぼ同じ | 今のプレイヤーの位置から数え、必ず実際のカメラの右端 + 4m より外に置く。止まっていた間の置き残しをまとめて置かない |
| 4 | ボーナスで敵を追い越す | 被弾のノックバック中は自動の走りの速さで運んでいた(攻撃の踏み込みの分だけ追いつかれる)+ 殴られた後の急加速/減速 | 近づかれる → 届く距離で並走 → 離れる の段を、加速度の上限つきでなめらかに。被弾中もプレイヤーの実際の前進で運ぶ |
| 5 | 荒野の背景が同じに見える | 0〜40km がずっと「城の川辺」(A)の時間帯違い | 10km ごとに A 城の川辺 → B 風車と水車の村 → C 石橋の峡谷と岩山の見張り塔(既存の絵の並べ替え) |
| 6 | 道中の空中敵を見かけない | 出てはいる(0.5km から戦いの 2〜4 割)が、抽選の偏りで 1 分以上出ない区間・画面の上端(HUD の帯)の高さ・縦/高速で画面にいる時間が短い | 空の敵が続けて居ない時は空の組を選びやすく+それでも無ければ 1 体足す / 高さの上限 / 狭い画面・高速の時だけ前へ少し流す |
| 7 | 城下町に入ると背景が高速で流れ続ける | 城下町(関門の後の内部 1.2km)の絵の位置を「走行距離 × 0.5 を絵の幅で割った余り」で毎フレーム決めていた。絵の幅はカメラの寄り/引きで変わるので、距離が止まっていても毎フレーム数十〜数百 m 跳んだ(11km のボスは城下町の中で始まる) | 前のフレームからの距離の進みだけを足す(距離が止まれば止まる) |

### 4. BONUS の逃げるゴブリン(-qaBonusChase、黒剣士。ゴブリンが前攻撃の届く 3m に入ったら前攻撃を1回)

| | 時速 35km 追い越し | 届いた→当たる→離れる→また届く | 時速 100km 追い越し |
|---|---|---|---|
| 直す前(-bonusChaseLegacy) | 6 | 2 | 0〜2(届いた回数 1 = ほとんど届かない) |
| 直した後 | **0** | **6** | **1**(届いた 3 回、当てた 19) |

原因は 3 つ重なっていた: (1) 殴られた後の急な加速/減速(相対速度が段で跳ぶ)、(2) 被弾のノックバックの間は自動の走りの速さで運ばれ、攻撃の踏み込みの分だけ近づく + 穴の縁へ押されると真下に落ちる、(3) 高速では穴が 10m より広く、向こう岸を探しきれずに縁で待つ。
加えて時速 100km では BONUS の敵が 80〜150m 先に出て 4.5m/s で寄るため、BONUS(320m ≒ 11秒)の間に届かなかった → 画面の外にいる間だけ速く寄る。
なめらかさ: ゴブリンの速さの変化は 0.1 秒ごとに最大 29〜36m/s²(時速 35km)。前への瞬間移動 0。

## 追加の確認(2026-11-05、マスターの3件)

### 1. BONUS 時速 100km の「前への跳び」

エミュレーターの記録は跳びの回数だけで、1回ずつの記録が無かった → 跳びの瞬間に「画面に見えていたか・その時の状態」を書く記録を足し、
エミュレーターの粗いフレームを Windows で再現(1フレーム 0.05秒 = 20fps に固定、-bcDt 0.05)して撮った。

- 直す前(20fps 再現): 前への跳び 7 回。**すべて画面の中**(画面の横 38〜56% の位置)。
  - どれも「そのフレームにプレイヤーの移動が 0m、ゴブリンは普段どおり 1.2〜1.3m 進んだ」。ゴブリンが瞬間移動したのではなく、
    ヒットストップ(命中の一瞬の停止)がフレームの途中で始まった時、プレイヤーは Time.timeScale を見てそのフレームから止まり、
    敵は Time.deltaTime(次のフレームまで前の値のまま)で 1 フレーム多く進んでいた。60fps では 0.4m なので目立たず、20fps で 1.3m(画面の 2〜3%)になる。
  - 該当の秒数: 7.25(空中コンボの最中)/ 8.05 / 9.00 / 9.95(2体ずつ)。動画 `video/4_bonus_100kmh_lowfps_before.mp4`(画面の下に秒数)。8.05〜8.10 で距離の表示が止まっている間にゴブリンだけ進む。
- 直した後(1): 敵の動き(EnemySpecialBehavior)と被弾/打ち上げの動き(EnemyController)も、timeScale が 0 のフレームは動かさない(プレイヤーと同じ)。→ 20fps 再現で前への跳び 0。`video/4_bonus_100kmh_lowfps_after.mp4`
- エミュレーター(APK 434)で残った跳びは 2 種類:
  - 空中コンボで打ち上げた敵の「寄せ」(anchored)。プレイヤーの速さ + 寄せる速さで動く(瞬間移動ではない)が、粗いフレームでは 1 フレームに 1m 余分に動いて見える。エリアルコンボの既存の動きなので変えていない。
  - プレイヤーが 0.2〜0.3 秒止まった(0m)のに、ゴブリンは自動の走りの速さで走り続けて離れていった。→ 直した後(2): ゴブリンの基準の速さを「プレイヤーが実際に進んでいる速さ」に(速くなる時はすぐ、遅くなる時は 0.06 秒でなめらかに)。
- 直した後(2)の結果(Windows): 20fps 再現 = 跳び 0・追い越し 0 / 15fps 再現(エミュレーター相当)= 跳び 1〜2(どれもプレイヤーが止まった最初の 1 フレーム、1.2m)・追い越し 1〜3 / 実時間 = 跳び 0・追い越し 1。
- エミュレーター(APK 435、時速 100km × 2 回): 前への跳び 9(APK 433)→ **2 / 1**、残りはすべて空中コンボの「寄せ」(anchored)。プレイヤーが止まった時の跳びは 0。追い越し 1 / 2。時速 35km は追い越し 0・届いた→当たる→離れる→また届く 13 回。例外 0。
- 追い越し(同じ高さ = 高さの差 2m 未満で前へ出た)は、どれも殴った直後(0.1〜0.4秒)にプレイヤーが跳んでいる/踏み込んでいる最中。
  殴られた瞬間に少しだけ弾かれる(goblinHitKick 1.5m/s)・踏み込みの速さにはすぐ合わせる、を足した。空中コンボで上の段/空を通り過ぎるのは追い越しに数えない(記録だけ)。
- 時速 35km: 追い越し 0、届いた→当たる→離れる→また届く 13 回。
- 既存のエリアルコンボの試験(-qaAerial 黒剣士/双剣士 時速 45/100km): 当たった数 黒剣士 61→60、双剣士 58→64(ばらつきの範囲)、例外 0。

| 自然洞窟 | 遠景は 100km まで同じ洞窟の絵(暗さも同じ)。変わるのは遠くの結晶(目的地)の光の色と明るさだけ: 青(0〜20km)→ 青緑(20〜40)→ 紫(40〜60)→ 赤(60〜90)、10km ごとに明るい/暗いが交互。天井の高さ/針の区間は距離に関係なく混ざる | **門と遠くの光の色だけが変わり、道中の景色は同じ** |
| 天空回廊 | 遠景は昼の浮島 ↔ 夜の浮島を 20km 周期(10〜15km で夜へ、18〜20km で昼へ)。目的地はずっと神殿(色・向き・大きさだけ変わる) | **時間帯(昼夜)と神殿の色だけが変わり、道中の場所は同じ** |
| ラスダン | 遠景が 25km / 55km / 85km で別の場所の絵に変わる(各 1.5km かけて)。区間の地形の選び方(天井が抜ける区間など)も段階で変わる。90km からはボスラッシュ・静かな道・三姉妹の専用演出 | **すでに景色が変わる(10km ごとではなく 3 回)→ 変更不要** |

### 3. 天空回廊の空の雑魚(縦画面で HUD に隠れないか・見てから狙えるか)

縦画面の HUD の帯は画面の上 17%(下から 0.83 より上)。種類ごとに「体の上端が HUD の帯に入っていた時間」「体の中心が HUD より下で画面の中にいた時間(狙える時間)」を測った。

| 縦画面 | 種類 | 体の中心の高さ | 体の上端の最高 | HUD に隠れた時間 | 狙える時間(平均) |
|---|---|---|---|---|---|
| 通常 1.1km〜 | ハーピー 14 / 荒野の鳥 3 | 0.23〜0.39 | 0.41 | 0秒 | 1.8 / 2.3秒 |
| 高速 ×1.8 5.2km〜 | ハーピー 22 / 嵐の精 1 | 0.23〜0.36 | 0.37 | 0秒 | 0.5秒 |
| 通常 10.3km〜(倒す) | ハーピー 11 / 嵐の精 1 | 0.23〜0.34 | 0.36 | 0秒 | 0.7 / 1.0秒 |
| (参考)横 通常 | ハーピー 19 | 0.36〜**0.98** | 1.01 | 平均 0.01秒 | 1.5秒 |

- 縦画面ではどの種類も HUD に隠れない(地面のすぐ上、画面の下から 2〜4 割の高さ)→ 高さの上限は入れていない。
- 縦画面の高速では、ハーピーが画面にいるのは平均 0.6秒と短い(画面が狭い + ハーピーは専用の動きで、荒野/洞窟に入れた「前へ流す」が効かない)。
  狙いにくいのはこの「時間」の方で、必要ならハーピーにも同じ前へ流す処理を入れられる(未対応、マスターの実機の感触で判断したい)。
- 横画面ではハーピーが画面の上端(HUD の帯)まで上がることがある(1 回あたり 0.01秒程度)。
