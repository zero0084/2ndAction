## ① 小さすぎる敵の表示サイズ

**直したこと(25種、数値の変更だけ。絵・動き・HP は変えていない)**
- 地上・空中の通常の敵 43種を、体(武器・翼・効果・余白を除く)の大きさでゴブリンと比べました。
  - 縦長の人型は「体の高さ」、横長・翼・塊の形は「体の面積の平方根」で比べています(体形・縦横比はそのまま)。
- ゴブリンの 0.97倍より小さい 25種を、一番小さいものが 1.00倍・境目近くが 1.06倍になるよう拡大しました(小さい物どうしの大小の順は保つ)。
  - 十分に大きい 18種は変えていません(大小の関係を保つ)。縮めた敵はありません。
- 一番小さかった荒野の鳥(`flying_wyvern`、荒野/天空/ラスダン)は不具合でした。
  - 実際に出ていた羽ばたきのコマが小さい解像度の設定で読み込まれ、本来の約1/3(ゴブリンの0.22倍)で出ていました。
  - 当たり判定も止まった絵から作られ、見た目と合っていませんでした。
  - 直し方: 4.58倍にし、当たり判定を羽ばたきの絵から作るよう変えました。
- 当たり判定は見た目と同じ倍率で、足元(地上の敵)/体の中心(空中の敵)を基準に広げています。
  - 洞窟コウモリは、以前から判定が体の 0.4 上にずれていたので、体の中心へ合わせました。
- 一覧(前→後の倍率・体の比): `Docs/EnemySize_2026-11-28/enemy_size_audit.md`、`apply_log.txt`

**実際の戦闘画面での確認(補助試験 `-qaEnemySize`: ゴブリンと並べて 移動→攻撃→被弾→撃破 を撮影、毎フレームの大きさを記録)**

## ② 自分の順位と先頭との差

**作り**(参加者の欄の見出しの下に1行。表示だけで、勝敗・報酬・距離の計算は変えていない)
- VERSUS: 「2位 / 4人　先頭まで 125m」
  - 順位は RESULT と同じ並べ方: 脱落・脱出 = 確定した距離、走っている人 = 今のコース上の位置。
  - 退出した人は数えません。
- CO-OP: 「走行位置 2 / 4　先頭まで 125m」
  - チーム距離ではなく、実際のコース上の位置で並べています。
  - 並べるのは コースに居る人(生存・DOWN)。脱出・脱落・退出した人は外します。
- 「先頭」: 走っている人の一番前のとき。走り終えた人とは比べません。
- 表示の切り替わり:
  - DOWN の間は差を出さず、並び順だけ。
  - CO-OP で自分の走行が終わった後は出しません。VERSUS は順位だけ残します。
  - ラスダンのクリア後(エンドロール・問いかけ)は出しません。
- 配置: 縦・横とも、参加者の欄の中の1行です(欄が1行分のびる)。ほかの HUD と重なりません。
  - 撮影: `runs/N1_coop_natural_shots/`
- 文言 4件(ID 11119〜11122)はエステルに 29言語へ訳してもらい、取り込み済みです。

**確認**
- 通常条件の通し試験 N1(協力)/ N2(VERSUS)/ O1・O2(Relay):
  - 合流補助・DOWN・復活・脱落の後も、行が正しく更新されました。
  - VERSUS の最後の表示(例「2位 / 4人」)は、RESULT の順位と4人とも一致しました。
- 補助試験(ワープ直後)の注意:
  - HOST がほかの人の距離の急な跳びを抑える仕組み(セキュリティ監査)が、ワープした距離を少しずつ追うため、ワープ直後の数十秒だけ VERSUS の順位がずれます。
  - 普通の走行では起きません。

## ③ マルチで死神に倒されたら復活不可

**作り**
- 対象: CO-OP・VERSUS の荒野街道・自然洞窟・天空回廊。ラスダン・ソロは変えていません。
- 「死神の攻撃で HP が 0 になった」時だけ、復活できない脱落にします。
  - CO-OP は DOWN にせず脱落 = 仲間の長押しの救助の対象外です。
  - VERSUS は元から脱落です。
- 死神の攻撃かどうかは、攻撃の持ち主(死神本体)で決めます。名前の文字や参加者の申告の文字では決めません。
  - HOST: 当たった攻撃の部品の持ち主。
  - 参加者: 申告の番号から HOST が本物の攻撃を引いて判定。死神の飛び道具・続く攻撃も同じです。
- HP が残る被弾では印を付けません(後でほかの原因で倒れれば今までどおり DOWN)。通常の敵・落下も今までどおりです。
- HOST の PHOENIX・最終進化(PHOENIX)の緊急復活も使いません。
  - 参加者の HP は以前から HOST が決めていて、参加者の端末の PHOENIX はマルチでは元から働いていません(既存の作り。今回は変更なし)。
- 判定は HOST だけです。復活は HOST が DOWN の人にしか通さないので、通信の遅れで復活することはありません。救助の欄も出ません。
- 表示:
  - 本人には「ELIMINATED」の下に「死神に倒されました(復活できません)」。
  - 全員に「P2が死神に倒されました(復活できません)」の知らせ。
  - 参加者の欄の札は「REAPER」。
  - 文言 3件(ID 11124〜11126)はエステルの 29言語を取り込み済みです。
- 残る点(マスター判断): ONE MORE CHANCE(1ランに1回、倒れる一撃をハート1つで耐える)は「復活」ではなく HP が 0 にならないので、死神の一撃でも今までどおり働きます。止める場合は1行で変えられます。

**確認(補助試験: 99,200m へワープ・HP の指定)**

|---|---|---|
| C1a/C1b | CO-OP。HOST が PHOENIX を所持 | ・壁の致命傷 → PHOENIX で HP 0→10 に戻った(今まで通り)<br>・死神の致命傷 → PHOENIX を持ったまま「復活できない脱落」<br>・普通の致命傷の参加者 → DOWN → 救助(今まで通り) |

## ④ マルチのクリアと全員の終了

### 通常3マップ(HOST の脱出成功 = クリア)
- 100km では終わらず、死神の追跡と 100km 以降の走行は今までどおりです(L2 の通し試験・C 系の補助試験で確認)。
- HOST の脱出の成功が確定した瞬間に、HOST が1回だけ確定し、ランに残っている全員(後ろ・ボス戦中・カード選択中・一時停止中・DOWN)を脱出成功で終えます。
  - 各自の距離・MILE・能力は各自のデータのままです(HOST の値は写さない)。
  - 開いている画面(カード選択・一時停止・設定)は閉じてから終わりの動き → RESULT。DOWN の人は倒れたまま暗転して RESULT。
  - 知らせ: 「HOSTが脱出に成功しました」(ID 11123、29言語)。
- すでに脱出・脱落・退出した人は、その結果のままです。
- VERSUS: 終了時点の既存の順位で確定します(全員1位にはしない)。
- 二重を防ぐ作り: 知らせ(SyncHostClear)と状態の表のどちらで届いても1回だけ当てます(脱出の確定は二度通らない)。HOST 側も1回だけです。
- 通常の脱出成功は、ラスダンの正式なゲームクリアの記録・解放(GameCleared / ルカ・宇宙人の解放)には数えません(以前から別の記録)。
- L2 で見つかった不具合(HOST が先に脱出してホームへ戻ると、残った人が敵も死神もいない世界を走り続ける)は、この作りで起きなくなりました。

**確認**

| 試験 | 種類 | 内容 | 結果 |
|---|---|---|---|
| H1 | 補助・LOCAL・CO-OP | ・後ろを走る P2<br>・一時停止中の P3<br>・DOWN の P4 | 3人とも各自の距離・MILE で脱出成功。RESULT・保存・ホームの所持 MILE が各人で一致 |
| H2b | 補助・LOCAL・VERSUS | ・カード選択中の P2<br>・一時停止中の P3<br>・先に脱落した P4 | ・P2/P3 は脱出成功、P4 は脱落のまま<br>・順位は終了時の距離順で4端末一致 |
| N1 | 通常条件・LOCAL・CO-OP | HOST が 3,300m で脱出 | 走っていた3人がそれぞれの距離で終了。保存一致 |
| O1 | 通常条件・Relay・CO-OP | 同上 | 同上 |
| N2/O2 | 通常条件・VERSUS | HOST が脱出前に脱落 | 通常の VERSUS の決着。最後の順位表示 = RESULT |
| OH2 | 補助・Relay・VERSUS | H2b と同じ条件 | ・P2/P3 は脱出成功<br>・先に脱落した P4 は脱落のまま VERSUS の結果(#3/4・ボーナス付き)<br>・4端末一致 |

### ラスダン(三姉妹 → 全員クリア → エンドロール → ONE MORE MILE?)

**作り(マルチでも動くようにした)**
- 三姉妹:
  - HOST が動かし、参加者の端末には既存のボスの同期で人形として映します。
  - 参加者の攻撃も HOST へ届くので、最後の一撃が参加者でも撃破が成立します。
  - 三姉妹の弾も参加者の画面に出て当たります。
- 三姉妹戦の間は、全員が戦いの並びで止まります。入れ替わり(1人ずつの間)でも足止めは切りません。
- 勝利を HOST が1回だけ確定し、全員へ知らせます。
  - ランに残っている人(生存・DOWN)はクリア。DOWN の人はその場で立ち上がり、エンドロールを走ります。
  - 先に脱出・脱落・退出した人はその結果のままです。
  - VERSUS は確定時点の既存の順位で各自の順位を決めて知らせます(全員1位にはしない)。
  - 先に脱落していた人には、その時点の試合の結果(順位・VERSUS の MILE ボーナス)を送ります。
- エンドロールは各自の端末で、自分の位置から走ります。
  - この間は合流補助で移しません。移すと自分のエンドロールの先へ出てしまうためです。
  - 順位の行も出しません。
- ONE MORE MILE?:
  - HOST の YES/NO を全員へ送ります。参加者の YES/NO の石は攻撃で壊れず、HOST の答えを待ちます(「HOSTの選択を待っています」ID 11124)。
  - 参加者が後から着いた時は、着いた所で HOST の答えで進みます。
  - HOST がクリアしていない(脱落していた)・HOST と切れた時は、参加者は自分で選べます。
- 報酬:
  - YES の確定(そこまでの MILE・記録)も NO の終了も、各端末の自分のデータで行います。
  - YES の後に倒れても、確定した分は失いません(既存の作り)。
- 正式なゲームクリアの記録: ソロと同じ条件で、エンドロールに入った時点で各端末に記録します(CPU サポート・開発機能を使ったランは数えない)。
  - 補助試験はワープを使うので、記録されないことを確認しています(「not recorded as a clear (debug)」)。
  - 通常条件で 100km まで走る通し試験は、時間の都合で今回は未実施です。

**確認(補助試験: 99,700m へワープ・三姉妹の HP を 300 に短縮)**

| 試験 | 内容 | 結果 |

  - クリア時点で順位とボーナスを確定させる場合は、別の作りが必要です。

- 三人同時の時の連携技の光の線は、HOST の画面だけに出ます。

## ⑥ ドラゴンの BREAK 耐性と怒り中の BREAK

**調べた結果(怒りの種類)**
- 「怒り」(激昂、HP の段階)は、どのボスも HP が決まった割合を下回ると上がる段階で、撃破まで続きます。
  - 一定時間で解けるものはありません。時間で解けるのは、段階が上がる時の約1秒の咆哮だけです。
  - 段階 2 に上がる目安: 荒野の竜は HP 60%、天空の竜は 55%。
- そのため「怒り中は BREAK しない」は、実際には HP の後半は BREAK なしになります。

**作り**
- ドラゴン系4種の BREAK に要る蓄積を 1.5倍にしました(荒野の竜 26→39 / 天空の竜 18→27 / 地底竜 38→57 / メカドラゴン 52→78)。
  - HP・攻撃力・BREAK の長さは変えていません。近づいて攻撃する動きもそのままです。
  - 再戦の段階の倍率は、この上に掛かります。
- 怒り(段階 2 以上)の間:
  - 蓄積を止め、怒る前の量を残します(時間で減らさない)。通常のダメージは通ります。
  - 怒りが解ける作りにも対応しています(今のボスには解ける怒りはありません)。
- 重なった時の扱い:
  - BREAK 中に怒りへ移った時は、その BREAK(追撃を含む)を最後まで続けます。
  - 同じ一撃で両方が成立した時は、怒り(咆哮)が先で BREAK しません。
- 対象: BREAK を持つボス全部(荒野・洞窟・天空・ラスダンの各ボス、竜、魔人)。
- ゲージの表示: 怒り中は灰色になり、赤い線と「RAGE: NO BREAK」の札が出ます。
- マルチ:
  - 判定は HOST です。参加者の画面のゲージにも HOST の値と停止の印を送っています。
  - N1 で、HOST の「rage: BREAK locked (gauge kept 0.43)」と、参加者の「lock ON gauge=0.43」が一致しました。
- 比較用: 開発版の起動引数で前の動きに戻せます(`-dragonBreakMul 1` / `-rageBreakLock 0`)。

**比較(ソロ・闘技場の診断、57km 相当、各2回の平均)**

カードなしの通常構成(プレイヤーは無敵にして、ボスが攻撃できた回数を数えた):
