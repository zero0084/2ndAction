## まとめ(見つけて直した主な不具合)

1. **ボスが残ったままのラン再開の後、雑魚が1分以上出ない**(自然洞窟/天空回廊で毎回再現)— カメラの判定用の中心が、時間が止まっている間の浮動原点のずらしに付いてこず、敵の出現位置が 1〜2km 先へ送られていた。CameraFollow で修正(同じ値を使う雑魚の攻撃範囲/ボスの画面基準の位置も正しくなる)
2. **ボス戦の後の 30〜66ms の処理落ち** — 速度で広がる先読みの地形(約300区画)を1フレームで作っていた。分けて作る
3. **停止の検出が中くらいの停止を見逃していた** — Unity の unscaledDeltaTime はなめらかにされる。実時間で検出
4. **高解像度で HUD が小さい**/**4:3 でメニューが切れる**/**長い言語で字が重なる/極小**/**インド系文字の母音が逆**/**連続命中が帯と重なる** ほか画面の11件
5. 既知の9件(向き/攻撃で数秒止まる/操作不能/BREAK のずれ/天井の敵/転がる石/竜魔人のガタつき ほか)
6. テストの側の問題(製品は正しい)を十数件直した: 古い前提(デッキ10枚・古い変数)、BONUS ZONE や点滅の扱い、同時実行や保存の方式の違い

確認した環境(混ぜずに書く):
- **Windows**: 開発ビルド(Builds/WindowsNetTest)を自動テスト(-qa…)で動かした。テストは専用データ(-memSave、またはレジストリのテスト用データ)で、通常のセーブは使っていない(レジストリを使うテストは前後で一致を確認)
- **Android エミュレーター**: Pixel 系 AVD(Android 15 / x86_64 / 2400x1080)。APK を入れて自動テストと手動の確認
- **Android 実機**: 無し → 実機の項目は **未確認**
- **本物の通信サービス**: 広告はテスト広告(Google のテスト用 ID)だけ。課金は Unity IAP の FakeStore。ランキング/オンラインは未接続 → **未確認**
