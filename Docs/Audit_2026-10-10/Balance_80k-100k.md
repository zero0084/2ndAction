# 終盤(8万〜10万m)の雑魚の硬さ — 調査と調整案(2026-10-10、値は変えていない)

## 条件
- キャラ: 黒剣士(SWORDSMAN、攻撃 20、3連撃、攻撃速度 1)
- カード: なし / ATTACK UP Lv9 だけ(テスト用データ、レベルアップでカードが混ざらないよう経験値を止めた。キャラカードなし、デッキの他のカードの効果なし)
- 無敵、オートの補助は既定(100km/h から自動攻撃/回避)
- 各マップで 80,000 / 90,000 / 100,000m へワープして 35秒走り、出てきた雑魚ごとに 最大HP・命中ごとのダメージ・撃破までの命中数/時間 を記録(-qaBalHits)

## 計算式(コードから)
- 雑魚の HP = (5 + floor(距離 / 2,000)) × 10 × 種族の倍率 × カードの倍率(TOUGH ENEMIES 等。今回は 1.0)
  - `DistanceTierManager.CurrentEnemyHp`(baseHpBonus 4、hpIncreaseDistance 2,000)
  - 0m で 50、10km で 100、50km で 300、**80km で 450 / 90km で 500 / 100km で 550**(0m の 9〜11倍)
- 黒剣士の1回の命中 = 実効攻撃(EffectiveAttackPower)。ATTACK UP は +5%/Lv → **Lv9 で +45%(20 → 29)**。連撃の段で威力は変わらない(段の印はカードの発動用)
- 精鋭(ELITE)はさらに HP 倍(ChallengeSystem.MakeElite)

- 実際のラン(100km/h 前後)では、多くの雑魚は **2〜8回の命中のうちに置き去り**になって倒れなかった(記録した 179体のうち撃破は 1割ほど)。撃破できたのは、少数の命中で済む状況(穴へ落ちる/範囲の重なり/止まって戦う時間がある)だった。
- 近接の届く距離(黒剣士の基準 3.6m)を 100km/h(27.8m/秒)で通り過ぎるのは 約0.13秒で、1体に当てられる回数がそもそも少ない。
- **体感の「攻撃アップ Lv9 でも普通の雑魚に何発も要る」は、計算どおり**(HP は距離で 11倍まで伸び、攻撃は Lv9 でも 1.45倍まで)。カードの効果が反映されていない不具合ではない(ATTACK UP Lv9 = 29 で実測と一致)。

## 他のカード/強化の条件(今回は使っていない。参考)
- 攻撃系: ATTACK UP(+5%/Lv)、GROUND/AIR ATTACK(地上/空中で)、MOB KILLER(雑魚へ)、GIANT SLAYER(HP の高い相手へ)、BERSERKER/LAST STAND(HP 条件)、MOMENTUM(速度)、FINAL EVOLUTION(Lv9 の 5,000m 後に一時強化)、ULTIMATE。同系統は枠で合算して曲線(カードバランス v3)。
- 持ち込み育成(合成 Lv9)は「1回取れば Lv9」になるだけで、上限(Lv9)は同じ。

## 調整案(マスターの判断待ち。どれも未実施)
1. **距離による HP の伸びを緩める**: 例) 50km 以降は 2,000m ごとの +10 を 4,000m ごとに → 100km で 550 → 425(Lv9 で 15発)。
2. **雑魚の HP に上限**: 例) 基礎 300(=50km 相当)で止める → 100km でも Lv9 で 11発、なしで 15発。強さは数と編成(精鋭/重装)で出す。
3. **攻撃の伸びを距離に合わせる**: 例) MOB KILLER 系を「雑魚への与ダメージ +x%/Lv」→「距離 10km ごとに +y%」等、終盤ほど効くカードを1枚置く。
4. **重装/番兵(×3.0/×3.2)だけ倍率を下げる**(×2.0 にすると 100km で Lv9 38発)。
5. 速度が上がるほど当てる時間が減るので、**「すれ違いざまの一撃が重い」仕組み**(高速時は前方の雑魚に追加の当たり判定、補助の前方ダメージを強く 等)。
→ 数値は案で、敵 HP/攻撃倍率/速度/報酬/解放条件はどれも変えていない。
