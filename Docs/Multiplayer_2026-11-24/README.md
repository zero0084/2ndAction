# マルチの停止・距離ずれ / 購入の復元の結果 / 部屋のボタン(2026-11-24)

マスターの依頼(優先順: ① マルチの停止・距離ずれ → ② 購入の復元と処理結果の表示 → ③ 部屋のボタンの文言)の対応の記録です。

## ① マルチの停止・距離ずれ

### 原因(コードで特定し、2台の自動試験で再現)
1. **ボスの足止めの解除が遅すぎた。**
   - HOST が「ボス戦で走りを止める(HoldsRun)」を全員へ送っています。
   - 以前は、この足止めがボスの報酬のカードを選び終えるまで続いていました。
   - そのため HOST がとどめを刺すと、HOST がカードを選んでいる間じゅう、闘技場にいる全員と後から着いた人が止まっていました。
   - 変更前の決まりで HOST がボス報酬を 10 秒選ばない試験では、2 人とも撃破の後 **17 秒**止まりました。
2. **HOST だけが時間を止めていた。**
   - ボスの登場の演出(TempoDown)は、時間を 0 まで遅くします。
   - 撃破の演出には、スローモーションがあります。
   - 一時停止のメニューも、時間を止めます。
   - これらはマルチでも HOST の世界ごと止めていました。HOST の世界は共有なので、敵とボスが全員の画面で止まり、HOST 自身の走りも止まりました。
3. **距離の数え方が端末ごとに違った。**
   - ボス戦の間、HOST だけが自分の距離を止め、さらにボス戦の移動を距離から除いていました。参加者(JOIN)は止めず、除きもしませんでした。
   - そのためボスの後で、端末ごとに距離が違いました。変更前の試験では、2 台の画面の差が最大 **61 m** でした。
4. カード選択は以前から「本人だけ止まる」作りでした。1 の足止めが撃破の後も残っていたため、ほかの人も止まって見えていました。

### 修正
- マルチでは、ボスを倒した時点で足止めを解きます(`BossManager.HoldsRun`)。
  - 報酬のカードを選ぶ本人だけが止まります。止まっている間は狙われず、被弾もしません。これは今までの「選択中」の仕組みです。
  - シングルは今までどおり、報酬まで止まります。
- 後から来た人の扱い:
  - ボスが生きている間に闘技場へ着いた人は、そこで止まって同じボスとの戦闘に合流します(今までどおり)。
  - 着く前に倒されたボスには止められません。関門は使い終わっているので、再出現もしません。
- ボスの HP・BREAK・撃破・とどめの人は、今までどおり HOST が 1 回だけ決めます。
  - ボス報酬の知らせに番号を付けました。受け取る側は、同じ知らせを 2 回受け取りません。
- マルチでは、時間を止める/遅くする演出をしません。対象は、ボスの登場の TempoDown と、撃破のスローモーションです。
- 一時停止のメニュー:
  - マルチでは時間を止めません。カード選択と同じく、本人だけが止まって守られます。HOST へも「選択中」として知らせます。
  - シングルは今までどおりです。
- 距離:
  - マルチではボス戦の距離の除外・停止・関門への戻しをしません。全員「実際に進んだ距離」で数えるので、順位・結果に使う値と同じです。
  - 協力の復帰(置き直し)で距離の報酬から除いた分は、位置の物差しにだけ足し戻します。これで、チーム走行距離が数秒止まることがありません。
- **協力の画面の距離 = チーム走行距離(HOST が決める)。**
  - 計算: `WorldProgress.FrontHigh`。HOST の物差しで測った「活動中のプレイヤーの最前の距離」の、このランの最高値です。
    - 下がりません。先頭が DOWN・退出しても巻き戻りません。
    - ボスの関門・距離のイベントと同じ値です(2026-10-11 に採用した「共有世界の進行距離」)。
  - HOST は毎フレームの値を出します。
  - 参加者には表で約 1 秒ごとに届きます。間は、直前 2 回の値の速さで最大 1.25 秒分まで先へ伸ばし、表示は下げません。
  - 各プレイヤーの位置は動かしません(表示だけです)。距離の MILE・EXP・記録は今までどおり各自の距離です。
  - 対戦(VERSUS)とシングルは、各自の距離のままです。
- 版: マルチの通信の版を 13 → 14 にしました。止まり方と報酬の知らせが違う古い版とは、部屋を混ぜません。

## ② 購入の復元と処理結果の表示

### 原因
- 結果は 1 つの文(`NoAdsPass.LastNote`)に書いていました。起動時・復帰時の自動の確認も同じ文を書きます。
- そのため、「持っていない」「もう持っている」のよくある 2 つの場合、押す前と後で画面が全く同じでした。
  - 持っている時は、何も書いていませんでした。
  - 答えはすぐ返るので、「確認中…」も 1 フレームしか出ません。結果として「押した反応だけで、その後の結果が出ない」ように見えました。
- ストアへの繋ぎ方の途中で答えが来ないままだと、以後の確認が全部「繋がらない」になっていました。

### 修正
- 押した操作ごとに結果を出します。
  - 押す → 「購入情報を確認しています…」(黄色) → 結果(成功は緑、失敗は赤)。
  - 結果の種類:
    - 復元しました(権利を反映した後)
    - 確認しました・すでに有効
    - 復元できる購入が見つかりませんでした
    - お支払いの完了待ち
    - 繋がらない(パスを持っている人は「有効のまま」と添える)
    - 応答なし
    - 購入が取り消された
    - ストアを利用できません
  - 購入の時も同じ行に出ます: 有効になりました / キャンセルしました / 購入できませんでした。
  - 復元でその日のログイン特典が付いた時は、その行も添えます。
- 起動時の確認の最中に押した時は、走っている確認の答えをその結果として出します(押しても無反応、にしない)。
- 応答なし(20 秒)の時は、待ち続けずに結果を出し、もう一度押せます。打ち切りの後に「持っている」が届いた時は、有効にして結果を「復元しました」へ直します。
- 設定・パスの小窓を開き直すと、前の結果は消えます(古い結果を新しい結果に見せない)。
- 繋がらなかった・応答が無かったことを理由に、確認済みの購入の権利は外しません(今までどおり)。
- ストアへの繋ぎ方の途中で 30 秒答えが無い時は、次の試みを許すようにしました。

### 端末別
- **Android**: Google Play(Unity IAP)の購入・復元。上の修正の対象です。Play 経由の本物の購入・復元はまだ試していません(未確認、Release_2026-11-19 の手順)。
- **iOS**: 購入の仕組み(IAP)はまだ無く、設定にパスの欄も出しません。そのため復元も無く、今回の対象外です。
- **Windows**: 広告も課金も無いので、パスの欄は出ません。

### 押しても結果が分からない操作の点検
| 操作 | 点検の結果 | 対応 |
|---|---|---|
| 購入を復元(設定/パスの小窓) | 結果が出ない | 上のとおり |
| 広告なしパスの購入 | 結果は出ていた。「もう持っている」の後だけ無言 | 同じ結果の行へ。確かめ直しの結果も出す |
| 広告のプライバシーの設定 | 開けなかった時に記録だけ・連打できた | 開いている間は押せない(「読み込み中…」)。開けなかった時は理由を出す |
| 部屋の退出/解散(特に ONLINE) | 通信の間に何も出ず、部屋の画面に戻って押し直せた | 「部屋を解散しています…/退出しています…」→「解散しました/退出しました」。10 秒で終わらなければ失敗を出してもう一度押せる |
| ランキングの「更新」「再試行」 | 2 秒以内の押下を黙って捨てていた(失敗の直後の再試行が無反応) | 捨てずに後回しにし、その間は「読み込み中…」。終わったら「更新しました」 |
| コードネームの「保存」 | 音だけ | 「保存しました」 |
| データの削除(サービスに繋がらない時) | 閉じて開き直すしかなかった | 「再試行」のボタン |
| MILE 2 倍・広告ガチャ・データ引き継ぎ・ONLINE の部屋の作成/参加 | 処理中・結果・失敗の表示と連打防止あり | 変更なし |
| 設定の保存 | 自動保存(ボタンは無い) | 変更なし |

- 二重の防止:
  - 購入・復元は Busy で 1 本です。
  - 部屋の作成は「作成中は押せない」(既存)です。
  - 退出/解散は、処理中は押せません。
  - 報酬は SDK の通知 1 回・ボス報酬は番号付き(①)です。

## マスターの実機での確認(短い手順)
1. **マルチ(CO-OP、2 台)**
   1. 片方が先に走ってボスに着き、倒してカードを選ばずに待つ → もう片方は止まらずに走れる。
   2. 後ろの人がボスの所に着いたら、その場で戦闘に加わる。
   3. 倒した後、2 台の DISTANCE がほぼ同じ(数 m 以内)で、下がらない。
   4. 一時停止のメニューを開いた人だけが止まり、相手は走り続ける。
2. **VERSUS**: 各自の距離のまま、相手のカード選択・一時停止で止まらない。
3. **購入を復元**(Android): 設定 → 購入を復元 → 「購入情報を確認しています…」の後に結果が出る。機内モードでは「ストアに接続できませんでした…」が出て、もう一度押せる。
4. **部屋**: 部屋を作成 / 部屋に参加 / ゲーム開始 / 部屋を解散 / 部屋から退出 の文言。解散・退出は確認が出て、「閉じる」では部屋に残る。
