## D. マスターの操作(まとめ)
1. **AdMob**
   - B3: 欧州向けの同意のメッセージが公開済みかを見る。無ければ作って公開する。
   - B1/B2: ID とストアのリンクを見る。
2. **Play Console**
   - C1〜C5: アプリのコンテンツの5つの申告が済んでいるかを見る。
   - C10: 署名の SHA-1 をアップロード鍵と照らす。
   - C8: お支払いプロファイルの本人確認の期限(12/01)を見る。
3. **app-ads.txt**(B5/C11)
   - 独自ドメインを用意するかどうかを決める。
   - 広告は無くても出ますが、収益に影響します。
4. **広告なしパスを売る時だけ**(C6/C7/C9)
   - 商品・価格・ライセンスキー・テスターを用意する。
   - ライセンスキーを受け取ったら、アイリーンが GooglePlayTangle を作って購入欄を出します。
5. **本番用のビルド**
   - アップロード鍵の環境変数を指定して、「Build Android Production」を実行する。
   - パスワードはマスターが入力します。
