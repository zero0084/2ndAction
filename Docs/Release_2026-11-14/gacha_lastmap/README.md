# ガチャ = 最後に出発したマップ + 共通 30%(2026-11-15 確定版)

## 決まったこと(マスター)
- 筐体は1台です。最後に実際に出発したマップ(荒野/洞窟/天空/ラスダン)に合わせて、筐体の見た目と抽選の対象が切り替わります。
  - 出発した時点で記録し、成功でも敗北でも同じです。帰還・再起動の後も残ります。
  - マップ選択の画面で選んだだけでは変わりません。チュートリアル/闘技場/DEBUG RUN は出発に数えません。
  - まだ一度も出発していない時は荒野です。
- 1回ごとに「共通 30% / マップ 70%」で分類を抽選し、その分類のレア度の割合で1枚選びます(案1)。通常のガチャも広告ガチャも同じで、引く操作をした時点で対象が決まります。
- マップ側に対象のカードが無い時は、共通だけに切り替えず引けません。MILE も広告の回数も使いません。
  - 案内は「このマップで引けるカードがまだありません」と「条件：…」です。
- 「提供割合」の入口から、共通とマップの割合と、今の条件でのレア度別の割合を見られます。中身は抽選と同じ関数で計算します。
- 割合の表は [../GachaOdds.md](../GachaOdds.md) にあります。

## 画面(エステルと2回確認)
最終版の画像は [v3](v3) にあります。
- 横画面の家と、日本語・英語・独語・アラビア語・タミル語・ロシア語の札。
- 縦画面の家と、同じ6言語の帯。
- 提供割合の画面と、対象が無い時の画面。

1回目の相談で受けた指摘と、その直し方:
| 指摘 | 直したこと |
|---|---|
| 縦画面の帯と広告ボタンが接している | 間を 5px 空けた |
| 対象なしの長い文が帯に入らない | 文字を小さくせず、帯を上へ伸ばす(下の位置は固定) |
| 台が右端で半分切れていて、帯とのつながりが弱い | 縦画面では、台の右端(飾りの分を含む)が画面に入るまで左へ寄せた |
| 「荒野のカード 70%・」で行末に区切りが残る | 区切りの所で「荒野のカード 70%」「共通 30%」に改行(区切りの記号は消す) |
| 横画面で「広告で1回引く」が右の列(ゲーム終了)に重なる | 右の列の左端から 10px 離れるまで左へ寄せた(以前からの重なり) |
| 提供割合の表の見出しが列からずれる・割合の列に見出しが無い | 見出しと列の位置をそろえ、割合の列に「合計」 |
| 「–」が「無い」「0」「対象なし」のどれか分かりにくい | 出ない星は薄い「0%」。マップ側が空の時は表を出さず、理由と条件 |
| 説明が先で表まで遠い | 対象マップ → 表 → 注記 → 詳しい抽選の方法の順 |
| 文言 | 11042/11044/11045/11048/11049 をエステルの推奨案へ。通常と広告ガチャで割合が同じことも書いた |

確認の途中で見つけて直した物:
- アラビア語で、差し込むマップ名の文字が逆順になっていた(表示用の並べ替えを二重に掛けていた)。差し込む語は並べ替えの前の訳(Loc.AutoPlain)にした。
- アラビア語の縦の帯で、行の順番が入れ替わっていた。元の順で行に分けてから並べ替える既存の仕組み(LocGUI.RtlFix)を使った。
- タミル語で「広告で1回引く」の文字がボタンからはみ出していた(以前から)。入るまで字を小さくする(下限 65%)。
- お知らせ(タイトル)の1行目が前の仕様の「分類を選べるようになりました」のままだった。新しい説明(ID 11050)に差し替え、版を 453 にした。
