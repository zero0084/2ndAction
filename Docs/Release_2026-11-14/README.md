## 1. ガチャの分類を選ぶ機能(機能の追加。混入の不具合の修正ではない)

### 調べた結果(変更前)
- 筐体は1台で、選べる台はありませんでした。抽選は全分類(共通+解禁済みのマップ)からでした。
- 5つの台に見えたのは、直前に引いたカードの分類の見た目(スキン)が筐体に残る演出です(11/06 の依頼「共通の筐体+マップ別のスキン」)。
- 抽選の混入や、前の結果・古い所属の表示が残る不具合はありませんでした。結果の分類の表示は毎回カード自身から出ています。

### 変更後(マスターの仕様)
- 筐体は1台のまま、引く前に「共通/荒野/洞窟/天空/ラスダン」を選びます。選んだ分類のカードだけを抽選します。
  - マップの分類に共通カードは混ぜません。
- 未解禁の分類(マップ未解放/ラスダン未解放)は鍵で選べません。押すと「天空はまだ解禁されていません」のように、押した分類名を出します。
- ガチャLv・カードごとの解禁条件はそのまま(今までの抽選の対象を分類で絞るだけ)。
- 筐体のスキンは選んでいる分類に合わせます(直前に引いたカードではない)。結果の板の色・排出の光はカードの分類のままです。
- 引く前の案内:
  - 横画面: 「ガチャ」の札の2行目に「天空のカードだけが出ます」。
  - 縦画面: 下のボタンの上の帯(見出し「ガチャの分類」/紋+名前/案内)。
- 通常ガチャ・広告ガチャとも、分類はタップした時点で確定します。広告を見ている間や結果の演出中に分類を変えても、確定した抽選は変わりません。
- 対象のカードが無い分類では引けません。
  - 「この分類には引けるカードがありません」と出し、ガチャ・広告のボタンを引けない見た目にします。
  - MILE も広告の回数も使いません。別の分類へ自動で切り替えることもしません。
- 価格・1日の回数・広告なしパスの扱い・レア度の重み(50/30/15/4/1)はそのままです。
- 選んだ分類は保存します(読み込んだ時に未解禁なら共通)。所持カード・枚数・Lv・デッキは変えません。

### レア度の出方(分類別にしたことで変わる所。変更案)
レア度の重みは今までどおり「その分類にあるレア度の間で」配っています。このため、マップの分類は ★1 が無い分、高レアの割合が上がります。全部を解禁した状態の例です。

| 分類 | その分類にあるレア度 | 実際の確率(★1/★2/★3/★4/★5) |
|---|---|---|
| 共通 | ★1〜★5 | 50 / 30 / 15 / 4 / 1 %(今までと同じ) |
| 荒野・洞窟 | ★2〜★4 | 0 / 61 / 31 / 8 / 0 % |
| 天空 | ★2〜★5 | 0 / 60 / 30 / 8 / 2 % |
| ラスダン | ★3〜★5 | 0 / 0 / 75 / 20 / 5 % |

- 保証(天井)の仕組みは元々ありません。
- 変更案(マスターの判断待ち。今は上の表のまま):
  - **A 今のまま**: マップの分類は高レアが出やすい(選ぶ楽しみがある。ただしラスダンの ★5 が 5 倍)。
  - **B 無いレア度の分をその分類の一番低いレア度へ**: ★4/★5 の確率は今までと同じになります。
    - 例: 荒野 ★2 80% / ★3 15% / ★4 4%、ラスダン ★3 95% / ★4 4% / ★5 1%。

### 確認(自動試験 -qaGachaCat、横 1920×1080 / 縦 608×1080)
- 5分類それぞれ 120 回引いて、対象外のカードは 0 件。
- 未解禁は選べない。対象の無い分類は MILE も広告の回数も使わず、自動で切り替えない。
- 引いた直後に分類を変えても、順番待ちのカードは引いた時の分類のまま。筐体の見た目は切り替えた直後から新しい分類。
- 広告ガチャ: 広告の間に分類を変えても、タップした時の分類から出る。パスでも同じ。
- 所持カードの Lv・枚数とデッキは変わらない(増えるのは引いた Lv1 だけ)。
- 分類の列と案内が画面に収まり、見切れない。

## 2. 広告

### 強制広告(確認の結果、もとから仕様どおり)
- 強制広告は FAILED(倒れた/時間切れ等)の結果画面から「ホームへ戻る」時だけです。
  - GAME CLEAR、長押しの成功帰還、ラスダンの「NO」では出ません(IsWin で除外)。結果画面から戻る時もホームに戻った後もです。
- 予約の仕組みは無く、その結果画面のその場で出すかを決めます。前の敗北の分が次のランや成功帰還に持ち越されることはありません。
- 頻度の条件はそのまま: 初回ランは対象外/起動から5分以上/前回の広告から5分以上/結果1回につき最大1回。
- 用意できていない時は待たせずホームへ戻します。
- 「GAME CLEAR の後に出た気がする」件はコード上は出ない作りです。
  - 可能性があるのは VERSUS で負けた時(結果は FAILED 扱い)だけです。

### 今回直したこと
- 成功の結果画面で広告が未準備の間、画面を描くたびに読み込みを要求していました(段階的な待ちが効いていなかった)。
  - 読み込みは段階的な待ち(10秒 → 20 → 40 … 最大5分)だけにしました。
- 広告なしパスを持っている時は、報酬広告も読み込まないようにしました。
- 「購入の確認/復元」でストアから返事が来ないと、確認中のまま止まっていました。20秒で打ち切り、最後に確認した状態のままにします。
- 広告ガチャの報酬が、広告の間に画面が読み直された時に表示されないことがありました。今の画面で表示するようにしました(カードはもとから所持済み)。
- 報酬の付与はもとから SDK の正規の報酬通知だけです。通知の重複・閉じる通知との前後・遅れて来た報酬も、1回だけ付与します(既存の試験で確認)。
  - コードの説明にあった「落ちても次の起動で回収できる」は誤りだったので訂正しました。通知から付与までの一瞬に落ちた場合の回収の仕組みはありません。サーバー側の確認(SSV)も使っていません。

## 3. 更新の案内
- Google Play 公式の「アプリ内アップデート」(com.google.android.play:app-update 2.1.0)で、その人が Play から入手できる新しい版があるかだけを確かめます。
  - クローズドテスト・段階配信は、Play がその人に配信済みの版だけを返します。
- Play 以外から入れた時(開発の APK を直接入れた等)は確かめません(未配信の版を求めない)。Windows では何もしません。
- ホームに落ち着いてから1回だけ確かめます(起動は止めない、ランの途中には出さない)。ある時だけ「新しいバージョンがあります」を出します。
  - 「あとで/ストアを開く」の2択で、強制しません。通信できない時や確かめられない時は何も出しません。
