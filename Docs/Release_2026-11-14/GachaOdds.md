# ガチャのレア度の確率(2026-11-14 第2回、マスター決定)

## 決めたこと
- (第2回の途中の訂正)ガチャの対象は「最後に出発したマップの分類」になりました(gacha_lastmap/README.md)。下の表のマップの各分類の行が、そのマップに出発した時の確率です。共通の表は、共通カードの入手の仕方が決まった後に使い方が決まります。
- その分類で引けないレア度の確率は、すべて「その分類で引ける一番低いレア度」へ回します。
- それ以外のレア度は、重み(★1 50% / ★2 30% / ★3 15% / ★4 4% / ★5 1%)のままです。★4・★5 は、その分類にそのレア度のカードがある限り、4%・1% のままです。
- 抽選は、この表を作る関数(GameManager.GachaRarityOdds)と同じ物を使います。抽選と別に確率を計算する所はありません。
  - 普通のガチャも広告ガチャも同じです。
  - レア度を表で選んだ後、そのレア度のカードの中から同じ確率で1枚選びます。

## 表と抽選が一致することの確認
自動試験 -qaGachaOdds(Windows の開発版・試験用の保存)で確かめ、すべて合格しました。
- 下の表の組み合わせ(56行)ごとに、レア度の乱数を 0〜1 に等間隔で 20,000 個並べて、本物の抽選へ通しました。
  - どの組み合わせでも、出た回数が「表 × 20,000」と ±1 以内で一致しました。偶然に頼らない確かめ方です。
  - 対象の分類・対象のカード以外は出ませんでした。
- 全部を解禁した状態で、画面の抽選が使う対象と表が、下の表の最後の行と同じであることも確かめました。
- 既存の試験(-qaGachaCat 縦横・-qaGacha)も合格しました。分類ごとに 120 回引いて、対象外のカードは 0 枚でした。

## 成立しない条件
- ありません。どの組み合わせでも、一番低いレア度は ★1〜★3 です。
- 仮に将来、一番低いレア度が ★4 か ★5 になる分類ができた場合は、そのレア度が残りを受け取るので 4% / 1% になりません。
  - この時は GachaOddsIssue が理由を返し、試験が失敗します(黙って別の配分にしない)。

## ゲームの画面での確率の表示
- 今のゲームには、確率を表示する画面がありません(以前から)。この表は資料だけです。
- 画面に出す場合は文言と 29 言語の訳が要るので、エステルと相談して別に作ります。出すかどうかはマスターの判断です。

## 変わる所(変更前 = APK 451)
- 共通は、全部を解禁すると変わりません。解禁の途中は、無い ★4/★5 の分が ★1 へ回ります。
  - 例: ガチャLv1 は ★1 62.5% → 70%。
- 荒野・洞窟・天空: ★2 が増え、★3/★4 が減ります。
  - 例: 荒野の全解禁は ★2 61% / ★3 31% / ★4 8% → 81% / 15% / 4%。
- ラスダン: ★4 20% → 4%、★5 5% → 1%(★3 が 95%)。前回の報告の「★5 が 5倍」はこれで元に戻ります。

## 注意(古い保存のデータ)
- マップの分類の仕組みを入れる前から遊んでいた人は、距離の条件を満たしたマップのカードが、そのマップでの到達に関係なく解禁済みのままです(2026-11-06 の引き継ぎ)。
- その人の対象は、下の表の「到達」の列が大きい行と同じ形になります。★2 のカードは誰でも解禁済みなので、一番低いレア度は ★2 のままです。

---

重み ★1〜★5 = 50 / 30 / 15 / 4 / 1。変更前 = APK 451(対象にあるレア度の間で重みを配り直す)。変更後 = 無いレア度の分を対象の一番低いレア度へ。
ガチャLv = BEST の距離(Lv1 0m / Lv2 5,000m / Lv3 20,000m / Lv4 50,000m / Lv5 100,000m)。到達 = その分類のマップでの最高到達距離(共通は無関係、ラスダンは解放済みのとき)。
対象が同じレア度の組になる条件はまとめています。「–」は出ない。
