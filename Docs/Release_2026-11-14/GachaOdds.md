# ガチャの提供割合(2026-11-15、マスター決定)

## 決めたこと
- **対象**: 最後に実際に出発したマップ(荒野/洞窟/天空/ラスダン)。出発した時点で記録し、帰還・再起動の後も同じです。
  - まだ一度も出発していない時は荒野です。チュートリアル・闘技場・DEBUG RUN は出発に数えません。
- **分類の割合**: 1回ごとに、まず「共通 30% / そのマップ 70%」で分類を抽選します。通常のガチャも広告ガチャも同じです。
- **レア度**: 選ばれた分類のレア度の割合で選び、そのレア度のカードの中から同じ確率で1枚選びます。
  - その分類で引けないレア度の分は、その分類で引ける一番低いレア度へ回します(11/14 の B 案)。★4・★5 は、その分類にある限り 4%・1% です。
- **マップ側に対象のカードが無い時**: 共通だけには切り替えず、引けません。MILE も広告の回数も使いません。
  - 案内は「このマップで引けるカードがまだありません」と、分かる時は「条件：…」です。
- **計算の場所**: 抽選・ゲームの「提供割合」の画面・この資料・自動試験は、すべて同じ関数(GameManager の GachaShareOdds / GachaRarityOdds / GachaFinalOdds)を使います。

## 表と抽選が一致することの確認(自動試験 -qaGachaOdds、すべて合格)
- 分類ごと(1段目)は、56 通りの組み合わせで「表 = 抽選」を確かめました(乱数を等間隔に 20,000 個並べ、±1 以内)。
- 共通 30% / マップ 70%(2段)は、マップ × ガチャLv の 20 通りで確かめました(分類 100 × レア度 1,000 の等間隔の乱数を本物の抽選へ通し、表 × 100,000 と ±101 以内)。
- マップ側が空の時は、共通があっても引かないことを確かめました。
- ゲームの提供割合の画面の数字が抽選の表と同じことは、-qaGachaCat の O で確かめました。

## 成立しない条件
- ありません。分類ごとの一番低いレア度は、どの組み合わせでも ★1〜★3 です。
- 1回あたりの ★5 が 1% にならない時があります。重みのずれではなく、片側の分類に ★5 が無いためです(下の表で明記)。
  - 荒野・洞窟は、マップ側に ★5 がありません。1回あたりの ★5 は、共通側の 0.3%(30% × 1%)だけです。
  - 共通の ★5 は BEST 50,000m から出ます。それまでのラスダンは、マップ側の 0.7%(70% × 1%)だけです。
