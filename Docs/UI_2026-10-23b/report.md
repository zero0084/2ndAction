## 1. キャラカード枠(デッキ編集の「○○のキャラカード」の3枠)
- 原因: 枠を大きく見せるためにカード自身を 1.45 倍にしていたが、カードを表示し直す時(装着/外す/キャラの切り替え/開き直し)に倍率が 1 へ戻り、カードと空き枠の輪郭が小さく上寄りになっていた(初めて開いた時だけ正しかった)
- 修正: 倍率は外側の入れ物に持たせ、カードは入れ物の中央(縦横比 2:3 のまま枠の内側いっぱい)。空き枠の輪郭も同じ大きさ・位置。「タップして設定 / タップで外す」は枠の外(下)のまま
- 画像: `1_charcard_slots.png`(キャラを切り替えた後の比較)

## 2. 横画面ホームの重なり
- 原因: 右上の 設定/マルチ/ランキング/闘技場 が 2×2 で、左下のランキングがガチャ機械の看板の上に重なっていた。機械の押せる範囲も絵の左右の透明な余白まで含んでいた
- 修正: 4つを所持MILE の下に1列(縦画面と同じ順)。出していないボタン(マルチ無し/闘技場の未解放)の分は詰める。機械の押せる範囲は絵の見える所だけ。狭い画面(4:3)では重なる時だけボタンの幅を少し狭める
- 確認(-qaHomeLayout): 1280x720 / 1920x1080 / 1024x768 / 縦 720x1280 × ガチャ5段階 × 闘技場 未解放/解放 で、機械とボタンの重なり 0、画面外 0
- 画像: `2_home_overlap_landscape.png`、`2_home_portrait_after.png`

## 3. タップ攻撃
- 短く触って(0.25 秒以内)、ほとんど動かさず(画面の短い辺の 2.5%、最低 12px)離した時に、右フリックと同じ前攻撃を出す。前への踏み込みだけ 0(後退・他の技の動きはそのまま)
- 出さない: フリックとして出た指(上フリックの前に攻撃が出ない)/ 長押し(帰還の溜め)/ 一時停止・取得カードの欄・COMBO の印・ULTIMATE などの上で始まった指 / 止まっている間(カード選択など)に置いた指・閉じた指 / 取り消された指(回転・中断)
- 経路は右フリックと同じ: 攻撃の速さ・硬直・コンボの受付・先行入力(1つだけ)・オートの抑止(手動の入力から 0.35 秒)。ヒットストップ中のタップも先行入力へ(踏み込み無しも引き継ぐ)
- 全12人(射撃/魔法も各キャラの前攻撃)。忍者は前攻撃が「瞬身」なので、タップでは移動せずその場で斬る
- 確認(-qaTap、全12人 × 地上/空中 × オート OFF/ON): タップは全件で 振りが出る・踏み込み 0・二重に出ない・連打で右フリックの連打より速く振れない。比べるための右フリックが被弾の反応中(入力を受け付けない仕様)だった回は試験側で待つように直した
- 動画: `Docs/TapAttack_2026-10-23/video/tap_attack_arena.mp4`(git には入れない)。闘技場の平らな床で 黒剣士/拳銃士/忍者/魔法使い: タップ×3 → 右フリック → ↑ → タップ×3 → ↑ → タップ×2 → ↓
- 練習の説明に2行(指の操作の時だけ、エステルのレビュー済み 30言語、keys_extra22)
