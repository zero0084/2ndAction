# #100 ULTIMATE(2026-10-04)

キャラ固有の必殺技のカード。Gauge を溜めて好きな時に発動すると、キャラ固有の派手な技で画面内の敵を攻撃しながら大きく前進し、その勢いのまま通常のランへ戻り、しばらく強化(BUFF)が続く。

数値はすべて仮。調整値は `UltimateTuning`(`Resources/Ultimate/UltimateTuning.asset` を作ると上書き。無ければコードの既定値)。

## 1. カード

| 項目 | 値 |
|---|---|
| cardId | `character_ultimate`(新しいID)|
| 表示名 | ULTIMATE |
| カテゴリ | SPECIAL |
| 効果 | `EffectType.UltimateLevel`(1Lvごとに+1。Lv9 上限は既存の能力ごとの仕組み)|
| レア度 / 解放 | ★5 / BEST 20,000m・ガチャ段階3(仮)|
| アイコン | 仮(手続き生成)|

- #79 は今まで通り cardId `"ultimate"`(表示名 ALMIGHTY)。保存の互換は変わらない。
- 数値の正本は `Editor/CardBalanceV3.cs` の表の最後(#100)。アセットは `CardDatabaseBuilder` の Spec が作る。
- Lv 表示 / Lv9 MAX / 候補の除外 / キャラカード / デッキ / コレクション / 保存 / CONTINUE は、既存のカードと同じ仕組みで動く(特別な処理なし)。
  - 例外はマルチだけ(候補に出さない)。

## 2. Lv ごとの値(Lv1 / Lv5 / Lv9、間は直線)

| | Lv1 | Lv5 | Lv9 |
|---|---|---|---|
| 前進(m、画面上で進む合計) | 100 | 150 | 200 |
| 通常の敵へのダメージ(その距離の HP倍率1 の雑魚のHP × ) | ×1.8 | ×2.8 | ×4.0 |
| ボスへのダメージ(最大HPの割合) | 10% | 14% | 18% |
| BUFF の時間 | 5秒 | 8秒 | 12秒 |
| BUFF 攻撃力 | +10% | +15% | +20% |
| BUFF 攻撃速度 | +8% | +12% | +15% |
| BUFF 走る速さ(勢い) | +6% | +9% | +12% |
| Gauge の溜まりやすさ | ×1.00 | ×1.16 | ×1.32 |

- 通常の敵: HP倍率 1.35 以下の雑魚は Lv1 でも1回目の当たりで倒れる。
  - 重い敵(heavy_ogre ×3)と精鋭(×3)は Lv1/Lv5 で残る。Lv9 なら倒れる(実測)。
- ボス: 1回の ULTIMATE で入る量の上限は最大HPの 22%。1回で戦闘は終わらない(残りHPが少なければ倒せる)。

## 3. Gauge

| 入り方 | 量(%) |
|---|---|
| 距離 | 1m ごとに 0.05。ただし 1秒あたり 0.55 まで(高速で距離だけで連発しない)|
| 通常の敵の撃破 | 1.2 |
| 精鋭(ELITE/WANTED)の撃破 | 4 |
| ボスへのダメージ | ボスのHP1本分で 30(1発あたり最大 3)|
| ボスの撃破 | 20 |

- 発動中は溜まらない(ULTIMATE 自身の撃破/前進では溜まらない)。BUFF 中は半分。
- 発動で 0 に戻る。発動中にもう一度押しても何も起きない。
- CONTINUE: 中断データ(`RunCheckpoint.Data.ultimateGauge`)に保存して戻す。古いデータは 0。
- 目安: 距離だけなら最速でも 約3分。撃破を混ぜると 約1〜2分に1回。

## 4. 発動(ボタン)

- HUD の左下に丸いボタン(カードを持っている時だけ)。
  - 左上 BEST/DISTANCE/SPEED・上中央 Lv/EXP・右上 HP/カード・右下 II と重ならない。
  - 大きさは画面の高さの 12%(84〜160px)。DEBUG RUN の表示がある時は少し上へ。
- 表示: 下から溜まる円 + 「ULTIMATE」+ 「%」。100% で光って「READY」。発動できない理由があれば理由を出す。BUFF 中はボタンの上に残り秒数。
- 誤タップ/フリック対策:
  - ボタンの上で押して、そのまま離した時だけ発動する(40px 以上動かすと取り消し)。
  - ボタンの周り(+10px)で始まったタッチは、攻撃/ジャンプのフリックにしない。
- 使えない時: 停止/カード選択中、カウントダウン/再開の準備、ボスの登場演出中、被弾のリアクション中、BONUS ZONE 中、ゴール/脱出の演出、ラスダンのエンディング、マルチ。
- 開発版はキーボードの U でも発動。

## 5. 流れ(全員共通のゲーム処理)

| CUT | 長さ | 動き | 当たり |
|---|---|---|---|
| 1 構え | 0.45秒 | 通常の 55% の速さ。ズーム・背景の暗転・技の名前 | なし |
| 2 一撃目 | 0.45秒 | 通常の 90% | 画面内の全員 |
| 3 前進 | 約1.9秒 | 地面に沿って高速で走る(最高 約40〜120m/s)| 0.35秒ごとに画面内(入ってきた敵も)|
| 4 締め | 0.5秒 | 通常の速さへ繋ぐ | 画面内の全員 |
| BUFF | 5〜12秒 | 通常のラン | — |

- ゲーム上のダメージ: 1体につき最大2回(1回目 75%、残りは画面に残っていれば次の当たりで)。ボスは最大4回(締めで残りを全部)。
  - 見た目の命中(火花/花びら/斬撃線など)は別に何度でも出す。
- カードとの関係:
  - カードの攻撃力(A)の一部を掛ける: `1 + 0.35 × SoftAttack(A)`、上限 ×1.8。ボスへは平方根。
  - 例: 攻撃特化 Lv9(攻撃 ×2.48)→ ULTIMATE ×1.52。
  - 属性/追加攻撃(炎上・落雷・連鎖爆発など)は ULTIMATE のダメージからは起きない(無限連鎖を防ぐ)。
  - 撃破の報酬(EXP/MILE/ドロップ)は通常どおり。
  - 既存99枚の数値は変えていない。

## 6. 前進の安全

- 瞬間移動ではない。毎フレーム `transform.position` を少しずつ進める。
  - 距離・EXP・関門・BONUS ZONE・昼夜・景色・距離のイベントは、通常の走行と同じ `ReportDistance` で進む(二重に数えない)。
- 地面に沿う(`PlayerController.UltimateMoveTick`):
  - 段差/上り坂は乗り上げる(潜らない/引っかからない)。
  - 下り/穴は直前の地面の高さを保って渡り、ゆっくり下りる(穴に落ちない)。
  - 洞窟の天井の下で頭打ち。空中ルートにいた場合は下の地面へ。
- 守り:
  - 発動中 + 終わってから 0.8秒は、接触/敵の攻撃/ノックバック/足止めを受けない。
  - 発動中の落下は地面へ戻すだけ。終わった後の無敵は残らない。
- 止まる所: 前進の合計は次の場所の手前で止まる。
  - 次のボス関門(締めでも進むので、速さに応じて30m以上手前)
  - 100,000m(三姉妹/死神)
  - ボスの後の BONUS ZONE の抽選の地点
  - 途中で BONUS ZONE/ボスの戦闘/ラスダンの演出が始まったら、そこで締めに入る。
- 着地点:
  - 着地点の前後(−25〜+45m)は穴/坂を作らない(CONTINUE の安全区間と同じ仕組み)。
  - 着地の 25m 先までは敵/障害物/Formation を出さない。
  - 出現位置は前方へ送り続けるので、後で溜まった敵がまとめて出ることはない。
- レベルアップ/ボス報酬の選択は、発動が終わってから出す。

## 7. ボス戦(アリーナ)

- 関門のボス戦の間(または走り込んでくるボスがいる時)は前進しない。
- 代わりに、ボスを通り抜けて(ボスの奥 3m)、ボスの手前 6m へ戻る。
  - この間だけボスの間合いの即時補正を外す(`WildBossBase` の `UltimateArt.ArenaFreeGap`)。終わった後は素早く間合いへ戻る。
- 関門は飛ばさない。戦闘は終わらない(実測: 撃破済み扱いにならない、`IsBossPhase` のまま)。距離はボス戦の間は進まない(既存の仕組み)。
- 旧ドラゴン/魔人(天空回廊の関門のドラゴンなど)は通り抜けず、その場で撃つ(同じ上限)。

## 8. マルチ
