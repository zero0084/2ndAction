# カードの絵とレイアウトの見直し 報告(2026-10-31)

エステル(ChatGPT)と共同。効果・数値・レア度・カード ID は変えていません(変えたのは絵・素材の割り当て・表示のレイアウトだけ)。

## 1. 照合の方法

- 最新のカードデータ(Resources/Cards の 112 枚)とゲーム内の説明の書き出し(CardCatalogExport)を基準に、全 112 枚を 16 枚ずつの一覧にして照合しました(`sheets_before/`)。各枠: 元の絵 + 実際の表示の大きさ(48px / 32px)+ ID・名前・レア度・種類・属性・今の効果。
- 絵の割り当て: 112 枚すべて、カードの ID と同じ名前の絵を指していました(割り当ての間違いは 0)。
- カードの資産の説明とゲーム内の説明の書き出しは 112 枚とも一致(説明と実装の食い違いの「別件」は今回は見つかっていません)。
- APK 402 で再設計した属性 20 枚と APK 403 で追加した 12 枚は、効果と絵が合っていて、属性の色と形で見分けられる → 変更なし(エステルも同じ判断)。

## 3. レイアウトの修正

| 画面 | 問題 | 修正 |
|---|---|---|
| カード面の名前(全画面) | 空白の無い 1 語の長い名前が語の途中で 2 行に切れた(ドイツ語 MONSTERANSTURM → 「MONSTERANSTUR / M」、RÜCKWÄRTSGANG) | 1 語の名前は 1 行のまま 50% まで縮める(折り返さない) |
| デッキの枠・キャラカードの枠(小さいカード) | 名前が 6px ほどで読めず、2 行の名前は板からはみ出していた | カードの大きさで名前の最大の字が 10px 未満になる時は名前を出さない(絵と Lv で見分け、タップの詳細で名前)。1920×1080 などの大きい画面では今までどおり出る。同じ大きさのカードは全部同じ扱い |
| カード合成のフィルター | ドイツ語の「Verteidigung」が語の途中で折れた。縦画面の細いボタンでは字が潰れていた | 1 行に収まる大きさまで縮める。それでも入らない細いボタンは名前を隠して種類のアイコンだけ(デッキ編集のフィルターと同じ形) |
| カード合成の見出し(縦画面) | 「Kartenfusion」が所持 MILE の板に重なり、所持 MILE の文が 2 行に折れていた | 見出しの幅を空いている所までにして 1 行に収める / 所持 MILE も 1 行に収める |

- 古い正方形の絵(10 枚、1254×1254)は、カードの中での大きさを測ると 392×589 の絵と同じか小さいため、作り直しはしていません(うち 3 枚は今回の描き直しで 392×589 になりました)。
