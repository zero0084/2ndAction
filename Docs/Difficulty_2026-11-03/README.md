# 通常マップ 中盤以降の難易度の再調整(2026-11-03〜04)

テーマ: 「中盤以降をダレさせない」「雑魚は倒しやすく、攻撃は痛く」「ボスでテンポを切らない」。ラストダンジョン・闘技場・操作の練習は対象外。死神の接触(即死)と落下はそのまま。90km 以降(90km ボス/大群/3連戦/死神)の流れもそのまま(被ダメージの帯だけ適用)。

値はすべて `DifficultyTuning`(`Assets/Scripts/Balance/DifficultyTuning.cs`、asset `Resources/Balance/DifficultyTuning`)。Inspector で直せる。旧仕様へ戻す: asset の `legacy = true`、開発版は起動引数 `-diffLegacy 1`。

## 5. 同時攻撃の上限

90〜95km の大群用の `ZakoAttackLimiter`(予兆〜攻撃を同時に始められる雑魚は 3 体まで、他は待つ)を **50km から** 有効にした(`attackLimiterFromKm`)。見た目は多いが、実際の攻撃は数体ずつ。

## 6. ボスの出現間隔(案C を採用)

| 距離 | 関門 |
|---|---|
| 0〜20km | 1km ごと(今までどおり。序盤の戦闘の変化として) |
| 20〜90km | 5km ごと。10km の倍数は大ボス(今までの 10km 固定の専用ボス) |

- 案A(1km 維持・一部飛ばし): 中盤の「またボス」の感想が残るので不採用
- 案B(全部 5km): 序盤(速度が低い)の戦闘の変化が無くなるので不採用
- 案C(序盤だけ 1km、20km から 5km): **採用**。リズムは「戦う → 雑魚の群れ → しばらく走る → 大きな関門」
- 飛ばした 1km の地点では BONUS ZONE の抽選だけ行う(ボスが減った分の道中の変化。`bonusRollAtSkippedGates`)

## 7. 測り方(`-qaDiff`、開発版)

帯ごとに、その距離までのカード(枚数 ≒ 4 + km/4、構成ごとの6系統)を持たせ、帯の始めへワープして 120 秒走る。操作は自動補助(常時)に「不注意」を入れたもの: **毎秒 0.6 回の確率で 0.5 秒間なにも入力しない**(補助は約3割の時間止まる)。死んだら HP を戻して続ける(死亡回数として数える)。

構成: 攻撃(攻撃/速さ/範囲/空中/雑魚特効/2回攻撃)、防御(攻撃/ハート/シールド/HEAVY ARMOR/IRON WILL/速さ)、回復(攻撃/吸血/血の刃/ハート/SECOND WIND/速さ)、属性(攻撃/炎/氷/氷の守り/連鎖雷/BLOOD RUSH)、推奨(攻撃/速さ/ハート/シールド/吸血/空中)。

### 調整の経過

最初の値(ボスの通常が 45km から 2)では、50〜70km の不注意プレイで **2 回死亡**(63〜65km のボス1体から 2 ハート × 11 回)。「油断すると HP が減る」より厳しいので、**ボスの通常を 70km から 2** に変えた(v2)。60〜70km のボスの通常は旧(15)より軽い 10 になるが、雑魚の通常攻撃が 2 になるので帯全体のダメージは旧と同程度。

## 10. 防御・回復カードの価値

- **防御**: 旧は攻撃構成でも防御構成でも死亡回数がほぼ同じ(旧 攻撃 1〜2 回 / 防御 0〜1 回)。新は攻撃構成が 50km 以降の各帯で 1〜7 回死ぬのに、防御構成は **90km まで 0 回**。HEAVY ARMOR が 2 ハートの攻撃を 1 に減らす(ボスの攻撃 `BossCombatPart` が防御構成だけ 1 ハートのまま)のが効いている
- **回復**: 回復構成は 70〜90km で 0 回(攻撃 1 回、推奨 1 回)。吸血で HP を戻せる時間が生まれた
- 攻撃構成は敵を最も速く倒すが、一番 HP が少なく(5 ハート)、中盤以降は事故で落ちやすい。「攻撃だけ取れば全部解決」ではなくなった

## 12. AUTO(高速補助)の確認

- 初期設定: オートモード **ON**、開始速度 **100km/h**(60〜160、5 刻み)、ボス戦でもオート ON、自動攻撃 ON、自動回避 ON
- 自動回避 = 穴・障害物・壁・トゲへのジャンプ(ボス戦では弾や攻撃範囲も)。自然加速の上限が 100km/h なので、**標準速度では中盤以降ずっとオート**になる → テスターの「途中から勝手にジャンプ」はこれ
- 説明は設定の「操作」に既にある(どの操作が自動か / 開始速度 / 手動優先 / 必ず避けられるわけではない)
- **追加**: オートが働いている間、右上の速度表示の `SPEED` が水色の `AUTO` に変わる(いつから自動なのかが画面で分かる)
- 自動補助だけ(不注意なし)の結果: 0〜90km は死亡 0〜1 回、90km で 3 回。補助が強すぎて難易度が消える、ということはない(新では 20km 以降で被弾する)
