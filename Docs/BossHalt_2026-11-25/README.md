# ボス戦の「前進しっぱなし/これ以上進めない」の見直し(2026-11-25)

マスター報告: 「ボス戦でたまに前進しっぱなし、もしくはこれ以上進めないといった現象がある」
あわせて: ボス戦の「最終段階!」の文言を消す(技名は残す)

## 原因

ボス戦は BossHalt(2026-10-29)で「その場に止まって戦う」作り。止まる時の処理に3つの問題があった。

| # | 症状 | 原因 |
|---|---|---|
| 1 | 前進しっぱなし(マルチで顕著) | 止まる所が「上の道/分岐/穴」だと、平らな所が見つかるまで走り続けて止まらなかった。マルチはボス戦の場所の地形を平らにしないので、上の道が続くと **12〜19秒・66〜75m** 走り続けた(下の表 M0)。ソロも、平らにしていない所で始まる遭遇では同じ形になり得た |
| 2 | これ以上進めない | 前への踏み込みの上限(止まった所から 22〜30m)の基準を **止まり始めた所** で取っていた。実際に止まるまでの減速の滑り(100km/h で約9m)と、1の走り続けた分まで基準からの距離に入るので、戦い始めた時点で上限の近く/外にいて、前攻撃の踏み込みが弱まる/0 になった(ボスが前にいても) |
| 3 | 戦いながら前へずれる | ボスがまだ歩いて来ている間も、前攻撃の踏み込みが「ボスが遠いほど伸びる」倍率(最大 ×2.6)で伸び、3秒で約17m 前へ飛び出していた(自動の試験の記録 hs3)。これで 2 の上限に早く当たった |

## 修正(BossHalt.ArenaV2、開発版は `-haltArena 0` で前の作りと比べられる)

1. 平らな所を探すのは、理由が「上の道/分岐」なら **2.5秒まで**。過ぎたらその遭遇の間はその場で止まる(上の道のボスへは既存の BreakRouteLift で寄る)。穴の上では止まらない(探し続ける)
2. 基準は **実際に止まりきった所**(滑った分は含めない)
3. ボスがまだ登場して歩いて来る間は、前攻撃の踏み込みを伸ばさない(通常の長さ)
4. ソロ: 前にボスの体がある間は踏み込みの上限で止めない。代わりにボスが止まった所から 20m より前へ押し出されない(範囲の中で戦う)
5. 「最終段階!」の帯を出さない(通常のボス/ドラゴン/魔人)。途中の段階の「激昂!」と技名の帯はそのまま

記録だけの見張り BossHaltWatch を追加(`[HaltWatch]` 行: seek/runBoss/reach/noBoss/ahead と1戦ごとのまとめ。`-haltTrace 1` で 0.25秒ごとの位置)。試験は `bash Tools/qa/haltsoak.sh OUT "stage:char ..." 距離 倍速`(-qaFullRun = ワープなしの実際のラン・補助あり・無敵・-memSave)。

## 結果

### ソロ(自動の実ラン、ワープなし、3倍速)

| 試験 | 作り | 戦数 | 止まれず走り続けた(2秒超) | 届かないまま止まる(5秒超) | 止まった所からの最大の前のずれ | 撃破の平均(ゲーム内秒) |
|---|---|---|---|---|---|---|
| 荒野街道・黒剣士 25km | 前 | 21 | 0 | 0 | 28.2m(止まり始めた所から) | 5.73 |
| 荒野街道・黒剣士 25km | 後 | 21 | 0 | 0 | 23.3m(止まった所から) | 5.76 |
| 自然洞窟・双剣士 25km | 前(40kmの前半) | 21 | 0 | 0 | 25m超 19戦 | 6.29 |
| 自然洞窟・双剣士 25km | 後 | 21 | 0 | 0 | 16.4m | 7.03 |
| 天空回廊・格闘家 40km | 後 | 24 | 0 | 0 | 24.2m | 6.14 |
| ラストダンジョン・拳銃士 40km | 後 | 40 | 0 | 0 | 30.3m | 6.06 |

ソロは地形を平らにしてあるので、自動の試験では「走り続ける」は出なかった。前の作りでは毎戦ほぼ上限(22〜30m)まで出ていた。撃破の時間はほぼ同じ(双剣士は +0.7秒。ボスの組み合わせが違うので誤差の範囲と見ている)。撃破後に走り出すまでの止まり(報酬の前の撃破の演出)は約2秒(実時間)で、前と同じ。

### マルチ(LOCAL 協力 2台、HOST が 60m 前、20秒でボス)

| 試験 | 作り | HOST | JOIN |
|---|---|---|---|
| M0 | 前 | 上の道で **12.5秒・75m** 走り続けた | 上の道で **19.0秒・66m** 走り続けた |
| M1 | 後(1回目、あきらめた後に探し直す不具合あり) | 2.5秒ごとに3回 → 60m | 6回 → 73m |
| M2 | 後(修正済み) | 2.5秒で止まる(滑りを含め 29m) | 3m で止まる |

M2 のチーム距離・選択中に止まらない等の確認(teamrun.py)は、HOST の命中の一瞬の停止(以前からの約0.1秒)が 0.5秒ごとの記録に3回続けて写った1件の NG だけ(M0 はたまたま PASS)。

記録: `runs/`(hs2old/hs2new = 前後比較、hs3 = 0.25秒ごとの位置、hs4/hs5 = 後の作り、mp_M0/M1/M2 = マルチ)

## 実機での確認手順

1. マルチ(協力)で上の道を走っている時にボスが来る → 2〜3秒で止まり、走り続けない
2. ソロでボスに着いたら前攻撃を連打 → ボスが歩いて来る間は大きく飛び出さない。戦い始めてから前へ攻撃できなくなる所がない
3. ボスの HP を減らして段階が変わる → 「激昂!」は出る、最後の段階で「最終段階!」が出ない。技名の帯は出る
