# デッキの同一カード重複禁止 — 報告(2026-10-30)

## 今まで何を保存していたか
- 保存キー `DeckCardIds` = カードのキーをカンマ区切りで最大12個(デッキは1つだけ。プリセットや複数デッキは無い)。
- キーは、素のカード(Lv1・合成なし)は `attack_up` のようなカードID、Lv2以上や合成した物は `v2|attack_up|3|1|attack_up*3` のように **主カードID・Lv・レア度・能力の中身を含むキー**。
- つまりデッキは「所持している特定の1枚(Lv込み)」を指していて、Lv は所持データからではなくキーから決まる。合成でLvを上げた時は別のキーになるので、デッキの方は自動では変わらない(使用中のカードは合成・変換できない、という今までの決まりのまま)。
- 今までは「同じカードを何枚でも入れられる(所持枚数まで)」仕様だった(2026-09 の依頼で解禁されていた)。

## 重複禁止の実装
- **同じ種類 = 主カードID**(`GameManager.DeckKindOf`)。v2 キーは主カードIDに戻して比べる。Lv違い・合成の中身違い・レア度違いも同じ種類。
- `GameManager.AddToDeck`: 同じ種類がもうデッキにあれば追加しない(結果 `SameCardInDeck`)。入れ替えもしない。上限・所持枚数の確認は今までどおり。
- `GameManager.SetDeck`(おすすめ編成・全て外す・テストの一括設定): 先に来た方だけ入れ、同じ種類の2枚目以降は入れない。
- 所持枚数・合成素材・カードLv・保管(Mastery)には一切触れない。キャラカード枠(キャラごと3枠)はデッキとは別の入れ物なので、デッキと同じカードを付けられる(今までどおり)。
- ラン中の LEVEL UP / ボス報酬で同じカードを何度も取って Lv が上がる仕組みは変えていない(テスト I)。
- ラン中の3択はデッキから等確率で選ぶので、前の版で同じカードを何枚も入れていた人は、そのカードの出やすさが元に戻る(重複が無くなった分)。

## Lv違いの扱い
- SPEED UP Lv3 がデッキにある時、SPEED UP Lv8 は追加できない。Lv8 にしたい時は、デッキの Lv3 を押して外してから Lv8 を入れる(テスト H)。
- 所持一覧では、デッキに入っているその1枚に **緑のチェック**(今までの印)、同じカードの別のLv/合成の物に **灰色のチェック**。カードの絵は暗くしない。詳細パネルに `[IN DECK: Lv.n]`。
- 押した時は「このカードはすでにデッキに入っています」(Lv違いなら「Lvの違う同じカードに替える時は、先にデッキから外してください。」も)を詳細の下に出し、デッキの中のその1枚を光らせる。

## 既存セーブの修正(Migration)
- デッキの読み込み(`GameManager.LoadDeck`)で、並び順に見て **同じ種類の2枚目以降をデッキから外す**(最初の1枚を残す)。外したカードは所持のまま。空いた枠は空欄のまま(自動で埋めない)。
- 外した時は、その結果を1回だけ保存し、ホームでお知らせ(見出し「デッキを整理しました」)を1回出す。次の起動では重複が無いので、外す物も保存もお知らせも無い = 何度起動しても同じ(テスト K、本物の再起動3回で確認)。
- 「最初の1枚だけ残す」は何度やっても同じ結果になる処理なので、途中で落ちても次の起動でもう一度同じことをするだけ(印のキーは足していない)。
- カード合成改修より前の古い形式(Lvを持たない `A,A,B`)は、今までの変換(CardDataMigration)の後に同じ整理がかかる(テスト F2)。
- 上限(12枚)を超えていたデッキの整理(2026-10-07 からの仕組み)は、重複を外した後に数える。

## 自動編成など
| 入口 | 対応 |
|---|---|
| おすすめ編成(CardDatabase.BuildRecommendedDeck → SetDeck) | 元から重複なし(カードの一覧から1枚ずつ)。SetDeck でも重複を入れない |
| 初期デッキ(DefaultSave.StartingDeck) | 元から重複なし。テスト J で確認 |
| 全て外す | 空にするだけ |
| デバッグ/テストのデッキ(CardVisualTour・FusionAutoTest・QaSweep) | すべて AddToDeck / SetDeck を通るので重複は入らない。FusionAutoTest の「重複したデッキが残る」期待は新しい仕様に直した |
| セーブの引き継ぎ(SaveTransfer)で読んだデッキ | 次の読み込みで同じ整理がかかる |
| 闘技場の構成(デッキからコピー) | デッキに重複が無いので、そのまま |
