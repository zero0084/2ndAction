# 闘技場 — 正式な練習モード(2026-10-06)

ホームから誰でも入れる練習場(リリース版にも含む)。
「キャラやカードを自由に試せる練習場」。開発用の闘技場(Arena_2026-10-04.md)を正式な機能へ作り替えたもの。

## 1. 入口と流れ

- ホームの「闘技場」ボタン(マルチプレイの下)。マルチの部屋にいる間は出さない。ソロ専用。
- 開発用の機能(Developer Menu / ワープ / DEBUG RUN)とは切り離した。
  - DEBUG パネルの入口は残すが、同じ正式な入口(`ArenaLauncher`)を通る。
- 流れ: キャラ → カード → 相手 → (詳細) → 開始。準備画面はタブ。
  - 右上の「開始 / 同条件で再戦」「ホームへ」は常に見える。
- 初めての時の既定:
  - 今選んでいるキャラ、カードなし、動かない標的、0 km/h、無敵 OFF。
  - 操作アシストは通常の設定と同じ値。

## 2. 準備画面

| タブ | 内容 |
|---|---|
| キャラ | 立ち絵の一覧 + 大きい絵・名前・特徴。キャラには所持の区別が無いので全員選べる |
| カード | 絵・名前・効果・試す Lv(±)。検索と分類の絞り込み。所持していないカードは「試用」と表示。「今のデッキをコピー」「キャラカードをコピー」 |
| 相手 | 練習標的 / 雑魚 / 荒野 / 洞窟 / 天空。数・動きの強さ。「○km地点相当」の強さ。地形を使う技の注意書き |
| 詳細 | 速度(0 / 基準速度+補正 / 実効速度固定、説明つき)、無敵、HP回復、操作アシスト(OFF / ON。判定速度)、対応していない機能の一覧 |
| 結果 | 今回と前回の比較(与/被ダメージ、無敵中の本来の被ダメージ、命中、撃破、撃破時間、試したビルド)。「同条件で再戦 / 設定を変更 / ホームへ」 |

- 試すカードは試用であり、所持は変えない。
  - 所持Lv、ランのLv、Mastery、AWAKENED、FE は混ぜない。
  - 闘技場で効くのは「ランのLv」だけ。
  - FE / AWAKENED / Mastery / ULTIMATE ゲージ / レベルアップ / ボス報酬 / BONUS は対応外で、その旨を画面に明記する。
- 相手の選び方:
  - 選べるのは会ったことのある相手だけ。
    - 雑魚: 解放済み、かつそのステージを走ったことがある。
    - ボス: `ProgressStats.HasSeenBoss`。
  - まだ会っていない相手は「？？？(まだ会っていない)」と表示し、名前も絵も出さない。選べない。
  - 保存した構成からも外す(`ArenaConfig.Sanitized`)。
  - 練習標的はいつでも選べる。
  - 「全部の敵」は開発版だけの項目。
- ボスは1種類まで(加えると前のボスと入れ替わる)。雑魚と一緒に出せる(ボスを先に出し、雑魚は後から)。

## 3. 戦闘

- 起動・再戦は毎回シーンを読み直す。
  - 前の敵、弾、設置攻撃、予告、継続ダメージ、予約された攻撃、状態、クールダウンは残らない。
  - その後、荒野街道のランを始めて平地の闘技場へ作り替える。
- 速度:
  - 0 km/h は自動前進だけを止める(時間・攻撃・重力・敵は動く)。
  - 0 より上では平らな闘技場を走り続ける。床・背景は途切れない。
- HUD は与ダメージ・被ダメージ・秒。左側のボタン:
  - ≡ 設定
  - 同条件で再戦
  - 敵を全削除(敵 + 敵/ボスの弾・設置攻撃・予告・落石・洞窟の地形攻撃。プレイヤーののけぞりも戻す)
  - ホームへ
- 設定を開いている間は戦闘も計測も止まる。UI のタップが攻撃にならない(`ArenaMode.BlockRects` / `UiInputGate`)。
- 倒れてもゲームオーバーにならず、結果が開いてすぐ再戦できる。
- 無敵中は、本来受けたはずのダメージを別に数える。

## 4. 保存(進行は書かない)

- `ArenaMode.Active` / `PendingStart` の間、`DebugRun.WritesBlocked` が真になる。
  - すべての進行の保存の入口(`DebugRun.BlocksSave`)が止まる。リリース版でも同じ。
  - 止まるもの: BEST、MILE、カード、Mastery、解放、累計距離、会ったボス、CONTINUE、選択中のキャラ/ステージ、キャラカード。
- 巻き戻しには頼らず、書く前に止める。起動の読み直しの前から止める(ランの開始で CONTINUE を消さない)。
- 闘技場を出る時は、メモリ上の進行を保存値から読み直す(`SaveSystem.ReloadCaches` + `CardMastery`)。
- 闘技場の最後の構成は専用のキー `ArenaConfigV1`(設定の分類)にだけ保存する。デッキや所持カードには書かない。
- 闘技場の操作アシスト/無敵は闘技場の中だけ。通常の設定へは漏れない(`HighSpeedAssist.ArenaRestore` と設定の読み直し)。

## 5. 主なファイル

| ファイル | 役割 |
|---|---|
| `Arena/ArenaLauncher.cs` | 起動/再戦/退出 + `ArenaConfigStore`(構成の保存) |
| `Arena/ArenaController.cs` | 準備画面/HUD/結果/敵の出し方 + `ArenaCatalog`(遭遇済みの判定) |
| `Arena/ArenaMode.cs` | 状態/構成/結果 |
| `Arena/ArenaStage.cs` | 見た目 |
| `Arena/BossManager.Arena.cs` | ボスの出し方(関門・報酬・遭遇の記録を通らない) |
| `Arena/GameManager.Arena.cs` | ビルド/距離/HP |
| `Save/DebugRun.cs` | `WritesBlocked` |

- 見た目は本番の絵(2026-10-06、ChatGPT で生成。画風の参考は荒野街道の背景)。
  - `Resources/Arena/arena_stands.png`: 観客席・旗・門の背景。左右がつながる位置で切り、継ぎ目を溶かしてある(元の生成画像の繰り返しの周期が合う所を探して切った)。
    絵の中の床と壁の境目(上から 66%)を地面の高さに合わせ、上端〜境目が画面の上端〜地面に収まる大きさで置く。横に5枚並べ、少し遅れて流れる。キャラを読みやすくするため少し暗くしている。
  - `Resources/Arena/arena_floor.png`: 床の断面の砂岩の石積み(上下左右につながる)。1024px = 4m。床の縁は砂色の帯。
  - 取り込み設定は `Editor/ArenaArtImporter.cs` が自動で掛ける(Sprite・FullRect・床は Repeat・Android ASTC 6x6)。絵が無ければ従来の手続き生成の絵になる。

## 6. テスト

`-qaArena <dir> [-qaArenaOnly ABCDEFGHJKIU] [-qaArenaShots 1]`(開発版のビルド)

| 記号 | 内容 |
|---|---|
| A | 0 km/h |
| B | 走行(基準 / 固定) |
| C | ビルドが残らない |
| D | 再戦 |
| E | 停止 |
| F / G | 倒れる / 無敵 |
| H | ボス(報酬なし、死神なし) |
| J | 未遭遇の相手が漏れない |
| K | 敵を全削除 + 雑魚とボスの同時出現 |
| I | 退出(進行の保存が1つも変わらない、CONTINUE / 所持カード / 選択中のキャラ / 通常の設定が無傷、その後の通常のラン) |
| U | 画面の撮影 + 初めての時の既定 |

- 試験の前に中断データ(CONTINUE)が無ければ、試験用に作って「消えない」ことを確かめる。
- 最後に機械のセーブを戻す。
