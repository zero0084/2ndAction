# カードの次の段階(2026-11-06 マスターの依頼の要約)

進め方: 現在の112枚を一覧化 → 方針で初期分類 → 必要な共通カードを追加 → エステルと見た目・レイアウト確認 → マスターが見て次の追加・移動を決める。

## 1. 現在の112枚を正式に一覧化(コード上の実値を基準。過去資料より現在の実装を優先)
各カード: ID / 日本語名 / 英語名 / レア度 / 属性 / 効果 / Lv1 / Lv9 / COMBO対象か / FINAL EVOLUTION対象か / ULTIMATEなど特殊ルール / 現在の解禁条件 / 現在の初期デッキ採用有無 / 現在のガチャ・ラン中抽選対象

## 2〜3. 5分類(共通 / 荒野街道 / 自然洞窟 / 天空回廊 / ラストダンジョン)。まず仮分類、後でマスターが調整
- 共通: どのマップでも自然に使えるもの(MILE / EXP / 移動 / 速度 / ジャンプ / 汎用攻撃補助 / 汎用報酬 / 条件付き報酬)
- 荒野街道: 攻撃・BREAK・コンボ・攻め。火属性の攻撃寄りも荒野候補
- 自然洞窟: 防御・HP・回復・吸収・耐久。SHIELD や VAMPIRE 系も基本こちら
- 天空回廊: 補助・空中・速度・既存カード強化・属性補助
- ラストダンジョン: 超強力・特殊・ルール変更級(ULTIMATE 級、最終報酬枠)

## 4. 分類は「そのマップで解禁する場所」。マップ専用使用にはしない
一度解禁したカードは、その後ほかのマップでも通常どおり使用・抽選できる。

## 5. 抽選率を隠れて下げない
解禁後はレア度に応じた通常の抽選ルール。強さの調整は レア度 / 解禁場所 / 初期デッキに入るか / 効果そのもの で行う。

## 6〜7. 共通カードを追加: シンプルな単一条件カード10枚(★1、初心者にも分かる)
MILE: ①コンボ数に応じて ②撃破数に応じて ③ボス撃破時 ④走行距離に応じて ⑤生存時間に応じて MILE増加
EXP:  ⑥コンボ数 ⑦撃破数 ⑧ボス撃破時 ⑨走行距離 ⑩生存時間 に応じて EXP増加
既存カードのレア度は勝手に一括変更しない。

## 8. リスク付き複合カード(基本★3): 敵側が強くなる代わりに報酬が増える
候補: 敵数UP→MILE / 敵数UP→EXP / 高火力敵出現率UP→MILE・EXP / 空中敵出現率UP→MILE・EXP / 判断イベント頻度UP→MILE・EXP / ボス火力UP→ボス報酬増加 など。
敵HPだけを上げない。敵数・高火力敵・空中敵・判断イベント・ボス火力など「ゲームが忙しくなる方向」のリスクを優先。

## 9. ノーリスク複合カード(基本★4): 複数条件・複数報酬、デメリットなし
例: コンボ＋撃破数→MILE/EXP / 距離＋生存時間→MILE/EXP / ボス撃破＋通常撃破→MILE/EXP / 長距離になるほどMILEとEXP両方
ONE MORE MILE と完全に同じ効果にはしない。条件・プレイスタイルに個性を。

## 10. ★5は必要最小限(明確にルールを変える級)。必要と判断した場合だけ NO TURNING BACK 系 / ENDLESS HUNT 系 を候補に。まずは★1・★3・★4中心。

## 11〜12. 総数は増えてよい。将来は各マップ 40〜50種類のカード候補(共通＋そのマップで解禁＋他マップで解禁済み)。20枚程度しか候補がない状態にはしない。

## 13〜14. 初期デッキを確認。HP大強化/SHIELD/VAMPIRE/強力な防御・回復が初期から簡単に揃うなら報告。大幅な初期デッキ変更はしない(一覧と提案まで)。シンプルな共通カードを初期候補へ入れるのは検討可。HP強化(特に大きなHP増加)は初期カードから外す方向 → 候補として報告。

## 15〜17. カード編集画面を枚数増加対応に(重要)
以前、所有カードの行数が固定上限を超え ★5 カードが表示されなくなった。絶対に再発させない。
固定 pool 上限(160件/200件など)に依存しない。必要数を動的に確保 or 仮想スクロール。200〜300種類でもカードが消えない。
同じカードIDでも Lv違い/融合状態/所有状態で表示行数が増える → カード種類数ではなく実際に必要な表示エントリ数を基準に。

## 18. マップ別フィルター: ALL / COMMON / WILDERNESS / CAVE / SKY / LAST DUNGEON(日本語: すべて/共通/荒野/洞窟/天空/ラスダン)。30言語対応。
## 19. 未解禁カード: 所有済み・解禁済みは通常表示、未解禁はシルエット/鍵などで表示可。ただし完全に未知のカードを全部見せるかは現在仕様を優先。マップ別フィルターでは「このマップでまだ解禁できるカードがある」ことが分かる程度の見せ方も検討。
## 20. ソート: レア度/Lv/属性/名前/所有数/解禁順 など現在のソートを整理。既存ソートは壊さずマップ分類を追加。
## 21. フィルター併用: マップ＋レア度、マップ＋属性(例: 荒野＋★4)。複雑すぎるならまずマップフィルターだけでもよい。
## 22. 12枚デッキ表示は維持。一覧をフィルターしても現在デッキの12枚は上部で常に確認できる。
## 23. 横画面・縦画面の両方で使いやすく。縦画面でフィルターUIのせいで一覧領域が狭くなりすぎない。
## 24. エステルと UI を実画面で確認(フィルターの位置/ボタンの大きさ/選択中の見え方/密度/200枚以上/縦/横/長押し詳細との干渉)。
## 25〜26. 新規カード画像もエステルと制作(モチーフ/アイコン/色/構図/既存との見分けやすさ)。新規カード名は既存と重複しない英語名＋日本語名、30言語へ展開。名前・説明は効果が理解しやすいことを優先。
## 27. 今回の分類は最終決定ではない。マスターが一覧を見て移動・追加を指示する。
