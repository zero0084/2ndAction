実装(Resources/Cards のアセット + ゲームと同じ式)から書き出した値です(`Tools/cards/catalog_20261106.py`、元の TSV は `raw/`)。全項目は `catalog.tsv`。
**現行 112 枚 + 新規 18 枚 = 130 枚。** 既存のカードのレア度・性能・初期デッキは変えていません(新規 18 枚と、マップ分類による解禁の条件だけ追加)。

- 日本語名: ゲームの日本語表示は今も英語名です。既存のカードの日本語名はカタカナの読み(資料用)、新規 18 枚は新しく付けた日本語名(マスターの確認待ち。ゲームには出していません)。

## 3. マップ分類による解禁(実装した決まり)

| 分類 | 解禁の条件(今までの BEST/ガチャ段階の条件に加えて) |
|---|---|
| 共通 | なし(今までどおり: BEST の距離 ≥ 解放距離 かつ ガチャ段階) |
| 荒野街道 | 荒野街道で、成功したラン(帰還)の到達距離 ≥ そのカードの解放距離(解放距離 0m のカードは最初から = 今までと同じ) |
| 自然洞窟 | 自然洞窟で、成功したランの到達距離 ≥ max(解放距離, 1,000m = 最初のボスの関門) |
| 天空回廊 | 天空回廊で、成功したランの到達距離 ≥ max(解放距離, 1,000m) |
| ラストダンジョン | ラストダンジョンが解放されていること(通常3マップすべてで死神 + 累計 1,000,000m) |

- 到達距離はマップ別の「1回のランで到達した最高距離」(`UnlockRules.Reach`。キャラ/マップの解放と同じく、帰還した時だけ確定。既存データはマップ別 BEST から作ってある)。
- 既存のデータ(遊んだ形跡がある): この版で初めて起動した時に一度だけ、**今までの条件で使えていたマップのカード + 所持しているカードを解禁済みのまま**にします(`CardMapGrandfatherV1`、SaveKeys に登録)。取り上げません。
- 新しいデータ: 最初から分類どおり。初期デッキ(下の 12 枚)は今までの条件で作るので変わりません。初期デッキのカードは所持しているので使えますが、マップのカード(HEART UP/SHIELD/VAMPIRE/AIR ATTACK UP)をガチャで重ねて引けるのは、そのマップで解禁してから。
- 解禁の判定は `GachaStage.IsCardEligible` の1か所(ガチャの候補・解放済みカードの一覧・おすすめ編成が同じ判定)。画面用に `CardMapUnlock.IsUnlocked(card)` / `ConditionSrc(card)`(条件の文、30言語の鍵)/ `RequiredMeters(card)` を用意しました。
- 開発版の「全カード開放」はそのまま全部開きます。

### HP / SHIELD / VAMPIRE / 防御・回復が最初から揃いすぎるか(報告)

**揃います。** 12 枚のうち 3 枚(HEART UP / SHIELD / VAMPIRE)がまさに該当し、新規プレイヤーの最初のランから全部 Lv9 まで取れます。

- HEART UP(★1): Lv9 で最大HP ハート+9(取得で最大HPが増えると全回復)。**ゲームで一番大きい HP の伸び**で、★4 の FORTRESS(+9、移動速度-27% の代償つき)と同じ量を ★1・代償なしで持っています。
- SHIELD(★2): Lv9 で Shield 3 つ・回復の短縮 13.5 秒(24 秒 → 約 10.5 秒ごとに 1 つ)。
- VAMPIRE(★2): Lv9 で命中の吸収 5%・撃破でハート1つ回復 40%。
- このほか SPEED DOWN(デメリットだけのカード)も初期デッキに入っています(おすすめ編成では後回し)。

### 提案(実装はしていません。マスターの判断待ち)

1. **初期デッキから HEART UP / SHIELD / VAMPIRE を外し、新規の共通 ★1 を入れる**(例: ROAD PAY / HUNT TRAINING / COMBO PAY)。外した 3 枚は分類どおり自然洞窟で解禁されるので、
   「洞窟で守りを覚える」流れになります。SPEED DOWN も SURVIVAL PAY などへ替える候補。やり方は `DefaultSave.StartingDeck` を固定の 12 枚の一覧にするのが確実(sortOrder に頼らない)。既存のデータのデッキ/所持は変えない。
2. **HP カードのレア度**: HEART UP ★1 → ★3(5km)を推奨(★4 FORTRESS と同じ伸びを代償なしで持つため)。または ★1 のまま「2Lvごとにハート+1(Lv9 で +5)」に。
   HEAVY ARMOR(★3、+5 + 重い一撃の軽減)は ★4 候補。IRON WILL / LONG HAUL(★3、+3)はそのままでよい。THE LONG ROAD / ALMIGHTY(★5、+5)もそのまま。
3. SHIELD ★2 / VAMPIRE ★2 はレア度は据え置きで、初期デッキから外す(1.)だけで「最初から揃う」状態はなくなります。
4. 新規の共通 ★1 を初期デッキへ入れるのは、効果が分かりやすく危険がないので向いています(報酬だけのカードなので、序盤の強さは変わらない)。

- 疾走出発/CONTINUE/ワープで距離が飛んだ区間は払わない(その位置から数え直す)。数え途中の端数は中断データに入れない。
- 敵 HP だけを上げるリスクは使っていません(高火力敵・空中雑魚・判断イベント・ボスの火力)。★5 は今回は作っていません(ルールを変える級の必要が出た時に NO TURNING BACK / ENDLESS HUNT 系を検討)。
