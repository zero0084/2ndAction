# 死神三姉妹: アニメーションの確認と、正式な絵への差し替え(2026-10-20)

全部の動作を30コマ/秒で撮影して確かめました(`-ldQa <dir> -ldQaMode sisrec`、26場面)。
- 「コードで直すもの」と「絵を足して直すもの」に分けました。
- 必要な絵はアイリーンが決めて、エステルさんへ直接依頼しました。三姉妹が63コマ、弾と効果が8枚です。
- 届いた絵は1枚ずつ縮尺と位置を確かめ、すべてゲームに入れました。

## 1. 最初に確認した時の状態(仮の絵のまま)
| 姉妹 | あった絵 |
|---|---|
| 長女 | 待機1枚、歩き4コマ |
| 次女 | 待機1枚、浮遊4コマ |
| 三女 | 待機1枚、スキップ4コマ |

溜め・攻撃・被弾・BREAK・撃破のコマは0枚でした。待機の絵を傾けたり伸ばしたりして見せる、紙芝居の状態です。

### 不自然だった箇所と、直し方の分類
| 箇所 | 原因 | 分類 |
|---|---|---|
| 溜め/攻撃に入った瞬間に、体が最大36%大きくなる | 移動のコマが待機の絵より小さく描かれていた(長女0.74倍・次女0.79倍) | **コード**: 移動のコマを待機の絵の高さへそろえた(当たり判定と一致)。追跡モードは元のまま |
| 溜めで体全体が赤い影のようになる | 手続きの点滅が強すぎた | **コード**: 強さを35%・姉妹の色に |
| 大鎌が動かない、振り切りも余韻もない | 溜め/攻撃/戻りの絵が無い | **絵**(各技 溜め2・攻撃2・戻り1) |
| 攻撃が終わると、すぐ移動のコマに戻る | 戻りの絵も受け口も無い | **コード**: 受け口 `recover_` / `recoverB_`。**絵**: 戻り |
| BREAK中に足が動き、「歩きながらBREAK」に見える | BREAK中の寄せ(移動)の間に移動のコマを回していた | **コード**: BREAK中は脱力のコマ。**絵**: 崩れる・脱力・立ち直り |
| BREAKから立ち直る瞬間に、待機の絵へ急に戻る | 立ち直りの絵も受け口も無い | **コード**: 受け口 `rise_`。**絵**: 立ち直り2コマ |
| 被弾が赤い点滅だけ | 被弾の絵が無い | **絵**: 2コマ(崩れる→立て直す)。**コード**: 2枚以上なら順に見せる(0.28秒) |
| 撃破が三人とも同じ倒れ方 | 表のキーが三人共通 | **コード**: 姉妹ごとの倒れ方。**絵**: 撃破3コマずつ |
| 飛行の倒れ方は、撃破のコマを2枚しか使えない | 墜落の前後で2つに分けていた | **コード**: 落ちる間に順に、地面で最後のコマ(メカドラゴンの2コマは今までどおり) |
| 絵の姿勢の上に、手続きの反り/伸び縮みが二重に掛かる | 絵のないボス向けの変形がそのまま | **コード**: 本物のコマがある時は30%に弱める |
| 棺の口の攻撃の姿勢が、顎が閉じる前に出る | 姿勢の時刻がずれていた | **コード**: 顎が閉じる瞬間に攻撃の姿勢(噛みつきの時間は同じ) |
| 三人同時で体が大きく重なる | 並びの間隔3.6m | **コード**: 4.6m |
| 連携技だと分かりにくい | 合図が音だけ | **コード**: 三人が同時に光る + 三人を結ぶ光の三角形(番の姉妹の線が明るい) |
| 1人目の登場で絵の読み込みが重い | 姿勢の絵(各21枚)をその場で読んでいた | **コード**: 戦いの始め(登場の演出の間)に読む |
| 前半の退く時に、普通の立ち姿のまま薄れる | 退く絵が無い | **コード**: 被弾の1コマ目のまま薄れて退く(絵の使い回し) |

**変えていないもの**: 攻撃の発生時間、当たり判定、ダメージ、BREAK、弾の時間。

## 2. 入れた絵(エステルさんへの依頼の結果)
決まり:
- 右向き
- 待機の絵と同じ縮尺
- 縦長1024×1536に1枚1ポーズ
- 背景はマゼンタ
- 効果や文字は描かない

受け取った後の処理(`Tools/art/reaperpose.py`):
1. マゼンタを抜く。
2. 顔の大きさを待機の絵に合わせる。
3. 顔の横位置を待機の絵と同じにする。
4. 足元を下端にそろえる。地面に食い込む大鎌の刃や座った体は、足元の線で切る。

| 動作 | 長女 | 次女 | 三女 | 受け口 |
|---|---|---|---|---|
| 技1 溜め/攻撃/戻り | 大地断ち 2/2/1 | 冥府の輪 2/2/1 | 急降下 2/2/1 | windup_ / attack_ / recover_ |
| 技2 溜め/攻撃/戻り | 断罪の扇 2/2/1 | 棺の口 2/2/1 | 羽刃の雨 2/2/1 | windupB_ / attackB_ / recoverB_ |
| 被弾(崩れる→立て直す) | 2 | 2 | 2 | hurt_ |
| BREAK(崩れる→地面) | 2(のけぞり→膝つき) | 2(落ちかけ→へたり込み) | 2(空中で回る→尻もち) | break_ |
| BREAKの間(繰り返し) | 2(肩で息) | 2(ぼんやり) | 2(目を回す) | breakloop_ |
| 立ち直り | 2(柄で起き上がる→構え直す) | 2(浮き上がる→担ぎ直す) | 2(片膝→跳び起き) | rise_ |
| 撃破 | 3(大鎌で耐える→膝→倒れる) | 3(力が抜ける→落ちる→仰向け) | 3(勢いを失う→頭から落ちる→うつ伏せ) | defeat_ |
| **合計** | **21** | **21** | **21** | |

- 置き場所: `Resources/BossAnim/reaper_<eldest|second|youngest>/`(ppu 512)
- 描き直してもらったもの: 大鎌が2本に見えた4枚、10ポーズが1枚に並んだ1枚
- BREAKの間の繰り返しの2枚目は、BREAKの2枚目と同じ絵です(エステルさんに位置をそろえて描いてもらったので、交互に見せてもずれません)

### 弾と効果(8枚、`Resources/Effects/Reaper/`)
- 三日月の斬撃弾、玉の弾、光の刃(**太め**。前回、三女の返せる刃の白い芯が細かった件)
- 返せる弾の芯(白い芯 + 十字のきらめき)
- 返せない弾(黒いとげ + 赤い縁)、地割れの牙
- 冥府の輪(魔法陣)、棺の顎
- 白〜灰色の絵には、ゲームで姉妹の色を掛けます。返せない弾・牙・顎は色付きの絵です。
- 絵が無い時は、前の手続きの仮の絵に戻ります。

### 移動のコマ
- 歩き/浮遊/スキップは今の4コマのままです。大きさの跳ねは直しました。
- 中間のコマを足すのは、次の段階にしました(今の4コマとつながる中間の絵は、元の絵の作り方と合わせる必要があるため)。

## 3. 姉妹ごとのテンポ(今の値)
- **長女**: 溜めは長い(0.85〜0.95秒)。攻撃の2コマは0.3秒で振り切り、戻りは0.54秒で重い余韻です。
