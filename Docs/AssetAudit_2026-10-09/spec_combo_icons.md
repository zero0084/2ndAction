## 1. 共通の仕様(15枚)

| 項目 | 内容 |
|---|---|
| 置き場所(提案) | `Assets/Resources/Combos/Icons/combo_<id>.png`(例 `combo_blazing_edge.png`) |
| サイズ / 比率 | **512×512(正方形)**、透過 PNG |
| 表示サイズ | RUN BUILD HUD: カードの枠の 62% = **約 25〜38px**(非常に小さい)/ 成立の通知: 64〜96px(実装後)/ 詳細パネル: 48px 前後 |
| 小ささへの対策 | **24px に縮めても判別できる大きく単純なシルエット**。細い線・細かい模様は使わない。主役は画面の 65〜75% を占める |
| 形 | HUD では角丸の四角に入る。四隅 10% は透明でよい。中央に寄せた構図 |
| 2つの構成カードの表し方 | **2つのカードの要素を「合わさった1つの現象」として描く**(例: 炎の刃 + 炎の魂 → 刃から炎の爆発)。2つの絵を並べない |
| 色 | 各 COMBO の `color`(下の表)を主色に。HUD の紺(RGB 10,15,36 前後)の上で読める明度 |
| アニメ | 不要(静止画)。ENHANCED/AWAKENED の光はコード側 |
| 画風 | ポップ6割 + ファンタジー4割、手描きの筆の質感、鮮やかだが派手すぎない、立体感はほどほど、**太すぎる黒い輪郭線なし**、主役1つ + 補助のエフェクト |
| 禁止(共通) | 文字・数字・略号(BE/WF など今の仮の文字を絵に入れない)、カードの枠、背景の風景、白飛び、既存作品のロゴ・紋章 |

共通の生成文(各 COMBO の本文の**先頭**に付ける):
```
ゲームのコンボ効果を表す小さな正方形のアイコンを1枚描いてください。画面ではとても小さく(24〜40ピクセル)表示されるので、主役は大きく単純なシルエットにして中央に置き、細い線や細かい模様は使わないでください。ポップ6割・ファンタジー4割、手描きの筆のタッチが残る塗り、鮮やかだが派手すぎない、立体感はほどほど、太い黒い輪郭線は使わない。主役は1つ、補助のエフェクトは控えめ。文字・数字・枠・背景の風景は描かない。正方形 1:1。
```
背景色: 寒色の COMBO はマゼンタ `#FF00FF`、赤/桃色の COMBO はグリーン `#00FF00`(各項に記載)。抽出の手順は `spec_ultimate_icons.md` 1章と同じ。

### 構成カードのうち、カード自体のアイコンがまだ仮のもの(重要)
COMBO の構成カードのうち **8枚** は、カードのアイコンがまだ C# の仮生成(`Assets/Art/Icons/Generated/`、丸/滴/線/×/吹き出しの記号)のまま出荷版に出ている:
`burning_soul`, `inferno`, `ice_prison`, `absolute_zero`, `chain_lightning`, `thunder_lord`, `gale`, `tornado`。
COMBO アイコンと**同じ時期に、同じ画風で**作ると揃いやすい。仕様は `spec_other.md` の「属性カード8枚のアイコン」。

### 1. BLAZING EDGE(炎の刃 + 炎の魂)
- 効果: 炎上中の敵を斬ると小さな炎の爆発(同じ敵には1秒に1回)。ENHANCED: 爆発が広く、爆発でも炎上させる。
- 主役: **燃える剣の刃先が炎の爆発の花を咲かせる瞬間**(剣は斜め、刃先に丸い爆発)。
- 色: 橙 #FF8026 + 黄の芯 + 少しの赤。剣は銀。
- 構図: 剣は左下→右上、爆発は右上 1/3。
- 本文: `主役は斜めに振り抜いた銀色の剣と、その刃先で丸く弾ける小さな炎の爆発(オレンジ色、中心は明るい黄色)。刃には炎がまとわりつく。色はオレンジ・黄色・少しの赤・銀。`
- 背景色: グリーン `#00FF00`
- 禁止: 炎で剣が見えなくなるほどの量、黒い煙。

## 4. 組み込み(差し替えだけで済むか)

**追加の実装が必要**(今は画像の参照先が無い):
1. `ComboTuning.Combo` に `Texture2D icon` を足す、または `Resources.Load<Texture2D>("Combos/Icons/combo_" + id)` で読む。`Resources/Cards/ComboTuning.asset` は無いので、Resources からの読み込みの方が `ComboTuning.asset` を作らずに済む。

4. シーンの作り直しは不要(IMGUI で実行時に描く)。
