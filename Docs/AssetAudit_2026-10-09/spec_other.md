# その他の必要素材 制作仕様 / SE・BGM の不足一覧

> 2026-10-09 素材監査(調査のみ)。コード・素材は変更していない。行の ID は `asset_ledger.csv` の ID。
> 共通の画風: **ポップ6割 + ファンタジー4割**、手描きの筆の質感、鮮やかだが派手すぎない、小さくても読めるシルエット、立体感はほどほど、**太すぎる黒い輪郭線なし**、主役1つ + 補助のエフェクト、透過 PNG が基本。
> UI の色: 既存の**紺(#0B1024〜#0F1221)/ 金(#FFD040 前後)/ シアン(#7FE8FF 前後)**。バトル HUD は**読みやすさ優先で重い装飾を避ける**。
> 透過の作り方は `spec_ultimate_icons.md` 1章と同じ(単色背景で生成 → 抽出。赤/桃色が主役ならグリーン `#00FF00`、それ以外はマゼンタ `#FF00FF`)。

## 1. 属性カード8枚のアイコン(ICN-01〜08、優先度 S)

いまは `Assets/Art/Icons/Generated/Icon_<id>.png`(C# が描いた丸/滴/線/×/吹き出しの記号)。他の91枚の手描き風アイコンと並ぶと**一目で仮と分かる**。カードはコレクション・デッキ編集・合成・ガチャ・LEVEL UP の3択・RUN BUILD HUD・闘技場のカード選択の全部に出る。

- 置き場所: `Assets/Art/Icons/CardIcons/<cardId>.png`(置けば `Tools/OneMoreMile/Build Card Database` が命名規則で自動採用。`Editor/CardDatabaseBuilder.cs` 22〜40行)。**素材の差し替えだけで済む**。シーンの作り直しは不要。
- サイズ: **392×589(2:3)**、透過 PNG(既存の81枚と同じ)。インポート設定は既存アイコンと同じにする。
- 画風の手本: 同じ属性の兄弟カード `flame_blade.png` / `frost_edge.png` / `thunder_strike.png` / `wind_cutter.png`(剣 + 属性)。兄弟は「剣」が主役なので、上位の8枚は**剣を使わず現象そのもの**を主役にして区別する。COMBO アイコン(`spec_combo_icons.md`)とも形を被らせない(下の「区別」)。
- 共通の生成文(先頭に付ける):
