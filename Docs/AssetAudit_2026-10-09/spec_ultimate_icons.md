## 1. 共通のデザイン基準(全13枚)

- 方向性: **ポップ6割 + ファンタジー4割**。既存のカード能力アイコン(`Assets/Art/Icons/CardIcons/*.png`、例 `flame_blade.png`, `thunder_strike.png`)と並べて違和感がないこと。
- 手描きの筆の質感(ブラシのタッチが残る)。鮮やかだが派手すぎない(彩度は高め、白飛び・発光の面積は全体の 25% 以内)。
- **小さく表示しても形が読めるシルエット**: HUD ボタンは画面高さの 12%(84〜160px)、カードの RUN BUILD 枠は 40〜62px。48px に縮めて主役が判別できるかを必ず確認する。
- 立体感はほどほど(柔らかい陰影 2〜3段)。**太すぎる黒い輪郭線は使わない**(輪郭は濃い同系色、線幅は 512px で 4〜6px 程度まで)。
- **主役は1つ + 補助のエフェクト**。要素を詰め込まない。
- 透過 PNG が基本。背景・枠・文字・ロゴは描かない(枠は UI 側で描く)。
- キャラ別アイコンは HUD の暗い紺色(RGB 15,18,33 前後、不透明度 82%)の円の上に乗る → 暗い色のモチーフ(黒剣士・忍者・吸血鬼)は**明るい縁取りの光(リムライト)**を必ず入れる。
- 禁止(全共通): 文字・数字・読める漢字/梵字/ルーン、既存作品のキャラ・ロゴ・紋章の模倣、写真調、3DCG調のテカり、太い黒フチ、背景の風景、画面いっぱいの白い光、ハイライトの白飛び、透かし・署名。

### 透過の作り方(既存の手順に合わせる)
- 生成 AI が透過を出せない時は**単色背景で生成 → 抽出**。背景色はモチーフと被らない色を選ぶ:
  - 既定: マゼンタ `#FF00FF`
  - ピンク/赤系が主役のキャラ(お嬢様騎士・巫女・吸血鬼・竜人・格闘家・拳銃士): グリーン `#00FF00`
- 光の筋・粒が多い絵は、これまでの経験どおり `chromakey_full.ps1` 系の全面抽出を使う(`bossart.ps1` 型の1体抽出では光が欠ける。メモ「Chroma key抽出の使い分け」)。
- 仕上げ: 余白を整え、縁の色かぶり(マゼンタ/グリーンのにじみ)を除去。

## 4. キャラ別の仕様

### 4-1. 黒剣士 SWORDSMAN — 「黒一閃」
- 演出(コード): 暗転 → 画面を横切る黒い斬撃 + 白い切り線 → 黒い残像で前進 → 締めの斜め大斬撃 + 白飛び。BUFF は黒い残像。
- 主役: **黒い三日月形の大斬撃**(左下→右上の斜め)。刃の縁に**細い白い切り線**。
- 補助: 斬撃の内側に紫の剣気、斬撃に沿う大剣の剣先のシルエット(柄は描かない、半分だけ)。
- 色: 黒紫 #290F42 + 白 + 紫の光 #A673FF。**紺の HUD に沈まないよう、斬撃の外縁に紫の光のリム**。
- プロンプト本文: `主役は左下から右上へ走る、黒い三日月形の巨大な斬撃。斬撃の縁には細く鋭い白い切り線が一本。斬撃の内側には紫色の剣気が揺らめき、斬撃に沿って大剣の剣先が半分だけ見える。黒が暗い背景に沈まないよう、斬撃の外側に紫の光の縁取りを入れる。色は黒紫・白・明るい紫。`
- 背景色: マゼンタ `#FF00FF`
- 禁止: 赤いマント(キャラ本体を描かない)、炎、血しぶき。

### 4-2. お嬢様騎士 NOBLE LADY — 「桜花乱咲薔薇ノ一太刀」
- 演出: 花びらの渦 → 開花の輪 → 桜吹雪 → 締めの大輪。BUFF は花びら。
- 主役: **大きく開いた一輪の薔薇**(正面)。その中心を**銀の大剣が縦に一閃**(剣先は下)。
- 補助: 薔薇のまわりを回る桜の花びら 6〜8 枚(渦を描く)。
- 色: 桜色 #FF8CBF、薔薇の紅 #FF406B、光 #FFDBEB、剣は銀と金の鍔。
- プロンプト本文: `主役は正面を向いて大きく開いた一輪の紅い薔薇。その中心を、銀色の大剣が上から下へ縦に貫くように一閃している(金の鍔が少し見える)。薔薇のまわりを桜の花びらが6〜8枚、渦を描くように舞う。色は桜色・紅・淡いピンクの光・銀。優雅で気品のある雰囲気。`
- 背景色: グリーン `#00FF00`(ピンクが主役のため)
- 禁止: 王冠・家紋・紋章(既存作品の紋章と誤解されやすい)、ハートマーク。

### 4-3. 双剣士 DUAL BLADE — 「双舞」
- 演出: 高速の斬撃線 → X字斬り → 青白い残像 + 薄い分身。BUFF は青白い残像と分身。
- 主役: **X字に交差する2本の片手剣の斬撃**(剣そのもの + 青白い軌跡)。
- 補助: X の後ろに半透明の剣の残像を1組(少しずらして)、交点に小さな星形の光。
- 色: 水色 #80E6FF、白に近い水色 #E0F5FF、光 #9EDBFF。剣身は銀、柄は濃紺。
- プロンプト本文: `主役は大きなX字を描いて交差する2本の片手剣と、その青白い斬撃の軌跡。Xの後ろに、少しずらした半透明の剣の残像がもう1組。交差する点に小さな星形のきらめき。色は水色・白に近い水色・銀・濃紺の柄。素早く鋭い印象。`
- 背景色: マゼンタ `#FF00FF`
- 禁止: 3本以上の剣、炎。

### 4-4. 二丁拳銃士 GUNSLINGER — 「オールレンジファイア」
- 演出: 追加の銃が現れる(今は四角の仮) → 全方向への曳光弾 → 硝煙 → 締めの砲撃。BUFF は強いマズルフラッシュ。
- 主役: **左右対称に外へ向けた2丁の拳銃**(銃口が左右斜め上)。
- 補助: 中心から**放射状に飛ぶ曳光弾の線 8 本**(全方向)、銃口の小さなマズルフラッシュ、下に薄い硝煙。
- 色: 橙 #FF9E26、黄 #FFF280、光 #FFD959。銃は濃い鉄色に金の装飾。
- プロンプト本文: `主役は、左右対称に外側へ向けて構えた2丁のファンタジー風の拳銃(濃い鉄色に金の装飾)。中心から全方向へ放射状に飛ぶ、オレンジと黄色の曳光弾の光の線が8本。銃口には小さなマズルフラッシュ、下のほうに薄い硝煙。色はオレンジ・黄色・濃い鉄色・金。`
- 背景色: グリーン `#00FF00`
- 禁止: 実在の銃の形の再現(リボルバーの実在モデル・ブランドの刻印)、照準のスコープマーク。

### 4-5. 竜騎士 DRAGON LANCER — 「龍殺凸」
- 演出: 龍の影(光の粒の連なり) → 白い衝撃波 → 白飛び → 槍の突進。BUFF は白い衝撃波。
- 主役: **右上へ突き出すランス**(穂先が大きく、円錐状の白い衝撃波を貫く)。
- 補助: ランスの柄に沿って後ろへ**光の龍のシルエットがうねる**(頭はランスの穂先の近く)。
- 色: 象牙白 #FFF5D9、金 #FFCC4D、白。ランスの穂先は青緑の金属(キャラの槍に合わせる)。
- プロンプト本文: `主役は右上へ鋭く突き出された長いランス。穂先は青緑色の金属で、白い円錐形の衝撃波を突き破っている。ランスの柄に沿って、象牙色と金色の光でできた龍のシルエットが後ろへうねるように伸びている(龍の頭は穂先の近く)。色は象牙白・金・白・青緑。力強く気高い印象。`
- 背景色: マゼンタ `#FF00FF`
- 禁止: 龍の写実的な鱗の描き込み過多(小さいと潰れる)、画面全体の白飛び。

### 4-6. 魔法使い SORCERESS — 「最高位魔法グラウンドゼロ」
- 演出: 静寂(紫の暗転) → 足元と空の魔法陣 → 光の柱 → 締めの巨大魔法陣 + 柱。BUFF は足元の小さな魔法陣。
- 主役: **斜め上から見た楕円の魔法陣**(下半分)と、その中心から**天へ立ち上る光の柱**。
- 補助: 柱のまわりに星屑、魔法陣の外周に回転を感じさせる小さな光点。
- 色: 紫 #B36BFF、金 #FFDB6B、光 #DBB8FF。
- プロンプト本文: `主役は、斜め上から見た楕円形の大きな魔法陣(紫と金の線、模様は幾何学的な円と多角形だけ)と、その中心から真上へ立ち上る太い光の柱。柱のまわりに小さな星屑、魔法陣の外周に小さな光の点。色は紫・金・淡い紫の光。神秘的で荘厳。`
- 背景色: グリーン `#00FF00`
- 禁止: 魔法陣の中の文字・ルーン・五芒星の宗教的な記号(幾何学模様のみ)、杖や本(主役が2つになる)。

### 4-7. 弓使い RANGER — 「レインロード」
- 演出: 空の光の紋章 → 矢の雨(前進と一緒に前へ) → 締めの光の大矢。BUFF は支援の矢。
- 主役: **画面中央を斜めに貫く1本の大きな光の矢**(左上→右下、矢じりが大きい)。
- 補助: 後ろから同じ向きに降る細い光の矢 6〜8 本(矢の雨)、上部に小さな光の紋章(円と葉の模様)。
- 色: 若草色 #80FF80、淡い黄 #FFF299、光 #D1FFB8。矢じりは金。
- プロンプト本文: `主役は、左上から右下へ斜めに飛ぶ、1本の大きな光の矢(矢じりは金色で大きく、軸は若草色の光)。その後ろから同じ向きに降り注ぐ細い光の矢が6〜8本。上のほうに、円と葉を組み合わせた小さな光の紋章。色は若草色・淡い黄色・金。爽やかで鋭い印象。`
- 背景色: マゼンタ `#FF00FF`
- 禁止: 弓本体を大きく描く(主役が2つになる)、文字の入った紋章。

### 4-8. 格闘家 BRAWLER — 「気合の連続パンチ」
- 演出: 気の輪 → 拳の残像の連打 → 締めの巨大ストレート + 衝撃波。BUFF は気のオーラ。
- 主役: **正面(画面手前)へ突き出す金の籠手の拳**。
- 補助: 拳の後ろに重なる 3〜4 個の拳の残像(半透明)、拳の周りの気の輪(リング1本)。
- 色: 橙 #FF8526、黄 #FFE66B、光 #FFB852。籠手は金と濃い赤。
- プロンプト本文: `主役は、画面の手前へまっすぐ突き出された金色の籠手をはめた拳(正面から見た迫力ある構図)。拳の後ろに半透明の拳の残像が3〜4個重なり、拳のまわりにオレンジ色の気の輪が1本広がる。色はオレンジ・黄色・金・濃い赤。熱く力強い印象。`
- 背景色: グリーン `#00FF00`
- 禁止: 腕より上の体、血、骨。

### 4-9. 忍者 SHINOBI — 「高速影分身」
- 演出: 煙 → 影の分身が四方から斬り込む → 分身の残像 → 締めの煙の爆発。BUFF は影の分身。

## 5. 確認のしかた(受け入れ基準)

1. 512px の原寸と、48px / 84px に縮めた版を並べ、主役が判別できる。
2. 紺の円(RGB 15,18,33、82%)の上に置き、暗いモチーフが沈まない。READY の金の輪(UltimateArt.cs 679〜680行の色 #FFD959)と色がケンカしない。
3. 12枚を並べて、各キャラの主色が区別できる(黒剣士・忍者・吸血鬼の暗色3人は、紫/薄紫/赤のリムで差を付ける)。

5. 透過の縁に背景色のにじみがない。
