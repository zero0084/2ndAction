# Enemy FINISH System(2026-10-06)

雑魚を倒した瞬間に「自分の攻撃でぶっ飛ばした」と感じられる撃破演出。

流れ: 最後の一撃 → HitStop → 攻撃の向きへ吹っ飛ぶ → 残像 → 画面の端で光って弾ける。

## 1. 構造

| ファイル | 役割 |
|---|---|
| `Finish/FinishTuning.cs` | 調整値(Resources/Finish/FinishTuning があればそちら) |
| `Finish/EnemyController.Finish.cs` | 敵本体の側: 撃破の種類/向きの決定、死亡確定、見た目への引き渡し |
| `Finish/FinishFx.cs` | 見た目だけの分身・残像・光・粒(プール) |
| `Finish/FinishDebug.cs` | 開発版: 敵を出して指定の FINISH で倒す |
| `Settings/DebugPanel.Finish.cs` | DEBUG →「FINISH TEST…」 |
| `QaSweep.Finish.cs` | `-qaFinish` |
| `EnemyDefinition` | `finishMass`(0 = 自動)、`finishKnockbackResistance` |

## 2. 死亡の処理と見た目の分離

HP 0 の瞬間(`EnemyController.FinishDeath`)に、すべてそのフレームの中で行う。

1. `dying = true`(以降の被弾・接触を無視)、動きの部品を止める。
2. 見た目の分身を `FinishFx` へ渡す。敵の絵・向き・大きさ・色の写しで、当たり判定もスクリプトも無い。
3. 本体を `SetActive(false)` にする。当たり判定・AI・攻撃・接触ダメージ・狙いの対象・敵の数から、その瞬間に外れる。
4. `RegisterKillReward`(EXP / MILE / BONUS ZONE / カードの効果 / マルチの報酬の行き先)。

- 「非表示 → 報酬」の順は従来どおり(BONUS ZONE の数え方のため)。
- 従来は報酬が撃破演出の後(約0.25秒後)だった。今は HP 0 の瞬間に確定する。
- 分身が途中で消えても(シーンの読み直し / GAME OVER / カード選択)、報酬は失われないし二重にもならない。
- 叩きつけ(浮いた敵への下攻撃)も、着地まで待たずに HP 0 で確定する。地面へ叩きつけるのは分身。
- 落下死は従来どおり(演出なし)。
- `FinishTuning.enabled = false` で従来の撃破演出に戻せる。

## 3. 撃破の種類と向き

命中した瞬間の攻撃判定(`PlayerAttackInfo`)とプレイヤーの状態から決める。攻撃判定は二重に持たない。

| 攻撃 | 形 | 向き |
|---|---|---|
| 前の攻撃 | Side | 右〜右斜め上 |
| 後ろの攻撃 | Side | 左〜左斜め上(向き = プレイヤーから敵への向き) |
| 上攻撃 | Up | ほぼ真上へ高速で上がり、小さくなって「キラーン」と星になる |
| 空中の攻撃 | Aerial | 前方の横〜少し下 |
| 下攻撃 / 叩きつけ | Slam | 地面へ叩きつける → 衝撃の光・土煙・揺れ → 斜め上(55°)へ跳ね返る |

- 飛び道具(キットの弾 / 拳銃士の弾)は、弾の飛んでいた向き。
- 叩きつけで複数を倒した時は、角度を ±8〜24° 散らす。速さも少しずつ変えて、弾ける時間をずらす。

種類の決め方:

| 種類 | 条件 |
|---|---|
| HEAVY | 判定のノックバック倍率 1.4 以上、判定の HitStop 0.08 以上、連続技の締め(`AttackSeqTag.Finisher`)、DownImpact、浮いた敵への下攻撃、エリート(標準) |
| OVERKILL | 最後の一撃のダメージ ÷ 直前の残り HP ≥ 3(`overkillThreshold`) |

HEAVY / OVERKILL は初速・残像・弾ける大きさ・粒を倍率(1.35 / 1.8)で強くする。OVERKILL は金色の太い光の筋と花火のような残る光粒。

## 4. 動き(高速走行への対応)

- カメラ基準(画面に対する位置)で動かす。走行速度(100 / 200 / 300km/h 以上)や FloatingOrigin の影響を受けない。
- 二重に速くなったり、画面に残り続けたりしない。
- 残像も画面に対する位置に残す(走行速度で伸びない)。
- 時間は `Time.deltaTime`。HitStop・停止・カードの選択の間は止まる。物理(Rigidbody)は使わない。
- 画面の端(4% 内側)に着くか、`finishDuration`(0.7秒)で弾ける。弾ける位置は画面の内側に収める。
- 空中の敵は重力なしの軌道。
- 重さ(`finishMass`、0 = 自動): 既定 1、Heavy の種類 2.2、空中の敵 0.8、これに絵の大きさを掛ける。エリートは ×1.2。初速は √重さ で割る。
- 重さ 3.5 以上は吹っ飛ばずに短く後退して倒れ、その場で大きく弾ける(巨大な敵)。

## 5. 弾ける光(画面の端)

1. 中心の光
2. 8方向の星形の衝撃
3. 輪
4. 円状に散る粒

- OVERKILL と連続撃破の時は、小さな光粒が少し残る(花火のように)。血や体の破片は出さない。
- 上攻撃は「キラーン」(4方向の光 + 小さな光粒)。

## 6. 連続撃破(FINISH STREAK)

- `streakWindow`(1.2秒)の中の撃破数を数える。UI は作らない。
- 3〜4体で弾ける大きさ / 粒 ×1.25、5体以上で ×1.5(`streakEffectMultiplier`)。

## 7. HitStop と揺れ

HitStop は既存の `HitStop.Freeze` を使う。

| 種類 | HitStop(秒) |
|---|---|
| 通常 | 0.07 |
| HEAVY | 0.10 |
| OVERKILL | 0.12 |
| 叩きつけ | 0.12 |

- 同じ時に複数倒しても、終わりの時刻が一番遅いものだけを使う(足さない)。
- 12体同時で止まった時間は 0.117秒(テスト J)。

揺れは `CameraFollow.Shake` を使う。

| 種類 | 揺れ |
|---|---|
| 通常 | 0 |
| HEAVY | 0.06 |
| OVERKILL | 0.12 |
| 叩きつけ | 0.1 |

- 上限 0.16。続けて来ても大きい方だけを使う(重ならない)。

## 8. プール(負荷)

- `FinishFx` は最初の敵の出現で、SpriteRenderer を `poolSize`(700)個作る。撃破のたびに Instantiate / Destroy はしない。
- 体・残像・光・粒をまとめて1つの LateUpdate で動かす(物ごとのスクリプトなし)。
- 空きが少ない時は粒・残像を自動で減らす。
- 12体同時の撃破で、プールが足りずに粒を減らした回数 0、フレームの最大 16.7ms(Windows、60fps 上限)。

## 9. ボス / エリート / BONUS ZONE

- ボス(荒野・洞窟・天空・ラスダン・死神・竜・魔人)は対象外。各ボスの撃破演出のまま(テスト M)。
- エリートは HEAVY が標準。ボスの関門の判定とは無関係。
- BONUS ZONE の報酬の敵も FINISH で飛ぶ(報酬の数え方は従来どおり)。

## 10. マルチ

- 死亡判定・報酬は HOST が決める既存の仕組みのまま。
- HOST は撃破の種類 / 形 / 向き / 重さを1つの数(`FinishInfo.Pack`、2バイト)にして、死亡の通知(OpDeath)の後ろに付ける。
- JOIN は消える通知(OpDespawn)の時に、同じ見た目を自分の端末で再生する。粒は送らない。
- JOIN の画面は、自分が倒した時だけ HitStop を掛ける。HOST の画面も、JOIN の人が倒した敵では止めない。

## 11. GAME OVER / シーンの切り替え

- `GameOverCleanup` で `FinishFx.ReleaseAll()`(何も待たない)。シーンを読み直すと `FinishFx` ごと消える。
- GAME OVER の直前の撃破でも報酬は確定済みで、結果画面へ進める(テスト R)。

## 12. 開発用

DEBUG →「FINISH TEST…」(ランの中で)。

- 通常 / HEAVY / OVERKILL / 上 / 叩きつけ×4 / 空中 / 後ろ / 5体同時 / 10体同時 / 空中の敵 / 大型の敵
- 走行速度 100 / 200 / 300km/h
- FINISH の ON / OFF(従来との比較)
- 敵の種類の切り替え
