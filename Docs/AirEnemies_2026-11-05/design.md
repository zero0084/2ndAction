# 空中雑魚 設計案(エステルと相談用、2026-11-05)

目的: 空中に居続けるだけで安全にならないようにする。地上が安全な時/空中が安全な時が入れ替わる。HP は低め(小型 1〜2 発、中型は短い連撃)、難しさは高度・配置・数・予兆・急降下で作る。

## 役割(5つ)と動き
| 役割 | 高さ(地面から) | 動き | 予兆 | 正解 |
|---|---|---|---|---|
| A 低空 | 1.6〜2.4m(普通のジャンプの高さ) | ゆっくり上下しながら前から来る | なし(見える) | 地上にいる/倒す |
| B 高空 | 3.6〜5.0m(二段ジャンプ・滞空の高さ) | 高い所をゆっくり漂う・留まる | なし | 二段ジャンプしない/地上へ戻る |
| C 急降下 | 4〜5m で止まる → プレイヤーへ斜めに急降下 → 上へ戻る | 止まる(0.6〜0.8秒、目が光る+軌道の細い線) | 止まって光る | 予兆の間に位置をずらす/空中なら急降下(Dive)で地上へ |
| D 横切り | 決まった高さ(地上の頭の上 or 跳躍の高さ) | 画面の右から左へ高速で横切る | 高さに細い線が光る(0.8秒) | 線の高さを避ける(上か下か) |
| E 群れ/編隊 | 2.4〜4.0m に 5〜7 体 | まとまって前から来て空中の通り道を一時的に塞ぐ | 羽音+影 | 地上を走る |

## 画像の作り方(今までと同じ)
- 1種につき 1 シート: 横に並べたポーズ = 飛行1 / 飛行2 / 飛行3 / 予兆(止まる・光る) / 攻撃(急降下・突進) / 戻り / 被弾(のけぞり) / 撃破(崩れる)。群れの敵は 1 体分。
- 左向き(右から左へ飛んでくる)。背景は単色(マゼンタ #FF00FF。赤/ピンクの敵は緑 #00FF00)。各ポーズの大きさ・位置をそろえる。
- 絵柄は今の敵(半写実の塗り、はっきりした輪郭、情報量多め)に合わせる。ゲーム内では高さ 0.4〜1.8m = 画面の高さの約 2〜9%。
