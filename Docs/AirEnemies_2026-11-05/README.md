# 空中雑魚 18 種(通常3マップ + ラスダン) 2026-11-05

目的: 空中に居続けるだけで安全にならないようにする。地上が安全な時 / 空中が安全な時が入れ替わり、人が見て「跳ぶ・地上にいる・倒す」を選べば抜けられる。
HP は低め(小型 1〜2 発、中型は短い連撃)。難しさは 高度・配置・数・予兆・急降下・地上との混成 で作る。オートは弱めていない(単体の空中雑魚はオートで十分倒せる)。

## 5 つの役
| 役 | 高さ(体の中心、地面から) | 動き | 予兆 | 人の正解 |
|---|---|---|---|---|
| A 低空 | 2.5〜2.9m(立っている頭の少し上) | ゆっくり上下しながら前から寄る。T1〜 は予兆のあと横へ 2.4m 突っ込む | 少し上がって止まる + 頭上の印 | 地上にいる(跳ぶと当たる)/ 倒す |
| B 高空 | 3.9〜4.9m(二段ジャンプの高さ) | 左へゆっくり漂う(向きは変わらない)。空中のプレイヤーが下に来た時だけ 1.6m 降りる | 少し上がって光る + 印 | 二段ジャンプしない / 地上へ戻る |
| C 急降下 | 4.2〜5.0m | 止まって光る + 軌道の細い赤い線 → プレイヤーが着く位置へ斜めに急降下(蜘蛛は真下)→ 上へ戻る(1 体 最大 2 回) | 0.7〜0.8 秒止まる + 線 | 地上: 降りてくる直前に跳ぶ / 空中: 急降下で地上へ / 倒す |
| D 横切り | 地上の高さ 0.8m か 跳躍の高さ 2.8m | 画面の右の外で待つ → 通る高さに画面を横切る線(0.9 秒)→ 右から左へ高速で横切る(体の通り道で当たりを確かめる) | 線(地上の高さ = 橙 / 跳躍の高さ = 赤) | 線が低い = 跳ぶ / 高い = 地上にいる |
| E 群れ | 2.5〜4.0m に 5〜7 体 | まとまって前から寄る。T1〜 はそろって短く突っ込む(羽音 = 小刻みに震える)。天燕は V 字で速く横切る | 震え | 地上を走る |

## 出し方(EncounterDirector / AirMinionTuning)
- 空中の枠(AirLow/AirMiddle/AirHigh)で、その距離で出せる空中雑魚を確率で置く(今までの空の敵の代わり。地上の敵の数は変えない): 0km 45% → 20km 55% → 50km 70% → 90km 50%(間は直線)。
  高い枠 = 高空/急降下/群れ、低い枠 = 低空/急降下/横切り/群れ。1 つの組に横切り・群れは 1 つまで(横切りは画面の右の縁で待って飛ぶので重ねない)。群れは 1 枠を 5〜7 体に広げる。
- 距離の解放(通常マップ): 0〜20km = 低空 1 種 / 20〜50km = + 高空・急降下(2〜3 種、今までの空の敵と混成)/ 50km〜 = 全種 + 判断型の道中イベント。
  90km〜(雑魚の大群・ボス 3 連戦)は群れと横切りを出さず、置き換えの確率も下げる(大群を潰さない)。
- ラスダン: 2km 死霊 → 15km 黒翼の魔物 → 30km 古代飛行兵器 → 45km 小型機械竜 → 60km 死神の眷属(1〜2 種ずつ)。90〜99km(ボスラッシュ)は確率 ×0.4・群れ/横切りなし、99km〜は出さない(静かな道)、100km の三姉妹は出さない。
- 敵の HP は距離の HP × 倍率(小型 0.35〜0.7 = 1〜2 発、中型 0.9〜1.4 = 短い連撃)。高火力敵(+1 ハート)は空中雑魚にも半分の確率で付く(群れは除く)。
- マルチ: HOST が置く(JOIN はパペット)。予告の線は HOST の画面だけ(印は同期)。

## 判断型の道中イベントでの使い方
| イベント | 空中雑魚 |
|---|---|
| 上空封鎖 SkyBlock | その距離の空中雑魚も候補(重み 1.5/種、今までの空の敵より多め) |
| 予兆付き突進群・上下交互(空の帯) | 空の帯の群れに空中雑魚(群れの種・低空の種) |
| 急降下の連続 AirDive(新) | 急降下の種を 3〜4 体、間隔 = 速さ × 1.5 秒。線の予兆を見て跳ぶ/空中なら急降下/倒す。急降下の種が居ないマップ(天空)は上空封鎖 |
| 横切りの連続 AirCross(新) | 横切りの種を 3〜4 体、1.5 秒ずつ、地上の高さ → 跳躍の高さ … と交互。居ないマップは突進群 |
| 高火力敵 | 急降下の種が居れば半分の確率で 1 体を「高火力の急降下」に |
| 通常の Encounter の混成 | 50km〜 の地上 + 空の組(MixedBias)に空中雑魚が入る |
- 帯の重み: 通常マップ 50/60/75km とも 急降下 0.8・横切り 0.8。ラスダン(新): 50km 確率 0.5・間隔 34〜50 秒 / 65km 0.6・26〜40 秒 / 80km 0.7・20〜32 秒(空中封鎖・急降下・横切りを多め)。90km〜 は出さない。ラスダンは今までの道中イベント・高火力・鎧の敵は無し。

## 絵とアニメーション(エステルと相談)
- 18 種 × 8 コマ(飛行 3 + 予兆 + 攻撃/急降下 + 戻り + 被弾 + 撃破)= 144 コマ。羽ばたきは 1-2-3-2 で再生(移動 4 コマ)。全コマ同じ正方形のキャンバス、体の重心(厚み重み)をキャンバスの中心 = ピボット中心(羽ばたいても体が跳ねない)。
- 切り出し: Tools/air/slice.py(枠の境目の一番細い列で切る・背景の色かぶりを抜く・半透明の縁の背景色を取り除く・--depink/--cool/--keepcolor/--bg green)。差し替え: Tools/air/splice.py(1 コマだけ描き直し)。元の絵: C:/GameProject/ArtSource_air/(リポジトリの外)。
- 取り込み: Editor/AirEnemyDatabase.cs(-executeMethod AirEnemyDatabase.BuildBatch、EnemyDatabaseBuilder からも)。素材が無い種は作らない。
- エステルとの確認: ① 18 種の案(古代飛行兵器を追加して 18 種)② 全 18 種の切り出し(採用、ハゲワシの予兆コマだけ描き直し → 差し替え済み、糸蜘蛛は紫が背景と近く緑の背景で描き直し)
  ③ ゲーム内(55km・300km/h・混成)→ 予兆線を太く + 明るい芯 + 横切りに流れる矢印、糸蜘蛛の糸を青白く + 目・背中の光、高速で予兆 +0.25 秒、眷属の間隔 1.2 倍 ④ 修正後 → 「この方向で進めてよい」。

### 当たるか(平らにした道、カード attack ビルド、荒野 55km、急降下 4 体 + 横切り 3〜6 体を出す)
| 操作 | 結果 |
|---|---|
| オート OFF(何もしない) | 急降下 4 ハート、地上の高さの横切りは 3/3 当たる、跳躍の高さの横切りは 0/2(立っていれば当たらない = 正しい) |
| オート ON・放置 | 地上の高さの横切り 1/4 当たる(オートの跳躍・攻撃で多くは避ける) |
| オート + 人(予兆で跳ぶ/地上にいる) | 0 |
- 直した不具合: 横切りの当たりを猶予の仕組みへ回していて、フレームの最後には通り過ぎて当たらなかった → その場で当てる / 地上の高さ 0.8m が立っている体(足元から約 1.0m)の上を抜けていた → 0.5m・地形へすぐ合わせる /
  急降下が速さで決まっていて斜めの距離のぶん遅れて後ろへ外れた → 決まった秒数(0.42 秒)で着く所へ寄せ続ける・予兆の間はプレイヤーの少し前に居る・着く所の本当の地面 + 0.55m へ
- 確認の落とし穴: 推奨ビルドの SHIELD が当たりを黙って防ぐ(QaDamageEvent に出ない)→ GameManager.QaShieldEvent を追加して数える。

### 放置 と 人 の比較(60.3km から 150 秒、推奨ビルド、黒剣士)
| マップ | 放置: 全被弾 / 空中雑魚から | 人: 空中雑魚から |
|---|---|---|
| 荒野 | 7 / 0〜(SHIELD が受ける) | 0 |
| 洞窟 | 9〜13 / 2〜4(糸蜘蛛・突っ込み) | 0 |
| 天空 | 0〜14 / 0 | 0 |
- 空中雑魚の単体はオートでほぼ倒せる・避けられる(オートを弱めていない)。急降下/横切りの連続や混成では放置で当たり、人は予兆で避けられる。
- 人の操作(自動のもの)は予兆に合わせて跳ぶため、オートの地形の跳躍と重なって壁/穴の被弾が増えた(人の操作の簡易さによるもの。空中雑魚の被弾は 0)。
