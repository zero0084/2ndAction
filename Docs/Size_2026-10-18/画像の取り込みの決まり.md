# 画像の取り込みの決まり(2026-10-18)

今後、エステルと画像を増やす時に、取り込みの設定がばらばらにならないための決まりです。
**Android の設定は `Assets/Editor/TextureImportRules.cs` が自動で掛けます。** `Assets/Art` か `Assets/Resources` に置くだけで効きます。

## まず知っておくこと(今回分かったこと)

- Android の既定の圧縮(ETC2)は、**幅と高さが4の倍数の画像しか圧縮できません。**
  - それ以外の画像は、**無圧縮(1画素 4バイト)のまま** APK に入っていました。
  - 今の絵の大半(883枚・1.41GB)がこれでした。
- ASTC は、どの大きさの画像でも圧縮できます。そこで、Android は用途ごとに ASTC を使う決まりにしました。
- このゲームは、**ほぼ全部の画像を起動時に読み込みます**(ホーム画面の時点で 1,241枚)。
  - そのため、APK の容量がそのまま実行中のメモリにもなります。

## 用途ごとの設定

| 用途 | 置き場所の例 | Android の圧縮 | 1画素 | 最大サイズ |
|---|---|---|---|---|
| プレイヤー・敵・ボス | `Art/<キャラ>…_v1`、`Art/WildBoss` など | **ASTC 4x4** | 1 バイト | 2048(既定のまま) |
| UI・カード・アイコン・立ち絵 | `Art/UI`、`Art/Icons`、`Resources/CardFrames` | **ASTC 4x4** | 1 バイト | 表示の約2〜3倍まで |
| 背景・地面・飾り・障害物 | `Art/Background`、`Art/LastCorridor`、`Art/Cave` など | **ASTC 5x5** | 0.64 バイト | 2048 |
| エフェクト・砂ぼこり | `Art/Effects`、`Resources/Effects` | **ASTC 6x6** | 0.44 バイト | 表示に合わせて(多くは 1024 以下) |
| 専用の取り込みがある所 | `Resources/BossAnim`、`Arena`、`Scenery` など | 専用の取り込みのまま(ASTC 6x6) | | |

共通の設定:
- **Mip Map: オフ**(2D で、画面の大きさがほぼ一定のため)。
- **Read/Write: オフ**(実行中に画素を読む物だけオン。今は 0枚)。
- **Alpha Is Transparency: オン**(キャラ・UI)。背景で透明が要らない物はオフでもよいです。
- **Sprite Mode: Single**、**Mesh Type: Full Rect**(今の作りと同じ。Tight にすると縁の処理が変わります)。
- **Filter: Bilinear**、**Wrap: Clamp**(地面を繰り返して並べる物だけ Repeat)。

Windows 版など、Android 以外の設定には触りません。

## 新しい絵を作る時の目安

- **キャラ・敵のコマ**: 画面では、大きくても高さ 150px 程度です。
  - 画面の横幅は 41.6 ユニットです。横 2400px の端末で、1 ユニットは約 58px です。
  - 一番寄った時(撃破の寄り 0.85倍)でも約 68px です。
  - 元の絵は、高さ **600〜800px** あれば十分です。今の絵もこの範囲です。
  - 1コマの周りの余白は少なめにしてください(今のキャラの絵は、平均で約26%が透明な余白です)。
    - ただし、**位置合わせ(足元・顔の位置)が決まっている絵は、余白を勝手に切らない**でください。ピボットがずれます。
- **カードのアイコン**: カードの上では最大でも約80px で表示しています。元の絵は **256〜512px** で十分です(今の 1254px は大きすぎ)。
- **カードの枠・立ち絵**: 表示は大きくても幅 600px 程度です。元の絵は **1024px 前後**まで。
- **背景**: 画面いっぱいに出すので、横 **1600〜2048px**。
- **エフェクト**: 一瞬しか見えず、光らせて重ねます。**512〜1024px** で十分です。
- 幅・高さは、できれば **4の倍数**にしてください(ASTC では必須ではありませんが、他の機種向けにも効きます)。

## 確認のしかた

- `Tools/2ndAction/Apply Texture Import Rules (Android)`: 今ある画像へ決まりを当て直します(新しく置いた画像には自動で掛かります)。
- `SizeAudit.Run`(Unity をバッチで実行): Build Report を表(TSV)にします。次の3つです。
  - 画像ごとの容量
  - 取り込み設定
  - Android での形式
- `-qaMemProbe <dir>`(開発版): ホームと各キャラのラン中の画像メモリを測り、同じ場面を撮ります。

## 例外にする時

- 決まりと違う設定が必要な場所は、`TextureImportRules.Owned` へ追加してください。そこは専用の取り込みのクラスで決めます。
- 例: ボスのコマ(`BossAnimImporter`)、闘技場(`ArenaArtImporter`)。
