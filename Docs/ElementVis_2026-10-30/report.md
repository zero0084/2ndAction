## 1. 変更前と変更後

| | 変更前 | 変更後 |
|---|---|---|
| 炎 | 頭上の小さな橙の点。延焼は橙の丸い広がり。SE なし | **付与**: 大きめの炎がボッと上がり火の粉が散る / **炎上中**: 体に小さな炎が2〜6個(大きさで数を変える)、長短を付けて揺れる。外は橙(普通の合成で白く飛ばない)・芯は黄 / **継続ダメージの瞬間**: 小さな火の粉が上へ / **INFERNO の延焼**: 炎の柱+輪 / SE「ボッ」 |
| 氷 | 頭上の水色/白の点。砕けは水色の丸 | **冷え**: 結晶が一瞬光る、足元と体の端に薄い霜 / **凍結**: 氷片が放射状に飛び、体の下側と左右の端を青白い角ばった氷(濃い青の縁)で覆う。体の中央は覆わない / **砕け**(ABSOLUTE ZERO): 氷片が飛び散る+輪 / SE「キン」 |
| 雷 | 細い黄色の線 0.12秒(作って消すだけ) | 稲妻は細い淡黄の芯+くっきりした金黄の外側(0.16秒、連鎖は0.24秒残して追えるように)。上位ほど少し太い。落ちた所に短い小さな光(同じフレームの光は3つまで)/ **帯電**: 落雷の直後0.8秒と HIGH VOLTAGE の停止の間、体のまわりを金色の短い電気が走る / SE「バチッ」 |
| 風 | 薄い緑の刃(空・雲で見えにくい)。竜巻は緑の丸 | 風刃は明るい青緑+濃い緑の縁(背景に埋もれない)。出した時にプレイヤーに短い風の線 / 当たった所に渦 / **竜巻**: 3段の渦の柱と、吸い込まれる風の線、巻き込んだ敵のまわりに風の輪 / SE「シュッ」 |
| 血 | 出血は頭上の赤い点。**吸収・回復の表示は無し** | **出血**: 赤黒い滴が下へ落ちる(炎の火の粉は上、血は下)/ **吸収・出血の回復が実際に起きた時だけ**: 敵からプレイヤーへ赤い粒が戻り、届くとプレイヤーに小さな回復の輪と光 / SE 低い吸収音 |
| 頭上のマーク | 小さな色の点1つ(凍結>炎上>出血>冷えの1色だけ) | 下の「状態マーク」 |

- 上位カードほど少しだけ強く(見た目だけ): 入口のカードだけ=段1 / 中位を持つ=段2 / 上位を持つ=段3。炎は体の炎の数と大きさ、雷は太さ、氷は凍結の氷片の数、風は風の線の数。画面を覆うほどにはしない。INFERNO・竜巻・砕けは上位のカードで起きる現象そのものが見えるので、それが一番の「上位の印」。
- 旧の表示は開発版の起動引数 `-elemVfx old` で戻せます(比較用)。

### SE
- 5種類を合成で作成(`Tools/audio/gen_audio_elem.py`、外部の素材なし): 炎 0.26秒 / 氷 0.32秒 / 雷 0.20秒 / 風 0.18秒 / 血 0.30秒。大きさは命中の音より約5dB小さい段。
- 間引き: 同じ属性は0.1秒に1回、全属性で0.25秒に4回まで。さらに音の表(AudioLibrary)で最短間隔0.08秒・同時2つまで・優先度は低(大事な音を押しのけない)。
- 40体に5属性を当て続けた試験で、鳴ったのは20秒で38〜62回(1秒に2〜3回)、間引いたのは288〜515回。

- ダメージ数字: このゲームにはダメージ数字の表示が無いので、属性のダメージ数字は足していません(演出とマークで足りる、という判断)。

## 3. 大きい/小さい敵・色の違う敵での見え方
- 演出の大きさは敵の当たり判定の大きさで変える(雑魚 ≈1、大きなボス ≈2〜3倍)。体の炎や氷は体の範囲の中の決まった位置に付くので、大きなボスでも体に埋もれない。
- 確認したボス: サイクロプス(大型)、黒騎士(黒い)、フェニックス(明るい空・炎の体・飛ぶ)、クリスタルゴーレム(明るい)、グリフォン(飛ぶ)。死神三姉妹はラスダンの試験で5属性ありで戦わせ、例外なし。
- フェニックスのような炎の体のボスでは、体の炎だけでは炎上が分かりにくい → 頭上のマークを主な手がかりにする(エステルと合意)。
- 氷はボスの顔・武器・予兆を隠さない範囲(体の下側と端だけ)。

## 4. 複数の属性が同時に付いた時
- 5属性ぜんぶ Lv9 でボスに当てると、同時に付いた状態は最大5つ(サイクロプス/黒騎士/フェニックス)。マークは3つまで、残りは付いた瞬間だけ先頭に出る。
- 体の表示はそれぞれ別の場所に付く(炎=体の中、氷=下側と端、帯電=輪郭、血=下へ落ちる)ので、色が混ざって何も見えない状態にはならない。
- 属性同士の新しい COMBO は足していません。

## 8. 「見えない」のか「弱い」のか(アイリーンの見立て)
- **入口のカード1枚・Lv1 は、発動しても弱い**: 雷 THUNDER STRIKE Lv1 は100回で4回・合計32(1発20の1.6発分)。風 WIND CUTTER Lv1 は8回・48。炎・血も Lv1 は 7〜9%。今回の改修で「発動した」ことは見えるようになったので、残るのは性能の問題です。
- **系統を揃えると強い**: 炎・雷・風は系統 Lv9 で全ダメージの6〜7割。上位カードは入口のカードとの組み合わせで効く作り。
- **氷はダメージより「止める」属性**: 冷えにダメージは無く、凍結の砕け(ABSOLUTE ZERO)で初めてダメージが出る。実戦でも倒す数は少ない。鈍化/凍結の価値は、今回の見た目(霜・氷・マーク)で分かるようになった。
- **血は数字が小さい**: 出血の継続ダメージは 1発20に対して毎秒3.6〜8.4。吸収は撃破が必要で、回復の量はハート1つ。見た目は戻る粒で分かるようになったが、効果の実感は性能の側の問題。

## 9. エステルとの相談
- 1回目(試作の画面4枚): 「画像は作らずコードの絵を磨く」方針。直す3点 = 炎の形が滴に見える / 雷の白い重なり / マークと HP バーの重なり。マークの形の案(炎=先の曲がった2つの山、冷え=太い6方向、凍結=菱形の氷塊、風=中心の空いた渦)、新しく付いた状態を一度強調、血は加算をやめて暗い赤、発動は強く・継続は控えめ、上位の差は大きさより輪郭や動きで。
- 2回目(静止画と動画): 雷は「この方向で採用」、炎は「前より炎に見える・これ以上大きくしない」。追加の確認の依頼 = 炎の上位の発動が確実に映る場面 / 攻撃を止めて状態が切れる所 / 複数属性とボスの予兆が隠れないこと → 動画を作り直して確認(`video/`)。
- 新しい画像素材は作っていません(マーク・粒はすべてコードで描いた絵。`Elements/ElementArt.cs`)。

## 13. 実機で優先して見てほしい所(エステルの意見も含む)
1. 黒騎士などボスの攻撃の前に、属性の表示に邪魔されずに予兆に気づけるか
2. 複数の属性が付いた敵の近くで、自分のキャラの位置を見失わないか
3. 頭上のマーク(雑魚 約22px・ボス 約30px 相当)が、普段の持ち方の距離で読めるか
4. 90〜95km の大群で5属性を揃えた時の重さ(fps)
5. SE がうるさくないか(1秒に2〜3回まで間引いています)
見づらい時は、属性全体を弱めるより「予兆の輪郭を少し明瞭にする / 継続中の炎を胴体の中心から少し外す」程度の調整がよい(エステル)。
