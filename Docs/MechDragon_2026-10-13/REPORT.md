## 3. 攻撃(全部、予告 → 発射 → 隙)

- レーザー: 照準(追う間は白く薄い)→ 発射の 0.4秒前に固定(赤)→ 照射(地面まで)→ 冷却(降りてきて約2.6秒 + 1.4秒の隙)
- なぎ払い(第2段階〜): 上の帯の予告 → 帯の上から下へ。帯の下端より下へは来ない
- バルカン: 砲身の構え 0.85秒 → 各連射の 0.45秒前に帯の予告 → 6発 × 3〜4回、連射の間に切れ目 0.45秒。高さは帯で固定(追尾しない)
- 空爆: 上昇 → 爆弾倉 → 着弾地点の予告 → 爆弾が落ちて爆発。穴の上ではない安全な地点を必ず1つ残す
- 必殺技 OVERKILL PROTOCOL: なぎ払い → 空爆 → 固定レーザー2〜3発 → 冷却 4.2秒(被ダメージ1.3倍・崩し2.6倍)。避ける判断 4回(検証)
- 第2段階以降で強くなる(なぎ払い・空爆の地点が増える・バルカンの帯が交互)が、予告は必ずある
