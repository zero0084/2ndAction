## 3. ガチャのマップ別の見た目
- 構造: 共通の筐体(今の5段階の絵)+ 土地ごとのスキン(GachaSkinFx)。**台を選ぶタブにはせず、引いたカードの土地で台が変わる**(選んでも中身が同じだと「その土地が出やすい」と誤解させるため。抽選・確率・レア度は変えていない)
- 流れ(エステル案): 回す間は共通の金の光と振動 → 排出の直前に土地の飾りが一瞬明滅 → 排出の粒子 → 結果に土地の紋と名前 → 閉じた後も台はその土地の飾り(共通のカードなら元の青金)
- 飾り(エステル作): 荒野=角の頭骨・赤茶の旗・砂と岩 / 洞窟=看板の左右の結晶・足元の結晶と苔 / 天空=白金の翼・光輪・雲 / ラスダン=紫の封印円・黒鉄の鎖
- 新規画像 15 枚(飾り 6・土地の紋 5・羽 1・古代文字 3、合計 約 1MB)。粒子は同時に最大 48・回した時と出た時だけ(常時は後ろの光の明滅のみ)
- ★4/★5: 今のレア度の光が主役。土地の粒子は半分にし、結果の板の後ろにだけ出す(カードと★を隠さない)
- 未解禁: 台の下の紋の列で、マップが未解放なら暗い紋 + 鍵、候補のカードがまだ無い土地は薄く(中身は出さない)。縦画面は台が小さいので列を出さず、結果の土地の札で示す
- 確認: Windows 横/縦(-qaGachaSkin、例外 0)、Android エミュレーター(-qaMapCardShots の中のガチャ)。実機は未確認
