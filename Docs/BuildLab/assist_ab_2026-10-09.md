# 自動操作補助 ボス戦の地形ジャンプ A/B(2026-10-09)

## 変更(HighSpeedAssist.Decide のボス戦の分岐)
ボス戦中はボス用の判断(DecideBoss)が先に決まり、走路の段差/穴へのジャンプ(DecideInner の Up)が
後回しになっていた。検証では、ボス戦中の最後の被弾のうち約4割が「穴に落ちた/段差(壁)に当たった」だった。
変更後は、地形のための Up はボスの「低く構える(stayLow)」指示が無い限り優先する(BossTerrainJumps で回数を数える)。

## 比較の条件
- 同じ試行表 `trials_assistAB_v1.csv`(12キャラ × 3マップ × ボス関門 10k/50k/90k × seed 501/502 = 144件)
- A = 変更前の exe(blexe9)、B = 変更後(blexe10)。どちらも `-memSave`(通常の保存に触れない)
- 方式は「途中から」(`-blPartialAt`: デッキの全カード Lv9 にして関門の手前へ)= 火力は十分なので、差は被弾の数と時間に出る

## 結果(両方そろった 143 件)
| マップ | ボス戦の秒数 A → B | ボス戦の被弾 A → B | 全体の被弾 A → B |
|---|---|---|---|
| 荒野街道 | 1398 → 1241 | 120 → 122 | 139 → 140 |
| 自然洞窟 | 1520 → 1476 | 105 → 79 | 128 → 108 |
| 天空回廊 | 1290 → 1183 | 130 → 93 | 148 → 120 |
| 合計 | 4177 → 3870(-7%) | 352 → 292(-17%) | 409 → 365(-11%) |

- 時間切れ: A/B とも 0 件。全件で関門のボスを撃破
- 荒野街道は差なし(平らな区間が多い)。穴/段差の多い洞窟・天空回廊で被弾が 2〜3 割減った
- 悪くなったマップは無い → 変更を採用
