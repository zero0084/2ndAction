# ビルド検証(依頼F、2026-10-08〜)

目的: 各キャラ×各ステージを、実際のゲームの自動補助だけで攻略できるビルドを探し、キャラ・カード・ボス・地形の相性を把握する。測定と報告だけで、ゲーム本体のバランス(カード性能・敵の強さ・自動補助)は変えていない。

- 固有カード: キャラ専用のカードは無い。各キャラにキャラカード枠3つ(所持カードを付けると、ランの最初からその能力が付く。1能力 Lv9 まで)。character_ultimate(ULTIMATE)はキャラごとに技が違う普通のカード。

### デッキ / ラン中のカード
- デッキ 12 枚(重複可、所持数まで)。ラン中のカードはデッキのカードだけから出る(デッキの重複は出やすさになる)。
- レベルアップ(全回復)/ ボス報酬で3択。各能力はラン中 Lv9 まで(CanStillPick)。Lv9 に達した能力は 5,000m 後に FINAL EVOLUTION(一時強化)が3択の1枠に出る。
- 経験値: 1m で 1、雑魚 15、ボス 100。Lv2 まで 150、以降 150+60×(Lv-1)。

### 持ち込み育成
- 合成 Lv(1〜9)はカードの能力の量。Lv9 のカードを1回取ると、その能力がラン中 Lv9 に届く。キャラカードは最初から付く。
- Mastery/AWAKENED は能力値を変えない(FINAL EVOLUTION の時間 +10% だけ)。
- 今回の育成段階: G0 = 全カード Lv1(キャラカード3枠も Lv1)/ G9 = 全カード Lv9(合成の最大)。比較は同じ段階どうしだけ。

### 自動補助
- 既定 ON: 開始 100km/h(設定 60〜160)、ボス戦でもオート、自動攻撃、自動回避。
- 開始速度より遅い間は何もしない(走るだけ。ジャンプも攻撃もしない)。ボス戦は 30m 以内なら速度に関係なく働く。
- 自然な速度は 18km/h(×移動)から、100m 以降 +5%/100m で 100km/h(×移動)まで(約3.6km)。移動 0.93〜0.95 のキャラ(弓・お嬢様・竜人)は速度カード無しでは既定の開始速度に届かない。

### ボス戦
- 1,000m ごとの関門(10km ごとに大物、100km は関門なし → 死神)。ボス戦の間は距離が進まない。時間制限は無い(倒すまで続く)。
- 検証では 1 回のボス戦に 240 秒(ゲーム内)の上限を置き、超えたら「制限時間内に撃破できず」で試行を終える(先へは進めない)。

### 疾走出発
- 10,000〜90,000m(10k ごと)の関門の 250m 手前へ。通過した関門ごとにボス報酬と同じ候補から1枚(自動)、5,000m ごとのリングで追加の3択(入力でくぐる)。経験値/レベルアップは無い。到着後は CONTINUE と同じ再開(停止画面 → タップ → 3-2-1)。
- 今回はリングの入力なし(下の段のリングだけ自然に通る)= 入力を仮定しない条件。

### 終了条件
- 通常3マップ: ゲームとしての終わりは無い(脱出か倒れるまで)。検証の成功 = 100,000m 到達。その後の死神からの生存は別項目(最大 300 秒)。
- ラスダン: 成功 = 100km の三姉妹戦(最終戦)を突破してエンドロールへ。

## 2. 検証の方法
- 測定用コードは開発版だけ: `QaSweep -qaBuildLab`(Assets/Scripts/QaSweep.BuildLab.cs)、保存は `-memSave`(Dev/MemorySaveStore.cs、プロセスのメモリの中だけ。通常のセーブには触れない)。開発用の解放(全キャラ/全マップ/全カード/疾走の行き先)もそのメモリの中だけ。
- 検証側がするのは、出発・カード選択(ビルドの優先順位で、実際に出た候補から)・停止画面のタップ・案内を閉じる・記録だけ。攻撃・回避・無敵・回復・ワープはしない。
- 速さ: 通常速度(60fps)。ゲーム時間だけを固定刻みで早送りする方法は、実時間で進む処理(疾走/演出)とずれたので使わない。描画なしも疾走が進まなかったので使わない。小さい窓で描画し、複数のプロセスを並列に走らせる。
- 乱数: 地形(WorldRng)と敵の出現(-encounterSeed)をシードで固定。カードの提示などは `Random.InitState(seed)` から始めるが、実行のタイミングで揺れる(同じシード = 同じ地形と敵の編成)。
- ビルド定義: builds_v1.json(make_builds.py で作成)。試行の一覧: trials_*.csv。並列実行: run_trials.py。集計: aggregate.py。
