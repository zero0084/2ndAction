### 1.2 成功の定義(README / result.json どおり)
- 荒野街道・自然洞窟・天空回廊: **100,000m 到達 = 成功**(`success=true`)。その後の死神からの生存は別の項目(最大 300 秒)。
- ラストダンジョン: **100km の最終戦(三姉妹)を突破してエンドロールへ = 成功**。
- 部分試験: 目的の関門のボスを倒した = `partial_cleared`(関門突破)。ラスダン 100km の部分試験だけは最終戦の突破まで見るので、突破すると `success=true` になります(通しの成功とは別に数えています)。
- ボス戦は検証側で 1 戦 240 秒(ゲーム内)を上限にし、超えたら「時間切れ」として試行を終えています。ゲームそのものには時間制限はありません。

### 4.2 出発の種類と自動補助の設定
- **通常出発 + 既定の補助(N: 100km/h、E: 60km/h)は 384件すべて 547m 以内で倒れた**。自然な速度は 18km/h から始まり 500m 付近でも 23km/h で、開始速度に届く前(補助は何もしない)に最初の雑魚・障害物・穴に当たる。開始 60km/h にしても結果は同じ(最長 423m → 547m)。今回は「入力を仮定しない」条件なので、プレイヤーが手で動く前提なら話は別です。
- **常時補助(AL、検証専用)にすると通常出発でも走れる**が、中央値は 1.7km。G0 の序盤(Lv が低い間)が弱く、天空回廊は 48件中 21件が 1〜2km のドラゴンで、ラスダンは 48件中 39件が 3km 未満で倒れた。成功した3件はすべて D(耐久)型。

## 5. データの欠け・注意点
- **結果なし 6件**(1.4節)。集計からは外し、CSV には `hasResult=False` で残しています。
- **ほとんどのセルは試行1件**(シード固定)。シードを変えて 10回ずつ回したのは SB の3組(剣士・巫女 × 荒野、魔法使い × 洞窟)だけで、それでも成功率は 3〜4割と 10割に分かれた。1件だけの結果は「たまたま」の幅が大きいと考えてください。
- **シードが条件ごとに違う**(N/E = 101、AL = 401、SB/SD/G9 = 201、P = 301、AB = 501/502)ので、AL と SB の比較は同じ地形どうしではありません。SB / SD / G9 は同じシード 201 どうしの比較です。
- **実行した exe が混ざっている**: N は blexe(10-08 14:24)、AL は主に blexe7(17:01、メモリ漏れ修正後)、SB は blexe と blexe7、SD と G9 は主に blexe9(10-09 08:05)、AB-B だけ blexe10(補助の変更後)。result.json の `commit` 列は起動時のリポジトリの HEAD で、exe の版ではありません(長い試行の間にリポジトリが進んだため、SD などで値がばらばら)。どの exe かは CSV の `exe` 列に入れました。
- 疾走出発の A/S 型、通常出発の G9、ラスダンの通常出発での G9 は未実行。
- 「常時補助(AL)」は検証専用の設定で、実際のゲームの設定にはありません。
- 「未確定」(N で 41件)は、補助が働く前の倒れ方を判定できなかった物です。
- 敗因のボス名は「その試行で倒しきれなかった最後のボス戦」で、倒れた瞬間にボス戦中だったとは限りません(雑魚・地形が直接の原因でも、ボスの名前が付くことがあります)。
- ボス戦 240秒の上限は検証側の都合です。「時間切れ」はゲームでは負けではなく、時間をかければ倒せた可能性があります。
- 処理速度: 小さい窓・複数並列で通常速度(60fps 目標)で回しています。平均 fps は CSV の `avgFps` 列。

## 6. 提案(すべて案です。未実施・数値は変えていません)
1. **[案] 通常出発の序盤の扱い**: 入力なしだと補助が働く前に必ず倒れる。開始速度に届くまでの間も最低限の回避(ジャンプ)だけは働かせる、または開始速度の下限を自然な初速(18km/h × 移動)付近まで下げられるようにするか、検討の余地があります。手で操作する人の体験とどちらを優先するかはマスターの判断です。
2. **[案] 足の遅い3人の補助の開始速度**: 開始速度を「キャラの移動倍率を掛けた値」にする、または補助の開始速度を 90km/h 前後に選べるようにする、など。現状 G0 では speed_up を入れても届かない。
3. **[案] 大物の時間**: 荒野 80km のドラゴンとラスダンのドラゴンは、Lv9 でも 240秒で倒しきれない試行がまとまって出ています。時間制限の無いゲームでは負けではないものの、長すぎる戦闘になっている可能性があるので、実際の秒数の分布(CSV の bosses から出せます)を見て HP を検討する価値があります。
4. **[案] お嬢様・忍者のボス火力**: どちらも部分試験(Lv9)の最終戦で 4型とも突破できず、時間切れが多い。キャラごとの火力倍率か、専用の得意カードの見直し候補です。
