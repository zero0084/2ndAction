# 設定「最高速度」(2026-10-24)

自然に加速した時の最高速度を、プレイヤーが 60〜120% の間で選べるようにしました。
難易度ではなく「遊びやすい速さの好み」として扱っています(EASY/HARD とは書いていません)。

## 1. 仕様

| 項目 | 内容 |
|---|---|
| 場所 | 設定 → 操作 の一番上(高速補助の設定の上) |
| 範囲 | 60〜120%、5%刻み、既定 100% |
| 操作 | −/+ のボタンで 5%ずつ。保存の値も 5%刻みへ丸めて 60〜120 に収める(壊れた値・中途半端な値にならない) |
| 表示 | 「80%」/ 100% の時は「100% (標準)」。下の行に選んでいるキャラの目安「SWORDSMAN: 約 80km/h  ゆっくり」(ゆっくり/標準/速い) |
| 注意 | 高速補助が ON で、目安が補助のオート開始速度より遅い時だけ「この最高速度では、高速補助が作動しない場合があります(オート開始速度より遅いため)。」 |
| ラン中 | 変更できません(−/+ が押せない。「ラン中は変更できません。次のランから反映されます。」)。走っている途中で上限が変わって急に減速するのを避けるためです |
| 保存 | 設定の分類(`MaxSpeedPercentV1`、SaveKeys に登録)。値が無い = 100%。アプリを再起動しても残ります。リリースの世代の初期化では消えません(設定の分類) |
| マルチ | 協力/対戦マルチでは全員 100% です(地形と敵の間隔を全員の端末で同じにするため) |

**実装の場所**
- `PlayerController.NaturalMultiplierAt`: 自然加速の倍率の**上限だけ**に `UserSpeedScale`(= 設定 / 100)を掛けています。
  - 加速の曲線(18km/h から 100m ごとに +5%)は今までと同じです。上限に着く距離だけが変わります(60% は約 2.6km、100% は約 3.6km、120% は約 4.0km)。
- `Settings/GameSettings.cs`(値・丸め・保存)、`Settings/SettingsPanel.cs`(画面)、`Save/SaveKeys.cs`(保存の表)
- `Save/RunLedger.cs`: ランの記録に `speedSettingPercent`(今の設定)と `speedSettingMax`(このランで使った一番大きい値)を入れました。将来のランキング用で、今は記録するだけです(サーバーへは送っていません)。

**100% = 今までと同じ**
- 上限の倍率は `NaturalCapMultiplier × 1.0` で、以前の式と同じ値です。
- 既存の疾走出発の試験(`-qaSprint`)でも、到着の倍率は以前と同じ 5.56(100km/h)でした。0件の失敗。

## 2. キャラごとの最高速度(カードなし、自然加速の上限)

基準は 100km/h × キャラの速さ(groundMobilityMultiplier)です。設定はこの後に掛かるので、キャラの差はそのまま残ります。

| キャラ | 速さ | 60% | 80% | 100% | 120% |
|---|---|---|---|---|---|
| 弓使い(archer) | 0.93 | 55.8 | 74.4 | 93 | 111.6 |
| お嬢様騎士(noble_lady)/ 竜人(dragonkin) | 0.95 | 57 | 76 | 95 | 114 |
| 黒剣士 / 竜騎士 / 格闘家 / 拳銃士 / 魔法使い / 巫女 / 吸血鬼 | 1.00 | 60 | 80 | 100 | 120 |
| 忍者(ninja) | 1.08 | 64.8 | 86.4 | 108 | 129.6 |
| 双剣士(dual_blade) | 1.15 | 69 | 92 | 115 | 138 |

(km/h。遅め・標準・速めの3人は自動試験で実測し、表と 0.1km/h 単位で一致しました。)

## 3. ほかの仕組みとの関係

**高速補助(変えていません)**
- 補助の ON/OFF とオート開始速度は、最高速度の設定では一切変えていません(勝手に ON にしない・開始速度を下げない)。
- 補助は今までどおり実際の速さ(km/h)で働きます。開始速度 100km/h のままで 80% にすると、カードなしでは 100km/h に届かないため補助は働きません。その時だけ設定画面に小さく注意を出します。
- 遅い設定で補助を使いたい場合は、プレイヤーがオート開始速度を 60km/h などへ下げれば働きます(試験で確認)。

**速さのカード(仕様は変えていません)**
- SPEED UP / SPEED DOWN などのカードは、上限の後で掛かります。設定が何%でも、カードの倍率は同じです(SPEED UP Lv9: 80% で ×1.27、100% で ×1.27)。
  - 例: 80% では 80 → 101.6km/h、100% では 100 → 127km/h。
- FINAL EVOLUTION などの一時的な加速、疾走出発の特別な扱い、演出、デバッグの速さ、ボス関連の速さは上限で止めていません(例: 80% + SPEED UP Lv9 + FINAL EVOLUTION = 130.6km/h)。
- 注意点: MOMENTUM(100〜150km/h で効く)と OVERDRIVE(115km/h 以上で発動)は、決まった km/h で判定します。そのため低い設定では発動しにくく、高い設定では発動しやすくなります。カードの数値は変えていません。

**CONTINUE**
- 再開後の加速(5秒)の目標は、今の設定の最高速度です。中断した時より高い速さへは戻りません。
- 試験: 100% で中断 → ホームで 60% に下げる → CONTINUE: 再開後は 60.0km/h(最大も 60.0)。記録は「今 60%、このランの最大 100%」。

**疾走出発**
- 到着後の速さは、到着した距離での自然加速の倍率(今の設定)です。
- 道中で自動で取った速さのカードの分は、その後で掛かります。
  - 80% では、道中のカードが ×1.06 → 到着後 84.8km/h(試験の期待値と一致)。
  - 120% では、道中のカードが ×0.92(SPEED DOWN を引いた)→ 110.4km/h(期待値と一致)。

**変えていない物**
- 敵・ボス・死神三姉妹の速さ、HUD(実際の km/h を表示)、闘技場・チュートリアル(それぞれ専用の速さ)、ラスダンの流れ。

**ランキングの注意(サーバーは変えていません)**
- Cloud Code のランキング(`omm_submit_run.js`)は、「平均 160km/h × 1.2 = 192km/h より速い」ランを不正として拒否します。
- 120% の双剣士は自然加速だけで 138km/h、SPEED UP Lv9 なら約 175km/h です。平均で 192km/h を超えることはまずありませんが、今までより上限に近づきます。
- 本番への反映はマスターの確認が必要なので、触っていません。必要なら上限の値を見直してください(最大 120% なら 160 → 192 程度)。
