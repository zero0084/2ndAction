# カードの所属の点検(2026-11-07)

## 結果
- 全150枚に所属が設定済み。分類漏れは0件(カードの資産150枚 = 分類表150行、表に無いカード0・表にだけあるカード0)。
- 「どこにも属していないように見えた」原因は、データではなく表示の欠落。カード詳細(長押しの大きな詳細)に所属を出す行が無かった。
  - それまで出ていたのは「解禁の条件」の文だけ。マップのカードは「洞窟で〇m」と出るが、共通のカードと解禁済みのカードは、どこの所属か画面で分からなかった。
- 一覧のフィルター(すべて/共通/荒野/洞窟/天空/ラスダン)とガチャの抽選対象(GachaStage.IsCardEligible → CardMapUnlock.MapGateOpen)は、どちらも同じ分類表(CardMapCategories.Of)を読む。分類を変えると両方が同時に変わり、食い違いは起きない作り。

## 直したこと
- カード詳細の「解放条件」に「・マップ: 共通/荒野/洞窟/天空/ラスダン」の行を、全カード必ず出すようにした。
  - 文言は既存の訳(マップ / 共通 / 荒野 / 洞窟 / 天空 / ラスダン)だけを使うので、30言語とも新しい訳は不要。
  - 確認画像: 0005_bd_land_phoenix.png / 0013_bd_port_phoenix.png ほか。
- 分類の変更は6枚。能力・レア度・解禁の距離・ガチャの段階は変えていない。

| カード | 変更前 | 変更後 | 入手方法の変化 | 決め方 |
|---|---|---|---|---|
| PHOENIX | 洞窟 | 共通 | 自然洞窟で 50,000m 到達 → BEST 50,000m(ガチャ段階4) | マスター指示(汎用の復活) |
| HEART UP | 洞窟 | 共通 | 自然洞窟で 5,000m → BEST 5,000m(段階2) | エステルと相談(最大HPの基本の成長) |

- そのままにしたもの(エステルの判断): SHIELD / VAMPIRE / SECOND WIND(洞窟)、SKY RUNNER / MOMENTUM(天空)、FIRST STRIKE / DOUBLE ATTACK(荒野)。それぞれのマップの戦い方の特色にあたる。
- 既存のデータ: 所持カード・Lv・合成・装備は分類と関係なく保存しているので、そのまま。解禁済みのカードは解禁済みのまま(共通へ移ると条件が緩くなるだけで、解禁が取り消されることはない)。
