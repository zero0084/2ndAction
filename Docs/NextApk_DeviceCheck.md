### ガチャまわりの配置(2026-11-15、456de2f0、確認用 APK 454)
- 直した所: ホームの分類・割合の説明文を外し、「提供割合」を横画面は「ガチャ」の札の右、縦画面は「広告で1回引く」の上(右寄せ)へ。
- 確かめること:
  1. 縦画面・横画面で、「ガチャ」の札(縦はボタン)・「提供割合」・「広告で1回引く」・カード合成・右の列が重ならない。
  2. 「提供割合」が押しやすく、押すと提供割合の画面が開く。
  3. 「提供割合」と「広告で1回引く」を押し間違えない(縦画面は上下に並ぶ)。
  4. 対象のカードが無いマップで引こうとすると、理由と条件が短い間だけ出る。

### カード合成の説明欄・結果欄のスクロール(2026-11-09 修正、46e790b6)
- 直した所: `Unity/2ndAction/Assets/Scripts/CardFusionUI.cs` の SyncScrollContent。
  - 説明欄/結果欄の中身(Content)の高さが 0 のままで、文字だけがはみ出していた。
  - そのため欄がスクロールできず、長い説明の下の行が読めなかった。
- 確かめること(縦画面・横画面の両方):
  1. 異なるカードを2枚選ぶ → 説明欄を指で上へ送れる。「【異名合成】結果は抽選」「メイン側の全能力を継承する確率 50%」「素材の全能力 継承率 25%」「両側失敗: 完成カードなし・MILE を還元」「実行すると、選んだ2枚は消費されます。」が最後まで読める。
  2. 同じカードを2枚選ぶ → 「【同名強化】成功率 100%」の行まで送れる。
  3. 合成の結果の欄(能力が多い合成の後)も最後の行まで送れる。
  4. 短い説明の時は今までどおり動かない(見た目が変わっていない)。
  5. マウスのホイール(Windows)・パッドの右スティックでも動く。
