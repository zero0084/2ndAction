# 以下は最初の「2倍の案」(採用されなかった、参考)

2026-11-26 アイリーン。数値はコードと設定の調査(下の「今の仕組み」)と、開発版の自動走行 20km の実測から。
距離の MILE・ガチャの値段(1回 500 MILE)・マルチの受け取り/分配の決まりは変えない前提です。

## 1. 今の仕組み(撃破の MILE)
| 種類 | 今の基本額 | 掛かる補正 | 設定の場所 |
|---|---|---|---|
| 雑魚(地上) | 種類ごとに 1〜5(ゴブリン/アリ等 1、ホッパー等 2、ワーム/弓兵等 3、オーガ等 5) | 距離で ×1.0(〜1km)→×1.5(10km)→×2.0(20km)→×4.0(100km)。カード(MOB KILLER 等)・GREED・CHAIN BOUNTY・HORIZON | `Resources/Enemies/*.asset` の mileReward、距離は `RunRewards.EnemyMileFactor` |
| 空中の雑魚 | 1〜6(コウモリ/イナゴ等 1、ハーピー等 2、嵐の精 4、空の狩人 6) | 地上と同じ | 同上 |
| 強敵(ELITE ENEMIES) | その種類の ×3 | 同上 | `ChallengeSystem.EliteMileMul` |
| WANTED(賞金首) | 撃破は強敵と同じ + 賞金 20+10×Lv | 宝の MILE の補正 | `ChallengeSystem` |
| BONUS ZONE の報酬の敵 | 宝運びゴブリン 5/ヒット・45/撃破、ミミック 6/ヒット(上限 150)・30/撃破 | ゾーンの倍率 | `Resources/Encounters/BonusZone.asset` |
| BONUS ZONE のクリア/パーフェクト | 30〜160(撃破とは別の達成報酬) | 同上 | 同上 |
| ボス(全マップ) | ボスごとの値(狼 30 〜 メカドラゴン 900)× **1.5** × 強さ(HP の倍率で 1〜2.5) | ボス用カード(BOSS PAY 等)・GREED・BREAK DOMINION | `RunRewards.BossMileBase = 1.5` とボスの表 |
| 空中ボスの乱入 | ボスの式 × 0.5 | 同上 | `BossManager.AirRaid` |
| 死神三姉妹 | 1 体 1,200 | — | `ReaperSisterBoss` |

- 取得はラン中の仮の額で、脱出(成功)の時だけ持ち帰り(倒れたら失う)。マルチ協力は人数で割った額を各自、VERSUS は最後に当てた人。
- 二重の加算は、雑魚 = 死亡の印(dying)、ボス = 報酬済みの印(rewardRegistered 等)、マルチ = HOST が死亡を確定して1回だけ配る、で防いでいます(変えません)。

## 2. 増額の案(たたき台: 2倍)
| 種類 | 今 | 案 | 備考 |
|---|---|---|---|
| 雑魚・空中の雑魚 | 1〜6 | **2倍、ただし最低 3**(1→3、2→4、3→6、5→10、6→12) | 元が 1 の敵は2倍でも 2 で手応えが小さいため、最低額を上げる案(こまめに稼げる) |
| 強敵 | ×3 | ×3 のまま(元の額が2倍になるので結果も2倍) | |
| WANTED の賞金 | 20+10×Lv | 40+20×Lv | 撃破の報酬なので2倍 |
| BONUS ZONE の報酬の敵 | ゴブリン 5/45、ミミック 6/30(上限150) | ゴブリン 10/90、ミミック 12/60(上限300) | クリア/パーフェクトの達成報酬は撃破ではないので据え置き |
| ボス | 基本 ×1.5 | **×3.0**(2倍) | 強いボスほどまとまった額(ボスごとの差はそのまま) |
| 空中ボスの乱入 | ボスの式 ×0.5 | 同じ式(元が2倍になる) | |
| 死神三姉妹 | 1,200 | 2,400 | |

※ マルチの HOST から届く額の上限(`NetSecurity.MaxMileBase` 50,000)は、2倍でも超えません(最大のボスでも数千)。

## 3. どのくらい増えるか(開発版の自動走行・荒野街道・剣士・ソロ、実測と試算)
自動走行(補助つき・攻撃力の上乗せあり)の値なので、人の操作では倒す数が変わります。比べの目安です。

| 距離 | 今(実測) 持ち帰り | 内訳(距離/雑魚/ボス/BONUS) | 案(試算) 持ち帰り | 増え方 | ガチャ回数(今→案) |
|---|---|---|---|---|---|
| 1km | 46 | 10 / 36 / 0 / 0 | 約 93 | 約 2.0倍 | 0.1 → 0.2 回 |
| 5km | 891 | 50 / 98 / 187 / 556 | 約 1,470 | 約 1.65倍 | 1.8 → 2.9 回 |
| 10km | 1,928 | 100 / 227 / 596 / 1,005 | 約 3,200 | 約 1.65倍 | 3.9 → 6.4 回 |
| 20km | 4,600 | 200 / 418 / 1,665 / 2,317 | 約 7,600 | 約 1.65倍 | 9.2 → 15.2 回 |

- 20km の BONUS 2,317 の内訳: ゾーンの撃破/ヒット 837・クリア/パーフェクト 1,412・カードの PAY 等 68。案で増えるのは撃破の 837 だけ(→ 1,674)。
- 雑魚は「最低 3」で 2.3倍ほど(418 → 約 960)、ボスは 2倍(1,665 → 3,330)。
- 距離の MILE(100m ごとに 1)とクリア報酬は変えないので、全体では 1.65〜2倍。
- 初回チュートリアルの 5,000 MILE(⑧、1回だけ)とは別です。

## 4. 判断していただきたいこと
1. 倍率: 2倍でよいか(雑魚の「最低 3」の案を含めるか)。
2. ボスは 2倍でよいか(ボスの比率が大きいので、ボスだけ 1.5倍にする案もあり: 20km で約 6,800)。
3. BONUS ZONE の撃破分も 2倍でよいか(クリア/パーフェクトは据え置き)。
4. WANTED の賞金・死神三姉妹も対象に含めるか。

決まったら、設定の値の変更 + 自動試験(報酬の二重加算なし・マルチの分配・RESULT の表示)で確認します。
