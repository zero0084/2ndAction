## ② 戦闘 SE
- **「ポヨーン」の正体(調査)**: 候補は2つ。
  1. **被弾の音**(敵の攻撃が自分に当たった時、PlayerController.ApplyDamageReaction)= 外部素材の 110→64Hz へ下がる澄んだ音 → 「ボヨーン/ポヨーン」。「ときどき・敵の攻撃かも」に一番合う。
  2. **雑魚の攻撃の予兆**(突進/近接/急降下/跳ね/ワームの構え、道中の大群の知らせ)= 500→1300Hz へ上がる三角波 → 「ピュイーン」。
  - どちらも音程が上下する澄んだ音でアニメ調だったので、**両方を、音程の上下しない重い音へ作り直しました**(自前の合成 `Tools/audio/gen_audio_v4.py`、`player_damage_v4` / `enemy_telegraph_v4`)。大きさは前と同じ段(音量を上げたのではなく音色の変更)。
- **空振り音**: 近接の空振り(シュッ。上/下/空中の攻撃も)を **0.72 倍(約 -3dB)**。音の種類はそのまま。射撃/魔法の発射音は変えていません。全体の SE 音量も変えていません。
- **重なり**: 攻撃が当たったら、その攻撃の空振り音が鳴っていれば **0.07 秒で減衰**(命中音を優先)。空振り音の始まりは遅らせていません。手動の攻撃の命中だけ(属性の追撃などは対象外)。
- 聞き比べ: `se/se_compare.mp4`(28 秒。連続攻撃 / 命中時 / 3体へ命中 / 被弾 / 予兆 の前後)。ゲームと同じ素材・同じ倍率を並べた物で、画面の録画ではありません。
- 未確認: 実機(スマホのスピーカー)での聞こえ方。近接・射撃・魔法で重なりすぎないかは、命中の音の数の上限(既存: 同じ命中音は4つまで)のまま。

## ⑤ 脱出の円形ゲージ
- 上から時計回りに埋まる本当の円形ゲージ、赤→黄→緑。% と残り秒も。必要な長押しの時間は 3 秒のまま。
- 離すと少しずつ減る(満タンから 0 まで 3 秒)。押し直すと残りから再開。離している間は確定しない。
- 被弾だけでは戻らない。死亡/DOWN/脱出できない状態/カード選択・一時停止の画面では 0。
- 穴: 落下が確定した時(落下の線を越えた時)に即 0、復帰後は一度指を離すまで溜めない。穴の中を落ちている間は進めない・確定しない(落下と満タンが同時なら落下が先)。
- ジャンプ/攻撃を止めるのは「今の押下が 0.3 秒を超えて溜めている」時だけ。減っている途中のタップは普通の操作で、ゲージも増えない。
- マルチは本人の操作だけ(ゲージは各自の端末のもの。世界の進行は止めない)。
- 自動試験 -qaEscGauge 合格: 1.5秒で半分 → 離して 0.7秒で 1.53→0.83 → 押し直しで増える / 被弾で 1.00→1.40(続く)/ 落下で 0、押しっぱなしでは 0 のまま / 同時の落下で脱出しない / 0 から 3.02 秒で脱出。
- 動画: `escape/escape_gauge.mp4`(増減・被弾・落下)。既存の -qaEscape(死神との順番など 12 ケース)も脱出の判定は全部合っていた。
- ※ 溜めている間は自動操作補助が跳ばないので、溜めたまま穴へ走ると本当に落ちます(今まで通り)。
