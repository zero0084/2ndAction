# 全12キャラの攻撃判定・攻撃ルール監査(2026-10-03)

黒剣士を Reference = 1.00 として、「同じような攻撃をした時の実戦上の当てやすさ・安全性」を揃えるための監査と修正。

次のものは変えていない。

- 敵/ボスのHP・基本ステータス
- カード91枚の数値・10倍スケール・MILE/EXP・速度/属性カードの数値
- ULTIMATE・Final Evolution

ATTACK RANGE UP の数値もまだ変えていない。

## 測り方(`QaSweep -qaHitAudit`、開発版Windows)

最新コードの判定を、ゲームの中で実際に出して測った。古い仕様書の数値は使っていない。

**R(間合い)**

- 立ち止まった状態(自動前進OFF)で、標準の敵(ゴブリン)を前方 d m に置き、1回だけ攻撃する。
- d = 0〜4m を0.2m刻み。記録するもの:
  - 当たったか
  - 攻撃中に体の接触ダメージを受けたか(置いた時に体が重なっていない距離だけ)
  - 出ていた攻撃判定の範囲 / 発生・終了の時間 / 踏み込みの距離
- 実効リーチ = 当たった一番遠い d(敵の中心までの距離。踏み込みも含む)。
- 体どうしが触れる距離は 1.05m(竜人は1.12m)。これより近い d は、置いた時点で体が重なっているので評価から外した。

**A(エアリアル)**

- 地上の上攻撃 → ジャンプ → 空中攻撃×2 → 下攻撃 の流れ。
- 記録するもの: 打ち上げ / 空中で当たった数 / 敵との最大の距離(置き去り) / 空中の敵への叩きつけ。

**S(高速)**

- 50/100/125/150km/h で、前から来る敵へ、人が押すタイミングで1回だけ攻撃する。
- 記録するもの: 当たったか / すり抜けたか / 接触ダメージ / 飛び道具がプレイヤーより後ろに出ないか。
- 地形の穴と障害物は外して測った(自動ジャンプ補助をOFFにしているため)。

**F(初撃/締め)**

- 初撃と締めに見分けのつくボーナスを付け、各攻撃で何が乗ったかを、与えたダメージから読み取る。

**可視化(開発版のみ)**

- DEBUGパネル「判定表示」/ CARD BALANCE TEST「ビルド」タブ。
- 色: 赤=攻撃判定 / 橙=飛び道具 / 緑=被弾判定(体) / 青=地形の基準点 / 黄=敵の体 / 紫=敵・ボスの攻撃判定 / 水色=ボスの被弾範囲。

## Hitbox / Hurtbox / Collider

**A. Attack Hitbox**

- 近接: キャラの子の判定(通常/上/下/着地、技の箱、竜騎士の槍)。
  - キャラごとの調整(CharacterDefinition の attackHitbox* と MeleeReach)で形を整える。
- 飛び道具: 弾/矢/魔法/札/手裏剣など(1つずつ別の判定)。

**B. Hurtbox**

- プレイヤーの体の BoxCollider2D(タグ Player、幅1m×高さ1m)。
- 敵の攻撃と接触ダメージは、すべてこの箱で受ける。

**C. Movement / Ground**

- プレイヤーの移動は物理の Collider ではない。足元の点(groundOffset)と地面の線(TerrainManager.GetHeightAt)で決まる。
- 通り抜けられない物は WorldPlatforms で別に判定する。

今回、B と C は変えていない。変えたのは A(攻撃判定)と、攻撃中の踏み込みの扱いだけ。

## First / Combo / Finisher(PlayerController.AttackSeq.cs)

**定義(全キャラ共通)**

- 攻撃シーケンス = そのキャラの主攻撃(前/後)を続けて出したもの。
- 連撃のあるキャラ: 1段目 = First、最後の段 = Finisher、間 = Combo。
- 主攻撃が単発のキャラ: 1.2秒以内に続けて出した3回を1つのシーケンスとして数える。
  - 1回目 = First、2回目 = Combo、3回目 = Finisher。4回目からは新しいシーケンス。
  - First と Finisher は同じ攻撃に同時に付かない(以前のお嬢様騎士の二重強化は起きない)。
- 主攻撃以外の技は None(初撃/締めのボーナスなし)。
  - 対象: 上 / 下 / 急降下 / 着地 / 特殊技 / 爆発 / 結界 / 風刃など。
- 印は「技を出した時」に判定や飛び道具へ付ける。命中した時は、その印で決める。
  - 飛び道具を撃った後に別の技を出しても、撃った時の印のまま。
- 1回の入力のボーナスは、同じ敵へ1回だけ。
  - 札・手裏剣などを複数投げる技や、同じ敵に2回触れた判定でも、ボーナスは重ならない。
- ボーナスの値(FIRST STRIKE / COMBO PLUS 等)は変えていない。

**各キャラの現状と結果**(自動テストで、各攻撃に何が乗ったかを確認)

**影響**

- 弓/魔法/忍者/巫女の FIRST STRIKE / COMBO PLUS 系カードが効くようになる(今までは0)。
- お嬢様騎士と竜騎士は、締めのボーナスの回数が減る。

**判断をお願いしたいこと**

- 単発のキャラを「3回で1シーケンス」としたのは、全キャラを同じ規則で扱うための仮の定義。
- キャラごとに変えたい場合は、`SingleAttackSequenceLength` / `ChainTag` の呼び出しで変えられる。
  - 例: 弓の最大まで引き絞った矢を Finisher にする。

## Projectile の共通ルール

| 項目 | 今の扱い |
|---|---|
| Damage | 命中した時の攻撃力 × 判定の倍率(damageScale、撃った時に決まる)+ 撃った時の印の初撃/締め |
| Projectile Speed | 判定ごとの速度 + プレイヤーの走行速度(走行に連動、弾を追い越さない) |
| Lifetime / Travel Distance | 判定ごとの寿命。ATTACK RANGE UP を飛ぶ距離に掛ける口を用意(既定OFF、下記) |
| Projectile Size | 判定ごとの大きさ(射程のカードで大きくはしない) |
| Pierce Count | KitProjectile.pierce(0=最初の相手で消える、-1=無制限)+ 風属性の貫通 |
| Hit Target History | 同じ1発(SwingId)は同じ相手へ1回だけ |

Hit Target History の詳細:

- 雑魚: 以前から(EnemyController)。
- ボス/竜/魔人: 今回追加した(PlayerAttackInfo.AlreadyHit)。
- 爆発は別の1発なので、「弾+爆発」の2段の技は意図どおり2回当たる。

修正したもの:

- ボス/竜/魔人に、同じ1発が二重に当たり得た(弾の入り直し、高速時の掃引)。
- 前回の修正: 拳銃士の弾のボス貫通、飛び道具がボス/敵の攻撃判定で消える。

## 魔法使いの前方魔法弾2Hit

**調査結果: 意図した2段攻撃**

- 魔法使いの調整値の見出しが「前: 魔法弾(命中で小爆発)」。
- 爆発には専用の半径(0.85)と倍率(blastDamageScale 1.0)があり、ノックバックも別(1.2)。
- 上/下の魔法も同じ「弾+爆発」の作り。
- 爆発は周りの敵を巻き込むための技で、事故の二重ヒットではない。
- そのため今回は変えていない。

**A. 2段攻撃として残す場合**

- 単体への火力は「弾+爆発」で、平らな攻撃力の上乗せが2回分効く。
- 今の魔法使いのDPSは全キャラで高い方(カードなしでゴブリンに約60〜67)。
- 初撃/締めのボーナスは弾にだけ乗る(今回の整理で、爆発には乗らない)。

**B. 1Hitに統一する場合**

- 当てた相手には爆発が入らないようにする(周りの敵にだけ爆発)か、爆発の倍率を下げる。
- 単体への火力は約半分になる。
- 魔法使いだけ単体の敵に弱くなるので、魔法弾の倍率で戻すかの判断が要る。

## ATTACK RANGE UP(Effective Attack Range)の準備

- 近接: 今まで通り、攻撃判定の大きさ(前方の実効リーチ)に掛かる。
- 飛び道具: 寿命 = 飛ぶ距離に掛ける口を用意した(大きさは変えない)。
  - `PlayerController.RangeAffectsProjectiles`(既定OFF)。
  - 掛ける値は「カードで増えた分だけ」(今の値 ÷ キャラ自身の基準)。
- これで、同じ「Effective Attack Range」の考え方で扱える。
- カードの数値と、ONにするかどうかは次の段階で決める。

## 修正の一覧(Hurtbox / Movement Collider は変えていない)

**全キャラ共通**

- 攻撃が当たった後の踏み込みは、当てた敵の体の手前で止める。
  - 自動前進とノックバックはそのまま。当てる前の間合いは変わらない。
- First / Combo / Finisher の統一(上記)。
- ボス/竜/魔人の同じ1発の二重ヒット防止。
- 判定の色分け表示(開発版)。

**キャラごと**

- お嬢様騎士: 共通の踏み込みの修正で、接触ダメージ 3/14 → 0/14。
- 竜騎士: 上攻撃。
  - 槍の付け根を低く(肩の高さ−0.2m)、太く(×1.3)、角度を50°→40°にした。
  - 上攻撃として打ち上げるようにした。
  - 目の前の敵に当たらなかった → 1.6mまで当たる。
- 格闘家: 腕(判定の長さ)は伸ばしていない。
  - 踏み込みを各段+0.2m。
  - 判定の高さ 0.62→0.8m。
  - 前方の拾い(MeleeReach の走行中の補正)を時速0から有効にした(最大+0.5m)。
  - 横の広さ ×1.12、アッパーの幅 ×1.15。
  - 実効リーチ 0.67 → 0.83。
- 忍者: 上の斬り上げ(上昇ダッシュ)を上攻撃にして、打ち上げるようにした。
- 吸血鬼:
  - 上(霧の突進)を上攻撃にして、打ち上げるようにした。
  - 霧の判定を前へ広げ、低く平らにした(体が進む先を覆う)。
  - 急降下の判定を 0.9×0.9m → 1.5×1.3m にした(体の前下)。
