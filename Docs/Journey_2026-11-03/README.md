# 背景の旅の流れ(2026-11-03、エステルと相談して確定)

目的は「絵を増やすこと」ではなく「進んでいる感覚」。遠くに見えた場所へ近づき、関門のボスを倒し、その場所を通り抜け、外へ出ると次の場所が見える。

## 共通の仕組み(LandmarkJourney / JourneyProfile)

- 10km = 1章: **発見** 0〜2km → **接近** 2〜7km → **目前** 7〜9.5km → **門番**(章の終わりの大ボス)→ 撃破後に **門をくぐる**(約4秒)→ **内部** を撃破地点から 1.2km → **外へ**(次の目的地が見えてくる)
- 3層: 遠景 = 今の背景(章の終わりへ向けて最大 1.04〜1.06 倍)/ 中景 = 目的地(章の中の km で 1→3.2 倍の曲線、少し左へ寄る)/ 近景 = 門(地面の 0.7 倍の速さ)・内部(0.5 倍、横に繰り返し)・目印(章の 5km、0.8 倍)
- 内部に入るのはボスを倒した後(ボス戦の間は距離が止まるので、内部が途中で切れない)。CONTINUE/ワープで途中から始まった時は「今より前の関門は突破済み」で作り直す
- 並び順は元の背景の少し上(-97)〜雲(-45)の上・-40 より奥。地面/敵/弾/障害物には重ねない。目的地/門/内部/目印には背景の見やすさの調整(BackgroundTone)が掛かる
- 荒野の景色の変わり目(40km→B、80km→C)は、関門を突破して内部が画面を覆うまで前の景色のまま(内部の間に切り替えて、抜けると新しい土地)
- 90km の関門の先は今までの終盤(大群・3連戦・死神)の演出のまま。旅は 80〜90km の「最後の城塞/最深部/天空の果て」で止まる
- 内部のなじませ: 入口は門の中心が画面の中央を過ぎてから `interiorFadeInMeters`(48m、洞窟 12m)、出口は `interiorFadeMeters`(120m、洞窟 20m = 約0.5秒。暗い洞窟で長く重なると濁るため)
- 景色が変わる章の光: 関門の手前ではなく、内部の後半(`interiorLightFrom` 50%〜出口)で次の章の光へ。抜けた時には新しい土地の光になっている
- BONUS ZONE: 関門のボスを倒してから門が画面を抜けるまで(突破の確定待ちを含む)は始めない(`LandmarkJourney.GateVisible`)。抽選の確率・報酬は同じで、門を抜けた後に始まる
- CONTINUE/ワープで内部の途中から始めた時も内部の絵から始まる(3マップ × 10.7km/40.8km で確認)
- 値は `Resources/Journey/<stageId>_journey`(JourneyProfile の asset、Inspector で直せる)。無ければ `JourneyProfile.Default` のコードの既定値。開発版 `-journey 0` で旧来の見た目

### エステルの最終判定(2026-11-04)

- 荒野・洞窟・天空の3マップとも採用、全9章へ展開(9章の並びは上の表のとおり実装済み)
- 洞窟の石門: 絵を調整(石材 +9%・柱の結晶 +10%・要石の結晶 +18%、`lift.py` を2回: 全体 `--top 1 --gain 1.09 --glow 1.10` → 上 30% `--gain 1 --glow 1.08`)。大きさ 1.45 倍・速さ 0.7 倍・位置は維持(要石は画面の上の外。下げると柱が足場に隠れて巨大な門の感じが弱まるため、柱の結晶で伝える)
- 門の周りに大きな光の効果は足さない(敵/障害物の見やすさを優先)
- CONTINUE: 中断データはボスの報酬を受け取った時点(関門の直後)から走り直す既存の方式。BONUS の待機/実行は保存しない(報酬の二重取りを防ぐ)。再開すると門 → 内部の演出がもう一度流れ、その間 BONUS は始まらない
