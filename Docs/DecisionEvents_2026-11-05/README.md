# 判断型の道中イベント(50km〜、通常3マップ) 2026-11-05

目的: オートは補助のまま。50km 以降は「上か下か・避けるか倒すか・打ち上げるか」の一瞬の判断をランダムに、こまめに求める。
完全に放置するとダメージが積み重なり、人が画面を見て少し操作すれば簡単に抜けられる。1回のミスで倒れない(1回 1〜3 ハート)。

## 追加したイベント(RoadEventKind に追加。今までの道中イベントと同じ管理 = 1つずつ)
| 種類 | 見た目 | 正解 | 放置すると |
|---|---|---|---|
| 予兆付き突進群 TelegraphRush | 画面に固定した赤い帯が光り、上の縁の明るい線が右から縮む(残り時間)→ 群れが右から左へ横切る | 地上の帯 = 跳ぶ / 空の帯 = 地上にいる | 地上の帯は当たる(群れ全体で1回) |
| 上空封鎖 SkyBlock | 区間の上に赤い帯 + 飛ぶ敵(1.5倍)。区間がまだ画面の外の間は右の縁に細い赤い予告 | 下を走る(跳ばない) | オートが跳ばなければ当たらない(跳ぶと当たる) |
| 地上封鎖 GroundBlock | 重い敵を地面に並べ、赤い帯 + 上向き矢印 | 跳んで越える(背が高いので二段) | 地上の攻撃で下がらない → 体当たり(大型 2〜3 ハート) |
| 上下交互 Alternate | 地上の帯 → 空の帯 → 地上の帯(画面に固定) | 跳ぶ → 地上 → 跳ぶ | 地上の帯で当たる |
| 高火力敵 HeavyHitter | 赤紫のオーラ + 武器の光 | 先に倒す | ダメージ +1 ハート(HP は普通) |
| エリアルで退かす敵 AerialBrute | 鋼色の鎧 + 頭の上の水色の上向き二重矢印(暗い縁取り) | 打ち上げ → 空中で2回 → 大きく吹き飛ぶ | 地上の攻撃はほぼ効かず下がらない(硬い音と火花)→ 体当たり |
| 今までの5種(敵ラッシュ/飛行編隊/強敵/追跡/空中ボスの乱入) | APK430 のまま | — | 50km からはこの管理で選ぶ(重みは小さめ) |

- 帯の色: 赤 = 危ない所(不透明度 0.26)。矢印は帯の安全側の縁(地上の帯 = 上の縁の上に上向き、空の帯 = 下の縁の下に下向き)、3 組・ゆっくり。縁と矢印はマップの色(荒野 = 砂、洞窟 = 紫、天空 = 水色)。
- 群れは攻撃では止まらない(火花だけ)。オートが前の敵へ振った攻撃で群れが消え、放置でも当たらなかったため(最初の作り)。
- 群れの当たり: 画面を約 50m/秒で横切るので、フレームごとの通り道でプレイヤーの体と重なったかを確かめる(物理の判定だけだとすり抜けた)。
- 区間を使うイベントは、画面の外の先の穴を埋めて平らにする(TerrainManager.SetResumeFlatZone)+ その区間には普通の敵/障害物を置かない。
  画面に固定した帯も、危険が来る時刻に走る範囲を先に平らにする(被弾の硬直のあとに穴へ落ちる、穴を越える跳躍が空の帯に入る、を防ぐ)。
- 荒野の上下の分岐: プレイヤーが走っている方のルートに置く。下の道のすぐ上に上の道がある所は空/跳ぶ空間が無いので使わない(画面に固定した帯へ切り替え)。天空回廊の浮島は足場なので邪魔にしない。

## マップ別
| マップ | 地上の群れ | 空の群れ/上空封鎖 | 地上封鎖/鎧の敵 | 高火力敵 | 帯の色・粒 |
|---|---|---|---|---|---|
| 荒野街道 | 騎兵(突撃兵/追跡兵) | 飛竜 | オーガ/精鋭ゴブリン | ゴブリン系 | 砂色・砂ぼこり |
| 自然洞窟 | アリ/兵隊アリ | コウモリ | 兵隊アリ | アリ系 | 紫・結晶のかけら |
| 天空回廊 | 天狼 | ハーピー/飛竜 | 守護者/騎士 | 天空の雑魚 | 水色・風 |
(敵はそのマップのその距離の帯の敵から選ぶ。背景の旅: 章の後半(目的地へ近づく)は地上の封鎖/突進/鎧の敵を多く、天空は空の種類を多く、洞窟は地上封鎖を多く)

## 発生(DecisionEventTuning、Inspector で変更可)
| 距離 | 候補の間隔(走行時間) | 確率 | 終わった後の休み | 予兆 | 安全帯の広さ | 敵の数 | 2種類の重ね |
|---|---|---|---|---|---|---|---|
| 50〜60km | 24〜38 秒 | 70% | 7 秒 | ×1.3(1.43 秒) | ×1.25 | ×0.85 | なし |
| 60〜75km | 12〜22 秒 | 85% | 5 秒 | ×1.0(1.1 秒) | ×1.0 | ×1.0 | なし |
| 75〜90km | 8〜15 秒 | 90% | 4 秒 | ×0.95(1.05 秒) | ×0.95 | ×1.15 | 35% |
| 90km〜 | 出さない(今までの終盤のラッシュ) | | | | | | |
- 距離の下限 260m。同じ種類は続けない。ボス戦/ボスの後 5 秒/BONUS/門/カウントダウン/カード選択/次の関門の手前(500m + 速さ×6 秒)は始めない(待つ)。途中でボス戦/BONUS が始まったら帯と群れは消す。
- 空中ボスの乱入など今までの種類が終わった後は最低 5 秒空ける(エステル)。
- 予兆: 0.8〜1.6 秒(基準 1.1 秒 × 帯の倍率 + 速い時 最大 +0.25 秒)。画面に固定した帯は速さに関係なく同じ秒数。区間のイベントは「速さ × 予兆の秒数」以上先に置く(区間が見えるまでは右の縁に予告)。
- 危険帯の高さ: 地上の帯 0〜1.25m(群れの高さ 1.15m、1回のジャンプで越えられる)/ 空の帯 2.15〜4.6m(立っている頭より上)/ 上空封鎖の敵 2.8〜4.6m。
