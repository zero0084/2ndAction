## 1. HOST のカード選択中も雑魚が出る

- 原因: 撃破から「報酬を選び終える」まで遭遇(ボス戦)の状態が続き、その間は雑魚の出現を止めていた(BossManager.SpawnsHeld)。HOST が報酬を選ぶ間、ほかの人の前に雑魚が出なかった。
- 修正: マルチでは、全部のボスに致命の一撃が入った時点(MpBossFightOver)で雑魚の出現の停止をやめる。ラッシュ/95〜99km の3連戦/空中の乱入は今まで通り(次のボスがいる)。
- 仕組みの注意: 雑魚は「最前の人」の前に出る(前から同じ)。HOST が最前で止まって選んでいる間、HOST より前の予定は増えない。ほかの人が HOST を追い越すと、その人の前に出る(普段の後ろを走る人と同じ扱い)。
- 結果: R1(HOST がとどめ・10秒選ぶ、参加者が追い越す)で、HOST の選択中に予定4回・雑魚12体。変更前の決まり(R1_legacy)は 0 回(報酬の後まで止まっていた)。

## 2. 撃破後の約2秒の演出で、選ぶ人以外を止めない

- 原因: 撃破の扱い(BossDefeatedThisPhase)が倒れる演出(約2秒)の後に立つので、それまで闘技場の足止め(HoldsRun)が全員に続いていた。
- 修正: マルチでは「全部のボスに致命の一撃(0.3秒続けて戦っているボスがいない)」で足止めを解く。倒れる演出・報酬の選択はそのまま。報酬のカードを選ぶ本人だけが止まる。
- 結果: 撃破後に止まった記録(0.5秒ごと)は全試験で 0〜1 回(変更前の決まりは 34 回 = 約17秒)。

## 4. ヒットストップ(約0.1秒)

- 切り分け(以前): HOST は端末全体の時間(Time.timeScale)を止めていた。HOST は全員の敵/ボスを動かしているので
  - HOST の攻撃 → 全員の画面の敵/ボスが一瞬止まる
  - 参加者の攻撃(HOST が代わりに処理)/ボスの攻撃/ほかの人の BREAK → **HOST のプレイヤー(無関係)まで止まる**
  - 参加者の攻撃 → 参加者の端末だけ止まる(参加者の端末は自分のプレイヤーだけ動かしている)
- 修正: マルチでは端末の時間を止めない。この端末のプレイヤーの攻撃が直前(0.1秒以内)に当たった時だけ、そのプレイヤーだけを止める(動かず、指は先行入力として覚える)。当たった相手は今まで通り自分の怯みで同じ時間止まる。シングル/CPU サポートは今まで通り。
- 結果: 全試験で端末の時間が止まった記録 0(変更前の決まりは HOST に3回)。R3(参加者がとどめ)では HOST が参加者の攻撃を29回処理し、HOST のプレイヤーは止まらなかった。参加者は自分の命中で33回だけ自分が止まった。

## VERSUS への影響
- 共通の処理(1・2・4)は VERSUS にも効く(各自の端末で同じ扱い)。距離(個人)・順位・勝敗・報酬の決まりは変えていない。V1/V2/V3/O2 で「画面の距離 = 各自の距離」を確認。

## 一時停止中の保護(今の扱い、変更なし)
- マルチの一時停止のメニュー/カード選択の間: 本人だけその場で止まり、敵に狙われない(NetTargets)。
- **訂正(第3で確認)**: 「落下・弾などは通る」は誤り。選択中(一時停止も同じ)は攻撃/弾/接触の被弾を受けない(PlayerController.TakeDamage の NetIsChoosing、HOST も申告を拒否)。選択中はその場で固まり重力も掛からないので落ちない。下の「第3」を参照。
- 有利になるか: 止まっている間は個人距離が増えないので、VERSUS の順位では不利。CO-OP はチーム距離がほかの人で進むが、報酬・記録は個人距離。CO-OP で選択/停止の間に 120m 以上離れたら復帰の置き直し(ワープ)が入るが、ワープした分は距離の報酬・EXP から除いている(ExcludeWarpDistance)。
- 放置の上限は無い。必要なら「一定時間(例 30秒)で保護を切る/自動で閉じる」を提案(未実施)。
