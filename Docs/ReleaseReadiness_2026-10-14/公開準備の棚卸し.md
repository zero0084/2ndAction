## 1. ランキングはソロ(サポートなし)だけ — 実装と確認

| 項目 | 内容 |
|---|---|
| 投稿の対象 | CPU サポートを使っていない一人プレイの成功記録だけ。人間同士のマルチも対象外(以前から) |
| サポートありのラン | MILE・解放・ローカルの記録(BEST など)は今までどおり。ランキングへは投稿しない(`Leaderboard.IsEligible`: "CPU support used") |
| 一度でも使ったら対象外 | 出発時に記録した人数を下げない(`CpuParty.MarkLedger`)。仲間が倒れても外れても「サポートあり」のまま。中断→CONTINUE(`RunLedger.Resume`)とクレジット後の YES(`RunLedger.BeginContinuation`)でも人数と仲間を引き継ぐ |
| オート・疾走出発 | 既存の仕様のまま(使ってよい。一覧に印) |
| サポート用の表/スクリプト | 作らない。`omm_submit_support.js` を削除。クライアントの送信先は `omm_submit_run` だけ |
| 端末に残ったサポートの記録 | 起動時に、前の版が残したサポートの送信待ち・自己ベストを取り除く(`Leaderboard.PurgeSupportEntries`)。ソロの送信待ち/自己ベストは消さない。サポートの記録をソロへ振り替えない |
| 表示 | 順位の画面の「ソロ / CPU サポート」切り替えを削除。代わりに「ソロのランだけ(CPU サポート・マルチのランは対象外)」と表示。対象外のランは送信待ちに入らないので「送信待ち」「送信失敗」とは出ない |
| サーバー側の検査 | `omm_submit_run.js` に、`partySize` が 1 でない、仲間がある、人数の申告が無い(古い版)送信を "solo only" で拒否する検査を追加。端末は必ず `partySize = 1` を付ける。拒否は再送しない扱い |
| 出発の画面の説明 | 「サポートを使ったランはランキングの対象外です(MILE・解放・自己ベストは通常どおり)」(30言語) |

**確認(Windows、模擬サーバー)**:
- 前の版のサポートの記録 3件を取り除き、ソロの物は残った(送信待ち・自己ベストとも)。2回目の起動では何も消さない。
- サポートのラン / 一度サポートを使ったラン(人数が 1 に戻っても)は対象外。ソロのランは対象。
- 検査はサポートの記録を "solo only" で拒否し、ソロは通る。
- 送信の後に「送信待ち」「失敗」が残らない。表にはソロの記録だけが載る。
- サーバーのスクリプトの検査の部分を Node で単体試験した(ソロ / サポート / 仲間あり / 人数なし / 重複 / 速すぎ)。**本物の Cloud Code では未実行**です。

**限界**: 改造した端末が「ソロ」と偽って送る不正は、サーバーでは見分けられません。人数は端末の申告です。

## 5. 保存の未確認だった項目

- **前回メモリ保存で失敗した5件**(音量の保存 / 闘技場の構成3件 / CONTINUE の慣らし):
  - 原因は、試験が保存を PlayerPrefs から直接読んでいたことです。試験を、ゲームと同じ入口(SaveStore)で読むように直しました。
  - **専用のファイルの保存(`-fileSave`、通常のセーブに触れない)で、3つの試験とも合格**しました。
- **実際の保存と再起動後の読み込み**(新しい確認 `-qaPersist`、本当に終了して起動し直す):
  - 音量(全体 0.6 / BGM 0.35)が保存され、再起動後に音の設定へ反映される。
  - 闘技場の構成(キャラ / 距離 / 速さ / 速さの方式 / シード)が再起動後に読み込まれる。
  - 中断して終了 → 起動し直して CONTINUE で、同じ地点・同じ能力値/HP/レベル/カードから再開する。
  - **結果: すべて合格**(Windows、専用のファイルの保存。通常のセーブ(レジストリ)のゲームのキー 70 個は前後で同じ)。
  - 別件の注意: CONTINUE の試験の中の「既存の穴の上で再開した時の足場の連続」の1項目が、4回中2回失敗しました。保存とは関係のない地形の確認で、保存/読み込みの項目は毎回合格です。前の回(メモリ保存)では出ていなかった、断続的な失敗です。**未解決**として残します。
- **CPU の仲間のカード Lv**(説明を正確にしました):
  - 使うのは**プレイヤーが所持しているカードの Lv**(カード合成・強化で上がる、ランの外の所持 Lv)です。**ラン中のプレイヤーの Lv は使いません**。
  - 同じカードを複数の段で持っている時は、一番高い Lv。
  - **合成カード**(複数の能力を持つカード)は、主な能力のカードとして数えます(その主な能力の Lv)。合成カードの副能力は仲間には付きません。
  - **未所持**のカードは Lv1 として扱います。
  - 仲間はおすすめ構成の順に、レベルアップ/ボス撃破ごとに1回取ります。1回で上がる量 = その所持 Lv(上限 Lv9)。例: 所持 Lv5 なら 1回目で Lv5、2回目で Lv9。
  - プレイヤーのカードは読むだけで、消費もデッキの変更もしません。Mastery/AWAKENED・FINAL EVOLUTION は仲間には付きません。

| 引き継ぎ: キャンセル | 読み込み → 確認の画面で「キャンセル」(または選ぶ画面で戻る) | 何も変わらない |
| 引き継ぎ: 二重にならない | 同じファイルをもう一度読み込む → アプリを2〜3回起動し直す | MILE・カードの枚数が増えない |
| 引き継ぎ: 壊れたファイル | 別の JSON や画像を選ぶ | 「このゲームの引き継ぎファイルではありません(今のデータは変わっていません)」等で、何も変わらない |
| ランキング(本番の設定の後) | ソロで脱出に成功 → ランキングへ参加 → 順位の画面 | 自分の記録が出る。機内モードで成功 → 「送信待ち 1件」→ 通信を戻すと送信され、1行だけ |
| ランキング: サポート | CPU サポートありで成功 | MILE・解放・BEST は増えるが、順位の画面に「送信待ち」が出ず、表にも載らない |
| ランキング: 古い版からの更新(サポートの記録が送信待ちに残っていた端末) | 更新して起動 → 順位の画面 | サポートの送信待ちが消え、ソロの送信待ちは残る |
| 広告(テスト広告、テスト端末) | 脱出成功 → MILE 2倍 → 最後まで見る | 「Test Ad」と出る。MILE が表示の額だけ1回増える |
| 広告: 途中で閉じる | MILE 2倍 → すぐ閉じる | 「最後まで見なかったため…」。MILE は増えない |
| 広告: 中断・復帰 | 広告の途中でホームボタン → 戻る | 報酬は「最後まで見た時だけ」1回。二重に増えない、操作できなくならない |
| 広告: オフライン | 機内モードで MILE 2倍 | 「広告を準備中です…」等。MILE は増えない |
| 同意 | 初回起動(EEA でなければ何も出ない) | 必要な地域だけ同意の画面。設定に「プライバシーの設定」(必要な地域だけ) |
| 広告なしパス(GooglePlayTangle の後、ライセンステスター) | 設定 → 広告なしパス → 購入 → 再インストール → 購入を復元 | 購入後: ゲームオーバーの広告が出ない、MILE 2倍が広告なし、1日3回の無料ガチャ。復元で戻る |
| マルチ(本番) | オンラインで部屋を作る/入る、部屋で1人が抜けて戻る | 番号と色が変わらない。部屋で抜けた時は通知だけ(「接続が切れました」の画面にならない) |
