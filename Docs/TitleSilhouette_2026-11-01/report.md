# タイトル画面: 青空と影絵、選んだキャラの影(2026-11-01)

## 変えたこと
- **背景**: マスター提供の青と黒の横スクロール風の絵から黒剣士の影だけを消し、足もとの地面の線をつなぎました(`Tools/title/inpaint_bg.py`、`Resources/Title/title_bg.png` 1920x1080)。
  - 人物の周りの圧縮のにじみも消しました。空は左右の色をつなぎ、遠くの空のかすかなむらを足しています。
  - 草の小さな塊は残しています。
- **ロゴ**: ホームと同じ「ONE MORE MILE」のロゴ(`GameManager.titleLogo` = `TitleLogoV2.png`)を空の中央に重ねます。
  - 横は画面幅の 40%、縦は 86% です。
- **キャラの影**: キャラ選択で最後に決定したキャラ(既存の保存 `SelectedCharacterId`)を、次の起動のタイトルに出します。
  - 初回、保存値が無効、未解放の時は、ゲームと同じ判定で黒剣士です。
  - 影の絵: 出発演出(`<Kit>Start_v1`)から1人1コマを選び、透過を保った黒一色の絵にしました(`Tools/title/silhouettes.py` → `Resources/Title/Silhouettes/<id>.png`)。
    - 線画の透けと小さな穴はふさいであります。
    - 絵は「横の中心 = 足もと」に作ってあり、地面に合わせて立たせます。
  - 選んだコマ:
    - 黒剣士: 剣を前へ
    - 双剣士: 立ち姿
    - お嬢様: 剣を下げたマント
    - 拳銃士: 銃を前へ
    - 竜騎士: 槍先を斜め上へ
    - 弓使い: 弓を引く
    - 魔法使い: 杖
    - 格闘家: 拳の構え
    - 忍者: 曲刀を掲げる
    - 巫女: 札を掲げる
    - 吸血鬼: 手を伸ばす
    - 竜人: 翼を広げる
    - ルカ: 尾を巻き上げる
    - ペンタ: 立ち姿
  - 大きさは、人は添付の絵の黒剣士と同じ背丈(背景の高さの 16.5%)です。槍・杖・翼の分だけ絵が高い人は少し大きくしています。ルカは 10%、ペンタは 12% です。
  - ルカの巻き尾、竜騎士の槍先が、草や岩に埋もれないことを確かめました。
- **縦画面**: 背景を高さに合わせ、足もとが画面の左 30% に来るように横をずらします。キャラの全身とロゴが収まり、右に道が見えます。
- **開始の案内と流れ**: 今までどおりです。案内の文は、地面(黒)の上、足もとより下に移しました。
- ゲームの仕様・保存の形式は変えていません。

## 確認(試験用の保存ファイルだけ)
起動を6回続けました。初回(新しい保存)→ キャラ選択で竜騎士を決定 → 再起動 → ルカを決定 → 再起動。キャラ選択の「決定」と同じ処理で保存しています。

| 機種 | 結果 |
|---|---|
| Windows 開発確認版(横 1920x1080 / 縦長の窓 608x1080) | 6回とも期待どおりの影。全項目合格、例外 0。通常の起動確認(早押し・入力の持ち越し・1回だけ)も合格。本物のセーブは変化なし |
| Android エミュレーター APK 414(横 2400x1080 / 縦 1080x2400) | 6回とも期待どおりの影。例外 0、Unity のエラー 0 |

- Android の「入力からホームまで 0.2〜0.5 秒」の項目だけ、1.2〜1.5 秒で不合格でした。
  - タイトルが消える演出そのものは 0.35〜0.53 秒です。残りは、エミュレーターで次のコマが描かれるまでの遅れです。
  - Windows では合格しています。実機での確認をお願いします。
- 撮影の落とし穴:
  - Android の試験用の保存は、同じフォルダの控え(SaveBackups)から自動で復旧されます。初回を試す時は、フォルダごと消す必要がありました(セーブ消失を防ぐ仕組みが正しく働いた結果です)。
