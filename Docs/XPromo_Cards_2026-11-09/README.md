## 合成の成功率を誤解させないために
- 同名合成は画面の「【同名強化】成功率 100%」の行まで見せてから、字幕「同じカードで確実に強化！」。
- 異名合成は、画面の継承率の行(メイン 50% / 素材 25%)を見せ、字幕に「※異名合成は確率で能力を継承。失敗することもあります」を常に出す。
  - 成功例(合成大成功)のすぐ後に、**失敗の例(両方とも継承失敗 → カードは消費、MILE を還元)**も入れた。
- 撮影の都合: 異名合成の「合成大成功」と「失敗」は、2通りを撮り分けるために開発用の結果の固定(`CardFusionLogic.DebugForcedOutcome`)を使った。
  - 確率そのもの(50%/25%)、演出、結果の画面は製品と同じ。成功する確率は上げていない。

- すべて現行版のコードの Windows 撮影用ビルド(開発版の透かし無し)で、2026-11-09 に撮った映像。
  - 締めの戦闘と「能力の発動」の4カットだけは、前回の PV(2026-11-08、同じ版)で撮った戦闘。
  - 炎/雷/氷/風のカードのデッキで走った実際のランなので、雷の連鎖・落雷はカードの能力そのもの。

- セーブ: `-memSave`(その場だけの保存)だけで撮った。本物のセーブには触れていない。
  - 撮影用ビルドが本物のキーに書く窓の大きさの設定は、撮影のたびに元の値へ戻した。
- 撮影用の保存は「遊び込んだ人」の状態にした。
  - 3マップとも 52km 前後で帰還済み。解禁済みのカードをいろいろな Lv で所持。デッキのプリセット 2つ(1 炎と雷 / 2 風と氷)。
