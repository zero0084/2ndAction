# キャラ選択の幻想画(立ち絵+選択カード)の取り込み(2026-11-01)

マスターとエステルが作った幻想画(`OneMoreMile_Fantasy_Steam_Android.zip`)を、キャラ選択画面の中央の立ち絵(`<id>_main.png`)と下の選択カード(`<id>_card.png`)へ取り込みました。14人全員です。ゲーム中のキャラの大きさ・当たり判定は変えていません。

## 版による衣装の違い
| | Steam 向け Windows 版 | Android 版 |
|---|---|---|
| 女性7人(双剣士・お嬢様・魔法使い・拳銃士・忍者・巫女・竜人) | 元の衣装 | 布を増やした衣装 |
| ほかの7人(黒剣士・竜騎士・弓使い・格闘家・吸血鬼・ルカ・ペンタトゥットゥルー星人) | 共通 | 共通 |

- 切り替えは絵の取り込みの時に行います(`Assets/Editor/CharacterCostumeImporter.cs`、ZIP の処理を採用)。
  - Android の時だけ、`Assets/Editor/AndroidCharacterArt/<id>_<main|card>.png.bytes` を同じ絵へ書き込みます。
  - 絵の GUID は1つのままです。キャラのデータ・並びのカード・シーンの参照は、版ごとに書き換えません。立ち絵とカードは必ずセットで切り替わります。
  - Editor フォルダの `.bytes` はビルドに入りません。
- 中央の立ち絵は、紙の地まで描いた 2:3 の1枚の絵です。全体(武器の先・描き込んだ効果まで)を、縦横比を保って表示領域に収めます(`CharacterSelectUI.Visual.cs`、ZIP の版)。

## ZIP から変えた所
1. **カードの大きさを4の倍数にそろえました。** 透明な余白を最大3px 足しています。Steam と Android で同じ大きさにしてあります(Android の4枚は元が 1px 低かった)。
   - 4の倍数でないと、Windows では無圧縮(1画素 3〜4バイト)のままビルドに入るためです(SizeGuard の決まり)。
   - 今は Windows が BC7、Android が ASTC 4x4 です。
2. **カード14枚の取り込み設定で、2のべき乗への引き伸ばし(nPOTScale)をやめました。**
   - 以前の設定のままだと、カードが 1024x2048 に引き伸ばされていました。拳銃士のカード(796x1984)は約25%横に太って見えるところでした。
3. **並びのカードの表示を直しました**(`CharacterSelectUI.cs` の FitGlows)。
   - シーンに焼き込んだカードの表示範囲が古い絵の大きさのままで、新しいカードの左下の一部だけが拡大されて出ていました。
   - 原因は、差し替えを「絵が別物の時」しかしていなかったことです。同じ絵で大きさが変わった時も作り直すようにしました。
   - 試験(`-qaCharSelect`)でも、カードの絵の全体が出ていることを確かめるようにしました。

## 確認
### 取り込み後の絵(28枚)
同じ作業環境で **Windows → Android → Windows** と切り替えました。`CharacterCostumeCheck.Dump` で取り込み後の絵を書き出し、`Tools/charart/costume_check.py` で元の絵と比べています。比べるのは、2つの衣装で違う画素だけです。

| 段階 | 結果 |
|---|---|
| Windows(1回目) | 28/28 元の衣装または共通。女性7人は元の衣装との差 0.3〜0.7、Android の衣装との差 80〜120 |
| Android | 28/28 布を増やした衣装または共通。Android の衣装との差 0.2〜0.4 |
| Windows(2回目) | 28/28 元の衣装または共通。前の衣装は残っていません(Unity が機種ごとの取り込み結果を使い分けるため、切り替えは約3分) |

### 実際の画面
`-qaCharSelect` で14人を順に選んで撮影しました。撮影から立ち絵と選んだカードの範囲を切り出し、どちらの衣装かを判定しています。

| 機種 | 画面 | 結果 |
|---|---|---|
| Windows 開発確認版 | 1920x1080 / 1280x720 | 全項目合格・例外 0。28/28 元の衣装または共通。本物のセーブは変化なし |
| Android エミュレーター(APK 411) | 横 2400x1080 / 縦 1080x2400 | 全項目合格・例外 0・Unity のエラー 0。28/28 布を増やした衣装または共通 |

- 14人とも、顔・武器・カード名・役割札が見えています。一覧の画像は次のとおりです。
  - `charsel_windows_1920x1080.jpg`
  - `charsel_android_landscape_2400x1080.jpg`
  - `charsel_android_portrait_1080x2400.jpg`
- 比較(双剣士、左 = Windows / 右 = Android): `compare_dual_blade_steam_vs_android.jpg`

## 容量
- APK は 445MB → 473MB(+28MB)です。絵が 700x1100 → 1024x1536 になり、カードも約2倍の大きさになったためです。
- Windows はどちらも BC7 で圧縮しています。

## 追加: 立ち絵の紙の縁を黒い背景へなじませる(同日、APK 414)
- 黒い背景に、立ち絵の紙色が四角く浮いて見えていました。元の絵はそのままで、表示だけで外周を透かします(`Resources/Shaders/UIPaperFade.shader`)。
- 外周:
  - 四辺から、絵の高さの 9% の幅で、水彩が薄れるように不揃いに透明へ変わります。
  - 角は丸くなじみます。
  - 人物の後ろの紙はそのままです。
- 保護:
  - 紙の色から離れた所(線・色・武器・布)と、紙より白い所(ペンタトゥットゥルー星人の体)は透かしません。
  - その周りにも淡い紙を残します。黒い剣先なども黒い背景に溶けず、紙に描かれたまま見えます。
- 確認した所: 黒剣士の剣先、竜騎士の槍先、吸血鬼のマントの端、ペンタの輪郭と手の先。
- 変更前後:
  - `paperfade_before_after.jpg`(Android 横/縦、黒剣士・ペンタ)
  - `paperfade_windows_before_after.jpg`(Windows 横)
- 試験 `-qaCharSelect`: 全員にこの描き方が付いていることを確認しました。`-csPaperFade 0` で変更前の見た目を撮れます。Windows・Android の縦/横とも合格です。
