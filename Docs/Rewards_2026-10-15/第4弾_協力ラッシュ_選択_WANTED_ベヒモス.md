## 1. 協力マルチの各マップのボスラッシュ
`Scripts/BossManager.MapRush.cs` / `BossManager.LastDungeon.cs`。

### 決まり
- **対象**: 協力マルチを追加しました(ソロ・CPU サポートは第3弾のまま)。**対戦は変えていません**(今までどおりの関門)。
- **HOST が全部を決めます**: 出現 / 撃破 / 待ち列 / ラッシュの完了。
  - JOIN の端末はボスの処理をしません(今までの関門と同じ)。
  - ボスは HOST が出し、JOIN には同じボスの写し(パペット)が届きます。全員が同じボスと戦います。
  - 節目(90〜98km)は先頭の人の距離で決めます(今までの関門と同じ)。
- **二重の出現・二重の報酬が起きない理由**:
  - ボスを出すのは HOST だけで、1体ずつ番号を付けて送ります。JOIN は届いた番号の写しを作るだけです。
  - 先頭の人が入れ替わっても、予約は HOST の待ち列に1回だけ入ります(HOST が「次の節目の番号」を1つずつ進めるので、同じ節目を2回は予約しない)。
  - 撃破は HOST が1回だけ確定します(撃破済みの印)。知らせが遅れて2回届いても、受け取った番号の記録で1回にします。
  - ラッシュ全体のボスの報酬(1回)は、最後のボスに止めを刺した人へ(今までの関門と同じ決まり)。
- **99km の足止め**:
  - HOST が 99km の近く(-0.5〜+30m)に居る時だけ、HOST の距離を 99,000m へ合わせます。
  - HOST が後ろに居る時に HOST の距離を動かすと、全員の距離の基準がずれるので動かしません(ボス戦の間の距離の除外は今までどおり)。
- **雑魚**: ラッシュの間は出しません(ソロも同じ。出してすぐ消える繰り返しをやめた)。
- **疾走出発の 90km の解放**: ソロの通常ランだけです(今までの関門と同じ)。
- **HOST が DOWN の時**: HOST の未処理の選択では次のボスを待ちません(DOWN の間は選択を開けないため)。

## 3. 協力の WANTED
- **Lv**: 参加者の WANTED のカードのうち、**一番高い有効 Lv** を使います。
  - HOST が持っていなくても、JOIN が持っていれば出ます。
  - 人数分の Lv や効果は足しません。
  - 各人の WANTED の Lv は、各自の端末から HOST へ知らせます(通信の版 6 → 7)。
- **出た時に決まる**: 強さ(HP)と賞金は、その賞金首が出た時の Lv で決まります。後でカードが変わっても、出ている敵の値は変えません。
- **全員で一致**:
  - HOST が賞金首を出すと、「賞金首であること」と賞金を JOIN へ送ります。JOIN の画面でも同じ見た目(赤み・大きさ)になります。
  - 撃破は HOST が確定し、撃破の知らせの賞金を全員が人数で分配します(第3弾のまま)。
- **対戦 / ソロ**: 今までどおり自分(HOST)のカードだけです。

## 6. ラスダンのボスラッシュへの当てはめ方(案、未実装)
ラスダンのラッシュ(90〜98km)は、最大3体が同時に出て、タグの規則があります。各マップのラッシュの方法をそのまま使わない理由と、使う場合の案です。

- **そのまま使わない理由**
  - 各マップのラッシュは「次のボスがまだ出ていない間」に選択を出します。ラスダンでは、前のボスが生きている間に次のボスが出ることが多いです。そのため、選べる間がほとんど来ません。
  - 「選択が終わるまで次を出さない」を入れると、ラスダンの待ち列に予約が溜まります。空きができた時に一度に出る数が増えて、難しさが変わります。
- **案**
  1. 生きているボスが 0体になり、予告もしていない「自然にできた間」にだけ、未処理の選択を順に出します。ボスを出すのを待たせるのは、その間に選択中の時だけです(今のラスダンの間隔 2秒の中に収まる範囲)。
  2. 99km の足止め(残りを全部倒した後、三姉妹の前)では、残っている選択を全部出します。
  3. 選択を閉じた時の指の扱い(離すまで無視)は、各マップのラッシュと同じにします。
  4. ラッシュ全体のボスの報酬は1回のまま。協力マルチは「選択中の人だけ止まる・最長 15秒待つ」も各マップと同じにします。
- **確かめること**: ラスダンのラッシュで「自然にできた間」が何回あるか(育成の構成ごと)。少なければ、今と同じく最後にまとめて出ます。
