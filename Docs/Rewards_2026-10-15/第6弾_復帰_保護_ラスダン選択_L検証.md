# 報酬の見直し 第6弾(2026-10-16)— 協力の選択後の復帰 / 選択中と終了直後の保護 / ラスダンのカード選択 / 天空ボス L の検証

## 1. 協力: カード選択で大きく離れた人の復帰
`Scripts/Net/NetMatch.Rejoin.cs`(判断と安全な足場)、`PlayerController.NetRejoinTo`(置き直し)。

### 決まり
- **いつ**: カード選択を閉じた時だけです(協力マルチ)。
  - 選択中はその場で止まる(今までどおり)ので、選んでいる間に仲間との間合いが広がります。
- **復帰の対象にする距離の基準**:
  - **選択の間に広がった間合いが 120m 以上**の時だけ戻します。
  - 基準の仲間 = 前方の、生きていて選択中でない一番近い人です。
  - 普通の2〜3秒の選択は 30〜110m 程度なので、戻しません(試験では 2秒の選択で 52〜59m)。
  - 選ぶ前からの遅れ(被弾/普通の遅れ)は数えません。広がった分だけを見ます。
- **置き直す位置**:
  - 基準の仲間の「選ぶ前の間合い」だけ後ろです(最低 8m 後ろ)。
  - そこから後ろへ 1m ずつ、安全な足場を探します。選んでいた位置の 20m 先より後ろには戻しません。
  - 安全の条件:
    - 足元と前後(−1.5〜+5m)に地面が続いていて平ら(穴・段差・壁が無い)
    - 天井が低くない(洞窟、3.2m 以上の空き)
    - 障害物・地形の危険・敵・ボスの攻撃の判定・弾が無い(体の周り 4m × 2.6m)
    - ボスの体から 5m 以上離れている
    - 予告中の危険の上ではない
  - 見つからなければ戻しません(記録に残します)。
- **全端末で一致**:
  - HOST が自分の世界で位置を決めます(地形は全端末で同じ作り、敵/攻撃は HOST が正)。
  - 決めた位置を、論理の位置で本人へ送ります。本人の端末も同じ確認をして、危なければ後ろへ探し直します(HOST の決めた位置より前には置きません)。
  - 置いた後の位置は、いつもの位置の同期で全員に届きます。
- **DOWN の人**: 戻しません(選択の終わりだけで復活/移動させない)。ランの終わりも戻しません。
- **報酬と進行**:
  - 飛ばした距離は**距離の除外**へ足します。距離の MILE・EXP・累計距離・記録の控えは新たに付きません。
  - ボス戦で距離を止めている間は、その戦いの終わりの除外に含まれるので、二重に除外しません。
  - 関門・ボスの出現・死神は、先頭の人の距離(WorldProgress)で決まります。置き直しは先頭より後ろなので、二重には起きません。
- **保護**:
  - 置き直す間は、選択中と同じ扱いです(止まる・操作を拾わない・被弾しない)。
  - 置き終わって操作できるようになった時から、閉じた直後の保護(1秒)を数えます。

## 2. 選択中と終了直後の保護
- **終了直後の保護**: 1秒です。
  - **協力だけ**にしました。第5弾で対戦にも効いていた分を外しています。
  - 対戦は、今までどおり**選択中の保護だけ**です(選択中は狙われず、被弾の申告は取り消し)。
- **位置を戻した時**: 置き終わって操作できるようになった時から1秒を数えます(HOST にも知らせて、HOST の判定も同じ時から数える)。
- **選択中の落下**:
  - 選択中は、その場で止まります(重力も止まる)。選択中に落ちて倒れることはありません。
  - 閉じた時に足元が穴の中だった場合(空中で選択が開いた / 操作できない間に足場が無くなった)は、近くの安全な足場へ置き直します(協力)。
    - 前(穴の向こう側)を先に探します。手前に置くと、助走が無いまま同じ穴へ落ちることを確かめたためです。
    - ジャンプの途中で開いた選択は、跳んでいた勢いのまま進むので、すぐ前(6m)に足元より低い地面があれば何もしません(跳び越えられる)。
- **選ぶ前の DOWN / 死亡は取り消しません**(生きている時だけ働きます)。
- **選択を閉じた時の指**を次の攻撃や選択に使わない処理は、そのままです。協力の置き直しの後も同じです。

## 3. ラスダンのカード選択(自然にできた合間)
- **決まり**(第5弾の 7章の案を採用、`BossManager.MapRush.cs` / `BossManager.LastDungeon.cs`):
  - 生きているボスが 0体で、次のボスの予告も始まっていない時に、未処理のレベルアップの選択を出します。
  - ソロ / CPU サポートでは、選択中は世界ごと止まります。2秒で打ち切りません。
  - 選択を閉じた後は、次のボスの予告の前に、出現の間隔(2秒)を取り直します。待ち列のボスをまとめて出しません。
  - 合間ができなかった分は、ラッシュを全部倒した後、三姉妹戦に入る前に残りを全部処理します。
    - 100km に着いても、選択が残っている間は三姉妹戦を始めません(念のため最長 10秒)。
  - ラッシュ全体のボスの報酬は1回のままです。
  - 協力: このラッシュを使える範囲では、各マップと同じ仕組みです(選択中の人だけ止まる、最長15秒待つ、個人の選択)。
    - 三姉妹戦/エンディングのマルチ対応は、今回はしていません。
- 開発版は `-ldRushChoices 0` で以前の「最後にまとめて」に戻せます(比べるため)。

## 4. 天空ボス L の検証方法
検証を分けました(`QaSweep.SkyBoss.cs`)。

- **決まった条件**: 補助を切る・入力なし(走りの速さのまま)・攻撃で崩しを溜めない・被弾ののけぞり/押し戻しを起こさない(テストの時だけ)。
  - そのため、ボスとプレイヤーの位置関係は毎回同じです。
  - 最初の作りでは、足元を狙う落雷が当たってプレイヤーが下がり、後の落雷が最大 4.8m ずれて見えました。のけぞりを起こさない条件を足してからは、毎回 0.00m です。
- **L1(最後の段まで出る)**: ボスの側の段の記録で、落雷5本 → 前の波 → 後ろの波 → 空中の帯 → 突進 → 終わり が全部出たかを確かめます。
- **L1(狙った位置に判定が出る)**: 落雷ごとに、狙った位置(プレイヤーからのずれ)と、判定が出た瞬間の実際のずれを記録します(`SkyStrike.Placements`)。全部の差が 0.35m 未満かを確かめます。
- **L2(BREAK で正しく中断される)**: 落雷の段の途中で崩しを起こします。次の3つを確かめます。
  - 0.6秒以内に必殺技が止まる(必殺技中の印も消える)
  - 崩れた状態になる
  - その後に新しい段や落雷が出ない
- **L3(参考値)**: 補助ありで自由に動くプレイヤーへの命中の回数です。記録だけで、合否にはしません。

## 5. 確認の結果
### 協力の復帰(2プロセス、荒野街道のラッシュ)
| 場合 | 結果 |
|---|---|
| JOIN がボスの出番の直前から30秒選ぶ | 間合い 5m → 648m(選択中に +643m)→ **仲間の16m後ろへ置き直し**(632m)。JOIN の距離の除外 +630m(距離の MILE/EXP は増えない)。HOST の確認(戻し終わった時から保護) |
| HOST が30秒選ぶ | 間合い −10m → 479m → **仲間の8m後ろへ**(471m)。HOST の距離の除外 +471m |
| 普通の2秒ほどの選択(ラッシュの間に 30回以上) | 広がりは最大 54m(120m 未満)→ **一度も戻していない** |
| 選択が開いた時に穴の中へ置く(選択3秒、120m 未満で戻さない場合) | 閉じた時に**穴の向こう側 4m の安全な足場へ**置き直し。落下なし |
| ↑ 直す前(手前を先に探していた時) | 手前 6m に置いた後、助走が無いまま同じ穴へ落ちた(落下のダメージ 2回)→ 前を先に探すように直した |

- ラッシュの9体・ボスの MILE・完走報酬(各1回)は、置き直しのある回も無い回も同じでした(関門/出現の二重は無し)。
- 置き直しで安全な足場が見つからなかった回はありませんでした(見つからなければ戻さずに記録します)。

### 選択中と終了直後の保護
- **協力**: 選択中の被弾の申告 → 取り消し(選択中)。閉じて 0.3秒後の申告 → 取り消し(閉じた直後)。
- **対戦**: 選択中の被弾の申告 → 取り消し(今までどおり)。閉じて 0.3秒後 → **取り消さない**(閉じた直後の保護は協力だけ)。
- 選択を閉じた後の指: 今までどおり、次の攻撃/選択に使われていません(協力の置き直しの後も同じ処理)。

### 天空ボス L(決まった条件、単独で2回 + 全体の中で1回)
- **L1 段**: 毎回、落雷5本 → 前の波 → 後ろの波 → 空中の帯 → 突進 → 終わり が全部出ました。
- **L1 位置**: 落雷5本(+3.6 / −3.6 / +0.2 / +6.8 / −6.8m)は、狙った位置に**誤差 0.00m**で判定が出ました(単独の2回)。
  - 全体の試験の中では、補助を切ったプレイヤーが段差で止まり、プレイヤーの方が走りから最大 15.7m ずれました(落雷は走りの速さで流れるので、正しい動き)。
  - プレイヤー自身の走りからのずれを差し引いて比べるようにしました(地形に左右されない)。
  - 回し直した全体の試験では、プレイヤーのずれは最大 12.0m でした。差し引いた後の誤差は 5本とも **0.00m** です。
- **L2 BREAK**: 落雷の段(開始から 1.6〜1.9秒)で崩すと、**0.00秒**で必殺技が止まりました。崩れた状態になり、その後に新しい段・落雷は 0 でした。
- **L3 参考値**: 自由に動くプレイヤーへの命中は 4〜5回でした。

### 回帰
- **失敗 0件**:
  - ボス / パーティ(CPU サポート) / パーティの再開 / パーティの疾走 / ULTIMATE / 疾走出発 / ビヨンド / 翻訳 / 闘技場 / 解放 / メカドラゴン / カード v3(T・X・R)/ ソロのラッシュ / 協力のラッシュ
  - 保存・ランキング・引き継ぎ(10項目)
  - 通常の保存(レジストリ)は変わっていません。
- **回し直したもの**:
  - 天空ボスの全体: 失敗 0件。
  - 重なりの確認: 失敗 0件。1回目の失敗は、閉じた直後に本物のレベルアップが開いた時の揺れでした。
  - 洞窟ボス: ムカデの必殺技の確認(D/E/F)が、5回のうち2回失敗しました。
    - 原因: 試験が必殺技を強制した時に、プレイヤーの攻撃でムカデが崩れていました(崩れている間は技を出さない)。そのため、決めた時間の中で必殺技が始まりませんでした。
    - 崩れた回数は、変更前の版と同じくらいです(ムカデ 3〜4回)。強制した時刻と崩れた時刻が重なるかどうかの揺れで、ゲームの動きとしては正しいです。
    - 試験を直しました。崩れていたら解けるのを待ち、確かめる間は攻撃で崩しを溜めません(天空の J/L と同じ)。
    - **崩しを止めて最後まで見たら、本当の不具合が見つかりました(前からあった)**:
      - ムカデの必殺技(天井を這う CAVE CRAWLER)は、途中で天井が途切れる所へ来ると落ちて、必殺技をやめます(APK 273 からの安全の処理)。
      - その時は 0.5秒の構え直しだけで、必殺技の最後の隙(ひっくり返る = 攻撃のチャンス)が出ていませんでした。崩しで止めた時は崩れた隙が出るのに、地形で止まった時だけ何もありませんでした。
      - 変更前の版で試験が通っていたのは、必殺技が始まって 0.2秒で崩しにより切れて、「崩しで止まった」の扱いになっていたためです。最後までは確かめられていませんでした。
      - **直したこと**: 必殺技の途中で天井から落ちた時は、必殺技の最後と同じ大きな隙を出します(ムカデ。文言は既にある「ひっくり返った! 大チャンス!」をそのまま使うので、新しい訳は要りません)。ほかのボスは今までどおりです。
      - 試験も、地形で必殺技が切れた時は崩しの時と同じ扱いにしました(判断の回数は求めず、隙が出ることを確かめる)。
    - 直した後: 洞窟ボス 2回とも失敗 0件。ソロのラッシュ(洞窟を含む)と闘技場も失敗 0件。
    - 天井の確かめは、張り付く位置の前 12m ほどだけを見る作りです(技の全区間を求めると、低い天井が混ざる洞窟ではほとんど選べないため)。そのため、試験の区間では、ムカデの必殺技は途中で切れることが多いです(2回とも切れた)。切れた時も隙は出るようになりました。
