  2. 後回しにしたレベルアップの選択

  - 念のため、死神の出現の条件に「ラッシュが残っていない」を足しました。
- **強さ**: そのボスの節目の距離での再戦の強さ(距離の HP の倍率 × 最終強化再戦 ×1.3、被弾 ×2)× ラッシュの倍率 0.6。

  - 各ボスの MILE: 種類と強さ。
  - EXP: 大(80%)。
  - ラッシュを終えると、90km の門番を倒した扱いです(疾走出発の 90km の解放)。
- **中断と再開**: 再開は直前のチェックポイント(ラッシュの前の最後のボスの報酬)からです。ラッシュは最初からやり直しで、予約も作り直します。
- **見出し**: ラスダンと同じ「BOSS RUSH 走りながら戦え!」などの既存の文を使っています(新しい文は無い)。

## 2. 魔法使いの DPS が 0 になる件(テストの測定の不具合、修正)
- **原因**: プレイヤーが荒野の上のルート(上下の分かれ道)に立った後、テストのダミーの敵が下のルートの地面に出ていました。
  - 高さを返す関数が、下の地面を返すためです。
  - 水平に飛ぶ魔法は下のルートには届かないので、当たっていませんでした(実際のゲームでも上下のルートは別の道)。
  - 0 になったのは、7番目の構成(fire9)以降でプレイヤーが上のルートへ移ってからです。
- **修正(テスト側)**: ダミーをプレイヤーの足元の高さに置きます。
  - 当たった回数(敵の HP が減ったフレーム)と、高さの差も記録します。
- **修正の後**: 魔法使いは 10構成すべてで命中し、HP が減りました。
  - 例: none 100/s・50回、lightning9 339/s・68回、wind9 317/s・76回。
- fire9(89/s)と speed9(75/s)は、カード無し(100/s)より低く出ました。
  - 命中の回数が少なく(23回 / 43回)、ダミーとの高さの差が 2.1m と大きい計測でした。
  - 構成の強さの比較には、ここの値だけでは足りません(追加で確かめる項目)。

## 3. ATTACK UP のテストの期待値(仕様と計算式から更新)
- 確定の仕様: 2026-10-11 採用(BalanceTuning.AttackUpHighLevel)、カードの説明「Lv3までは1Lvごとに+5%、高いLvほど伸びが大きくLv9で+80%」。
- 計算式:
  1. カードの値 5%/Lv × Lv の係数(Lv9 = 16)= 80%
  2. 無条件の攻撃の曲線(0.8 まではそのまま)→ 80%
  3. 結果: ×1.80
- テストは、この式から期待値を出します(測った値に合わせていません)。
  - 式の結果がカードの説明の +80% と一致することも確かめます。

## 4. 黒剣士とタイタン(原因を特定して修正)
| 場面 | 構成 | 60秒(または 40秒)のダメージ / 命中 | 身をかがめた回数 |
|---|---|---|---|
| 天空の関門(3km) | カード無し・補助 | 36/s・97回 | 4 |
| 〃 | カード無し・手動のジャンプ攻撃(上 → 空中で前) | 6/s・17回 | 4 |
| 〃 | カード無し・手動の上攻撃だけ | 2/s・7回 | 4 |
| 〃 | 育成済み(mix Lv5)・補助 | 101/s・141回 | 4 |
| 天空 85km / ラスダン 31km(ラッシュの外) | カード無し・補助 | 30/s / 43/s | 2 |
| **ラスダンのラッシュの中(走りながら / 99km の足止め)** | カード無し・補助 | **0 / 0回**(攻撃は 136回出していた) | **0** |

- **原因**:
  - ラッシュのボスは再戦の最終強化(特殊攻撃 4秒 / 必殺技 9秒ごと)になります。
  - タイタンの行動の順は「必殺技 → 特殊攻撃 → 身をかがめる」でした。毎回、必殺技か特殊攻撃が先に来て、**身をかがめる番(近接が届く隙)が一度も来ませんでした**。
  - その間タイタンは回廊から 1.7m 以上離れたままで、黒剣士の攻撃は届きませんでした。
  - 届かなかった理由は当たり判定やオートの狙い方ではなく、ボスの行動の順番です。手動のジャンプ攻撃 / 上攻撃でも、身をかがめない限り届きません。
- **修正**: 必殺技 / 特殊攻撃も「攻撃の回数」に数え、身をかがめる番を先にしました(2回の行動ごとに必ず身をかがめる)。HP と攻撃力は変えていません。
- **修正の後**(ラスダンのラッシュの中、40秒): 走りながら 25回、99km の足止めで 25回命中しました(身をかがめる 2〜3回)。
- 今回の各マップのラッシュ(天空の 91km のタイタン)にも同じく効きます。

## 6. チェックポイントからの再開の説明
- **ホームの「続きから」**: 「{0}m から再開」はチェックポイントの距離です(以前から正しい)。
- **一時停止の「RETURN TO HOME」の確認**:
  - 以前は「ランは終了せず、この続きから CONTINUE できます」(英語 "CONTINUE from here.")で、中断した地点から再開すると読めました。
  - 新しい文:
    - ホームへ戻ります。
    - ランは終了せず、直前のチェックポイント({0}m)からCONTINUEできます。
    - それより後に獲得したMILE・EXP・カードは取り消されます。
  - 新しい文はエステルのレビュー待ちです(ID 10010 / 10011、`Docs/LocReview_2026-10-15c`)。
    - 日本語以外は前の文のままで、反映待ちとして管理しています。製品版のビルドは止まります。
- **記録の控えの二重の加算(修正)**:
  - 第2弾でラン中の状態をチェックポイントへ戻すようにした時、「最も遠くまで走った距離」も戻っていました。
  - そのため、走り直しの区間が「実際に走った距離」(累計距離の元)へ二重に足されていました。
  - 今は記録の控えの「到達した一番遠い所」も見て、それを越えた分だけ足します。
  - 確認: 1,000〜2,000m を走り直しても、増えたのは 2,000m を越えた 13m / 19m だけでした。
- **時間**: 記録の控えの時間は、そのランで実際に遊んだ時間です(ランキングの記録の不正の検査だけに使う)。
  - 走り直しの時間も実際に遊んだ時間として数えます。
  - 累計の時間の記録はありません。

### 以前の修正(2026-10-07)との差
- **時間でのラン再開は廃止のまま**です。
  - 関門の開始(`BeginEncounterClock`)で、再開の許可(encounterResumable)を必ず false にしています。
  - 時間の判定(`TickResume`)は経過の記録だけで、再開を起こしません。
  - 再開までの表示も出ません。
- **ラン再開(`ResumeRun`)の呼び出し元**:
  - **開発用の DEBUG の画面の「ラン再開」ボタンとテストだけ**です(`DebugForceResume`)。
  - 製品版のビルドには含まれません(`#if UNITY_EDITOR || DEVELOPMENT_BUILD` の中)。
  - 時間の判定は、再開の許可が立たないので、呼んでも何もしません。
- **「未撃破のボスが追従したまま次の関門へ」の経路**:
  - 次の関門の決め方(`ChooseNextGate`)には「ボスが生きている間に通った関門を保留する」処理が残っています。
  - ただし、通常の関門では距離が止まっているので、通る関門がありません。
  - 動くのは、開発用のラン再開を押した時だけです。
- **今回の各マップのラッシュ**:
  - 終わると次の関門は 101km で、99km / 100km の関門は出ません。
  - 99km の足止めで倒しきるので、ラッシュのボスが残ったまま先へ進むことはありません。
- **テストでの確認**(-qaBoss、今日の最終のビルドで 0件):
  - 荒野の関門で、以前の時間の上限を過ぎても戦闘が続き、ラン再開は 0回です。
  - 5km の関門で、上限を過ぎても距離は止まったままです。
  - 倒すまで次の関門は始まりません。
- **マルチ**: 置き去り防止(BossLeash)は、走っている人からボスが離れすぎないようにボスの動きを遅らせる仕組みです。ラン再開ではありません。

### 「101km 以降、通常のボス戦の間も死神が追ってくる」について(通常のボスの追従とは別の話)
- 通常のボスは、101km 以降も関門で距離を止め、倒すまで次へ進みません(上の決まりのまま)。
- 重なるのは **100km の死神の追跡**です。
  - 死神はボスではない特別なイベントで、100km で一度出た後は、ランが終わるまで後ろから追い続けます(倒せない)。
  - 死神の動きは、ボス戦の最中かどうかを見ていません。
  - そのため、101km 以降の関門で距離が止まっている間も、死神はプレイヤーへ近づき続けます。
- 通常のボスが次の関門まで付いてくるのではなく、別のイベント(死神)が関門の戦闘と同時に進んでいる、という状態です。
- 今回は変えていません(マスターのご指示どおり別の調整の項目)。
  - 案: ボス戦の間は死神の接近を止める / 距離を保つ。
