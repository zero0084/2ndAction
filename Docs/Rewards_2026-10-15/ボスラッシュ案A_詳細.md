# 終点の無い3マップのボスラッシュ 案A(90〜98km)の詳細 — 2026-10-15 第2弾

**状態: 案のみ(未実装)。** 開始距離と進行方式が決まってから実装します。

## 今のコードの確認(要点)
- **普通のマップの 90〜99km**
  - 1km ごとに関門があります。
    - 90km: 10km の大ボス(黒騎士 / 古代の魔王 / ガーディアン)
    - 95km: 中ボス
    - そのほか: 小ボス。撃破済みなら再戦の1体
  - **100km には関門がありません**。100km は死神の追跡で、101km から関門が再開します。
- **死神の追跡**: 距離が 100,000m に届くと出ます(`BossManager.cs:554`)。
  - 倒せません。報酬もありません。捕まるとソロでは倒れます。
  - ボス戦中かどうかを見ていません。
- **距離の止め方**: ボス戦の足止め(HoldsRun)の間は、距離(MaxDistance / MaxDistanceExact)が進みません。
  - そのため、99km でボスが残っていれば、死神は出ません。
- **時間でのラン再開**: 2026-10-07 に撤去済みです。火力が低いと、倒すまでボス戦が続きます。
- **ラスダンの走りながらのラッシュ**: 9体です。
  - 同時に **最大3体**、タグの規則(大型2 / 空2 / 範囲攻撃1 …)があります。
  - 予告 1.2秒、出現の間隔は 2.0秒以上です。
  - 99km で残りがあれば足止めし、報酬の選択は全体で1回です。
  - ボスの HP は ×0.6(走りながらの方式)です。
- **荒野の 80km の竜** は別の仕組み(DragonController)で、ラッシュに入れない印が付いています。
  - 天空の 1km の竜 / 5km の魔人も同じです。
- **メカドラゴン**: 普通の天空の関門には出ません(ラスダンだけ)。

### 進め方(走りながら1体ずつ)
1. 90km でラッシュの見出しを出し、1体目が出ます。距離は進み続けます(走りながら戦う)。
2. 1km ごとに次のボスを順番に予約します。前のボスが生きていれば、待ち列に並びます。
   - 同時には出ません。
   - 速く走って節目をまとめて越えても、越えた分を順番どおりに全部予約します(ラスダンの仕組み)。飛ばされる事はありません。
3. 99km で、まだ残り(戦っている / 待っている)があれば、**99,000m で足止め**します。
   - 残りを1体ずつ倒すまで進みません。走り抜けられません。
4. 最後(98km の大ボス)を倒すと、報酬の選択 → 足止めの解除 → 100km で死神の追跡(今の流れ)。
5. 中断と再開: ラッシュの途中で中断すると、チェックポイント(ラッシュの前の最後のボスの報酬)から走り直しです。
   - 今回の修正で、報酬は二重になりません。

### 火力が低くて倒しきれない時
- 時間でのスキップはありません(今の決まり)。99km で残りを倒すまで足止めします。
- そのため、火力が低い構成ほど「99km で連戦」の形になります。
- 下の実測(ラスダンのラッシュ、カード無し)で時間を見て、HP の倍率を決めるのが良いと考えます。

### ラッシュと死神が重ならないための処理
- 99km の足止めの間は距離が止まるので、100km の死神は出ません(今の仕組み)。
- 念のため、死神の出現の条件に「ラッシュが終わっている」を足します。
- ラッシュの間は、ふだんの 90〜99km の関門を出しません(ラスダンと同じく、ラッシュが関門の代わり)。

### 今もある別の重なり(参考・未対応)
- 101km から先は、普通の関門のボス戦の間も死神が追いかけてきます。死神はボス戦中かどうかを見ていません。
- ボス戦の間に捕まることがあります。
- 案A とは別の話なので、直すかどうか(ボス戦の間は死神を止める等)をご判断ください。
