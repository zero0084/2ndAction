> **現行の仕様(第6弾の時点)のまとめ**
> - 雑魚の MILE: 出た時の距離の段の強さで増える(序盤は据え置き)。
> - ボスの MILE: 種類 × 1.5 × 強さ(1〜2.5)。
> - ボスの EXP: 関門の役割(1km 20% / 5km 35% / 10km・ラッシュ 80% / 特別 120%)× 今の Lv の必要量の全体。
> - MILE の分配: ソロ 1 / CPU 自分 + 仲間 / 協力 参加人数(対戦は割らない)。WANTED の賞金も協力では分配。
> - 端数: **全経路で1つ**に貯め、帰還の時に1回だけ整数にする(持ち帰り = 正確な合計の切り捨て)。
> - 中断・再開: **直前のチェックポイントの状態へすべて戻る**(距離 / EXP / Lv / MILE と端数 / カード / CPU / 撃破数 / HP)。記録の控えの走った距離は二重に足さない。
> - 疾走出発: 到着の距離に合わせたプレイヤーレベル(90km で Lv50)。
> - 各マップの終盤のボスラッシュ: 90〜98km に9体、1体ずつ、99km で残りがあれば足止め、100km で死神(第3弾で実装)。
>   【第4弾】協力マルチにも追加(HOST が管理)。レベルアップの選択はボスとボスの間に出す(ボスの報酬はラッシュ全体で1回)。
> - 【第4弾】協力の WANTED: 参加者の一番高い Lv(足さない)。強さと賞金は出た時に決まる。
>   【第5弾】分配の後に各自の MILE の補正を掛ける(現状を採用)。端数は共通の繰り越し。
> - 【第5弾】協力のラッシュの完走報酬は、参加者全員(DOWN 中も)が1回ずつ選ぶ。選択を閉じた直後 1秒は被弾しない(マルチ)。
> - 【第5弾】大ボスは特殊攻撃を続けて使う時、間に普通の技を1回はさむ。近接の補助は、届く距離のすぐ外のボスへ踏み込みで寄る。
> - 【第6弾】協力: カード選択の間に仲間との間合いが 120m 以上広がったら、閉じた時に仲間の後ろの安全な足場へ戻す(飛ばした距離に報酬なし)。閉じた直後 1秒の保護は協力だけ(戻した時は戻し終わってから)。
> - 【第6弾】ラスダンのラッシュも、生きているボスが 0体の合間にレベルアップを選ぶ。残りは三姉妹戦の前に全部。
> - 【第6弾】ムカデが必殺技の途中で天井を失って落ちた時も、大きな隙を出す。

マスターからの3件の依頼をまとめて対応しました。
- 距離に応じた報酬調整・ボス報酬の増加・各マップ終盤のボスラッシュ
- 参加人数に応じた獲得MILEの分配
- 疾走出発後のプレイヤーレベル調整

決まりは `Scripts/Rewards/RunRewards.cs` に、受け取り口は `Scripts/Rewards/GameManager.RunRewards.cs` にまとめています。

## 1. 雑魚の MILE(距離と強さ)
- 式: その敵が**出た時**の距離の段の HP の倍率で増やします。
  - 係数 = 1 + 0.5 ×(HP の倍率 − 1)
  - 序盤(倍率 1)は今までと同じです。
- 敵を一律に硬くはしていません。HP は今までどおりで、MILE だけを強さに合わせました。
- 精鋭(×3)や種類ごとの MILE(1〜3)は、この係数の上に今までどおり掛かります。
- 疾走出発で飛ばした区間の敵は出ないので、報酬もありません。

| 距離 | 雑魚の HP | 1体の MILE(基本1の敵) |
|---|---|---|
| 0km | ×1.0 | 1 → 1.00 |
| 10km | ×2.0 | 1 → 1.50 |
| 20km | ×3.0 | 1 → 2.00 |
| 50km | ×4.4 | 1 → 2.70 |
| 100km | ×7.0 | 1 → 4.00 |

- 端数は内部で貯めて、1 になったら足します。少ない報酬が毎回の切り捨てで消えることはありません。
  - 【第2弾】第1弾では端数を経路ごとに貯めていて、帰還で経路ごとに捨てていました(3人で 23、4人で 17)。今は全経路で1つにまとめています。

## 2. ボスの EXP と MILE
### MILE
- 式: 種類ごとの基本 × 1.5 × 強さの係数
  - 強さの係数 = 1 + 0.5 ×(HP の倍率 − 1)。**1〜2.5 に収めます**(距離と再戦の強化が重なっても極端にならない)。
- ボスごとの難しさは、種類の基本値にすでに入っています(オオカミ 30 〜 黒騎士 500、メカドラゴン 900)。

| ボス | 以前 | 今(初戦) | 強さ ×2(再戦/遠い距離) | 上限 |
|---|---|---|---|---|
| 荒野 オオカミ(1km) | 30 | 45 | 68 | 113 |
| 荒野 ゴブリンライダー(5km) | 60 | 90 | 135 | 225 |
| 荒野 サーペント(10km) | 90 | 135 | 203 | 338 |
| 荒野 黒騎士 | 500 | 750 | 1,125 | 1,875 |
| 洞窟 古代の魔王 | 520 | 780 | 1,170 | 1,950 |
| 天空 ガーディアン | 580 | 870 | 1,305 | 2,175 |
| 天空 メカドラゴン | 900 | **1,350** | 2,025 | 3,375 |
| ラスダン 死神三姉妹(1体) | 800 | 1,200 | — | — |

- 天空の 1km の竜(50)と 5km の魔人(100)は、以前は既定値のままでした。今は同じ式で、距離の強化も反映します。

### EXP
- 以前は、どのボスも 100 でした。
- 今は「次のレベルまでに要る EXP」に対する割合です。どのレベルでも同じくらいの手応えになります。下限は 100(序盤は下げない)。
  - 小(1km の関門): 20%
  - 中(5km の関門): 35%
  - 大(10km の関門・ボスラッシュ): 80%
  - 特別(メカドラゴン・死神): 120%
  - 第2弾: 格はボスの種類ではなく、関門の役割で決めます(1km の関門の再戦に大ボスが出ても 20%)。詳しくは `第2弾_確認と修正.md`

| 距離(距離だけでの Lv の目安) | 小 | 中 | 大 | 特別 |
|---|---|---|---|---|
| 1km(Lv5) | 100 | 136 | 312 | 468 |
| 10km(Lv17) | 222 | 388 | 888 | 1,332 |
| 30km(Lv30) | 378 | 662 | 1,512 | 2,268 |
| 50km(Lv39) | 486 | 850 | 1,944 | 2,916 |
| 90km(Lv53) | 654 | 1,144 | 2,616 | 3,924 |

### 連続撃破
- ソロでカードを選んでいる最中に入ったボスの EXP は、以前は捨てていました。今は預かって、選び終えてから入れます。
- レベルアップの選択は、ボス戦の後にまとめて1つずつ出ます(今までの後回しの仕組み)。
- 確認では、すべての関門で「選択の数 = 上がったレベル + ボスの報酬 1回」でした。消えた物も、二重になった物もありません。

## 4. 参加人数での MILE の分配
### 人数
- ソロ: 1
- CPU サポート: 自分 + 仲間(ランの始めの編成)
- 協力マルチ: 参加した人間(ランの始めの人数)
- 倒れている仲間や画面の外の仲間も数えます。
- 途中で抜けた人がいても、計算し直しません。人数はランの始めに決めて、中断データにも保存します。
  - 再開しても二重に割りません。

### 計算の順番
1. 基本(種類の MILE × 距離/強さの係数)
2. **÷ 人数**
3. × 自分の補正(MILE 系のカード / GREED / 宝の補正)
4. 端数は貯めて、1 になったら足す(【第2弾】種類ごとではなく、全経路で1つ。帰還の時に1回だけ整数にする)

結果の画面の広告の2倍は、この後です(今までどおり)。

### 対象にした MILE(すべての経路)
| 経路 | 分配 |
|---|---|
| 雑魚の撃破 | する |
| ボスの撃破 | する |
| 距離の MILE(持ち帰り予定の距離ぶん) | する |
| BONUS ZONE(宝・CLEAR/PERFECT/JACKPOT) | する(マルチでは BONUS ZONE は出ない) |
| WANTED の賞金 | ソロ/CPU はする。【第3弾】協力マルチも、賞金首と達成を共有し、誰が倒しても1回だけ人数で分配。対戦は今までどおり(HOST だけ、割らない) |
| 疾走のリングの代わりの 100 MILE | する |
| 所持 MILE(ガチャ・カードの変換・デバッグ) | 触らない |

### EXP
- 分けません。
- CPU の取り分はプレイヤーに足しません(割った分は誰にも入らない)。

### 協力マルチ
- 撃破のたびに、HOST が「報酬の基本(距離の係数・精鋭込み)と EXP の倍率」を全員へ送ります。
- 全員が、自分の分け前の MILE を受け取ります。
- EXP と撃破数は、ラストヒットの人だけです。
- 通信の形が変わったので、版を 4 → 5 にしました(【第3弾】WANTED の賞金を載せて 6)。古い版とは部屋の一覧で VERSION MISMATCH になり、接続しません。
- 以前の不具合も直りました。JOIN の端末が倒した精鋭の MILE と EXP が、×3 / ×2 にならず通常の値になっていました。

### 対戦マルチ(今の決まりと案)
- 今: 撃破の報酬はラストヒットの人だけで、分配はありません。ランは最後の1人で終わり(NetForceGameOver)、MILE は持ち帰りません。
- 今回は変えていません(人数で割らない)。
- 案: 「自分で倒した分だけ持ち帰る(分配なし)+ 順位のボーナス」。
  - 勝ち負けがあるモードなので、協力のように割るより自然だと考えます。
  - 持ち帰りを有効にするかは、マスターに決めていただきたい点です。

## 5. ボス戦の途中の中断で報酬が二重になる不具合(修正)
【第2弾】下の「ボス戦の間は中断データを書かない」方式は、第2弾の「中断の保存は記録の控えだけ、再開はチェックポイントの状態」に置き換えました(ボス戦以外の区間も含めて、走り直しで報酬が二重にならない)。下は第1弾の記録です。
### 原因
- ボスを倒すたびに、中断データへ報酬を書いていました。
- 一方、再開はチェックポイント(前のボスの報酬を選んだ所)から始まります。
- そのため、撃破〜報酬の選択の間、またはボスラッシュの途中で中断すると、同じボスをもう一度倒して報酬が二重になっていました。

### 修正
- ボス戦が始まった瞬間(誰も倒していない状態)を1回保存します。
- そのボス戦の報酬が決まる(SaveCheckpoint)まで、中断データを書き換えません。
- 台本のボス戦(三姉妹)は、その後の YES の所までです。

### 確認
- 2km のボスを倒して、報酬を選ぶ前にホームへ戻り、CONTINUE しました。
  - ボスの MILE と撃破数は、ボス戦の前の値でした。
  - 倒し直すと、1回分だけ入りました。

### 今までどおりの点(参考)— 【第2弾で修正済み】
- 第1弾の時点: CONTINUE はチェックポイントから走り直しになり、チェックポイントの後に倒した雑魚の MILE は持ったままでした(走り直しの区間でもう一度報酬が出た)。
- 第2弾で、再開はチェックポイントの状態へすべて戻すように直しました。

## 6. 疾走出発の到着レベル
- 到着の距離 × 0.87 を「EXP の相当」として、そこまでの累計で届く一番高い Lv から始めます。
- **レベルの上限ではありません**。到着後は普段どおり上がります。
- EXP は 0、次のレベルまでの量は普段の式(150 + 60 ×(Lv − 1))です。
- 値だけを入れるので、まとめてのレベルアップは起きません。
  - レベルアップのカードの選択も、CPU サポートの「レベルアップで仲間も1枚」も出ません。
  - 疾走の自動取得のカード / リングとは重なりません。
- プレイヤーレベルは、HP の回復以外に能力へ影響しません。攻撃・速さ・最大 HP は、カードとキャラの値です。
- 到着の SaveCheckpoint で1回だけ保存します。CONTINUE しても、二重に上がりません。
