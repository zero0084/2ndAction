# 報酬の見直し 第5弾(2026-10-16)— 剣士のにらみ合い / 協力ラッシュの完走報酬 / 選択と15秒待機 / 解放のお知らせ / WANTED の端数

## 1. WANTED の個人補正(現状を採用)と端数
- 決まり: 賞金を参加人数で分配 → 各自の MILE の補正を掛ける(第4弾のまま)。
- 端数は、ほかの MILE と同じ**1つの繰り越し**(`mileCarry`)に入ります(`AddRunBonusMile` → `TakeWhole`)。
  - 1回ごとの受け取り = 「繰り越し + 今回の正確な値」の整数部分。残りが次へ繰り越されます。
  - 持ち帰り = そのランの正確な合計の切り捨て(第2弾からの共通の決まり)。
- Lv5 の例(確認の結果は下の「6.」):
  - 35 × 2.75 = 96.25 → 繰り越しが 0 なら +96、繰り越しは 0.25 増える。
  - 繰り越しが 0.75 だった時は +97(0.75 + 96.25 = 97.00)。表示の数字はその回の整数の受け取りです。

## 2. 剣士のにらみ合い(原因を特定して修正)
### 再現
- 自然洞窟のラッシュで、8体目までを試験が倒し、8体目は 99km の足止めが始まるまで残しました。そのため、9体目の古代の魔王は足止めの中で出ます(止まった回と同じ条件)。
- 魔王の様子を1秒ごとに記録しました。

| 見た所 | 結果 |
|---|---|
| 間合い | 登場の位置の **9.0m** から2分以上動かない(寄る速さ 0) |
| ボスの動き | 「予告」と「待ち」の繰り返し。使った技は**特殊攻撃(床と天井の魔法)だけが 12回続けて** |
| 補助(剣士) | 「AncientDemon まで 7.4〜7.9m(届くのを待つ)」のまま攻撃しない(届く距離は 7m) |
| 高さ | 魔王はプレイヤーの 3.2m 上を飛ぶ。地上の前攻撃は高さが届かない(跳べば届く。作りどおり) |

### 原因(切り分け)
- **ボス側の位置調整(主な原因)**:
  - 再戦の最終強化では、特殊攻撃の間隔が 4.2秒です。一方、魔王の「床と天井の魔法」そのものは 4.3秒かかります。
  - 終わった時には次の特殊攻撃がもう使えるので、寄って爪を出す技(接近)と瞬間移動が一度も選ばれませんでした。
  - 第3弾のタイタン(特殊攻撃が身かがめの番を奪っていた)と同じ種類の問題です。
- **補助の接近**: 届く距離(7m)のすぐ外で待つボスには、何もしませんでした。
  - 前攻撃の踏み込みはボス戦の間、遠いほど大きく伸びます(最大 2.6倍)。人が前攻撃を連打すれば寄れる距離でした。
- **攻撃可能距離 / 回避**: 問題はありませんでした。寄った後は、補助は「高い所 → 跳んで攻撃」で当てています。

### 修正
- **ボス側**: 特殊攻撃を続けて使う時は、間に普通の技を必ず1回はさむ(`BalanceTuning.BossSpecialBreather`、`WildBossBase.SpecialReady`)。
  - 全部の大ボスに共通の所で直しました。間隔そのものと、技の強さは変えていません。
- **補助側**: 近接のキャラは、届く距離のすぐ外(14m まで)でボスが 1.5秒待ったら、前攻撃の踏み込みで寄る(`BalanceTuning.AssistApproachLunge`)。
  - 飛び道具のキャラは今までどおりです。
- HP を下げる、時間で戦いを飛ばす、といった直し方はしていません。
- 開発版は `-standoffFix base` で修正前に戻せます(比べるため)。

## 3. 協力ラッシュの完走報酬(参加者全員が1回ずつ)
- **以前**: ラッシュ全体のカード報酬は、最後のボスに止めを刺した人だけでした。受け取った人が DOWN 中だと、選択を出さずに捨てていました。
- **今**:
  - ラッシュを終えた時にランへ参加している人(生きている人も **DOWN 中の人も**)が、1回ずつ選びます。
  - HOST が全員へ知らせます(通信の版 7 → 8、`SyncRushReward`)。抜けた人・脱落した人には出しません。
  - DOWN 中の人も、この報酬だけは選択が開きます。ランが終わった後は開きません(今までどおり)。
  - **2回受け取らない**: 知らせには、そのランのラッシュの番号が付いています。同じ番号の2回目は無視します(受け取った数 / 無視した数を記録)。HOST も同じ番号では1回しか送りません。
  - **レベルアップの選択とは別**: ボスの報酬の順番待ちで扱います(レベルアップの未処理の数は変わりません)。
  - **MILE の人数分配は変えていません**。
  - **CPU サポート(ソロ)**: 今までどおりプレイヤー本人の1回だけです。CPU 用の選択の画面は出ません。
  - 通常の関門(10km ごと等)のボスの報酬は、今までどおり最後に倒した人です。

## 4. 協力のカード選択と15秒待機
### 決まり(確かめた結果)
- 選択中の人は、選択を続けられます。HOST は次のボスを最長15秒待ちます。
  - 待つ時間は、誰かが選び始めた時から数えます。
  - 15秒を過ぎると、次のボスを出します。
- **選択中の保護**: 狙われません。被弾(落下を除く)は HOST が取り消します(今までどおり)。
- **閉じた直後の保護(追加)**: 選択を閉じてから **1.0秒**は、落下以外の被弾を受けません(`NetMatch.ChoiceExitGrace`)。
  - 閉じた時に重なっていた攻撃を、避けられずに受けないためです。
  - 見た目の点滅は付けません。協力・対戦の両方で効きます。HOST の判定と、本人の端末の判定の両方に入れました。
- **置き去り**: 選択中はその場で止まるので、ほかの人より後ろになります。選び終わった後は追いついて、元の間合いへ戻ります。
  - その間に出たボスは、前の人が戦います。進行は止まりません。

### 見つけて直した不具合(前からあった)
- **DOWN 中の JOIN へ HOST の知らせが届かない**:
  - HOST は撃破を記録する時、相手の端末の番号を「0(= HOST 自身)」で上書きしていました。
  - 生きている JOIN は申告のたびに正しい番号へ戻ります。DOWN 中は何も送らないので、戻りませんでした。
  - そのため、DOWN 中の人へのボスの報酬・被弾の結果・復活などの知らせが、どこにも送られていませんでした。
  - 今は「分からない番号」で、分かっている番号を上書きしません(`NetMatch.GetOrCreate`)。

## 5. 解放のお知らせ(テスト H)
### 切り分け
- **解放そのものは成功していました**(ラスダン・竜人とも)。お知らせだけが、テストの中で確かめられていませんでした。
- お知らせを並べた/出した/消した時をログに残して、流れを追いました(`[Notice] queued / show / OK / cleared`)。
  1. 解放の確定と同時に、ラスダンのお知らせは順番待ちに入っていました。
  2. ホームでは、初めての脱出の後の案内(MILE の使い道)が先に開きます。案内の間、お知らせは待ちます(仕様)。
  3. 案内を閉じると、先に並んでいたお嬢様騎士の解放 → ラスダンのお知らせ → 竜人の順に1回ずつ出ました。
- **原因**: テストは案内が開いている間も4秒しか待たず、「出ない」と判断していました。テストの問題です。

### 確かめたこと(テスト H を作り直し、失敗 0件)
- 正式な解放の確定の後、ホームで**1回だけ**出る。
- 確認した後は、画面の読み直し・再起動の並べ直しで**もう一度出ない**。
- 確認する前に止めた(見ていない)場合: ランへ行って戻る / 再起動の並べ直しが2回重なる → **消えずに1回だけ出る**。ランの間は出ない。

### ついでに見つけて直した所(開発版のテスト用データだけ)
- テスト用データを「作り直す」時に、テスト用のバックアップを別の場所で消していました(専用の保存ファイルを使う時)。
- そのため、次の起動処理で、消したはずのテスト用データがバックアップから戻っていました。
- 今は実際の置き場所で消します。消すのはテスト用のフォルダ(`SaveBackups_test`)だけで、**通常のデータのバックアップには触れません**。

## 7. ラスダンのボスラッシュのカード選択(提案、今回は変更なし)
各マップのラッシュ(1体ずつ)の方法を、そのまま使わない理由と案です(第4弾の案に、今回の結果を足しました)。

- **そのまま使わない理由**
  - ラスダンのラッシュは最大3体が同時に出ます。前のボスが生きている間に次が出ることが多く、「次のボスが出ていない間」がほとんど来ません。
  - 「選択が終わるまで次を出さない」を入れると、待ち列に予約が溜まります。空いた時に一度に出る数が増えて、難しさが変わります。
- **案**
  1. 生きているボスが 0体で、予告もしていない「自然にできた間」にだけ、未処理の選択を順に出す。次を出すのを待たせるのは、その間に選んでいる時だけ(今の間隔 2秒の範囲)。
  2. 99km の足止め(全部倒した後、三姉妹の前)では、残りの選択を全部出す。
  3. 選択を閉じた時の指の扱い(離すまで無視)は、各マップと同じにする。
  4. 協力マルチは、各マップと同じ決まりにする。
     - 選択中の人だけ止まる
     - 最長15秒待つ
     - 閉じた直後の 1秒の保護(今回追加。ラスダンにも効いています)
     - 完走報酬は参加者全員が1回ずつ
  5. ラッシュ全体のボスの報酬は1回のまま。
- **確かめること**: ラスダンのラッシュで「自然にできた間」が何回あるか(育成の構成ごと)。少なければ、今と同じく最後にまとめて出ます。
- **にらみ合いの修正との関係**: 特殊攻撃の間に普通の技をはさむ修正は、ラスダンのボス(大ボスの共通の作り)にも効きます。
