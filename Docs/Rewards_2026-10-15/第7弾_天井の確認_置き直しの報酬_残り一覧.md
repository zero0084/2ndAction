# 報酬の見直し 第7弾(2026-10-16)— ムカデの天井の確認 / 置き直しの報酬の確認 / 残っている項目の一覧

第6弾の仕様(復帰の条件 120m・保護 1秒・ラスダンのカード選択)は、報告のとおりで確定です。今回、追加の機能はありません。

## 1. ムカデの天井の判定

### 調べて分かったこと
- 天井は、プレイヤーの前方の一定の範囲だけ作られます。作られていない位置の天井の高さを聞くと「無し」が返ります。
- 以前は、その「無し」を「天井が抜けている」と同じに扱っていました。
  - そのため、作られる範囲の外では、天井が続いていても落ちる作りでした。
  - 必殺技を選ぶ前の確かめにも、同じ扱いが入っていました。
- 実際に測ると、天井はムカデが動く範囲(プレイヤーの 10m 後ろ〜16m 前)より十分先まで作られていました。
  - 少なくとも 120m 先まで作られていました。3倍速では 269m 先までです。
  - そのため、今の試験の中で誤判定で落ちたことはありませんでした。
- ただし、作りとしては誤判定が起こりうるので、確認の方法を直しました(下)。

### 直したこと(`Bosses/HazardBossBase.cs`、`CaveStage.cs`)
- 天井の状態を分けて判定するようにしました。

  | 状態 | 意味 | ムカデ |
  |---|---|---|
  | 普通 | ぶら下がれる高さ(地面から 4.2〜9.5m) | 張り付いたまま這う |
  | **まだ作られていない** | 天井の生成の範囲の外 | **落とさない**(今の高さのまま、記録だけ残す)。技を選ぶ理由にもしない |
  | 抜けている | 天井が途切れている(mode 4) | 落ちて、必殺技をやめ、大きな隙 |
  | 高い空洞 | 天井まで 9.5m より高い(体が届かない) | 同上 |
  | 低い区間 | 天井まで 4.2m 未満(体が入らない) | 同上 |

- 実際の天井の切れ目で落ちる動きは、そのまま残しています。
- 「高い空洞」と「低い区間」で落ちるのは、APK 273 からの決まりのままです(天井はありますが、ぶら下がれない高さです)。
  - 変えたい場合は、別にご相談ください(今回は機能を広げていません)。

### 確認(`QaSweep -qaCeilingAudit`、自然洞窟、黒剣士、無敵)
**A: 走りながら、ムカデの動く範囲の天井の状態を毎フレーム数えた**

| 速さ | 走った距離 | 「まだ作られていない」の数 | 天井が作られていた先 |
|---|---|---|---|
| 1倍 | 394m | **0** | 120m 以上 |
| 2倍 | 1,075m | **0** | 129m 以上 |
| 3倍 | 2,086m | **0** | 269m 以上 |

- 最後の版でも同じく 0 でした(1倍 403m / 2倍 1,082m / 3倍 2,316m)。前の版(x23)の2回も 0 です。

**B: 普段の自然洞窟で、ムカデの必殺技を何度も強制した(崩しは止める)**

| 回 | 結果 |
|---|---|
| 1回目の試験(6回) | 最後まで 0 / 本物の地形で切れた 5(低い 1・高い空洞 4)/ 始まらなかった 1 |
| 2回目の試験(8回) | 最後まで 5 / 本物の地形で切れた 3(低い 1・高い空洞 2) |
| 3回目の試験(6回) | 最後まで 3 / 本物の地形で切れた 3(高い空洞 2・低い 1) |
| 4回目の試験(6回、最後の版) | 最後まで 3 / 本物の地形で切れた 2(低い 2)/ 技を選ばなかった 1(前の確かめが高い空洞を見た) |

- **切れた時は毎回、大きな隙が出ました**(隙が無かった回は 0)。
- 「まだ作られていない」で落ちた回は **0**、落とさずに待った回も 0 です。

**C: 天井が本当に抜けた区間を交互に置いた洞窟で(試験の中だけ区間の並びを差し替え)**

| 試験 | 結果 |
|---|---|
| 1回目(4回) | **抜けた所で落ちた 2(どちらも隙あり)**/ 技を選ばなかった 2 |
| 2回目(4回) | **抜けた所で落ちた 2(どちらも隙あり)**/ 技を選ばなかった 2(どちらも、前の確かめが抜けた所の手前の高い天井を見た) |

- 技を選ばなかった回は、始める前の確かめ(張り付く位置の前 12m ほど)が本物の切れ目を見たためです。天井の無い所へ這い出さないので、正しい動きです。
- 2回目の試験から、選ばなかった理由も記録しています。「まだ作られていない」が理由だった回は 0 です。
- 抜けた区間の境目は、天井の高さが 40m へ向かってつながるため、手前では「高い空洞」として見えます。どちらも本物の切れ目です。

## 2. 協力: 位置の置き直しで報酬が増えないか

置き直す直前の値と、置いた 2フレーム後の値を比べました(開発版のログ `[NET][WARPAUDIT]`)。比べた値は次の4つです。
- 距離
- EXP
- 距離の MILE の元になる距離
- 記録の控えの走った距離(累計距離の元)

| 場合 | 移動 | 距離 | EXP | 距離の MILE の元 | 走った距離(累計) |
|---|---|---|---|---|---|
| 遠くの仲間へ戻す(JOIN、選択 30秒、間合い +800m) | **794m** | +2.26m | +2.3 | +0.023 | +2.26m |
| 選択の終わりに穴の向こうへ(選択 3秒) | **4.0m** | +2.06m | +2.1 | +0.021 | +2.06m |
| 同上(別の穴) | **13.0m** | +2.08m | +2.5 | +0.021 | +2.08m |

- 増えた分は、置いた後の 2フレームに走った分だけです(約 2m)。移動した分は入っていません。
- 置き直しの時は、毎回「距離の除外」に移動の分が足されていました(794m / 4.0m / 13.0m)。
- HOST が戻される場合も、同じ処理を通ります。第6弾の試験で、除外 +471m を確認済みです(今回は数値の比較をしていません)。
- 試験の側の修正もしました。
  - 穴の確認で、試験自身がプレイヤーを穴へ動かした分(15〜57m)が、前は報酬に入っていました。そのため、最初の測定では「+38m」と出ました。
  - 試験の移動も除外するように直してから、測り直しました。ゲームの側の不具合ではありません。
