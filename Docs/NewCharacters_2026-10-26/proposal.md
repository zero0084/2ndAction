# 新キャラ2人の技・性能の案(2026-10-27、第2稿: エステルとの相談を反映)

決まっていること(マスター)を守る前提: ルカは四足の猫のまま(人型・衣装・武器なし)/ 宇宙人は飛べるとは決めない /
新しい操作ボタンは増やさない(今と同じ 前・後・上・下 の4方向+ジャンプ+オート)/ 全能力最強・常時無敵にしない /
既存の12人は調整しない。数値はたたき台で、試作と検証(当たり判定の監査・ボス戦・オート・マルチ)で決める。

既存の12人の幅(参考): HP 20〜50(最大 30〜60)、攻撃 10〜40、ジャンプ 1〜2回、ジャンプ力 0.85〜1.0、地上の機動 0.93〜1.15。

## ルカ(猫)— 役割: AGILE / POUNCE(身軽・飛びつき)

「小さくて速い、近くで手数を出す、跳びつきで高い所にも届く」。格闘家(最短射程の連打)と忍者(位置を変える)の間。
ただし瞬身のような無敵の技は持たない。

| 項目 | 案 |
|---|---|
| HP / 最大 | 30 / 40(小柄で打たれ弱め。忍者と同じ) |
| 攻撃 | 20(標準) |
| ジャンプ | 2回、ジャンプ力 1.05(身軽)。2回目は少し高い |
| 地上の機動 | 1.08(忍者と同じ) |
| 走り | 四足のギャロップ(前足と後ろ足が交互に伸び縮みする猫の走り)。耳・しっぽで勢いを出す |
| 前(通常攻撃) | **猫パンチ3段**: 右パンチ → 左パンチ → 3段目「飛びかかり」(前へ短く跳んで両前足で押さえ込む)。1・2段は格闘家並みに短く速い、3段目は前進して届かせる |
| 後 | **後ろ跳び+しっぽ払い**: ぴょんと後ろへ跳ねて、背中側の敵をしっぽで払う(後ろの敵の対処。無敵は付けない) |
| 上 | **飛びつき**: 斜め上へ跳び上がって引っかく。空中の敵・飛ぶボスに届かせる技(空中では1回のジャンプにつき1回) |
| 下(空中) | **飛びかかり急降下**: 前脚を突き出して獲物に飛びかかるように落ち、着地で衝撃(エステル案。蹴りより猫らしい) |
| 下(地上) | **低い引っかき**: 姿勢を低くして足元の小さい敵を払う |
| 空中の前 | 空中で前足を振り回す引っかき(空中で出せる、出した後は少し落ちる) |
| 固有特性 | **ねこの身のこなし**: 被弾の硬直が短い(すぐ体勢を戻す)/ 高い所からの着地で硬直しない。強さではなく「立て直しの速さ」 |
| ULTIMATE(#100) | 案「ねこまっしぐら」: 画面を駆け回る連続の飛びかかり(既存の ULTIMATE と同じ枠・長さ) |

### 低い体の当たり判定(マスターのご心配の点)
- 今の12人は、体の当たり判定がみな同じ大きさ(幅1×高さ1の箱。竜人だけ大きくなる)。
- **ルカも同じ大きさの箱のまま**にして、絵の方を「頭と背中が箱の上の方まで来る」大きさで描く(四足でも耳の先まで入れると、箱とほぼ同じ高さになる)。
  → 「背が低いから攻撃が全部頭の上を通る」ことは起きない(判定は他の11人と同じ)。
- 見た目と判定がずれて見える攻撃(高い位置を横に払う攻撃など)は、試作の時に代表のボスで「ルカと黒剣士で、同じ条件で当たる攻撃の数」を比べて確かめる(数が大きくずれたら箱の高さを少し下げる/絵を調整する)。
- **攻撃が届かない問題**: パンチの判定の高さは足元から体の中ほどまで。大きいボス(当たり判定が高い)には、3段目の飛びかかり・上の飛びつき・空中攻撃で届く。既存の攻撃判定の監査(-qaHitAudit、黒剣士の 3.6m を基準)で、格闘家と同じくらいの届き方になるよう調整する。

## ペンタトゥットゥルー星人 — 役割: BOUNCE / STRETCH(弾む・伸びる)

「ぽよんと弾む体と、ぐーんと伸びる手足」。遠くまで届くが、出だしが遅い(伸ばす溜めがある)。踏んで弾むと高く跳べる。
飛行はしない(普通のジャンプと落下。雲の姿でも浮かない)。

| 項目 | 案 |
|---|---|
| HP / 最大 | 40 / 50(体がふわふわで少し丈夫) |
| 攻撃 | 20(標準) |
| ジャンプ | 2回、ジャンプ力 1.0。着地の時に体がぽよんと潰れて戻る |
| 地上の機動 | 0.95(細い足でちょこちょこ。少し遅い) |
| 走り | 細い足が速く回る+体が上下に弾む(触角も揺れる) |
| 前(通常攻撃) | **のびーるパンチ**: 腕がぐーんと伸びる(届く距離は弓・槍の間くらい、溜めが少しある)→ 2段目 反対の腕 → 3段目 両腕で「ぽかぽか」(近くの連打) |
| 後 | **もくもくバンプ**: 体をぷくっと膨らませて背中側の敵を弾き飛ばす(ノックバック強め、ダメージ弱め) |
| 上 | **のびのびアッパー**: 触角がぴんと立つ予備動作 → 両腕が真上へ伸びる。上へ長く届く対空(エステル案: 触角は攻撃に使わず合図に) |
| 下(空中) | **ぽよんスタンプ**: 体を丸めて落ち、着地の瞬間に体が横へ広がって周りを弾き、すぐ元の形へ戻る。着地の後に小さく跳ね返る |
| 下(地上) | **のびーるキック**: 足を伸ばして低く遠くを払う |
| 空中の前 | 空中で腕を伸ばすパンチ(空中でも遠くへ届く) |
| 固有特性 | **ぽよんボディ**: 敵・ボスの上に落ちると、踏んで高く弾む(踏まれた相手に小さなダメージ)。1回のジャンプにつき1回 |
| ULTIMATE(#100) | 案「ペンタトゥットゥルー・ビッグバン」: 体が大きく膨らんで、伸びた腕で画面中をぽかぽか |

### 横に広い体の当たり判定
- 見た目は横長。**判定の箱は少し横に広く、少し低く**(案: 幅1.2 × 高さ0.9。面積はほぼ同じ)。
  横に広い分、前後からの攻撃にはむしろ当たりやすい(見た目どおり)。
- 伸びるパンチは届く距離が長い代わりに、出だしの溜めと戻りの隙を大きくする(遠くから安全に連打するだけのキャラにしない)。

## 2人とも

- 新しい操作ボタンは無し。オート(自動操作補助)にも2人の技の間合いを教える(今の12人と同じ作り)。
- 被弾・倒れる絵: **ルカは飼い猫のモデルなので、倒れる演出を「目を回してころん」と可愛く**する(痛そうな表現にしない)。宇宙人も「しぼんで目を回す」。
- 解放: 三姉妹を倒してエンディングに到達したら、2人同時に解放(正規のクリア記録を使う)。ホームで1回だけ加入を知らせる。
- 既存のキャラの ID・保存データの順番は動かさない(新しい2人は後ろに足す)。

# 解放の条件(調べた結果)

**今のゲームには「三姉妹を倒してエンディングに到達した」という保存された記録が無い。**
- 三姉妹の撃破とエンドロールは、その場だけの状態(保存しない)
- 保存される物は「三姉妹に出会った」(`ReaperMet_*`、倒したではない)/ 「ラスダンが開いた」(`FinalDungeonUnlocked`)/
  クリアの後の確定(YES = 続きへ、NO = 終了。どちらもランの成功として `BestDistance_v2_last_corridor` に距離が残る)
- マルチのラスダンは三姉妹の終盤を通らない(昔の追いかけっこのまま)ので、「ラスダンの記録が 10万m 以上」だけではクリアと言い切れない

**案**: 新しい保存の項目「クリアした」(`GameClearedV1`、引き継ぎ・バックアップ・初期化の対象に登録)を作り、
ソロで三姉妹を倒してエンディング → ONE MORE MILE? に着いた時(YES でも NO でも)に書く。これを解放の条件にする。
開発用の確認はテスト用データで(通常のデータにクリアの記録を付けない)。

**マスターに決めていただきたいこと(既存のデータ)**:
- (A・おすすめ)ご指示どおり推測しない: 正規の「クリアした」記録は今までのどのデータにも無いので、**この版から先のクリア**で解放(すでにクリア済みの方も、もう一度エンディングまで行くと加入)
- (B)既存のデータは「ラスダンの確定した記録が 10万m 以上」をクリアとみなす(ソロでは三姉妹とエンディングを通らないと 10万m を確定できない作り。ただしマルチや 2026-09-30 より前の版の記録が混ざる可能性があり、厳密には推測)

# 変更の範囲(「12人固定」の調査の結果)

キャラは保存・通信・サーバーのどこでも**名前(ID)で持っている**(順番の番号で持っている所は無い)。新しい2人を後ろに足しても、既存のキャラ・保存はずれない。

| 場所 | 今 | やること |
|---|---|---|
| キャラの定義(`CharacterDatabaseBuilder`) | 12人(並び 0〜11) | 2人を 12・13 で足す(既存の番号は変えない) |
| 技の種類(`CharacterKit` の列挙) | 保存に番号で入っている | **末尾に**足す(Cat, Cloud) |
| 解放(`UnlockRules`) | 距離の条件の9人+最初の黒剣士+隠しの竜人。未解放は全部の一覧から隠れる | 「クリアした」で解放する道を足す(隠し方は竜人と同じ方式) |
| キャラ選択の画面 | カードの枠がシーンに焼き込み(12) | シーンを作り直す(または足りない枠を実行時に作る) |
| ランキングの検査(端末とサーバーの両方) | 12人の一覧。新しい ID は「キャラが違う」で拒否され、送り直さない | **両方に2人を足す。サーバー(Cloud Code)を先に配置してからアプリを出す**(development も production も) |
| 保存の鍵の一覧(`SaveKeys.KnownCharacterIds`) | 12人 | 2人を足す(キャラカードの枠の引き継ぎ・バックアップ用) |
| 引き継ぎ | 新しい版で作った引き継ぎのファイルは古い版では読めない(今までどおりの仕様) | そのまま |
| マルチ | キャラは名前で同期 | 通信の版(プロトコル)を上げて、古い版と混ざらないように |
| CPU サポート / 効果音 / 攻撃の光 / ULTIMATE の演出 | 12人の表。無いキャラは既定の物になる | 2人の分を足す(ULTIMATE の技の名前の文字も事前に用意) |
| オート(自動操作補助) | 技の種類ごとに間合いを教えている | 2人の技を教える |
| 試験 | 「12人」を前提にした確認がいくつか | 14人でも通るように直す。試験の構成(BuildLab)に2人を足す |
| 訳 | キャラ名・説明は30言語 | 新しい文をエステルに訳してもらう |

# エステルとの相談(2026-10-27)と基準絵

- 画風: ルカは「写真の子だと分かる」ことを最優先にした、写実寄りの厚塗り(頭や目を大きくしない)。顔・白い足先・短く巻いたしっぽが最重要。
  宇宙人はエステルの前の描き起こしのシンプルな線と色を保つ(ほかの12人から少し浮くこと自体が魅力。ただし輪郭の鮮明さ・接地の影・効果の明るさは揃える)。飛ばない、地面を走る。
- 基準絵: `base_v1/luka_base_v1.png`、`base_v1/penta_base_v1.png`(エステル作。切り抜き `*_cut.png`)
- ゲームの画面での大きさ(`base_v1/ingame_size_AB.jpg`): 実際の画面(100km/h でカメラが引いた時)で人のキャラは約60px(画面の高さの約5.5%)。
  - 案A: ルカ = 人の 0.6倍の高さ、宇宙人 = 0.85倍(エステルの最初の目安の比率)
  - 案B: ルカ = 0.75倍、宇宙人 = 1.0倍 → **アイリーンのおすすめ**(小さく表示された時もルカの縞・白い足・しっぽが読める)
  - 体の当たり判定は、ルカは他の11人と同じ箱、宇宙人は少し横に広く低い箱の案(上の表)。絵の大きさを決めた後に、代表のボスで被弾の数を比べて確かめる
